# 0.6.0 — Arcade: build games on the canvas (2026-07-05)

Yappy can build and play games now — the Flash-style feature, done the way Flash
actually felt: draw your sprites, give them behaviors from a panel, press Play.
This release also carries live the work built over 0.5.31–0.5.33 that wasn't yet
deployed (installable offline PWA, 33 design templates, Magic Resize, version
history).

## Highlights
- **Visual Game Builder** — no code. Select a sprite, name it, add WHEN→DO
  rules from big pickers. Playable on tablets with an on-screen gamepad.
- **Two ways to build**: the visual builder (headline) or a JavaScript game
  script (advanced). Both compile to the same runtime and both export.
- **Play in the editor and in exported HTML** — a game document exports to a
  single self-contained file with a ▶ Play Game button.

## Game Builder (no code)
- **Menu → Game Builder** (or right-click a sprite → *Edit Behaviors*) opens the
  Behaviors panel. New? Tap **Load example: Pong** or **Catch the Star** and
  press Play.
- **WHEN → DO rules**: triggers — *on start, every moment, key pressed/held, when
  tapped, when it hits a sprite or a wall, when it leaves the screen*; actions —
  *move, glide, bounce, rotate, color, grow/shrink, show/hide, set text, jump to,
  spawn, destroy, change score, go to state, play effect, go to page, win, game
  over*.
- **Scene tab** for whole-game rules (start score, win/lose). **Code tab** shows
  the read-only `game.*` script your blocks generate — a bridge to real coding.
- Blocks are the source of truth (`element.behaviors` + `sceneBehaviors`,
  persisted with the document); they compile to the same `game.*` script the
  runtime and exported player run — so visual and hand-written games behave
  identically, with no second engine.

## Game runtime (advanced / script)
- **Menu → Game Script (advanced)** opens the code editor with starter templates
  (Pong, Catch the Stars, Blank). The `game.*` API: `onTick`, `onKey`/`key`,
  `pointer`/`onPointerDown`, `spawn`/`spawnText`/`find`, `hit`, `hud`, `score`,
  `goToState`, `playAnim`, `goToPage`, `end`, plus `Sprite` handles
  (move/color/text/rotate/destroy…).
- **Clean play stage**: Play hides all editor chrome and the page frame; the Stop
  pill sits top-center; after `game.end()` a Play again / Exit panel appears.
  Stop restores the document exactly (nothing a game does is saved).
- **Input**: arrows/WASD + Space/Z (A) + X/Shift (B), plus an on-screen touch
  D-pad and A/B buttons (auto on touch devices).
- Code starter templates are now idempotent (find-or-spawn) so they don't
  duplicate sprites you've already drawn.

## Also live in this deploy (from 0.5.31–0.5.33)
- Installable **PWA** with full offline cold-load; **Magic Resize**; **version
  history** with snapshots; a **33-template** design gallery with search;
  template/stock/crop/export refinements; Google Fonts live-preview picker.

## API
`Y.toggleGameBuilder`, `Y.getBehaviors/setBehaviors`, `Y.getSceneBehaviors/
setSceneBehaviors`, `Y.nameSprite`, `Y.compileGame`, `Y.playBehaviorGame`,
`Y.setGameScript/getGameScript/startGame/stopGame/isGameRunning`.

## Internal / tests
- New modules under `frontend/src/game/` (behavior types, block→script compiler,
  examples) and `components/behaviors-panel`. 20+ e2e specs across the arcade and
  builder suites; the embedded HTML player bundle is regenerated so exported
  games play.

## Breaking changes / migration
- None. Documents without games are unaffected; the new fields
  (`element.behaviors`, `SlideDocument.sceneBehaviors`, `gameScript`) are optional.
