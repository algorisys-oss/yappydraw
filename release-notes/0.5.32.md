# 0.5.32 — Magic Resize, offline PWA, version history & AI studio round 2 (2026-07-05)

The "as good as Canva" roadmap implemented: the one headline feature Canva
charges for (Magic Resize), the structural wins Canva can't offer (installable
fully-offline PWA), and the next tier of AI assists — all local-first, BYO-key.

## Highlights
- **Magic Resize** — design once, repurpose to any format in one click.
- **Installable PWA** — after the first visit, Yappy cold-loads and works
  completely offline (verified with the network disabled against the
  production build).
- **Version history** with automatic snapshots + a thumbnail recents grid.
- **Magic Edit / Magic Expand / AI Design** — inpainting, outpainting, and
  brief-to-design generation.

## Features
- **Magic Resize** (Menu → Magic Resize…, `Y.magicResize('instagram-story')`
  or `{width, height}`): page backgrounds stretch to fill the new size; every
  other element scales uniformly — no distortion, font sizes included — and
  keeps its relative position. All pages resize together; one undo step.
- **PWA / offline**: service worker precaches the app shell (152 entries);
  manifest + install icons included; Google Fonts runtime-cached so display
  fonts keep working offline after first use. The tap-version hard refresh
  still forces a clean update when needed.
- **Version History** (Menu → Version History…): automatic snapshots every
  ~3 minutes while editing (newest 15 kept in IndexedDB), manual
  "Snapshot now", restore or delete per version.
  `Y.snapshotVersion(label)` / `Y.listVersions()` / `Y.restoreVersion(id)`.
- **Recents grid**: Open Drawing shows thumbnail cards sorted by most recently
  saved; thumbnails are captured client-side at save time (no backend change).
- **Magic Edit (AI)**: right-click an image → Magic Edit (AI)… → describe the
  change; only that region is repainted (OpenAI image edits).
  `Y.magicEditImage('remove the car')`.
- **Magic Expand (AI)**: outpaint beyond the image borders — all sides +25%,
  wider (+50% L/R), taller (+50% T/B), or custom guidance. The padded canvas
  doubles as the mask, and the element grows by the same margins so the
  subject stays put. `Y.expandImage({left: 0.5, right: 0.5})`.
- **AI Design** (Menu → AI Design…): a text brief becomes a ready-to-edit
  design document — headline, subhead, bullets, CTA pill, and a harmonious
  palette laid out proportionally for the chosen size (default 1080×1080).
  Deterministic layout + LLM copy, so it works with any configured provider.
  `Y.generateDesign('sale poster for a coffee shop', 'instagram-post')`.

## Fixes
- **Google Fonts picker polish (user-reported):** the Done button keeps proper
  contrast on hover in light and dark themes, and the font list is now
  keyboard-navigable — ↑/↓ from the search box moves the highlight, Enter
  applies the focused font (the panel stays open for more tries), and the
  highlighted row scrolls into view.

## Internal / tests / docs
- New e2e suite `tests/canva-next.spec.ts` (6 specs): Magic Resize scaling
  math + preset ids + non-paged guard, version history round-trip, Magic
  Edit/Expand with mocked OpenAI (geometry + mask assertions), AI Design from
  a mocked LLM brief. Full regression pass: 39 specs across 7 suites.
- PWA verified end-to-end with a production-build script: SW registration,
  manifest validity, precache population, and an offline cold load that boots
  the app and creates a design.
- Bullet/numbered lists were already first-class in the rich-text toolbar —
  now documented (help doc + search keywords) rather than reimplemented.
- New dependency: `vite-plugin-pwa` (dev) — standard Workbox wrapper for the
  service worker + manifest.

## Breaking changes / migration
- None. The service worker activates on second visit; use the tap-version
  hard refresh if a stale cache is ever suspected.
