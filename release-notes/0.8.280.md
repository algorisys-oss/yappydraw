# 0.8.280 — PDF/X-4 that checks itself, and a fix for misplaced overlays (2026-10-09)

## Highlights
- **PDF/X-4 files check themselves before they're saved.** Yappy now refuses to save a PDF/X file that breaks a rule it is responsible for, and says what was wrong, instead of handing you one a print shop would reject.
- **Fixed:** rulers and tool overlays could sit offset from the canvas after 0.8.279.

## Features
- PDF/X-4: transparency (semi-transparent objects, images with alpha) now blends in CMYK — every page gets a CMYK transparency group; jsPDF's `/OpenAction` is removed.
- `verifyPdfX4` reads every PDF/X file back: version, output intent + embedded CMYK profile, XMP identification, matching Info/XMP dates, Trapped, title, Trim/Bleed boxes, page groups, no RGB anywhere (dictionaries or page content), every font embedded. A failing file throws `PdfXError` (API) / shows the problems (dialog) and is not saved.

## Fixes
- **#433** PDF/X-4 files with transparency had no CMYK page group, and nothing checked the output — listed as "known gaps" in 0.8.279, found again by comparing with VectorCraft.
- **#434** The print-preview overlay canvas (0.8.279) came before the drawing canvas in the page, so anything looking up "the canvas" — rulers and ~29 tool overlays' positioning, the screen-recording fallback — got the hidden overlay and measured from the window corner. Moved after the drawing canvas.

## Internal / tests / docs
- `tests/command-model.spec.ts`: model-based undo test with fast-check — random command sequences, consistency after every step, undo-all/redo-all round trip; probes the 27 document-editing commands so sequences actually exercise undo (327 steps over 300 sequences, clean). Self-test with a sabotaged undo. `MODEL_RUNS` / `MODEL_SEED` to search deeper or replay.
- Command sweep: junk parameters on all three document states; skip list shared (`tests/helpers/command-skip.ts`); a "needs a selection" assertion that passed vacuously on a non-existent id now checks the refusal reason.
- `pdf-x.test.ts` 7 → 15 tests; spec for PDF/X with transparency.
- `docs/vectorcraft-review-2.md` (what VectorCraft added up to v0.7.0, print head-to-head, ranked picks — #1 and #2 done here). `handoff.md` for the next session (internal).
- New dev dependency: `fast-check`.

## Breaking changes / migration
- `Yappy.exportPDF({ pdfx: true })` now rejects (with `PdfXError`, listing problems) when the file would not conform, instead of resolving with it.
