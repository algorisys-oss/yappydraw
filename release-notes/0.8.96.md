# 0.8.96 — Dimensions in exports (opt-in) (2026-07-14)

## Highlights
- Dimension annotations can now be **baked into exported files** — PNG, JPG, SVG, and PDF — when
  you turn it on.

## Features
- **Include Dimensions in Exports (opt-in).** Settings → *Include Dimensions in Exports* bakes your
  dimension annotations into exports: raster formats (PNG / JPG / PDF) draw them onto the image, and
  **SVG** keeps them as real vector lines, arrowheads, arcs, and text. Off by default so measurement
  chrome never leaks into an export unintentionally. Scripting:
  `Yappy.setExportIncludeDimensions(true)`.

## Fixes
- None.

## Internal / tests / docs
- New `utils/dimension-svg.ts` (`appendDimensionSvg`) mirrors the canvas dimension renderer for vector
  output; both share the pure `dimensionGeometry`. A `paintDimensions` helper replays `renderDimensions`
  onto the world-space export ctx for all raster paths. New Playwright spec `export-dimensions`.
- `globalSettings.exportIncludeDimensions` (localStorage-backed) + Settings toggle + API
  `set/getExportIncludeDimensions`.

## Breaking changes / migration
- None.
