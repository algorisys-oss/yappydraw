# 0.8.25 — Exported HTML now plays stick-figure animations (2026-07-08)

## Highlights
- **Export → HTML** now produces a self-contained page that **plays your
  animation** — figures walk, wave, run their sequences and follow their paths
  when the file is opened in any browser (no Yappy needed).

## Features
- Animated stick figures (and their sequences, walk-along-a-path and blending) are
  fully animated in the exported HTML player, not a static frame.
- **API** — `Yappy.exportHtml(name?)` exports the current scene as a self-contained
  `.html` file.

## Fixes
- The bundled offline **player** was rebuilt so it includes the stick-figure
  animation runtime (it previously shipped a pre-animation build, so exported HTML
  showed figures static/missing).

## Internal / tests / docs
- Regenerated `assets/player-assets.ts` via `scripts/embed-player.js`. The player
  (`player-app.tsx`) already mounts the same `Canvas` + shape registry as the app, so
  the `stickRig` renderer and the force-ticker animate exports with no player-specific
  code — only the prebuilt bundle needed refreshing. Help doc and learnings updated
  (note: rebuild the player on release when the render/animation path changes).

## Breaking changes / migration
- None.
