# 0.8.283 — Text on Path keeps the shape selected; its Text settings edit the text (2026-10-11)

## Highlights
- **Switching Text on Path on no longer "resets" the Properties panel.** The shape stays selected, with its own stroke and fill still showing, and its **Text** group now shows and edits the text that was put on its outline: Label, Font, Size, Text Color, Position, Start Position and the rest.
- **Selecting the shape later shows its text too**, with Text on Path still on. You only need to click the letters when you want to move, stroke or delete the text on its own.
- **Switching Text on Path off brings the text back** as the shape's plain label, keeping its font, size and colour.

## Features
- `Yappy.textPathObjectOf(shapeId)`: the Type-on-Path object carrying a shape's outline text, or `undefined`. The object records its shape as `textPathHostId`.
- The quick toolbar's Curved Text toggle and font controls on a shape read and write the same text object.

## Fixes
- **#440** Turning on Text on Path in the Properties panel moved the selection to the new, unpainted text object, so the panel showed a transparent stroke and fill and a different set of rows; selecting the shape again showed Label empty and Text on Path off. Nothing linked the text back to its shape. Now the toggle keeps the shape selected, the shape's Text controls route to the text object, and off welds the text back and removes the object. The Type on Path tool (Alt+T) and `attachTextToPath` still select the new text object.

## Internal / tests / docs
- `TEXT_PROPERTY_KEYS` (config/properties.ts) drives the routing in the panel (`getPropertyValue`, `handleChange`, `dependsOn`, font hover-preview) and the quick toolbar.
- Tests: `artboard-variations.test.ts` (+5: selection kept, link, idempotent on, weld back from either end, Pen paths unchanged) and `tests/text-on-outline.spec.ts` (+2, through the real checkbox).
- Help: "Text on a shape is its own object" now describes the shape's Text settings and the off switch. Bug log #440, learnings.

## Breaking changes / migration
- None. Text objects made before 0.8.283 have no `textPathHostId`; select them by their letters as before, or switch Text on Path off and on again on the shape to relink.
