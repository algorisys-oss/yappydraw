# 0.8.172 — Switch shapes without leaving the Node tool (2026-08-03)

## Highlights
- **Clicking another shape while node-editing now selects it.** It used to do nothing at all, so
  moving to the next path meant exiting the Node tool, selecting, and re-entering — three steps
  for what should be one.

## Features
- **Click a shape to switch what you're editing**, staying in the Node tool. **Shift-click** adds
  a second path, so several can be node-edited at once.
- **Clicking empty space lets go in two stages** — the first click drops the selected anchors, a
  second drops the path itself. Missing an anchor by a few pixels no longer costs you your place.
- **With nothing loaded, a rubber band picks shapes** instead of dragging a box over zero anchors.
  Once a path is being edited the band goes back to selecting its anchors.

## Fixes
- **Every branch of the Node tool's pointer handler swallowed the click.** `node-tool-overlay`
  installs a capture-phase `pointerdown` that `stopPropagation()`s so the canvas can't steal
  anchor drags — but it had no "was a shape clicked?" case, so the canvas never got a look in and
  clicking a different shape started a rubber band over nothing.

## Internal / tests / docs
- Ported from Inkscape's `NodeTool::select_point` and `select_area`
  (`src/ui/tools/node-tool.cpp`): an item under the cursor is selected, Shift toggles it into the
  set, empty space deselects in two stages, and the rubber band picks items when there is nothing
  to node-edit (`_multipath->empty()`). Illustrator's Direct Selection behaves the same way on the
  first point.
- `elementAt()` mirrors the canvas's own narrow-phase — reverse z-order, skipping locked elements
  and hidden/locked layers — so the Node tool cannot reach anything the Selection tool wouldn't.
- New `tests/node-tool-switch-shape.spec.ts` (4 tests): switch by click, Shift-add, the two-stage
  deselect, and the shape-picking rubber band. Verified to fail against the bug — stubbing the
  element hit-test turns the two switching tests red.
- Known: `node-tool-switch-shape.spec.ts` and `overlay-alignment.spec.ts` both boot the app
  repeatedly and will time out on `waitForFunction(window.Yappy)` if run together at the default
  2 workers against one dev server — the contention the Playwright config already warns about. Run
  them with `--workers=1`; both pass individually and serially.

## Breaking changes / migration
- None.
