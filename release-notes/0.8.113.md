# 0.8.113 — Comics that think and whisper

**Date:** 2026-07-19

## Highlights

- Thought clouds and whispered asides in comic panels — add a cue in brackets after
  the speaker's name.

## Features

- **Balloon types.** A cue after the name picks the balloon:

  ```
  Ann: Did we ship it?
  Ben (thinks): I have no idea
  Ann (whispers): me neither
  ```

  - `(thinks)` / `(thinking)` / `(thought)` → a **thought cloud**, complete with the
    classic trailing dots (and no tail, which a cloud shouldn't have).
  - `(whispers)` / `(whispering)` → a **dashed** balloon with italic text, the comic
    convention for an aside.
  - Anything else is a normal speech balloon, and an **unrecognised bracket stays part
    of the name** — `Ann (CEO):` still draws a speaker called "Ann (CEO)".

  Works in Comic Studio and via the API. A character who speaks and then thinks is
  still one person, so panel breaks and character placement behave as before.

  This completes the balloon vocabulary from Comic Chat §5.1 apart from the jagged
  shout balloon — left out as it was in Comic Chat itself, since ALL CAPS already
  poses the speaker with a megaphone.

## Fixes

- **`emotions` was missing from the API's option type.** It worked at runtime but a
  TypeScript caller passing `emotions` to `createComicPanel`/`createComicStrip` would
  have seen a type error. The option is now declared and documented, along with the
  new balloon cues.

## Internal / test changes

- `Utterance` and `BubblePlacement` carry a `kind`, so layout is untouched — only the
  element type and styling differ per balloon.
- 6 new unit tests (cue parsing and stripping, unrecognised brackets, speaker identity
  across cues, and the kind reaching the balloon placement) — 50 in the comic suite,
  162 overall.
- Verified in the running app: the three balloons render as solid, cloud and dashed.

## Breaking changes / migration

None. Scripts without a bracketed cue behave exactly as before.
