# 0.8.210 — the undo-depth control now keeps the range it advertises (2026-08-21)

## Highlights
- **Undo History Depth** enforces its stated 10–500 range on every route in, and is finally
  documented — it was a real, working setting that the help never mentioned.

## Fixes
- **#310 — the control did not honour its own bounds.** The number input in *Settings → Pen &
  Input* declares `min="10" max="500"`, but the browser applies that to the **spinner arrows
  only**; a typed value bypasses it. The change handler clamped with `Math.max(1, …)` and had no
  ceiling, so `3` was accepted and stored while the UI said the minimum was ten, and
  `Yappy.setHistoryDepth(50000)` was accepted too.
  Three routes set this value — the dialog, the scripting API, and a hand-edited `historyDepth`
  in localStorage — each with its own idea of the valid range. They now share
  `HISTORY_DEPTH_MIN`/`MAX`/`DEFAULT` and `clampHistoryDepth()`.
  The clamp is applied at the **top of `updateGlobalSettings`**, not at the persistence step:
  that function writes the store first and persists second, so clamping on the way to disk
  would have left the live value and the stored one disagreeing until the next reload.
- The input snaps back to the stored value on change, so a typed out-of-range number cannot sit
  in the box looking accepted.

## Features / docs
- **Help now covers the setting.** `workspace.md` documented the History panel and `Alt+H` in
  detail but never mentioned the depth was adjustable, so anyone hitting the 50-step ceiling had
  no way to find it. New *How many steps are kept* section: the range, that each step is a full
  document snapshot (so the ceiling is memory), that changes take effect immediately rather than
  at the next reload, that it is per-browser and not stored in the drawing, and the API.
- `Yappy.setHistoryDepth()` now **returns the value actually stored**, so a script can see when
  its request was clamped.

## Internal / tests
- 8 new tests in `store/history-depth.test.ts`, including that memory and localStorage agree
  after a clamp, and that normalising `historyDepth` does not drop other keys from the same
  update. Suite: 1075 tests across 73 files.

## Breaking changes / migration
- `Yappy.setHistoryDepth()` is now clamped to 10–500 (previously ≥1, unbounded above). A script
  passing a value outside that range gets the nearest end rather than the literal value; it now
  returns the stored number so the difference is visible.
