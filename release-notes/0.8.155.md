# 0.8.155 — The combine toolbar now recognises every shape (2026-07-29)

## Fixes
- **The contextual boolean toolbar didn't appear for most shape types.** It was gated on
  a hardcoded allowlist of 19 type names, while the app has 70+ element types with area
  — `pentagon`, `septagon`, `rightTriangle`, `cylinder`, `speechBubble`, `solidBlock`,
  `callout` and others. Selecting two of those showed nothing at all, with no
  explanation, which looked indistinguishable from the feature being broken.

  The gate is now the geometry rather than the type name: a shape qualifies if it
  flattens to at least one polygon, which is the exact precondition the boolean engine
  applies. It can no longer drift out of step with the engine, every shape with area is
  covered, and zero-area marks (lines, arrows) are still excluded for the right reason.
  (#223)

## Internal
- Regression covers eight previously-unsupported types plus the lines-only case, and was
  verified against a restored allowlist.
- Selections larger than 60 elements skip the geometry probe and go by count, so the
  cost stays bounded on very large selections.
