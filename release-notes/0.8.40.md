# 0.8.40 — Advanced colour picker (square + triangle) (2026-07-09)

## Highlights
- The colour controls (stroke / fill / text) now open a proper **interactive colour
  picker** with two modes:
  - **Square** — a saturation/value box + a hue slider.
  - **Triangle** — a happypaint/Krita-style hue ring around an SV triangle.
  Plus a hex field, an eyedropper (where the browser supports it), and a **recent
  colours** row. The mode you last used is remembered.

## Features
- New `ColorPickerPro` component (`components/color-picker-pro.tsx`), mounted in the
  Properties-panel colour popover above the hex row. Drag the SV box / triangle / hue
  ring to pick any colour; changes apply live to the selected element(s) as a single
  undo step. The native OS picker and hex input remain available alongside it.

## Internal / tests / docs
- HSV↔hex maths + a barycentric SV-triangle (pure-hue / white / black corners, rotated
  to the current hue on the ring). Eyedropper uses the `EyeDropper` API when present.
- Verified end-to-end: both modes render correctly, and dragging the picker updates the
  element's colour (e.g. stroke `#000000` → `#a63a3a`).

## Breaking changes / migration
- None. The existing swatch grid, hex field, and native picker are unchanged; the new
  picker is added alongside them.
