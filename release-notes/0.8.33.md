# 0.8.33 — UML class boxes auto-size to their members (2026-07-09)

## Highlights
- Imported UML class diagrams now size each class/interface box to fit its **widest
  member line**, so members like `-strategy: Strategy` or `-balance: number` stay on
  one line instead of wrapping (and, on SVG export, overflowing the compartment so the
  type after the colon looked dropped).

## Fixes
- **UML class/interface auto-sizing ignored members.** `applyAutoSizing` sized each
  node to fit its *label* only — for a class that's just the name, so the box stayed at
  its 180px default no matter how wide the attribute/method lines were. Added
  `computeUmlFittedSize`, which measures the widest of the header name and every member
  line (with the same renderer/font the drawers use) and sizes the box — width to fit
  the widest line, height for a row per member. Fixes both the canvas (was clipped) and
  the SVG export (was overflowing). Verified: the Account box renders `-balance: number`,
  `-owner: string`, and `-strategy: Strategy` each intact on one line.

## Breaking changes / migration
- None. Only affects boxes without an explicit width/height (the auto-sized default).
