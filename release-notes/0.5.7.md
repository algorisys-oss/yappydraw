# 0.5.7 — Procreate-style layer swipe gestures (2026-06-28)

## Highlights
- iPad/Procreate-style **swipe gestures** on layer rows: swipe-left for actions,
  swipe-right to multi-select.

## Features
- **Swipe-left → action tray** — swipe a layer row left to reveal a
  Lock / Duplicate / Delete tray; tap an action and the row springs back.
- **Swipe-right → multi-select** — swipe rows right to toggle them into a
  selection (left-accent highlight). A multi-select bar appears with **Group**
  (wraps the selected layers into a new group), **Delete**, and **Cancel**.
- Works with **mouse and touch/pen**. Layer **reorder** now happens by dragging
  the grip handle (`⋮⋮`); the row body is reserved for the left/right swipes (so
  a horizontal mouse drag triggers the swipe instead of starting a native drag).

## Internal / tests / docs
- Mirrors happypaint's layer-panel swipe UX. Deliberately ports only the
  gesture UX — the raster-only capabilities (blend modes, masks, adjustment
  layers, alpha-lock, pixel-select) don't map to yappy's vector layers.
- Notable choices: touch/pen-gated `startSwipe` (no conflict with native HTML5
  drag); 10px axis disambiguation so vertical drags still scroll the list; a
  timestamp click-guard (not a sticky boolean, which strands when a touch swipe
  emits no trailing click); tray occlusion via z-index + the row's opaque
  background.
- Tunable constants at the top of the component: `AXIS_SLOP` (10),
  `SWIPE_THRESHOLD` (48), `TRAY_W` (132).
- Help dialog gestures + learnings updated.

## Breaking changes / migration
- None.
