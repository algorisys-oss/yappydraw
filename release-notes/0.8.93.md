# 0.8.93 — Precision & measurement: gap measuring, richer readout, angle & point snapping (2026-07-13)

## Highlights
- A big **Precision & Measurement** push (plan Phases 2, 3, 4a, 4b): measure the gaps to a
  neighbour, read Δx/Δy/area/perimeter, constrain to clean angles, and snap shapes
  corner-to-corner.

## Features
- **Measure to a neighbour (Alt-hover).** With something selected, hold **Alt** and hover
  another object → red dimension lines show the pixel gaps to it, plus the distance to each
  artboard/page edge. Read-only; clears on Alt-up. Scripting:
  `Yappy.measureBetween(idA, idB, includeArtboardEdges?)`. *(Phase 2)*
- **Richer Measure readout.** The Measure tool now draws the **right triangle** for a diagonal
  drag with its **Δx/Δy** legs labelled, and — when one shape is selected — shows a card with its
  **W/H, area, perimeter** (circles/ellipses use true πab area + circumference; lines report
  length). Scripting: `Yappy.measureShape(id)`. *(Phase 3)*
- **Fixed-angle constraint (Shift → 15°).** Hold **Shift** to snap to clean 15° increments while
  **drawing** a line/arrow, **rotating** an element, or dragging the **Measure** line. The drag
  keeps its length; only the angle snaps. *(Phase 4a)*
- **Snap to point.** Dragging an element now locks its corners / edge-midpoints / centre — and
  vector **path anchors** — onto another element's matching points when they align on both axes,
  with a magenta diamond marking the lock. Hold **Shift** to suspend snapping. *(Phase 4b)*

## Fixes
- Snap-to-point reads each element's original pre-drag position, fixing a per-frame double-count
  that would otherwise only snap on the first frame of a drag.

## Internal / tests / docs
- New pure, unit-tested utils: `measure-gap.ts`, `measure-readout.ts`, `angle-constrain.ts`,
  `point-snapping.ts` (33 unit tests total). New Playwright specs: `measure-neighbor`,
  `measure-readout`, `angle-constrain`, `point-snapping`.
- `snap-renderer` gained `renderMeasureGaps` + `renderPointSnapMarker`; measure overlay and canvas
  render params extended. Help doc (`illustrator-tools`) + hotkeys list + API updated.
- Remaining in the plan: **Phase 4c** (path-intersection snapping) — deferred, wants the
  `object-snapping.ts` + WASM path.

## Breaking changes / migration
- None.
