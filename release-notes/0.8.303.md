# 0.8.303 — Diagram shapes drawn right in both styles; Escape puts a tool down (2026-11-03)

## Highlights
- Every Architecture, UML and Data shape was drawn with the real tools in sketch and
  architectural style and checked by eye. Fourteen shapes drew wrong in one style or both; all are
  fixed.
- Escape now puts a drawing tool down (back to Selection), so you can double-click the shape you
  just drew to label it.

## Fixes
- **DFD Data Store:** keeps its solid fill in sketch style; the ID compartment stays a narrow strip
  however wide the store is; the toolbar icon now shows the notation (it was a hard drive).
- **UML Fragment:** the operator (`alt`, `loop` …) goes in the corner tab, which widens to fit it,
  and the guard (`[condition]`) is drawn under it — it was never drawn.
- **UML Actor:** the name is under the figure, not across its torso.
- **UML Activity Action (sketch):** no longer bulges ~37px past its box.
- **UML Package (architectural):** the body edge under the tab is drawn.
- **Storage Blob:** fits its box (it overshot top and bottom); filled in sketch style.
- **Gauge (sketch):** the dial is drawn (only ticks and the needle were). Same RoughJS arc bug
  fixed on the Scale's pans, the Seedling's ground and the Sad face's frown.
- **Firewall (architectural):** proper staggered bricks.
- **Router (architectural):** outward arrows, as in sketch.
- **CDN (sketch):** latitude lines, as in architectural.
- **DFD Process, Container, API Gateway (sketch):** rounded corners; API Gateway's arrowhead solid.
- **User (architectural):** closed shoulders, filled with the shape's fill.
- **Escape** returns shape and connector tools to Selection (pens, text and the Pen tool keep
  Escape for finishing what you're doing).

## Internal / tests / docs
- `tests/diagram-shape-rendering.spec.ts`: 10 pixel checks, each verified to fail on the old
  renderers. `frontend/src/utils/dfd-data-store-geometry.test.ts`.
- `tests/uml-tools.spec.ts` presses Escape before double-clicking; it had been red since the tool
  started staying armed (v0.8.236).
- `utils/uml-fragment-layout.ts`: the Fragment tab size, shared by the renderer and the
  double-click handler.
- Help: Infrastructure gains a Data Flow (DFD) section, DFD API types and the Esc step; UML
  documents the Fragment's operator/guard and the Actor's name. Hotkeys: Esc — put the drawing
  tool down.
- Bugs #471–#476.

## Breaking changes / migration
- Storage Blob's caps are slightly flatter (they now fit the box). Actors with a label draw a
  slightly shorter figure to make room for the name inside the box.
