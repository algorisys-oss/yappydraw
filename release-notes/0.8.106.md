# 0.8.106 — Excalidraw import/export, text sizing, mindmap style inheritance & Slingshot polish (2026-07-16)

## Highlights
- **Excalidraw import & export** — round-trip your drawings with Excalidraw (`.excalidraw`), plus a public open spec for the Yappy file format so other tools can read/write it.
- **Text auto-size is now reachable and sticky** — the Auto Resize control shows for text, and dragging a side handle switches a hugging text box to fixed-width (Figma-style).
- **New mindmap nodes inherit the parent's full style** — fonts, size, bold/italic, alignment, colour and fill carry over on Tab/Enter.
- **Slingshot game overhaul** — a real Y-fork with stretchy elastic bands, a smashable block wall, a forgiving grab target, and physics matched to the code sample.

## Features
- **Excalidraw interop.** *Save/Export → Export to Excalidraw* writes a `.excalidraw` file; opening a `.excalidraw` file imports its elements onto your drawing. Core shapes (rectangle, ellipse, diamond, line, arrow, text, image, pen strokes) map 1:1; Yappy-only shapes export as their outline. Scriptable via `window.Yappy.exportExcalidraw()` and `window.Yappy.importExcalidraw(json)`.
- **Open Yappy format spec** (`docs/yappy-format-spec.md`) — the `.yappy` document JSON is now documented for third-party import/export.
- **Text sizing modes.** The **Auto Resize** toggle now appears for text/rich-text: on = auto-width (box hugs the text), off = fixed-width (wraps, height grows). Dragging a left/right handle converts auto-width → fixed-width, so the width sticks.
- **Mindmap style inheritance.** Tab (child) and Enter (sibling) now copy the source node's font, size, weight/italic, text alignment & colour, fill, and rounding (the branch stroke colour still tapers by depth).
- **Slingshot (Blueprint game):** a Y-fork slingshot with two **elastic bands** that stretch as you pull back and release on launch (new general-purpose `tether` action — draws a sprite as a bar between a point and a target); a **2×2 wall of destructible blocks** guarding the pigs; and a new **per-sprite gravity** option so a sprite can fall lighter/heavier than the global default.

## Fixes
- **Random text pasted on click (Linux).** An accidental middle-click inside a text label pasted the X11 primary selection (last-highlighted text anywhere). Middle-click is now blocked in the text editors; Ctrl+V and right-click→Paste are unaffected.
- **Alt+Enter with nothing selected** only shuffled the top-right icons and showed no panel — it now opens Canvas properties, and the icons no longer shift without a panel.
- **Behaviors (Game Builder) panel** opened partly under the slide-navigator on game documents, so its tabs/controls weren't clickable — floating panels now open clear of that column.
- **Slingshot felt "broken":** the bird was nearly ungrabbable (tiny hit target with no tolerance) — added a grab margin so a near-miss press still starts the aim; and the pull/gravity now matches the code-authored Slingshot.
- Copy Style / Graphic Styles now also carry bold/italic and text colour (previously dropped).

## Internal / tests / docs
- New pure module `utils/excalidraw-io.ts` (`toExcalidraw`/`fromExcalidraw`) with round-trip tests.
- New regression specs: `excalidraw-io`, `paste-guard`, `text-autosize`, `mindmap-inherit`, `behaviors-panel-overlap`, `game-gravity`, plus Slingshot band/block/near-miss coverage; repaired stale `behaviors-panel`/`behaviors-header-fit` selectors from the dock migration.
- Help docs updated (workspace, drawing-tools, mindmap, arcade); learnings & bug-fix log updated.

## Breaking changes / migration
- None. Excalidraw import adds to the current drawing (doesn't replace it); the Yappy document format is unchanged.
