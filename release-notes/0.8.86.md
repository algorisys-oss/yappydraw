# 0.8.86 — One-click Replace Background (AI) + persistent in-progress indicator (2026-07-13)

## Highlights
- New **Replace Background (AI)** on the image right-click menu — describe a new
  backdrop and the background behind the subject is swapped while the foreground
  stays untouched.
- AI operations now show a **persistent, non-obtrusive spinner** for the whole
  duration instead of a message that vanished after 3 seconds mid-work.

## Features
- **Replace Background (AI)…** — right-click an image → *Replace Background (AI)…*,
  type a description ("a sunny beach", "a solid teal studio"), and the background
  is regenerated via OpenAI `gpt-image-1` edits with `input_fidelity: high` (auto
  retry without it for accounts that reject the flag). The foreground subject is
  kept pixel-identical. Sits directly below *Remove Background (AI)*. Scriptable as
  `Y.replaceBackground('a sunny beach at sunset')`.

## Fixes
- **AI in-progress indicator disappeared mid-work.** Every AI photo/text op (Magic
  Write, Generate Image, Magic Edit, Magic Expand, Remove Background, Replace
  Background) showed its "…" message as an `info` toast that auto-hides after 3s —
  far shorter than the operation, so the screen looked idle until the result
  appeared. They now use the existing persistent `loading` toast (spinner, no
  auto-hide, pinned bottom-center so it never blocks the canvas), replaced by the
  terminal success/error toast when the work finishes.
- Hardened two exit paths so the now-persistent spinner can never hang:
  `magicWrite`'s no-op case (model returned only empty text) clears the toast, and
  `expandImage`'s "no canvas 2D context" case shows an error instead of returning
  silently.
