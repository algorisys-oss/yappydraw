# 0.8.292 — Editable PowerPoint export, PowerPoint import preview (2026-10-31)

## Highlights
- **PowerPoint export is now editable.** Export → PPTX used to write each slide as one picture. It now writes real PowerPoint shapes, text, connectors and images that stay editable in a presentation app. Checked in LibreOffice; not yet opened in PowerPoint itself. The old one-picture-per-slide output is still there as **Pictures**.
- **Opening PowerPoint files (Dev Mode preview).** With Dev Mode on, File → Open and drag-and-drop accept `.pptx` / `.potx` / `.ppsx`, and the presentation opens as a new slides document. It stays behind Dev Mode until it has been tried on more real-world decks.

## Features
- **Editable export (Export → PPTX → Editable shapes, the default).**
  - Rectangles, rounded rectangles and ellipses become PowerPoint's own shapes; every other shape keeps its exact outline as a custom shape.
  - Text stays text, with its fonts, colours, bullets, numbering and alignment.
  - Straight lines become connectors glued to the shapes; curves and elbows become paths with arrowheads.
  - Images keep their crop and opacity. Groups, slide backgrounds and transitions (Fade, Slide → Push, Zoom) carry over.
  - Anything PowerPoint can't draw (effects, masks, special fills, 3D, filters, text on a path, tables) becomes a picture of just that object.
  - Sketch-style objects export as clean, editable shapes. Use **Pictures** for the exact hand-drawn look.
  - Pages of another size are fitted to the slide instead of stretched.
- **Import (Dev Mode).**
  - Theme colours and fonts, slide master and layout styling, and the master's own artwork (logo bars, decorations) are applied.
  - All 187 PowerPoint preset shapes are drawn from the standard's own definitions: five become Yappy shapes, the rest exact vector paths.
  - Connectors become bound lines and arrows. Pictures keep their crop and transparency. Tables become groups of cells in PowerPoint's default style. Backgrounds and transitions come across.
  - Bullets and numbering keep their glyph (including Wingdings and Symbol bullets), colour, size, numbering style, start number, hanging indent and paragraph spacing.
  - SmartArt comes in as the editable shapes PowerPoint last drew for it.
  - Each paragraph keeps its own alignment, so a centred heading over left-aligned lines stays centred.
  - From a script: `await Yappy.importPPTX(file)`.
- **Per-paragraph alignment in rich text.** A paragraph can now be aligned differently from its text box, on the canvas and in SVG and PowerPoint export. There's no control for it in the editor yet; today it arrives through PowerPoint import.

## Fixes
- **List numbers ran into their text.** At large sizes "IV.", "a)" or "10." overlapped the item text, because the text started a fixed 20 px after the marker. It now clears the marker; small fonts look as before.
- SVG and vector-PDF output now draw partial and rotated ellipses, rounded rectangles with one to four radii, and `arcTo` correctly. This also affects the export fallbacks.
- Desktop app: rustls updated to 0.23.46 (Dependabot advisories), and the declared minimum Rust version raised to 1.88 to match the lockfile.

## Internal / tests / docs
- New `frontend/src/utils/pptx/` (pure OOXML reader and writer, ECMA-376 preset geometry evaluator, `deck.ts` shared by import and export). `pptxgenjs` removed; `fflate` is a direct dependency.
- Tests: `utils/pptx/read.test.ts`, `write.test.ts`, `guides.test.ts`, `rich-text-list-marker.test.ts`, `rich-text-paragraph-align.test.ts`; `tests/pptx-export.spec.ts` and `tests/pptx-import.spec.ts`. Checked against LibreOffice renders of exported decks and of three real corporate decks.
- Help: Workspace → PowerPoint export and import; Design Studio → Lists. `api.ts` (`exportPPTX`, `importPPTX`). Learnings.

## Breaking changes / migration
- The default PPTX export changes from pictures to editable shapes. Choose **Pictures** in the export dialog for the old output.
