# 0.8.119 — A cast you can tell apart

**Date:** 2026-07-20

## Highlights

- Comic characters each get **their own hair**, and it stays the same in every panel.
- **Eight new hair styles** — 18 in total: Swoosh, Mohawk, Afro, Bob, Braids, Top knot,
  Balding and Cap.

## Features

- **Distinct hair per character.** Readers tell stick figures apart by the head — it's
  the only place a character can carry an identity. Every speaker in a comic now gets
  their own hair style and colour, assigned by order of first appearance in the script.

  Crucially it is **stable across panels**: a character looks the same throughout, even
  in panels where the rest of the cast is absent. Adjacent slots in the palette differ in
  *shape* as well as colour, so a monochrome or printed strip still reads.

  Override per character, or turn it off:

  ```js
  Y.createComicStrip(script, {
    hair:       { Ann: 'bun', Ben: 'mohawk' },   // style per speaker
    hairColors: { Ann: '#2b2118' },              // colour per speaker
  });
  Y.createComicStrip(script, { distinctHair: false });   // everyone the same
  ```

- **Eight new hair styles**, usable anywhere hair is (library figures, animated figures,
  comics):

  | Style | Looks like |
  |---|---|
  | **Swoosh** | A big crest sweeping back into a point |
  | **Mohawk** | A narrow central crest |
  | **Afro** | A wide halo around the crown and ears |
  | **Bob** | A blunt chin-length cut |
  | **Braids** | Two plaits past the shoulder |
  | **Top knot** | A tight crop with a knot on the crown |
  | **Balding** | A receding hairline, sides only |
  | **Cap** | A baseball cap with a brim on the facing side |

  Solid styles take the hair colour; Fringe, Long, Spiky and Balding are outline-only and
  follow the figure's stroke colour.

## Internal / test changes

- New `library/comic/cast-style.ts` — a pure module holding the palette, `scriptCast`
  (speakers of the whole script in first-appearance order) and `assignCastHair`. It
  deliberately does **not** reuse `castSpeakers` from `panel-layout.ts`, which caps at
  the number of characters one *panel* can hold — the wrong bound for "who is in this
  comic", and a subtle way to reintroduce the drift the feature exists to prevent.

- `createComicStrip` computes the assignment once and passes it to every panel as an
  explicit override; `planComicPanel` still assigns for itself, so a single panel and a
  directly-called plan behave sensibly.

- Fixed a latent bug in `capPath`: it hardcoded the large-arc flag on its closing arc,
  which was correct for every hair style that spanned under 180° but sent the Afro's
  boundary under the chin — filling the whole face. The flag is now derived from the
  span.

- 7 new unit tests for `cast-style.ts` and 3 new Playwright tests (hair is identical
  across panels when a character is missing from one, per-speaker overrides win,
  `distinctHair:false`) — 72 in the comic suite, 226 unit tests overall.

## Breaking changes / migration

None, but comics generated before this release used one hairstyle for the whole cast;
regenerating a script now gives each character their own. Pass `distinctHair: false` for
the old behaviour.

## Still to come

Trouser / clothing styles for the figure library are the next piece — they follow the
**legs** rather than the head, so they need their own geometry pass.
