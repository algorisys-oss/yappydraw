# 0.8.309 — Security update: VS Code extension build tools (2026-11-26)

## Highlights
- Security update for the tools that package the VS Code extension. The web app, the SDK and
  the extension's own code do not change.

## Features
- None.

## Fixes
- **#485** `minimatch` < 11.0.1 (Dependabot #21, DoS via globparts amplification) and `glob`
  9.0.0–14.0.1 (GHSA-3g3m-2fjr-6pw4, AbortSignal cancellation bypass) in
  `vscode/package-lock.json`, through `@vscode/vsce`. Even `vsce` 4.1.1 asks for `minimatch ^10`,
  so `vscode/package.json` now overrides `minimatch ^11.0.1` and `glob ^14.0.3`.

## Internal / tests / docs
- `npx vsce ls` gives the same 1876 files before and after. `npm run package` builds the `.vsix`.
  `npm audit` in `vscode/` reports 0 vulnerabilities.

## Breaking changes / migration
- None.
