# 0.8.121 — Tops and ties

**Date:** 2026-07-20

## Highlights

- Stick figures can wear **tops and neckwear** — and like trousers, they follow the pose.
- Front-facing shoes redrawn as a trapezoid, which reads as a shoe rather than a blob.

## Features

- **Tops** — T-shirt, Long sleeve, Vest, Jacket, Hoodie, None. The body follows the
  torso and the sleeves follow the arms, so a waving figure's sleeve waves with it and a
  seated figure's jacket sits with them.

- **Neckwear** — Tie, Bow tie, Scarf, None. A tie hangs from the collar along the torso,
  so it leans when the figure leans.

- **Own colours** for tops and neckwear, alongside the existing hair, trouser and shoe
  colours. All four clothing axes are independent: change the trousers and the top,
  shoes and tie stay exactly as they were.

- **Front-facing shoes** are now a trapezoid (narrow at the ankle, flaring to a flat
  sole) instead of an ellipse — much closer to how a shoe reads head-on.

- **Joggers** lost the ankle cuff band, which crossed the trouser outline and read as an
  X. The taper alone carries the style.

- **API.**

  ```js
  Y.listStickTops();        // 6 tops
  Y.listStickNeckwear();    // tie / bowtie / scarf
  Y.setStickFace({ top: 'jacket', neck: 'tie', topColor: '#0f766e' }, ids);
  Y.insertAnimatedFigure('walk', { top: 'hoodie', neck: 'scarf' });
  ```

## Internal / test changes

- Tops reuse the offset-outline machinery trousers proved out: a garment is a limb
  polyline inflated into a closed outline. Only the source polylines differ — torso and
  arms instead of legs.

- **Limb identification was mined from the corpus again, and the obvious rule was again
  wrong.** "Arms are the subpaths starting on the torso" scores 55/58: a security guard's
  crossed arms touch neither shoulder, and some poses put the shoulder a few units off
  the torso line. Because `bones` only ever holds torso + arms + legs, subtraction is
  exact and needs no tolerance: arms = parts − legs − torso. Likewise the torso is the
  non-leg subpath passing *closest to* the hip, not the one ending there — a speaker
  behind a podium runs their torso past it. 58/58, frozen as unit tests.

- Torso and arm bones now carry `data-sf-part="torso"` / `"arm"` alongside the existing
  `"leg"`, so a flattened figure can still be re-dressed.

- 6 new unit tests and 3 new Playwright tests — 242 unit tests, 20 stick-figure e2e.

## Breaking changes / migration

None. Tops default to off, so nothing that already exists has changed.
