# 0.5.24 — Reliable Touch Type letter selection (2026-06-30)

## Fixes
- **Touch Type letter selection was inconsistent** — clicking the top/bottom of a tall letter (or slightly off-centre) often selected nothing. The hit-test now uses the glyph's column × the text row instead of distance-to-centre, so clicking anywhere on a letter selects it. Plain, Shift- and Ctrl/⌘-click are all reliable now.
- Added a context-menu guard on the Touch Type overlay (note: on macOS, Ctrl-click is the OS right-click — use **⌘-click** to add individual letters).

## Breaking changes / migration
- None.
