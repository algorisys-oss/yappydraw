# 0.8.287 — Auto Layout and rounded elbows (2026-10-11)

## Highlights
- **Auto Layout.** Select the shapes of a diagram (or nothing for the whole layer) and choose right-click → Arrange → Auto Layout: Top to Bottom (Alt+Shift+A), Left to Right, Bottom to Top or Right to Left; the command palette has the same entries. The connectors between the shapes are read as a graph and laid out in layers with crossings reduced and parents centred over children. Containers (frames, pools, any box enclosing other selected shapes) are laid out as units: children arranged inside, the container resized around them, nested containers included. Hand-routed elbows reset; everything re-routes; one Undo step; animated.
- **Rounded elbow corners.** New elbows bend with an 8px radius; Corner Radius in the Properties panel (0–40) sets it per connector. Same geometry on the canvas in both styles and in SVG export.

## Features
- `Yappy.autoLayout(ids?, { direction, nodeGap, layerGap, componentGap, animate, containerPadding })` → `{ moved, containers, direction }` or `null`.
- `elbowRadius` element option; `connect()` and the tool default to 8 on elbows.
- Commands `action-auto-layout` (Alt+Shift+A) and `action-auto-layout-lr`, translated (de, es, fr, ja).

## Internal / tests / docs
- `utils/graph-layout/layered-layout.ts`: in-house Sugiyama-style layout (cycle breaking, longest-path layering, dummy nodes, barycenter sweeps, priority placement, components). 9 tests.
- `utils/auto-layout.ts`: compound layout over geometric containment; moves shapes only and lets the canvas effect re-route connectors.
- `connector-geometry.ts`: `elbowPathCommands` / `elbowCommandsToPath` shared by the renderer's `definePath`, the sketch path and export.
- Help: Connectors → "Rounded corners", "Auto layout", shortcut list. Learnings.

## Breaking changes / migration
- None. Existing elbows keep sharp bends (no `elbowRadius`); set one to round them.
