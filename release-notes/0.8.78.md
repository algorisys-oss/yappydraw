# 0.8.78 — Turntable Phase 3a: AI reconstruction (2026-07-12)

## Highlights
- **✨ Reconstruct with AI** — the "reimagine from a new viewpoint" tier of Turntable. Set the
  Yaw/Pitch to the angle you want and let a vision model redraw the shape from that viewpoint —
  *inventing* the newly-visible parts — then drop the result in as a new editable path beside the
  original. Browser-direct, bring-your-own-key, like every other Yappy AI feature.

## Features
- **AI turntable reconstruction** (experimental) — a new button in the **TURNTABLE (3D SPIN)** panel
  (single shape). It rasterizes the shape, asks your configured AI provider (Claude / OpenAI /
  Gemini — set a key in *AI Settings*) to redraw it at the current turntable angle and return SVG,
  and inserts the parsed vector paths as a **new element** next to the source (nothing is
  overwritten, single undo). With no key / offline / on failure it simply reports and you fall back
  to the deterministic **Bake**. Scripting: `Yappy.reconstructTurntableAI({ yaw, pitch })`.

## Internal / test changes
- `ai/turntable-ai.ts` (new, lazy-loaded chunk): `reconstructTurntableAI(id, {yaw,pitch})` —
  `exportRegion`(download=false) → `parseDataURL` → `callLLM` (vision, SVG-out system prompt) →
  `extractSvg` → `svgToElements` placed beside the original → `pushToHistory` + `batch(setStore)`.
  Reuses the exact `generateDiagramFromSketch` scaffold; BYO-key gated via `getApiKey`.
- `components/property-panel.tsx`: **✨ Reconstruct with AI** button (lazy-imports the AI module so
  it stays out of the main bundle). `api.ts`: `reconstructTurntableAI`.
- `help-docs/features/effects-doc.tsx`, `docs/turntable-plan.md`, `docs/learnings.md` updated.

## Breaking changes / migration
- None. The feature is additive and no-ops (with a toast) when no AI key is configured.

## Notes
- This completes the planned Turntable roadmap end-to-end (Phases 1, 2, 3a, 4). An optional
  higher-fidelity **3b** tier (image-model reimagine → auto-trace to vector) remains as a possible
  future follow-up.
