# 0.8.30 — Mermaid UML class diagrams: real members & UML arrowheads (2026-07-09)

## Highlights
- Importing a Mermaid `classDiagram` now produces **real UML class boxes**: the
  attributes/methods compartments fill in, every class shows up (even ones only
  named in a relation), and each relationship draws its **proper UML arrowhead**
  instead of a plain arrow with a text label.

## Features
- **Distinct UML relationship arrowheads.** `classDiagram` relations now render the
  correct decoration on the correct end:
  - Inheritance `A <|-- B` → hollow triangle on the base.
  - Realization `A <|.. B` → dashed line, hollow triangle on the interface.
  - Composition `A *-- B` → filled diamond on the whole.
  - Aggregation `A o-- B` → hollow diamond on the aggregate.
  - Association `A --> B` / Dependency `A ..> B` (dashed) → open arrow on the target.
- **Wider relation syntax.** Added the navigable composite/aggregate forms
  `A *--> B` / `A o--> B`, the reversed forms `B --|> A` / `B --* A` / `B --o A`, and
  optional quoted cardinality/role labels on either side, e.g.
  `Subject "1" o-- "0..*" Observer : observers`.

## Fixes
- **Class members no longer vanish.** Parser sections were mapped onto
  `umlAttributes`/`umlMethods` while the renderers/layout/SVG export read
  `attributesText`/`methodsText` — a silent field-name mismatch that left every
  compartment empty. Now mapped onto the canonical fields.
- **Aggregation `o--` no longer drops the source class.** The relation regex listed
  the arrow as `" o--"` with a leading space, so after the separator whitespace was
  consumed it could never match — the line was treated as unrecognized syntax and the
  left-hand class (and the edge) disappeared. Fixed the alternation.

## Internal / tests / docs
- Verified the parser end-to-end (regex + edge orientation/arrowhead assignment)
  across all forward, reversed, navigable and cardinality forms.
- Updated the UML help doc (`help-docs/shapes/uml-doc.tsx`) with the Mermaid syntax
  for each relationship. Recorded in `docs/learnings.md`, `docs/bugs/bug-fixes.md`, and
  closed Gaps 1–3 in `docs/dsl-uml-gaps.md` (Gaps 4–6 remain open).

## Breaking changes / migration
- None. The auto-generated relation text labels ("extends"/"composition"/…) are
  replaced by the arrowhead itself; any user-supplied `: role` label is preserved.
