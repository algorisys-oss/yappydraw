# 0.8.64 — Live transform HUD (on-object size/position readout) (2026-07-11)

## Highlights
- **Transform HUD** — select anything and a small badge rides just below it showing
  its live **W × H** and position **X, Y** (plus **rotation ∠** for a single rotated
  object). It updates as you drag, resize, or rotate — so you always know the exact
  size and placement without opening a panel.

## Features
- **Live transform HUD.** A screen-space badge that follows the current selection:
  - Single selection → the element's own **W × H**, position **X, Y**, and **∠°**
    (shown only when rotated).
  - Multi-selection → the combined bounding box's **W × H** and position.
  - World units (unaffected by zoom), positioned via the viewport transform so it
    stays put under the selection through pan / zoom / canvas rotation.
  - Passive UI — `pointer-events: none`, so it never blocks canvas interaction —
    and hidden in Presentation mode and while the Measure tool is active.
- This is **Phase 1** of the precision & measurement plan
  (`docs/precision-measurement-plan.md`). It also doubles as the readout badge the
  planned After Effects–style animation scrubber will reuse.

## Internal / tests / docs
- New `components/transform-hud.tsx` (+ `.css`), mounted in `app.tsx` alongside the
  other canvas overlays. Purely store-derived (no event listeners) — the selection's
  element fields update reactively during a gesture, so the badge follows for free.
- Verified live against the running app (Playwright drive): creating + selecting a
  320×180 rect showed `320 × 180 · 200, 150`; deselecting removed it; no page errors.
- Help doc updated (`illustrator-tools-doc` → "On-canvas measurement") covering the
  HUD alongside the existing Measure tool, Rulers & Guides, and snapping.
- `tsc -b` and `npm run build` both green.

## Known limitations
- For a **rotated single element**, the badge anchors under its *un-rotated* frame
  bottom (the selection bounding box ignores rotation); numbers are correct, only the
  badge position is approximate for rotated shapes. Refinable in a later pass.
- Always-on when something is selected (not yet toggleable).

## Breaking changes / migration
- None.
