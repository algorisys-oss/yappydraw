# 0.8.197 — reusable Booleans, and a way to move things between layers (2026-08-15)

The two smallest, highest-friction items from the same feedback round as 0.8.196's bug fixes. Both
turned out to be about *reach* rather than missing capability.

## Highlights
- **Boolean operations are non-destructive by default.** Subtract now leaves you a shape that
  remembers what it was made from: change the operation later, release it back into the original
  shapes, or expand it to a plain path. Previously it flattened everything and threw the sources
  away, which is exactly why the request was "the resulting object should remain reusable/editable".
- **Move to Layer.** Right-click → *Move to Layer* → pick one. `moveElementsToLayer` had existed in
  the store and the public API since forever with **no UI anywhere**, so moving a shape between
  layers meant scripting it.

## Features
- **Non-destructive combining by default** (the ❖ toggle starts on). Applies to the Pathfinder
  strip buttons and to `Ctrl+Alt+U/D/I/X`. Fully destructive Pathfinder is unchanged and still one
  click away on right-click → *Pathfinder*, and ❖ turns the old behaviour back on.
  - The choice is now stored in `localStorage`, which the toggle's tooltip has always claimed —
    it previously only survived until reload.
- **Move to Layer** on the selection's context menu. Works on a whole selection at once; a tick
  marks the layer the selection is already on (every such layer, for a mixed selection). Group
  layers aren't offered (they're containers, not places artwork lives) and nor are locked layers.
  The entry is hidden entirely when there is nowhere else to move to.

## Behaviour change
**Subtract, Unite, Intersect and Exclude now produce a compound shape rather than a flattened
path.** The result looks and behaves like a shape, but it carries its sources. If a workflow
depended on getting a plain path immediately, either turn ❖ off once (remembered thereafter) or use
right-click → *Pathfinder*, which never changed.

## Docs
- Illustrator-class Tools: the ❖ section now describes non-destructive as *the default*, explains
  change/release/expand, and points at the destructive route.
- Workspace: a new "Moving objects between layers" section, which also documents moving a layer
  itself (drag the row, or `Alt+[` / `Alt+]`) — capabilities that existed but were nowhere in the
  docs, and were reported as missing.
- `docs/learnings.md`: that four of the eight requested "features" already existed and only needed
  reaching; that non-destructive was the wrong default from the start; and that reading a component
  beats guessing at its test selectors.

## Tests
- `tests/feedback-friction.spec.ts` — 5 cases: Subtract keeps the result editable by default with
  its sources recoverable (op changed after the fact, then released back into two shapes); the
  destructive path still genuinely flattens with no sources retained; the ❖ choice survives a
  reload; Move to Layer actually moves the selection; and the entry is hidden when there is nowhere
  to move to.
- `tests/boolean-ops-ux.spec.ts` updated for the new default — the old "clicking Unite" case now
  explicitly disarms ❖ so the **destructive** path stays covered rather than silently becoming a
  second test of the compound path. 14/14 pass.
- 563 unit tests pass.

## Still open from this feedback round
- **Diagonal / isometric grid** — genuine gap, next up.
- **Variable stroke width profiles** — the width tool exists; the preset dropdown (uniform, bulge,
  waist, taper) does not. Biggest of the remaining items, worth its own release.
- **"Keep originals" for Booleans** — if what was wanted is the *cutter* left on the canvas as a
  separate object alongside the result, that's a different option from the one shipped here (which
  keeps the result editable and the sources recoverable). Say so and it's a small addition.
- `envelopeWithTopObject` ("Make with Top Object") and layer reordering both already exist and are
  now documented; no code needed.
