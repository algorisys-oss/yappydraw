# 0.8.156 — Symmetry drawing, fill mode, and a draw-in that stops popping (2026-07-29)

## Highlights
- **Live symmetry drawing** — mirror, 4-way quadrant and mandala. Every drawing tool
  replicates what you draw *as you draw it*, with the copies tracking the stroke while
  the pointer is still down.
- **Fill mode** — an Alchemy-style toggle that commits freehand strokes as solid
  silhouettes instead of lines.
- **`drawIn` no longer pops in Sketch style** — the reveal traces the shape's real
  hand-drawn strokes, so it ends on exactly the shape you'd see with no animation.

## Features
- Symmetry modes: `off` / `vertical` / `horizontal` / `both` (quadrant) / `radial`
  (2–24 spokes), with a −90…90° axis tilt and a draggable centre handle.
  Interface mirrors HappyPaint's, so the two apps stay learnable as one.
  - `Yappy.setSymmetryMode()`, `toggleSymmetry()`, `toggleSymmetryAxis()`,
    `setRadialCount()`, `setSymmetryAngleDeg()`, `setSymmetryCenter()`,
    `setSymmetryEditing()`, `toggleSymmetryEditing()`, `mirrorAcrossSymmetry()`.
  - Surfaces: footer buttons, Canvas panel → Symmetry, `Alt+Y`,
    `Alt+Shift+Y` (move axis), and six Command Palette entries.
  - All instances of a mark share a group, so it moves, restyles and undoes as one.
- Fill mode (`Yappy.setFillShapeMode()` / `toggleFillShapeMode()` / `getFillShapeMode()`),
  with a paint-bucket toggle in the footer. Composes with symmetry — filled mandalas in
  one gesture.
- Symmetry is saved with the document (mode, centre, spokes, tilt); fill mode persists
  across sessions. The transient move-axis mode is deliberately not persisted.
- Sketch-style `drawIn` reveals edges in the order a hand would draw them, with RoughJS's
  two passes advancing in lockstep rather than tracing the shape twice.

## Fixes
- **#221** Sketch `drawIn` revealed a clean line, then snapped to the hand-drawn stroke at
  100% — the last frame added ~27% of the shape's ink. The reveal now traces the shape's
  own RoughJS geometry.
- **#222** A `null` `drawProgress` made a shape vanish (`dp !== undefined` let `null`
  through as progress 0).
- **#223** Mirrored *pen* strokes only appeared on pointer-up. The copies were in the
  document from the first move but culled by the renderer's sub-pixel filter: an
  uncommitted freehand stroke keeps its extent in `points` while width/height stay 0.
  Shapes were unaffected, which is why it looked tool-specific.
- **#224** Every freehand stroke rendered as a filled blob — the fill was keyed on
  `backgroundColor`, which freehand inherits from the default styles. Now an explicit
  `fillSilhouette` flag.
- **#225** Loading a document saved before symmetry existed kept the previous drawing's
  axis: the store was seeded from `initialState` by reference, so drawing had been
  mutating "the defaults" in place.

## Internal / tests
- New `utils/animation/rough-stroke-trace.ts` (capture proxy + opset flattening + reveal)
  and `utils/symmetry.ts` (modes, transforms, element-level ops).
- 24 unit tests, several running against real RoughJS output rather than mocked opsets —
  which is what caught that RoughJS emits only `move`/`bcurveTo` and traces every segment
  twice.
- 30 Playwright tests across symmetry, live drawing, footer/fill and the drawIn reveal.
  The live-symmetry regression test asserts **pixels**, not store contents — the earlier
  store-based test passed on the broken code.
- `computeElementHash` hashes `drawProgress` as a flag, not a value: one key for all
  reveal frames, a different key for the finished shape.

## Breaking changes / migration
- `store.symmetry` migrated from `{ enabled, axis, pos }` to
  `{ mode, cx, cy, radialCount, angle, editing }`. The old
  `toggleSymmetryGuide` / `setSymmetryAxis` / `setSymmetryPos` API still works as
  deprecated adapters on top of the new state (covered by tests).
- Documents saved before this release load with symmetry off.
