# 0.8.45 — Draggable in-shape labels + movable colour palette (2026-07-09)

## Features
- **Drag a shape's text label.** The text inside a shape no longer has to stay centred:
  select a container shape (rectangle, circle, diamond, sticky, callout, …) and drag the
  small blue grab-dot on its label to reposition the text anywhere within the shape.
  Stored as a per-element `textOffsetX/Y`, rotation-aware, one undo step, and honoured by
  the renderer + hit-testing. (Connectors, tables, UML compartments, plain text and
  data-structure shapes render their own text and are excluded.)
- **Movable global colour palette.** The floating PALETTE panel can now be dragged by its
  header (the `⠿ PALETTE` grip) and dropped anywhere on screen, like the other tool panels.

## Internal / tests / docs
- Verified: dragging the label handle sets `textOffsetX/Y` (e.g. +70/+40) and moves the
  text; the palette panel drags from the top-right to anywhere. Recorded in
  `docs/learnings.md`.

## Breaking changes / migration
- None. Existing shapes default to a centred label (offset 0).
