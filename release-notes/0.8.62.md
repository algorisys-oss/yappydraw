# 0.8.62 — Dockable panels Phase D: Vector Tools migrated (standalone panels complete) (2026-07-10)

## Highlights
- The **Vector Tools** palette is now a first-class **dockable panel** — dock it to
  an edge, float it, collapse it, reorder it in a stack, and the layout persists
  across reloads.
- This completes the **standalone-panel** migration onto the dock. Only the two
  most deeply-coupled panels (**Property** and **Layers**) remain, scheduled as the
  finale.

## Features
- **Phase D migration (Vector Tools):** the Illustrator-class tool palette (Build /
  Path / Paint / Warp / Symbol / Text / Insert / Effects) moved onto the shared dock
  chrome. Opening it the usual ways (toolbar button, scripting API) now opens the
  *dockable* version — drag it to the left/right edge to dock, reorder it within a
  stack, or float it. The panel had no header actions beyond Close, so it renders as
  a plain body.

## Internal / tests / docs
- Dropped Vector Tools' bespoke `setupPanel` — it hand-rolled dragging plus a
  `ResizeObserver` that persisted the panel's size to a `vectorToolsSize`
  localStorage key. The dock now owns positioning and sizing, so both are gone.
- Dropped the manual `showVectorToolsPanel` localStorage flag (read on init, written
  on every toggle); panel state now lives in the persisted dock layout. The toolbar's
  Vector-Tools button `active` highlight was rewired from `store.showVectorToolsPanel`
  to `isPanelOpen('vectorTools')` (an external read that would otherwise freeze).
- **Scope correction to the migration plan:** the earlier "remaining" list named
  `animation`, `ds-ops`, and `scene-timeline` as if dockable — they are not. The
  animation panel is embedded *inside* the property panel (it migrates with it);
  `ds-ops-panel` is a presentation-mode contextual overlay (no toggle, and the dock
  is hidden in presentation mode); `scene-timeline` is a full-width fixed bottom bar
  that doesn't fit a narrow left/right dock. The only remaining true dock candidates
  are **Property** and **Layers**.
- `tsc -b` and `npm run build` both green.

## Breaking changes / migration
- None. (The old `showVectorToolsPanel` flag and the `vectorToolsSize` /
  `showVectorToolsPanel` localStorage keys are now unused; panel state lives in the
  persisted dock layout.)
