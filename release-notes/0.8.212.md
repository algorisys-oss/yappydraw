# 0.8.212 — the i18n ratchet now runs (2026-08-21)

## Highlights
- Teaching Mode's menu strings are **translated** into all four locales, not just English.
- The i18n ratchet — which existed, worked, and had nothing to invoke it — now **blocks on
  commit**.

## Fixes
- **#311 — three hardcoded strings shipped past the guard built to catch them.** Teaching Mode
  (v0.8.207) added a menu label, a button `title` and an `aria-label` in English, taking
  `menu.tsx` from 120 to 122 hardcoded strings. `scripts/i18n-lint.mjs` would have failed on
  exactly that, but nothing ran it, so it shipped across four releases (0.8.207 → 0.8.210).
  The plan had flagged the gap in Phase 1a — *"needs a workflow, or a pre-commit hook, when one
  is set up"* — and that sentence sat in the doc while the count climbed.

## Features
- New **`menu.*` namespace** in `en`, `de`, `es` and `ja`, with real translations
  (`Unterrichtsmodus`, `Modo enseñanza`, `授業モード`) — not English placeholders. `en.ts`
  defines the `Dictionary` type, so a locale missing a key is a compile error; a placeholder
  would have been a silent lie in three languages.
- This makes `menu.tsx` the first file in the top-bar group to call `t()` at all. It is step 4
  of the plan's extraction order (§3.2) and remains otherwise un-extracted — 119 strings to go
  in that file alone.

## Internal / tests / docs
- **`.githooks/pre-commit` gained an i18n block that blocks**, unlike the repo-map refresh
  beside it which deliberately never does. It fires only on a real increase, and only when the
  commit touches `frontend/src/components/` (the directory the linter scans), so unrelated
  commits pay nothing. The failure message names both ways out — extract with `t()`, or
  `node scripts/i18n-lint.mjs --update` when the string genuinely is not user-facing — and
  `--no-verify` remains the escape hatch.
  *Enable per clone with `git config core.hooksPath .githooks` if you have not already.*
- Baseline tightened **1629 → 1628**. Extracting three strings and adding none back left
  `menu.tsx` one better than it started, and a ratchet that does not bank an improvement is
  only half a ratchet.
- Suite: 1075 tests across 73 files, including the 73 i18n tests that assert locale parity.

## Breaking changes / migration
None.
