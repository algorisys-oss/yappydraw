# 0.8.104 — Animated GIF export (2026-07-14)

## Highlights
- **Export → Animated GIF.** Export your animated page as an infinitely-looping GIF — same
  page-framed offline render as the MP4 export, so it captures exactly the page (animations
  playing), regardless of zoom/pan. GIF parity with HappyPaint.

## Features
- **Animated GIF export** on page documents (designs/slides): Export dialog → **Animated GIF** +
  the Duration field. Encodes with `gifenc` (per-frame 256-colour quantize, infinite-loop block),
  12 fps default, long side capped at 960px to keep file sizes sane (~0.5 MB for a 2s clip).
  API: `Yappy.exportGif(seconds?, fps?)`.

## Internal / tests / docs
- Refactor: the MP4 and GIF exports now share one `makePageFrameRenderer` (recording-manager), so
  the two paths can't drift in rendering semantics. Frames are sampled in real time on purpose —
  stick figures pose from the live engine clock.
- New dependency: `gifenc` (~5 KB, MIT) with a local `gifenc.d.ts` (ships no types).
- New specs: `gif-export-check.spec.ts` (page-framed looping GIF verified with ffprobe + NETSCAPE
  loop block), `timelapse-check.spec.ts` (records edits → mp4 download; documents the real-time
  export pacing stretched to the target duration).
- Help doc (Animated Stick Figures → export section) covers the GIF option; learnings logged.
- Player bundle rebuilt.

## Breaking changes / migration
- None.
