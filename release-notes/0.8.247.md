# 0.8.247 — Editable QR codes (2026-09-13)

## Highlights
- **QR codes you can keep editing.** Add a QR code to a poster, flyer, slide or card and change
  its link, colours, error correction or margin at any time. The code regenerates on every
  change, so a typo in a URL no longer means making the code again somewhere else.
- **Warnings before you print.** Yappy flags a code that may not scan: no data, data too long
  for the chosen error-correction level, colours too close in contrast, or a code lighter than
  its background.

## Features
- New `qrCode` element: Elements panel → Shapes → **QR Code**, Elements search (*qr*,
  *barcode*, *scan*), or the command palette.
- Properties: **QR Data**, **Error Correction** (L 7% / M 15% / Q 25% / H 30%), **Quiet Zone**
  (0–10 modules). The code uses the Stroke colour; the area behind it uses Background
  (transparent allowed).
- The code stays square and centred inside a stretched element.
- Draws identically in Sketch and Architectural styles and is not recoloured by dark mode — a
  hand-drawn wobble or a lightened module would stop it scanning.
- SVG export writes vector squares in both styles (sketch elements otherwise embed a bitmap).
- **API:** `Yappy.createQrCode(x, y, w, h, data?, options?)`, `getQrCodeData(id)`,
  `setQrCodeData(id, data)` (undoable), `getQrCodeWarnings(id)`.

## Internal / tests / docs
- New dependency `uqr` 0.1.3 (MIT, ~5 KB, no dependencies). Encoding uses `border: 0`; the
  quiet zone is applied by the element's own layout.
- The module matrix is cached (64 entries keyed by level + data); dark modules are merged into
  horizontal runs and filled as one path, avoiding hairline seams at fractional zoom.
- `utils/qr-code.test.ts` (17 bun tests: encoding, runs, layout, contrast, warnings) and
  `tests/qr-code.spec.ts` (5 Playwright tests: finder/timing patterns with byte-identical
  sketch/architectural output, API + undo, property-panel warnings, vector SVG export,
  Elements search insert). Exported codes were also decoded with `jsqr` during development.
- New Help → **QR Codes** page; `api.ts` documented; `todo.md` item closed.
