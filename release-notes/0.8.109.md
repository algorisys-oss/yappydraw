# 0.8.109 — Google Drive sign-in fix

**Date:** 2026-07-18

## Highlights

- Google Drive sign-in works again — the OAuth popup no longer hangs on
  "Connecting…" after you sign in.
- Removed the legacy "Workspace" options from the Load/Save dialog.

## Changes

- **Removed "Save to Workspace" and "Open from Workspace" from the Load/Save
  dialog.** The old internal-browser "workspace" store is superseded by the "My
  Drawings" local gallery (v0.8.108) and Ctrl/Cmd+S. Use My Drawings to keep and
  reopen drawings in your browser; `.yappy`/`.json` export/import remains for
  file-based backups.

## Fixes

- **Google Drive OAuth callback served the app shell instead of the callback
  page.** The PWA service worker's `navigateFallback` was catching the
  `/oauth-callback.html?state=…&code=…&iss=…` navigation and returning the
  precached `index.html` app shell (the callback URL is query-less in the
  precache, and the OAuth query string made it miss the cache). The callback
  script therefore never ran, no auth code was posted back to the opener, and
  the connect dialog stayed on "Connecting…" forever. Added
  `navigateFallbackDenylist: [/oauth-callback\.html/]` so the callback bypasses
  the app-shell fallback and loads the real static page.

## Internal / notes

- The fix ships in the service worker. Because the app uses
  `registerType: 'prompt'`, already-loaded clients keep their old SW until it
  updates on the next version-tap hard refresh — the fix applies immediately for
  new visits and after that refresh for existing ones.

## Breaking changes / migration

None.
