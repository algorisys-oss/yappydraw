# 0.8.58 — Dockable panels Phase D: History & Swatches migrated (2026-07-10)

## Highlights
- The **History** and **Swatches** panels are now first-class **dockable panels** —
  dock them to an edge, float them, collapse them, and the layout persists.

## Features
- **Phase D migration (History + Swatches):** both panels moved onto the shared
  dock chrome. Opening them the usual ways (menu, `Alt+H` / `Alt+W`, the scripting
  API) now opens the *dockable* version — drag it to the left/right edge to dock,
  reorder it in a stack, or float it. Swatches' "add swatch" action moved into a
  small in-body toolbar (the dock title bar carries dock/float/collapse/close).
- Under the hood: a `dock-layout.setPanelOpen()` bridge lets the existing
  `toggleXxxPanel` actions drive the dock store, so every entry point keeps working
  and the menu checkmarks track the real dock state.

## Internal / tests / docs
- Verified via Playwright: both panels open dockable from their hotkeys, render
  correctly body-only, Add-swatch works, no legacy floating chrome lingers, and
  toggle-off hides them.
- `docs/dockable-panel-system-plan.md` updated with the per-panel **migration
  recipe** and the remaining panel list (property/layers are the most coupled —
  scheduled last).

## Breaking changes / migration
- None. (The old `showHistoryPanel` / `showSwatchesPanel` settings flags are now
  unused; panel state lives in the persisted dock layout.)
