# 0.8.56 — Brand mascot + full mobile/tablet responsive pass (2026-07-10)

## Highlights
- **New YappyDraw mascot** — a paint-brush bicycle (handlebar grips are brushes,
  ringed with paint sprinkles). It's the boot splash *and* greets you on the
  welcome screen.
- **Mobile/tablet responsive pass** — phone controls that were untappable are now
  reachable, and floating panels/dialogs no longer run off-screen.

## Features
- **Boot splash mascot** (`frontend/index.html`): hand-authored animated SVG
  (floating bike, spinning spokes, loading dots, wordmark) painted before the JS
  bundle loads, then faded out on mount. Honours `prefers-reduced-motion`.
- **Reusable `<YappyMascot>`** (`frontend/src/components/mascot.tsx`) now sits atop
  the welcome screen alongside the existing feature list.

## Fixes
- **Phone: Settings / Properties / Help were untappable** — the bottom-docked tool
  toolbar (z-index 10002) intercepted their taps. The three buttons are now a
  single `.floating-tools-cluster` that relocates to a top-right vertical rail on
  phones. (#141)
- **Phone: property bottom-sheet was hidden behind the toolbar** — lifted clear of
  the toolbar/status bar on phones; tablets keep it at the bottom. (#142)
- **Phone: off-screen / overflowing surfaces** — Settings modal gained
  `max-width:92vw`; the Stick-figure, Brand-kit, and Behaviors panels (previously
  positioned by fixed desktop offsets) become full-width bottom sheets. (#143)

## Internal / tests / docs
- Includes the previously-unreleased **dockable-panel system Phase A foundation**
  (dock store, container + panel chrome, Effects pilot panel).
- Verified across phone (390×844), tablet portrait (820×1180) & landscape
  (1180×820), and desktop (no regression) via Playwright + screenshots.
- Learnings + bug-fixes logs updated; version bumped in `package.json`,
  `tauri.conf.json`, and `Cargo.toml`.

## Breaking changes / migration
- None.
