# 0.8.214 — Settings speaks four languages (2026-08-21)

## Highlights
- The **Settings dialog** is translated into Español, Deutsch and 日本語 — 63 strings, every
  section from General through Cloud Storage. It was the largest tractable block of English
  left in the UI.

## Features
- 63 new `settings.*` keys across all four locales: section headings, every label, every
  `<option>`, and the long explanatory tooltips (stroke stabilization, print bleed, mindmap
  auto-layout, time-lapse auto-record) — the strings that most needed translating, since they
  are the ones that explain rather than label.
- `settings.historyDepthTitle` is the first **interpolated** key outside the toolbar:
  `t("settings.historyDepthTitle", { min, max, def })` renders the range from the same
  `HISTORY_DEPTH_*` constants the store clamps with, so the tooltip cannot drift from the
  enforced bounds in any language.

## Internal / tests / docs
- Ratchet **1628 → 1565**; `settings-dialog.tsx` **76 → 13**. The 13 that remain are deliberate
  and covered by the glossary rule (§3.3): eight numeric-plus-unit options (`640 px`, `10 s`)
  where the notation is universal, and the `Google Drive` brand name.
- Translated properly rather than scaffolded with English placeholders. Placeholders were the
  tempting shortcut and would have been a regression: ~63 untranslated keys drops `de`/`es`/`ja`
  from 100% to about 92% coverage, under the 95% `READY_THRESHOLD`, which would pull three
  shipped languages out of the language picker entirely.
- Suite: 1085 tests across 74 files, including the 83 i18n tests that assert locale parity.

## Known limitation
These translations are **machine-grade and unreviewed by a native speaker** — that is §5 step 2
of the plan and it has not happened for any locale yet. They are consistent with the glossary
(shortcut letters, product and standard names, and API identifiers left untouched) and follow
graphics-application conventions, but a German or Japanese designer should read them before
anyone claims the UI is localised. The dense panel labels are where overflow will show up first.

## Breaking changes / migration
None.
