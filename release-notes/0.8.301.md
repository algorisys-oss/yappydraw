# 0.8.301 — Hardening: undo for slide settings, PowerPoint tables, accessible exports (2026-11-01)

## Highlights
- The first hardening release of November: bugs found by probing whole bug classes and by
  comparing PowerPoint imports with LibreOffice's renders, plus the open items from v0.8.300.

## Fixes
- **#467** Changing a slide's transition or background wasn't an undo step: Ctrl+Z undid the action
  before it and left the change in place (the undo snapshot shared the transition object). The ⚡
  picker, the slide's Properties, canvas texture/themes and the API's `updateSlideTransition` /
  `updateSlideBackground` now record one step each.
- **#468** PowerPoint tables: a cell after a merged pair landed a column too far right; rows
  stored too short (even 0) collapsed — they now grow to fit their text; a cell spanning rows takes
  their full height.
- **#469** Exported HTML presentations used a player last built in v0.8.255, which drew no data
  charts. Rebuilt.
- **#470** Editing shrink-to-fit text grew its box, so it stopped shrinking. The box keeps its size
  and the editor shows the fitted text as you type.

## Features
- **PowerPoint built-in table styles** a file names without defining (common in files from other
  apps): Medium Style 2 and Light Style 1 in the accents seen in PowerPoint's own files, and Table
  Grid. Style borders are drawn per edge (outer rules vs lines between cells).
- **Vertical text from PowerPoint** (shapes and table cells): turned a quarter either way, or
  stacked; rows grow to fit. (LibreOffice draws some of these rows taller; PowerPoint wasn't
  available to compare.)
- **Alt text in PDF** (invisible text over each object, read by screen readers, search and copy)
  and in the **HTML presentation** (each slide read out as it appears).

## Internal / tests / docs
- Probes in `temp/` for slide state; three-way renders (old / new / LibreOffice) over the 34 table
  decks of LibreOffice's corpus: 9 closer, none worse.
- `builtin-table-styles.ts`, `pdf-alt-text.ts`, `readingOrder()`; specs `slide-undo`, extended
  `text-fit` and `accessibility`; quiet xmldom in the broken-input unit test.
- Help: Workspace (PowerPoint import, Accessibility), Basic Shapes (shrink to fit).

## Breaking changes / migration
- None.
