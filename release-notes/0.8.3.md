# 0.8.3 — Arcade Hub, part 2: Code is a view, and a New Game chooser (2026-07-07)

## Highlights
- The game **script is no longer a standalone thing**. A game has one script, and
  **Code** is now just its lowest altitude — a fourth view alongside Simple, Graph
  and Blueprint. And starting a game is a clear choice up front via **New Game**.

## Features
- **Code view + authoring mode:** the switcher gains a **Code** tab. Visual games
  show the script **generated from the blocks, read-only** (a learning bridge);
  **Eject to code** (one-way) freezes it as the source so you can hand-edit it (the
  blocks stay but stop compiling). Code-authored games get the editable editor and
  starter templates. Runtime is mode-aware: a code game runs its authored script, a
  visual game runs the generated one.
- **New Game chooser** (**Menu → Game → New Game…**): pick **Blank**, a starter
  (**Pong / Catch the Stars / Platformer**), or **Code (Advanced)** — each opens a
  fresh game in the right editor, so the authoring mode is obvious from the start.

- None.

## Internal / tests / docs

- New `components/new-game-dialog.tsx` (+ signal module + css); `game-script-dialog`

## Breaking changes / migration
- None. Existing games load as visual (blocks compile as before); the retired
  "Advanced Script…" menu item is now the **Code** view.
