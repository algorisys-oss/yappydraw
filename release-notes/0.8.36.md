# 0.8.36 — Quick-toolbar font-size slider steps by 1 (2026-07-09)

## Fixes
- **Font Size mini-slider stepped by 2.** In the shape/quick toolbar, the Font Size
  slider's arrow keys (and number spinner) changed the size by 2 at a time. The
  quick-toolbar's own control config declared `fontSize` with `step: 2`; both entries
  are now `step: 1`, so arrow-left / arrow-right nudge by 1. Other intentionally-coarse
  sliders (opacity, filters, angle) are unchanged.

## Breaking changes / migration
- None.
