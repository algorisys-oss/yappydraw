# 0.8.305 — Scatter, bubble, radar, stock and combination charts (2026-11-05)

## Highlights
- Five new data chart types — **Scatter**, **Bubble**, **Radar**, **Filled radar** and **Stock** —
  editable in the Chart data window and drawn in both styles.
- **Combination charts**: columns, lines and areas in one chart, any series on a **right-hand
  axis**. **100% stacked** charts.
- PowerPoint charts of all these kinds now open as editable charts, and go back to PowerPoint as
  real charts.

## Features
- **Scatter / Bubble:** the first column holds X values (numbered points when it isn't numbers);
  an X axis that doesn't start years at zero; scatter **Lines** and **Smooth**; a **Size** column
  per bubble series (bubble area).
- **Radar / Filled radar:** a spoke per category from 12 o'clock.
- **Stock:** Open, High, Low, Close (or High, Low, Close) — high-low lines with boxes hollow on
  a rise and filled on a fall, or a close tick.
- **100%** option (with Stacked): every stack its category's total, the axis 0–100%, data labels
  still showing values.
- **Combination charts:** on a Column, Line or Area chart, each series' own type and a **Right
  axis** box under its name.
- **PowerPoint import** reads scatter (X/Y values, line style), bubble (sizes), radar, stock,
  100% stacked and combination charts (series types and secondary axis); export writes them
  natively, with the data in the embedded workbook.
- `Yappy.insertChart({ kind })` starts from that type's sample.

## Fixes
- **#480** Dates on a PowerPoint chart's category axis came in as day numbers (45658); they show
  as dates, on every chart type.
- **#481** A PowerPoint chart with two plot groups of the same type lost the second group's
  series and warned about a combination chart.
- **#482** Data labels on stacked bar charts sat past their segment; they are centred inside it.
