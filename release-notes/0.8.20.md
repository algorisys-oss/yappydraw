# 0.8.20 — More stick-figure poses + monochrome preview fix (2026-07-08)

## Highlights
- **18 new figure poses** deepen the library (now 225 assets with variants), and
  the **Mono** toggle now previews correctly in the panel.

## Features
- New poses across every theme:
  - **Daily** — stretching, shrugging, reading a book
  - **Office** — stressed, writing on a board, announcing (megaphone)
  - **Meetings** — brainstorming (sticky notes), showing a laptop
  - **Travel** — skateboarding, reading a map
  - **Social** — high five, open arms, meditating
  - **Services** — teacher, painter, mechanic, security guard
  Each variantable pose ships in all four character variants.

## Fixes
- **Monochrome preview** — with the **Mono** toggle on, panel thumbnails now show
  figures the way they'll actually drop (accent fills stripped). Previously props
  that set a bare fill (laptop screen, briefcase, phone) still previewed in colour
  even though they dropped monochrome. The preview and the drop now use the same
  accent classifier.
- Clearer **mechanic** wrench shape.

## Internal / tests / docs
- `toMonochromeSvg` strips any accent fill (tagged `data-sf-role="accent"` or
  classified by `roleFromFill`), matching insert. 18 poses appended to `poses.ts`.
  Help doc intro no longer hard-codes a figure count. Learnings recorded, repo map
  refreshed.

## Breaking changes / migration
- None.
