# 0.8.128 — Startup tool & pointer settings; My Drawings keeps every drawing (2026-07-21)

## Highlights
- Two new **Settings → Pen & Input** options: **Default Tool** (Ink Brush by default) and
  **Canvas Pointer** (Crosshair by default).
- `Ctrl+S` on an untitled drawing now **asks for a name** instead of filing it as "Untitled".
- **My Drawings** keeps every drawing — it used to hold only the most recent one.

## Features
- **Default Tool.** Choose which tool is active when Yappy opens: Ink Brush (new default),
  Fineliner, or Select. Changing it switches to that tool immediately so the toolbar matches,
  and it is remembered across sessions. Scriptable: `Yappy.setDefaultTool('fineliner')`,
  `Yappy.getDefaultTool()`.
- **Canvas Pointer.** Choose the cursor shown over the canvas while a drawing tool is active:
  Crosshair (+) (new default), Concentric circle, or Arrow (the previous behaviour). Select and
  Pan keep their own cursors, and contextual cursors — resize, rotate, move, crop — always win
  over the preference. Scriptable: `Yappy.setPointerStyle('circle')`, `Yappy.getPointerStyle()`.
- **Name-on-first-save.** `Ctrl+S` on an untitled drawing opens the Save dialog with the name
  pre-selected, so typing replaces it. Once named, every later `Ctrl+S` saves silently over that
  name and never asks again.

## Fixes
- Bug #184: **My Drawings only ever held the most recent drawing.** Save → File → New → save
  overwrote *and renamed* the previous entry, because a new document stayed pointed at the old
  library entry. Loading or resetting a document now detaches from the entry; only opening a
  drawing re-attaches — which also fixes the same hole on open-from-disk, paste-JSON, cloud load
  and template restore.
- Bug #185: **saving then choosing File → New still asked "save or discard?"** for work that had
  just been saved. My Drawings saves now clear the unsaved-changes flag, as workspace saves did.
- Bug #186: the compact toolbar's pen button was pinned to Fineliner, so no button highlighted
  while the Ink Brush was active and clicking it silently switched pens. It now tracks the
  selected pen for its highlight, icon and click target.

## Internal / tests / docs
- `activeDrawingId` moved to its own leaf module (`storage/active-drawing.ts`) so `app-store`
  can clear it in `loadDocument` — `drawings-store` imports `app-store`, so the dependency could
  only run the other way. Re-exported from `drawings-store`, so no caller changed.
- Verified in a real browser via Playwright against the running app (settings render, cursor
  switches per style, toolbar highlight + icon follow the selected pen, save prompt/round-trip,
  two drawings surviving in My Drawings). The specs were scratch and are not committed.
- Help docs: new "Saving to My Drawings" and "Settings — Pen & Input" sections in the Workspace
  doc.

## Breaking changes / migration
- **Yappy now opens with the Ink Brush active, not Select.** A click on empty canvas draws
  rather than selects. Set Settings → Pen & Input → Default Tool to **Select** for the old
  behaviour.
- The canvas cursor over drawing tools is now a crosshair. Choose **Arrow** under Canvas Pointer
  to restore the previous look.
