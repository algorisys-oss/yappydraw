# 0.5.29 — Faithful background removal + image model setting (2026-07-04)

## Highlights
- **Remove Background (AI) no longer restyles your subject** — the original
  pixels are preserved; the AI result is used only as a transparency mask.
- **AI Settings gains an Image Model selector** (GPT Image 1 / DALL·E 3) so
  the model used by AI Image is an explicit choice, not a hardcoded default.

## Features
- AI Settings → OpenAI → **Image Model**: pick *GPT Image 1* (best quality,
  requires a verified OpenAI organization) or *DALL·E 3*. Menu → AI Image…
  honors the choice, still falling back to DALL·E 3 if the configured model
  errors on your account. The setting is per-provider, ready for Gemini/Imagen.
- `Y.removeBackground(id, { preserveOriginal: false })` — opt back into the
  AI's regenerated image if you prefer its rendering over the masked original.

## Fixes
- **Remove Background restyled the foreground** (added effects, repainted
  textures). Cause: `gpt-image-1` edits regenerate the whole image rather than
  masking it. Fix: (1) the original image is composited with the AI output via
  `destination-in`, so only the AI's alpha channel is used and the subject
  stays pixel-identical; (2) `input_fidelity: high` is requested (with retry
  for accounts that reject the param) plus a hardened no-restyling prompt;
  (3) a degenerate-mask sanity check falls back to the AI output.

## Internal / tests / docs
- Pixel-level Playwright test proves the subject keeps its original colors
  even when the AI returns a restyled image; `input_fidelity` request
  assertion; 6 AI specs green (OpenAI mocked).
- Help doc (Design Studio → AI assists) and `docs/bugs/bug-fixes.md` updated.

## Breaking changes / migration
- None. Existing configs default to GPT Image 1, matching prior behavior.
