# 0.8.11 — Slingshot & Platformer play right, and the Play button fits (2026-07-07)

## Highlights
- **Slingshot** is fully playable now: you can fire every bird (not just the first),
  and a full pull actually reaches the fort.
- The **Platformer** sample is a real little game — run and jump across floating
  platforms, grab the coins, reach the flag to win.
- Fixed the game builder header so the **▶ Play** button is no longer clipped.

## Features
- **Platformer example rebuilt into a level** (`game/behavior-examples.ts`): three
  floating platforms, three coins (+100 each), and a goal flag that wins the game;
  falling off the screen is game over. Platform gaps/heights are tuned to the jump
  arc so every jump is makeable.
- **Real platformer jump feel** (`game/behaviors-to-script.ts`): `jump` now only
  fires while the sprite is grounded — no more floaty mid-air multi-jumps
  (non-gravity `jump` uses are unchanged). Snappier arc (`GRAV 1500→2200`,
  `JUMP 560/780/1000 → 680/860/1040`).

## Fixes
- **Slingshot "one shot then stuck":** the next bird only spawned once the fired one
  *settled*, but the settle test read a pre-clamp velocity that gravity kept above
  the threshold every frame, so a resting bird never settled. Now judged from the
  post-clamp grounded state → the next bird reliably respawns.
- **Slingshot underpowered:** max launch range (~640px) was shorter than the
  distance to the pigs (~900px). Bumped `POWER 7.5→10.5`, `MAXPULL 135→145`
  (range ~1450px) so a full pull reaches the fort.
- **Play button clipped:** in the 340px behaviors panel the view switcher + Play +
  Close overflowed. The switcher now compacts to icons (active tab keeps its label,
  tooltips name the rest) so everything fits one row; wide Graph/Blueprint/Code
  headers keep full labels.

## Internal / tests / docs
- New real-runtime/regression specs: `tests/slingshot-repro.spec.ts` (fire →
  respawn → fire again, and full-power reach), `tests/platformer-repro.spec.ts`
  (compiled example runs, hero moves & jumps, level content present), and
  `tests/behaviors-header-fit.spec.ts` (Play button fully inside the panel).
- Arcade help doc updated (grounded jump, the Platformer level, Slingshot levels);
  learnings and bug-fixes logged.

## Breaking changes / migration
- None. Gravity/jump-tuning changes affect gravity-based games (e.g. the Platformer
  starter); other games are unchanged.
