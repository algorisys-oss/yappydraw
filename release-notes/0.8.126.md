# 0.8.126 — Smart shapes keep your pen (2026-07-21)

## Highlights
- Hold-to-correct no longer drops you into the Select tool. Your pen stays in your hand.

## Features
- **Smart shapes keep the active tool.** After a freehand stroke snaps to a clean shape, the
  fineliner / ink brush / marker you were drawing with stays selected, so you can carry on
  sketching instead of re-picking the tool after every corrected shape. The snapped shape is still
  left selected, so the quick toolbar and Properties panel target it if you want to restyle it.
  Handle-dragging and marquee are gated on the Select tool, so the live selection is inert while a
  pen tool is active — the next stroke simply draws and replaces it.

## Fixes
- Bug #181: smart-shape snap kicked you out of the pen tool (`fireShapeHold` called
  `setSelectedTool('selection')`). See `docs/bugs/bug-fixes.md`.

## Internal / tests / docs
- The removed tool switch was implicitly guarding the heal-on-move path: `isPenDrawingTool()`
  going false is what stopped a still-in-contact pointer stylus (Surface, Wacom) from re-opening a
  stroke after the snap. `smartShapeSuppress` — which previously only covered the iPad TouchEvent
  path — is now set unconditionally after a snap, and its reset moved out of the pen-only branch of
  `handlePointerDown` so a mouse-driven snap clears it too.
- Help docs: Smart Shapes section of the Drawing Tools doc notes the tool now persists and points
  at `V` for Select.
- Learnings entry on implicit guards hiding behind a line you're about to delete.

## Breaking changes / migration
- None. If you relied on landing in the Select tool after a snap, press `V`.
