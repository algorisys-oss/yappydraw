# 0.8.21 — Animated stick figures for storytelling (2026-07-08)

## Highlights
- Stick figures can now **move**. Drop a figure that walks, waves, talks, points or
  jumps — a real little skeleton with bending knees and elbows and **planted feet** —
  and make it **walk along a path you draw**. Compose a scene, then bake any pose to
  editable vectors.

## Features
- **Animated figures** — a new **Animated** tab in the Stick Figures panel with six
  looping motions: **Idle, Walk, Wave, Talk, Point, Jump**. Click one and the figure
  appears already playing on the canvas. It's a normal object — move, scale, rotate,
  recolour (stroke colour) and switch to Sketch style; it keeps animating.
- **Figure controls** (with the figure selected): switch **clip**, **Play/Pause**,
  **Flip** facing (left/right), and **Bake** the current frame to editable paths.
- **Walk along a path** — draw a route with the Line/Pen/Pencil tool, select the
  figure **and** the path together, and click **“Walk this path”**. The figure travels
  the route with its **feet planted** (no skating — stride is synced to distance),
  automatically **facing the direction of travel**, looping. Reshape the path and it
  re-routes; “Stop following path” releases it.
- **Bake to paths** — freeze a moving figure's current frame into an ordinary editable
  grouped figure (ungroup to tweak a limb, drop into a diagram, etc.).
- **API** — `insertAnimatedFigure(clip, opts?)`, `setAnimatedFigureClip`,
  `setAnimatedFigurePlaying`, `flipAnimatedFigure`, `bakeAnimatedFigure`,
  `listStickFigureClips`, `attachFigureToPath(figureId, pathId, {dur})`,
  `detachFigurePath`.

## Fixes
- **Convert to Path** no longer shifts a **line / curved / freehand stroke** down-and-
  right by half its bounding box. Those elements store their points in element-origin
  coordinates; `shapeToPath` was applying the centre-offset meant only for the centred
  geometry other shapes emit. Closed shapes were already correct.

## Internal / tests / docs
- New animation rig under `library/stick-figures/anim/` — an 11-joint skeleton with
  forward kinematics + 2-bone foot IK (`rig.ts`), six procedural motion clips
  (`clips.ts`), and path-follow sampling (`path-follow.ts`). New `stickRig` element type
  + renderer (`shapes/renderers/stick-rig-renderer.ts`, both render styles), driven by
  the global clock via the canvas force-ticker (scrubbable, pause-aware). Field
  `DrawingElement.stickRig` (+ migration passthrough); hit-testing bbox fallback.
- New help topic **“Animated Stick Figures”** with a step-by-step tutorial (add a
  motion → controls → walk a path → bake). Learnings and bug log updated.

## Breaking changes / migration
- None. The `stickRig` field is optional and additive.
