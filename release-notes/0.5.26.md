# 0.5.26 — Touch Type works with letter spacing (2026-06-30)

## Fixes
- **Couldn't Touch Type the later letters after increasing letter spacing.** The letters render spread out, but the hit-test measured their positions *without* spacing — so it thought they were bunched on the left and clicks on the spaced-out letters missed. The Touch Type hit-test now accounts for letter spacing, so every letter is clickable wherever it's drawn.

## Breaking changes / migration
- None.
