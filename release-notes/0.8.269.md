# 0.8.269 — Every font weight, one-axis text scaling, a repeating eyedropper (2026-09-29)

## Highlights
- The built-in fonts now come in **every weight** — Inter, Poppins, JetBrains Mono and Source Code
  Pro from Thin to Black, Merriweather Light to Black — and Google fonts list exactly the weights
  they have.
- **Shift + side handle** stretches text horizontally or scales it vertically.
- The **eyedropper stays on** between picks, with a live preview of what it would pick.
- **Save to disk** asks where to save.

Phases 4 and 5 of Anshika's vector-workflow review.

## Features
- **Font weights.** The Style menu lists every real weight of the built-in fonts (18 styles for
  Inter). A Google font added by name loads and lists every weight Google has for it.
- **Width.** Variable font files with a width axis get a Width control (Ultra-condensed …
  Ultra-expanded), using the font's real condensed/expanded shapes. API: `fontStretch`.
- **Text scaling on one axis.** Shift + left/right handle = horizontal scale; Shift + top/bottom =
  vertical scale with the width held. Plain side-drag still sets the wrap width.
- **Repeating eyedropper** (style and colour). Stays armed; Esc, Enter, right-click (no context
  menu) or, for style, a click on empty canvas ends it. A chip beside the cursor previews the
  colour/hex, or the fill and stroke a style pick would copy. Scripted picks stay one-shot.
- **Colour picker** modes labelled **Square | Wheel**.
- **Save to disk** (`.yappy` / JSON) uses the system Save dialog in Chrome, Edge and the desktop
  app; the share sheet on phones; a download elsewhere.

## Fixes
- SVG export turned Light/SemiBold/Black into Regular/Bold, and shape labels lost their weight,
  italic and width entirely.
- The colour picker's pipette and screen-pick buttons were blank (icons squeezed to zero width by
  a global button padding) — the eyedropper's own entry point was invisible.
- Create Outlines outlined non-bundled weights of the built-ins with the Regular/Bold file; it now
  explains how to outline them instead.
- Saving a drawing revoked its download URL synchronously, which can cancel the download.

## Internal / tests / docs
- `config/builtin-fonts.ts`: one stylesheet URL for index.html, SVG/HTML export and the SDK, with a
  test that keeps index.html identical.
- `font-axes.ts` reads any `fvar` axis (`wdth` as well as `wght`); `custom-fonts.ts` discovers
  Google weights from the stylesheet.
- Tests: `builtin-fonts.test.ts`, `tests/text-weights-axis-scale.spec.ts`,
  `tests/eyedropper-repeat-save.spec.ts`; `tests/eyedropper.spec.ts` updated for the repeating pick.
- Help: font weights and width, Shift + side handles, repeating eyedropper, Square | Wheel,
  "Saving a file to your computer".

## Breaking changes / migration
- The eyedropper no longer switches off after one canvas pick (press Esc when done). Scripted
  `applyEyedropperFrom` / `pickColorFromCanvas` are unchanged.
- Create Outlines on a built-in font at a weight other than Regular or Bold (including 500/600,
  which used to snap to Bold) now stops with a message instead of outlining the wrong weight.
