# 0.5.11 — Make Pattern from Selection (2026-06-29)

## Highlights
- **Make Pattern from Selection.** Turn any selected artwork into a repeating
  pattern tile. Right-click → **Make Pattern from Selection** captures the
  selection and drops a new rectangle beside it, filled with that custom pattern
  so the repeat is immediately visible.

## Features
- New `type: 'custom'` pattern fill that tiles a raster capture of selected
  elements (stored on `patternFill.tile` with `tileWidth`/`tileHeight`). The
  PATTERN editor shows the source thumbnail and keeps **Scale** / **Angle**.
- Context menu: **Make Pattern from Selection** (available with 1+ objects
  selected, next to Create Symbol).
- `window.Yappy.createPatternFromSelection(ids?)` — captures the selection (or
  the current selection) and returns the new preview rectangle's id.

## Internal / tests / docs
- New `utils/pattern-capture.ts` (offscreen `renderElement` capture → data URL),
  kept separate from `pattern-fill.ts` to avoid an import cycle. `pattern-fill.ts`
  decodes the custom tile via the shared image cache (async load + redraw),
  mirroring image fills.
- Help doc: **Make Pattern from Selection** subsection; learnings + roadmap updated.
- Verified in-browser: a circle+square selection tiles correctly into the preview
  rectangle (3×3 repeats), scale/angle apply, zero console errors.

## Breaking changes / migration
- None. Additive; `patternFill.tile` rides through the existing passthrough.

## Known limitations
- Custom (and built-in) pattern fills only export as a vector SVG `<pattern>` in
  **Architectural** render style; **Sketch**-style fills still route through
  rough.js (which ignores complex fills), so a default-sketch preview rect omits
  the pattern in SVG export. On-canvas rendering is unaffected.
