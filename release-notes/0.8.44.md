# 0.8.44 — Tidy Canvas Theme + Texture (no duplication) (2026-07-09)

## Fixes / polish
- The Canvas Settings panel had both the new **Canvas Theme** picker (which sets
  background + texture) and a separate **Canvas Texture** dropdown, which read as
  duplicated. The texture control now lives as a single **Fine-tune → Texture** row
  directly under the Theme picker; the standalone dropdown is removed. A short hint
  clarifies that a theme sets background + texture, tweakable here or in the Background
  section below.

## Breaking changes / migration
- None. `canvasTexture` still persists and behaves the same; only its UI placement moved.
