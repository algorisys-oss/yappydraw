# 0.8.19 — Stick-figure browsing ergonomics (2026-07-08)

## Highlights
- Faster ways to work the Stick Figures library: a **Colour / Mono** drop toggle,
  **Favourites**, **Recents**, and **keyboard** navigation. Completes the planned
  Phase 3 (recolour ergonomics) for the library.

## Features
- **Colour / Mono toggle** (next to the search box) — drop figures with their flat
  colour accents, or in pure **monochrome** (outline only). The choice is remembered
  across sessions. Also available via the API: `insertStickFigure(id, { monochrome:
  true })`.
- **Favourites** — tap the ★ on any figure to save it; the new **Favourites** chip
  gathers your starred figures. Persisted in the browser.
- **Recents** — every figure you add is remembered under the **Recent** chip, so
  frequently-used poses are one click away.
- **Keyboard navigation** — Tab into the thumbnail grid, move with the arrow keys,
  and press **Enter** (or Space) to add the focused figure.

## Fixes
- None (feature).

## Internal / tests / docs
- New `library/stick-figures/prefs.ts` — favourites / recents / colour mode as
  localStorage-backed Solid signals. Monochrome is applied at insert by stripping
  `accent`-role fills (no separate art). Grid cells became focusable `div`s so a
  favourite-star button can nest legally and arrow-key roving focus works. Help doc
  and keywords updated; learnings recorded.
