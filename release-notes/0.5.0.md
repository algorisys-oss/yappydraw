# 0.5.0 — Illustrator-parity baseline + version reset (2026-06-27)

Versioning reset to 0.5.0. This baseline consolidates a large wave of
Illustrator-parity work (previously shipped internally as 0.27.x) plus a
test-infrastructure overhaul. Everything below is reachable from the
`window.Yappy` API and, where noted, the Command Palette (Ctrl/⌘+K).

## Highlights
- Big jump in Illustrator parity: stroke gradients, an effects toolbox, a Colour
  Guide, outline/trim views, richer artboards, and tablet-friendly input.
- The test suite is now self-hosting and was made collectable again.

## Features
**Input & editing**
- Math in numeric fields (`200-50%`, `+10`, `*2`, `/3`, `(4+1)*8`).
- Eyedropper Shift-click = colour-only; configurable undo depth; Ctrl/⌘+Arrow fine nudge.
- Spacebar-hold pan; Up/Down adjusts a selected star/polygon/burst's point count;
  two-finger pan + pinch-zoom (tablet).

**Vector & effects**
- **Stroke gradients** (`setStrokeGradient`/`clearStrokeGradient`) — architectural + SVG.
- Effects: Convert to Shape, Split Into Grid, Convert to Guides, Feather, Outer Glow,
  Scribble, per-object Crop Marks, Smooth path, Create Swatch Info sheet.
- Pathfinder/distort, outline-stroke, offset-path, swap fill/stroke (Shift+X),
  Object Clean Up.

**Colour**
- Colour Guide: `generateTints`, `generateHarmony` (complementary/analogous/triadic/
  split-complementary/tetradic/monochromatic), palette-from-image (`extractImagePalette`/
  `recolorFromImage`), recolor shuffle, swatch groups.

**Canvas & artboards**
- Outline (wireframe) view, Trim view, print bleed + crop marks.
- Artboards: rearrange-all grid, duplicate (with artwork), fit-to-artwork,
  paste-on-all-artboards, delete-unused-swatches; Select › Same (font/size/opacity/
  stroke-weight/type).

## Fixes
- Canvas now redraws on docType / artboard / view-mode / bleed changes (e.g. switching
  slides↔infinite no longer leaves a stale canvas).
- Path multi-piece ops keep unique ids; boolean results inherit the frontmost colour.

## Internal / tests / docs
- Added `playwright.config.ts` (webServer auto-starts Vite on :5173; defaults `YAPPY_URL`)
  — the suite self-hosts.
- Fixed a broken test import that made the **whole suite uncollectable**.
- New help doc "Effects & Colour Tools"; gap-analysis docs for several Illustrator videos;
  `docs/strategy.md` product roadmap.

## Breaking changes / migration
- Version scheme reset to 0.5.x (cosmetic).
- Some hotkeys differ from Illustrator by design (Spacebar = mindmap-collapse tap / pan
  hold; `Z` = Zen Mode). See the in-app shortcuts help.
