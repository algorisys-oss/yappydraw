# 0.8.39 — New Mind Map (one click) + `createMindMap` API (2026-07-09)

## Highlights
- **Menu → New Mind Map** now seeds a ready-to-edit mind map: an emphasised central
  node with a few colour-coded branches (some with sub-branches), laid out and styled
  automatically. This is the missing entry point — the interactive mind-map engine
  (per-branch colour, organic connectors, reflow, and a live layout switcher) was
  already there; you just couldn't easily *start* a map.

## Features
- **`Yappy.createMindMap({ x?, y?, title?, direction?, branches? })`** — seeds a mind map
  via the existing engine and returns the central node's id. `direction` is any mindmap
  layout (`balanced` (dual-side, default), `radial`, `horizontal-right`, `vertical-down`,
  …).
- Reminder of what's already there once a mind-map node is selected (Properties panel):
  **AUTO LAYOUT** switches the whole tree between Balanced / Horizontal-Right /
  Vertical-Down / Radial **non-destructively** (same nodes, just re-laid-out), plus Add
  Child (Tab) / Add Sibling (Enter) / Auto-Style / Collapse.

## Internal / tests / docs
- Verified end-to-end: the menu item creates a full map (central + 4 branches + 2
  sub-branches + organic connectors); switching layout preserves every element id
  (non-destructive) and updates the tree in place.
