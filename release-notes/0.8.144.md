# 0.8.144 — Animation Studio grows up: morphs, curves, guides, poses, sound, scenes (2026-07-22)

## Highlights
- Five major Animation Studio features in one release: **shape tweens** (outline morphing), a **bezier ease-curve editor**, **motion guides** (tweens ride a drawn path), **pose keyframes** for stick figures (bones/IK on the timeline), an **♪ Audio row** muxed into video export, and **scenes** (multiple stages per document).
- Timeline polish: sits above the status bar, drag-to-resize top edge, floating controls stay clear.

## Features
- **Shape tweens (P2)** — `tween: 'shape'` morphs the outline between two cels (resampled to 64 points, twist-aligned) on top of the normal pose/color tween; renders with fill + stroke in both render styles; strokes/lines/text/clip instances degrade gracefully to motion tweens. Green span arrows; `Yappy.anim.setTween('shape')`.
- **Ease curve editor (P3)** — per-span bezier popover (`curve` button): presets incl. Overshoot/Anticipate + two draggable handles (y beyond [0,1] for overshoot/wind-up); custom curves override named easings; one undo entry per drag gesture. `Yappy.anim.setFrameEaseCurve`.
- **Motion guides (P3)** — a tween's elements ride a drawn line/polyline/pen/freehand path by arc length (easing applies along the path); optional `orient` banks into the direction of travel; a guide on a hidden layer steers without rendering. `Yappy.anim.setFrameGuide`.
- **Pose keyframes (P4)** — a stick figure's pose (motion clip + cycle phase + facing) pins per cel via the timeline header's Pose controls; same-clip spans glide the phase through the cycle (foot IK intact), cross-clip spans blend the skeleton joint-by-joint (`lerpRigPose`, now pure/exported). Frame-exact on scrub, playback and export.
- **Audio row (P5)** — nine built-in synth SFX (previewed on pick) or imported audio files (≤4 MB, stored in the document) placed at exact frames; drag to retime, right-click to manage; plays on timeline playback (silent while scrubbing) and is **muxed into MP4/WebM exports** at exact offsets (GIFs stay silent). `Yappy.anim.addSound/sounds/moveSound/removeSound`.
- **Scenes (P6)** — each slide is a scene with its own stage + timeline; header picker adds/switches (camera glide)/deletes; only the active scene's artwork is visible and editable; persists as `SlideDocument.animScenes` with `animTimeline` back-compat. `Yappy.anim.addScene/setScene/deleteScene/sceneCount`.
- **Layout** — the timeline panel sits above the 28px status bar (the bottom layer row was hidden beneath it), its top edge drag-resizes (persisted), and the floating Settings/Properties/Help cluster lifts itself above the panel.

## Fixes
- Audio clip ids collided (both clips moved together): `generateId` derives uniqueness by scanning elements, and audio clips aren't elements — now `crypto.randomUUID`.
- Scene isolation held against three Solid-store traps caught by e2e before ship: stashed proxies alias later merges (stash clones), Record `setStore` never deletes keys (`reconcile()`), and identity-keyed caches never invalidate on reconciled proxies (content-derived instead).
- Sequence cross-fades and pose blends share one `lerpRigPose` (moved to pure `anim/rig.ts`); per-frame `console.log`s removed from the morph render path.

## Internal / tests / docs
- New: `utils/animation/anim-audio.ts` (playback scheduling + export-mux stream); sound-engine's synth primitives take an optional routing target (`sfxInto`) with game behavior unchanged; `VideoRecorder.start` accepts an audio stream (audio-capable mimeTypes).
- 96 unit tests + 18 Playwright e2e across `animation-timeline.spec.ts` / `animation-templates.spec.ts`; spec boots have 90s cold-dev-server headroom.
- Help doc sections for every feature (morphing, curves, guides, poses, sound, scenes); `docs/api.md` updated; learnings: the Solid store merge/reconcile/identity family.

## Breaking changes / migration
- None. All document fields are additive; older builds open multi-scene docs showing the first scene.
