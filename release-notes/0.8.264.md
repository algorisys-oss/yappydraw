# 0.8.264 — Draw from code the way you would on a canvas (2026-09-27)

`Yappy.draw` takes Canvas 2D or Cairo-style pen calls (`moveTo`, `lineTo`, `arc`, `fill`,
`stroke`) and turns each paint into an ordinary, editable path element. Programmatic drawing
code written for those libraries now ports almost line for line.

## Highlights
- **`Yappy.draw(ctx => { … })`**: Canvas/Cairo-style drawing from a script. Every `fill()` or
  `stroke()` becomes a path you can select, node-edit, restyle, animate and export. The whole
  call is one undo step.

## Features
- Path verbs: `beginPath`, `moveTo`, `lineTo`, `bezierCurveTo`, `quadraticCurveTo`, `arc`,
  `ellipse`, `rect`, `closePath`, plus Cairo's `curveTo`, `rectangle`, `arcNegative`,
  `relMoveTo`/`relLineTo`/`relCurveTo`, `newPath`.
- Transform stack: `save`/`restore`, `translate`, `rotate`, `scale`, `transform`,
  `setTransform`, `resetTransform`, `currentPoint()`. Transforms are baked into the anchors,
  so a rotated shape is still a plain node-editable path.
- Paint state: `fillStyle`, `strokeStyle`, `lineWidth`, `lineCap`, `lineJoin`, `globalAlpha`,
  `setLineDash`, and Cairo's `setSourceRgb`/`setSourceRgba`/`setLineWidth`/`setLineCap`/
  `setLineJoin`. Caps and joins default to butt/miter, as in Canvas and Cairo.
- `fill()` then `stroke()` on the same path produce **one** element with both paints.
- `mode: 'cairo'`: `fill()`/`stroke()` consume the path and `fillPreserve()`/`strokePreserve()`
  keep it, matching Cairo. Canvas semantics are the default.
- Options: any element option plus `renderStyle: 'sketch' | 'architectural'`; `roughness`
  defaults to 0.
- Data form for the embed bridge: `Yappy.draw([['moveTo', 0, 0], ['lineTo', 50, 0],
  ['stroke']])`. Only the documented methods and properties are accepted.

## Internal / tests / docs
- `utils/draw-context.ts`: `PathBuilder` (pen + transform maths, arcs as ≤90° cubics) and
  `DrawContext` (paint state, fill/stroke merging), store-free and injected with an `emit`.
- Tests: `draw-context.test.ts` (25 unit tests), `tests/draw-api.spec.ts` (element shape,
  cairo mode, data form, pixel check in both render styles, and every help-doc snippet run
  verbatim).
- New help doc **Canvas-style Drawing** (`/help/draw-api/`); the Vector Paths doc links to it.
- Release-notes index backfilled for 0.8.260–0.8.263.
