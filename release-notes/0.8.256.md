# 0.8.256 — tinyfly animations bring their shapes (2026-09-14)

## Highlights
- **Import a tinyfly animation into an empty document.** Menu → File → Import tinyfly animation…
  reads a tinyfly **Animation Document**, creates its shapes centred in the view and plays the
  animation on them. Before, the import could only bind to shapes you had already drawn, so a new
  document hit "None of this animation's targets matched a shape" with no way forward.
- **Text animated by tinyfly looks right**: `fill` recolours the letters and `scale` scales them.

## Features
- **`Yappy.tinyfly.import(file, { x?, y?, start? })`.**
  - Reads an Animation Document (tinyfly v0.67.0: More → Export Animation Document) or a saved
    tinyfly Project, where it takes the active scene.
  - Creates rectangles, circles, text, images, lines, arrows and paths, with the artboard centred
    on (`x`, `y`) or the view, selects them and attaches the clip. Shapes and clip are one undo step.
  - Groups, symbols, audio and video are left out and listed in `skipped`; hidden elements are not
    created.
  - A timeline-only file binds to existing shapes, like `add` with `requireMatch`.
  - Returns `add`'s result plus `created` (ids), `skipped` (types) and `scenes`.
- **`Yappy.tinyfly.add`** refuses a file with its own shapes and points to `import`.

## Fixes
- **#368: timeline-only import into an empty document was a dead end.** The menu now uses
  `import`, and the "nothing matched" message says to export the Animation Document from tinyfly.
  An embed `sequence.json` is refused with the same pointer, because its shapes are HTML.
- **#369: tinyfly `fill` painted a box behind text, and `scale` left letters full size.** On text,
  `fill` sets `textColor`, and a scale also scales `fontSize`.
- **#370: tinyfly tracks without ids cancelled each other.** The engine keys tracks by id, which the
  Animation Document format makes optional. Tracks now get unique ids when a file is read.

## Internal / tests / docs
- **New module:** `utils/animation/tinyfly-document.ts` (file detection, element → shape mapping,
  placement), with `tinyfly-document.test.ts` (15 tests).
- **api.ts:** `addTinyflyClip` (synchronous, so it can run inside `Yappy.batch`) and
  `createTinyflyShape` helpers.
- **Specs:** `tinyfly-clips.spec.ts` gains four import cases (document, project and sequence,
  timeline-only message, menu import); 13 cases pass.
- **Help:** Animation → tinyfly animations covers importing with shapes, text semantics, the
  `import` API and the new limits. README and all five locales updated.
- **Checked by eye:** the Draw · Guess · Repeat promo imports as 19 shapes and plays in both render
  styles.
- **Existing failures, unchanged by this release:** the bun unit suite's `react/jsx-dev-runtime`
  errors (for example `frame-pose.test.ts`) occur on a clean `dev` too.

## Breaking changes / migration
- **`Yappy.tinyfly.add`** throws for an Animation Document or Project with a message naming
  `import` (it threw for Animation Documents before, with a different message).
- **Clips on text:** a tinyfly `fill` track on a text element now changes the text colour instead of
  its background.
