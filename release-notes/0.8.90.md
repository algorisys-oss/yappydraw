# 0.8.90 — Unified search Phase 4: templates in the feed + greeting cards (2026-07-13)

## Highlights
- The **Elements** search is now Canva's full two-tier search: one query returns both
  **elements** (icons / illustrations / shapes / photos) **and whole templates**. Type
  "birthday" and you get greeting-card designs alongside the graphics.
- New **Templates** filter chip in the blended feed, with lightweight per-template page
  previews.
- A new **greeting-card design pack** — birthday, thank-you, congrats, party invite,
  anniversary, and new-baby cards — searchable by occasion and available in the template
  browser.

## Features
- **Templates in the unified feed** (Phase 4 of `docs/unified-element-search-plan.md`):
  - New `'template'` `AssetKind` and a provider in `library/elements/search.ts` that wraps
    the existing `templates/registry.ts::searchTemplates(q)` — no rebuild of template search.
  - `templatePreviewSvg` renders a tiny SVG thumbnail of a template's first page (rects /
    ellipses / text-as-bars) straight from the template's own element data + palette — cheap
    to draw, no offscreen rasterisation. Same look as the standalone template browser.
  - Selecting a template hit loads the whole design via the existing template-load path
    (confirms first if the current doc is dirty).
  - New **Templates** type chip in `elements-panel.tsx` (+ grid styling in
    `elements-panel.css`).
- **Greeting-card design pack** (`templates/data/designs/cards.ts`, registered in
  `designs/index.ts`): `birthdayCard`, `thankYouCard`, `congratsCard`, `partyInviteCard`,
  `anniversaryCard`, `newBabyCard` — built with the same `makeDesign(...)` helper as the
  existing designs, each tagged by occasion (`birthday`, `card`, `greeting`, `invite`,
  `anniversary`, `baby`, …) so they surface in both the unified feed and the template browser.
- **API**: `Yappy.searchElements(query, opts)` now includes template hits (lazy-loaded from
  the `elements-panel` chunk; `SearchElementsOptions` typed). Each `AssetHit` still exposes
  `insert()` directly.
