# 0.8.300 — Wipe/Cover/Split transitions, shrink-to-fit text, alt text and an accessibility check (2026-11-01)

## Highlights
- The last three items of the DeckCraft-based slides backlog (`docs/slides-feature-gaps.md`):
  more transitions, shrink text on overflow, and alt text with an accessibility checker.

## Features
- **Transitions: Wipe, Cover, Uncover, Split** — 16 types (wipe/cover/uncover in four directions,
  split horizontal/vertical, out/in). Both slides show at once, drawn from bitmaps on an overlay;
  going back plays them reversed. PowerPoint export/import as `p:wipe`, `p:cover`, `p:pull`,
  `p:split` (previously all read as Push). Also listed in the slide Properties panel, with Morph.
- **Shrink text on overflow** — Properties → Text Fit → Shrink on overflow (text boxes of a fixed
  size and shape labels, plain and rich): drawn at the largest scale that fits, down to 25%; the
  font size you set is kept. `setTextFit(ids, 'shrink' | 'none')`, option `textFit`. PowerPoint
  `normAutofit` both ways.
- **Alt text** — right-click → Alt Text… on any object, with Mark as decorative; one undo step.
  `setAltText`, `getAltText`. PowerPoint Alt Text and "Mark as decorative" on every object, both
  ways; SVG export names described objects with `<title>` and hides decorative ones.
- **Check accessibility** — command palette; a live panel listing missing alt text (pictures,
  video, charts, QR codes), text below WCAG AA contrast against its fill or the page, and pages
  with no text, with Go to / Add alt text. `checkAccessibility()`, `openAccessibilityCheck()`.
