# 0.8.290 — Stroke Text in the Command Palette (2026-10-11)

## Highlights
- **Hershey single-line text is now reachable without the console.** The Command Palette (<kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>K</kbd>) lists **Stroke Text: Hershey Simplex…** and the other four faces (Duplex, Sans, Script, Gothic). Pick one, type the words, and they land centred in the drawing area at 48px cap height, selected. Since v0.8.274 the feature existed only as `Yappy.strokeText`, so a user who had not read the help page could not find it.

## Features
- Five palette commands, `insert.strokeTextSimplex` … `insert.strokeTextGothic` (category Tools), each a native prompt for the text; cancelling creates nothing. The face is the command, so typing "hershey" shows every face and the choice is one keystroke.

## Internal / tests / docs
- `utils/command-registry.ts`: `insertStrokeText(font)` lays the block out first (`layoutStrokeText`) to centre it on `canvasCenterClient()`, then calls `createStrokeText`. Locale keys `commands.insert-stroke-text` (interpolates the face), `-prompt`, `-default`, `-failed` in en/de/es/fr/ja; the Japanese default word stays ASCII because the faces cover ASCII 32–126 only.
- The five ids are on the command-sweep skip list (native `prompt()`), with the reason.
- `tests/stroke-text.spec.ts` +1: the entries exist with the expected labels, a dismissed prompt creates nothing, an accepted one writes the word in the chosen face, centred and selected.
- Help: Illustrator-class Tools → "Single-line text" now opens with the palette route. Learnings.

## Breaking changes / migration
- None.
