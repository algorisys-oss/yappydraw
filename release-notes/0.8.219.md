# 0.8.219 — Inflate 3D, and three things that disagreed with each other (2026-08-25)

## Highlights
- **Inflate 3D**: puff any flat shape into a lit, rounded body — Illustrator's *Effect ▸ 3D and Materials ▸ Inflate*, with no 3D engine behind it. Give the object an image fill and that picture becomes the surface material.
- Cloud **pattern fills** stopped in a dead straight line partway up the shape. The cloud had been drawing outside its own bounding box all along; solid fill was the only style that hid it.
- **Layers could not be reordered** — the drag showed a no-entry cursor and no `drop` event ever fired.
- In a paged design, **one object appeared on two pages**, and deleting it "from one page" deleted it outright. Artwork now stops at the page edge, the way this editor's own exporter has always drawn it.

## Features

### Inflate 3D
The third of Yappy's 3D effects, and the only one that adds *form* rather than depth or rotation: 3D Extrude pushes a shape backwards, Turntable spins it, **Inflate rounds its interior**. Non-destructive — the outline is untouched, the fill becomes a shaded surface, and the stroke still draws in whichever render style is active.

There is no 3D model. The shape is treated as a **height field** built from its own silhouette, so the puff follows whatever outline was drawn, at any size: a circle becomes a sphere, a heart a cushion, a cloud cumulus.

**Property panel → INFLATE (3D)**: Bulge, Softness, Light angle, Light height, Intensity, Ambient, Roughness, Metallic, Highlight colour.

```
Yappy.setInflate();                                    // defaults
Yappy.setInflate({ bulge: 0.9, roughness: 0.1 });      // fatter, glossier
Yappy.setInflate({ lightAngle: 35, lightHeight: 70 }); // move the light
Yappy.clearInflate();
```

- **Materials.** The surface colour is the fill colour; give the object an **image fill** instead and the picture is shaded as the body rather than pasted flat on it — draw a silhouette, drop in a skin, inflate, light it.
- **The light belongs to the page, not the object.** Rotating an inflated shape leaves the highlight where it was, so a group of inflated objects still reads as one scene.
- Renders identically in **Sketch** and **Architectural**, and exports to PNG, PDF and SVG (as an embedded image inside the shape).
- Not included, deliberately: gradient/pattern/mesh albedo, a perspective contact shadow (the existing **Drop Shadow** pairs with it), and expand-to-paths — the surface is a raster. See `docs/inflate-3d-spec.md`.

## Fixes

- **#322 — Pattern fills stopped partway up a cloud.** Reported as a fill bug; it was geometry. Each of the cloud's ten scallops is an arc whose radius comes from its own chord, and a scallop bulges *outside* the ring its endpoints sit on. The ring sat on the box edge, so the bumps hung outside the element's declared bounds — 41% of the height on a wide cloud, 207px on the reported one. Pattern, mesh and image fills rasterise a `w × h` buffer, so above the top of the box there was simply no buffer left and the fill stopped square while the stroke carried on. Solid fill has no buffer, which is exactly why it was the one style that looked right. The same overflow is why the selection handles cut through the shape. The cloud now fits the box it was dragged to at every aspect ratio.
- **#323 — Layer reorder showed a red no-entry cursor.** The panel asked for `effectAllowed = 'move'`; `app.tsx`'s global image-drop handler was claiming the drag and forcing `dropEffect = 'copy'`. That pair is illegal, so the browser rejected the drop outright and no `drop` event fired at all. The handler's escape hatch named `.layer-panel`, and the panel had since been re-homed inside the generic dock-panel wrapper — so the selector matched nothing. Slide reordering kept working the whole time, which made it look layers-specific.
- **#324 — One object drawn on two pages.** Pages are frames on one shared canvas, so exactly one rule should say which page an object belongs to. There were two, and they disagreed: ownership (save, export, animation builds) used the object's centre, while on-canvas visibility used a box overlap. Anything hanging over an edge therefore drew on the *neighbouring* page as well — and deleting it from either was deleting the only copy. Nothing clipped, either, so the overhang spilled across the gutter. Artwork now belongs to one page and **stops at the paper**, matching what the exporter has always produced. Objects being dragged or selected still draw whole, so nothing is cut in half mid-move.
- **#325 — An object straddling the gap between pages belonged to no page at all.** Pages sit ~80px apart and the centre test asked only "is the centre inside this page" — for an object in the gap the answer was no, everywhere. Animation builds, the per-page count and PDF/PPTX export silently skipped it while the canvas drew it.

## Internal / tests / docs

- `utils/inflate.ts` keeps its maths free of canvas and DOM so it can be tested directly rather than by screenshot — 21 tests over the distance transform, the dome profile, the blur, the light vector and the shading.
- `utils/slide-utils.ts` gains `ownerSlideIndex`, now the single answer to "which page is this on", called by the renderer, four exporters, the page thumbnails and hit-testing.
- The cloud's containment test used to check only the arcs' *endpoints*, which is a different question from where the shape reaches, by a quarter of every chord. It now samples the arcs — written a different way from the code on purpose, which is what caught two bugs in the analytic version.
- Help: a new **Inflate (3D)** section in *Effects & Colour Tools*, a **page edge** section in *Design Studio*, and a correction to *Workspace* — only the grip (⋮⋮) starts a layer reorder, not the row.
- `scripts/record-inflate-demo.mjs` drives the app with real mouse gestures to record a feature demo.
- The i18n ratchet baseline moves by the Inflate panel's labels. Every 3D section in that panel — Extrude and Turntable included — is hardcoded English, and translating Inflate alone would leave a visibly half-translated panel in any other locale. Localising the whole 3D block is its own piece of work.

## Breaking changes / migration

- **Paged documents (design / slides) now clip artwork to the page.** An object overhanging a page edge used to draw in full and spill onto the neighbouring page; it is now trimmed at the paper, which is what every export of that page already produced. Selected and in-flight objects are exempt, so dragging is unchanged.
- **A paged document does not draw artwork parked beside the pages.** That was already true before this release — it is simply now documented rather than surprising.
