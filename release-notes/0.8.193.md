# 0.8.193 — mandalas that are actually mandalas (2026-08-15)

## Highlights
- **New Kaleidoscope symmetry mode.** Radial symmetry spins your wedge around the centre; that
  gives you a pinwheel. Kaleidoscope *also* mirrors it across each spoke on the way round, so both
  edges of every petal match — the bilateral symmetry traditional mandala work has. Draw half a
  petal and the rest of the page draws itself.
- **Spoke counts now go to 36**, up from 24. 32- and 36-petal rings are standard in mandala
  colouring pages and the old cap put them out of reach.
- **Ring guides.** Concentric dashed circles on the symmetry centre, so a mandala's bands stay even
  instead of drifting outward. They're guides, not elements: they never select, print or export.

## Features
- **Symmetry → Kaleidoscope** (`❋` in the tool options bar, or the Canvas panel's Symmetry
  section). N sectors produce **2N** copies — N rotations plus N mirror lines, the dihedral group
  D*n*. The panel shows the running total so the cost of a setting is visible before you draw.
  - The mirror lines sit **π/n** apart, not 2π/n. Composing a rotation with a reflection yields
    another reflection at half the rotation angle, so that spacing is what keeps the set closed;
    get it wrong and some wedges draw twice while others stay empty.
  - Everything that already worked with Radial works here: every drawing tool, live copies that
    track the stroke while the pointer is down, all instances grouped as one mark, abandoned
    strokes taking their copies with them, and **Angle** to tilt the whole arrangement.
- **Spoke / sector count raised to 2–36** for both Radial and Kaleidoscope.
- **Ring guides** — *Rings* (0–24) and *Ring gap* in the Canvas panel's Symmetry section. They
  stay visible when you switch symmetry off, because that's exactly when you're finishing detail
  work by hand and still need the scaffold. Set Rings to 0 to hide them.
- Saved with the document, alongside the existing symmetry state. Older files load with rings off.

## Fixes / polish
- **Symmetry guides no longer swamp the drawing at high spoke counts.** A 36-sector kaleidoscope
  draws 72 rays; at the old line weight that was a solid purple starburst you couldn't work inside.
  Rays now fade as they get denser (past 8), and they start a short way out from the centre so the
  hub — where the finest detail goes — stays clear.
- Help search finds this feature now. The Logo & Design Toolkit page had no search keywords at all,
  so "mandala", "kaleidoscope" or "colouring page" returned nothing.

## API
- `setSymmetryMode('kaleidoscope')` joins the existing modes.
- `setRadialCount(n)` now clamps to 2..36 (was 2..24).
- `setSymmetryRings(n)` — 0..24 concentric guide circles; 0 is off.
- `setSymmetryRingSpacing(px)` — world-unit gap between them.

## Docs
- Logo & Design Toolkit help page: Kaleidoscope in the modes table, a Radial-vs-Kaleidoscope
  explainer, a Ring guides section, and a step-by-step "Drawing a mandala for a colouring page".
- `docs/learnings.md`: why a mandala needs the dihedral group rather than more rotations, why the
  mirror lines land at π/n, and why guide density is a feature constraint rather than a cosmetic one.

## Tests
- New `frontend/src/utils/symmetry.test.ts` (11 cases). The important one asserts **group closure** —
  multiply every pair of the 2n transforms and check the product is back in the set. That is what
  catches the π/n-vs-2π/n mistake, and it is far more informative than counting instances.
  Also a differential test that pushes one point through both `buildSymmetryOps` and
  `buildSymmetryTransforms` and compares the orbits.
- New end-to-end cases: kaleidoscope emits 2n instances that are mirror-symmetric about the base
  spoke, the 36 ceiling is reachable, and ring guides render evenly and survive symmetry going off.
- `symmetry-guide.spec.ts` updated for the new 36 cap.

## Known issues
- **Not new, and not fixed here**: a selection-tool drag can delete a freshly drawn element. Repro
  on a blank canvas with symmetry **off** — draw a rectangle at (590,380)→(640,340), then drag
  (660,330)→(720,285); the element count goes 1 → 0. It reproduces identically in Radial and
  Kaleidoscope, and it is not a double-click-window issue (same at 250 ms and 1200 ms). A drag in
  empty space well away from the element is harmless. Lives in selection-handler territory.
- A 36-sector kaleidoscope re-derives 72 copies on every pointer move and is noticeably laggy
  (~77 ms/move measured, versus ~28 ms for the pre-existing radial-24). Cost is linear in copy
  count and the live path has always worked this way; 12–16 sectors is the comfortable range.
- The tool options bar overflows below roughly 1200 px wide and scrolls with a hidden scrollbar, so
  "Move axis" can sit off-screen. It already overflowed before this release's sixth symmetry button.
  Both the Canvas panel and `Alt+Shift+Y` still reach it.
