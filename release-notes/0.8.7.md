# 0.8.7 — Games are a single stage, not a slide deck (2026-07-07)

## Highlights
- A game now opens as a **single fixed stage** — no slide navigator, no "Add Page",
  no page/present toolbar. Just the play window and the game editor.

## Fixes
- **New Game showed a slide deck.** Because games were created as *design* documents
  (to get a fixed stage page), they inherited the full multi-page Design chrome — the
  slide navigator, Add Page, the floating page-control / Present toolbar, and a
  "Slide 1/1" readout — none of which belongs to a single-stage game.

## Internal / tests / docs
- New `game` docType. Split the paged concept: `isPagedDocType` (renders/plays/exports
  as a page — slides + design + game) vs `isMultiPageDocType` (the navigator / Add Page /
  present chrome — slides + design only). New Game creates docType `game`; the runtime
  already staged on `pageRect()` so nothing else changed. e2e: a game doc hides the
  navigator and still plays; design/slides suites regression-green (60).

## Breaking changes / migration
- None. Existing games (infinite or design) still open and run.
