# 0.5.4 — Table reorder feedback & touch select-all (2026-06-28)

## Highlights
- Table **column reordering** now shows a live drop indicator while you drag —
  no more blind rearranging.
- **Select all** is now reachable without a keyboard on tablets.

## Features
- **Table column-reorder drop indicator** — dragging a column header fades the
  grabbed column, highlights the target column under the pointer, and draws a
  blue insertion line on the exact side the column will land (right of target
  when moving right, left when moving left). Makes finger-dragging precise.
- **Touch select-all** — long-press the canvas (empty *or* with a selection) →
  **Select all**. Backed by a shared `selectAll()` action; the menu item is now
  in both context-menu branches, not just the empty-canvas one.

## Fixes
- Table column reorder was effectively a blind drag — the only feedback was the
  `grabbing` cursor, so you couldn't tell where the column would drop. (#134)
- No keyboard-free path to select-all on tablets; `Ctrl/Cmd+A` was the only
  trigger. (#135)

## Internal / tests / docs
- New `tableColumnDrop` pointer signal, rendered by `renderSelectionOverlays`
  (mirrors the existing pool-lane / reparent drop-target pattern).
- `selectAll()` extracted to the store and shared by the `Ctrl/Cmd+A` shortcut
  and the context menu.
- Help docs (table reorder + gestures), learnings, and bug-fixes updated.

## Breaking changes / migration
- None.
