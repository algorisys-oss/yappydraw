# 0.8.282 — Text on shapes works like Illustrator; flip fixed for rotated shapes (2026-10-10)

## Highlights
- **Text on a shape is its own object.** Putting text on a circle (or any closed shape) now makes a separate text object that follows the outline. Click its letters to select it, drag it on its own, and style it from the text settings only. The shape's fill and stroke never touch it.
- **Distance from Path and Position.** Bring text closer to the outline or push it away, and place it outside, centred on, or inside the shape.
- **Text all the way round a circle.** Long text now runs round the outline without stray letters landing inside the shape.
- **Flip works on rotated shapes.** Flip Horizontal on a shape turned 45° mirrors it left↔right, not along its own tilted axis.

## Features
- `putTextOnOutline(shapeId, text?, opts?)`: Type-on-Path object (`typeOnPath`) on a closed shape's outline. It's hit by its glyphs, and its unpainted guide path isn't clickable. The Text on Path switch (panel and quick toolbar), Alt+T on a shape, `attachTextToPath` and create-time `curvedText` all use it.
- **Detach Text from Shape** (right-click, command palette, `detachTextFromShape`): moves curved text from older documents onto its own object, keeping every letter in place.
- Properties → Text: **Position** (Outside / above, Centred on the line, Inside / below) and **Distance from Path** (px) replace *Text Position*. Also new: **Text Outline** with Outline Color and Outline Width, for text and for text on paths.
- Overset text, as in Illustrator: a loop shows at most one turn, and an open path drops letters past either end. Before, it printed over itself or piled up on the end point.

## Fixes
- **#437** Flip Horizontal/Vertical (and Mirror Copy) on a rotated object mirrored along its own tilted axis. `mirrorGeometry` now negates the angle.
- **#438** Curved text on loops flipped each letter on its own where the outline turned past vertical, so the letter also jumped inside the shape and the run read backwards. The old *Outside* setting put text inside a clockwise loop.
- **#439** Shape text was part of the shape (moved, selected and stroked with it) and was drawn in the shape's stroke colour. Changing a shape's stroke now pins its text to the colour it was showing.

## Internal / tests / docs
- `layoutTextAlongPath`: one layout for drawing, export and hit-testing. `utils/curved-text-hit.ts` is checked in `hitTestElement` before the JS/WASM split.
- Tests: `text-on-path.test.ts` (+8), `curved-text-hit.test.ts` (5), `geometry-mirror.test.ts` (+7), `artboard-variations.test.ts` (new model, 20 glyph-by-glyph detach checks, colour pin, undo), and `tests/text-on-outline.spec.ts` (5).

## Breaking changes / migration
- `attachTextToPath` returns the id of the element carrying the text (a new object for closed shapes) or `false`, instead of `true`/`false`. Truthiness is unchanged.
- Putting text on a closed shape creates a new element; the shape's `containerText`/`curvedText` are cleared. Existing documents with text welded to a shape render as before until detached.
- Curved text on loops no longer turns individual letters upright; use **Flip to Other Side** for bottom-of-badge text.
