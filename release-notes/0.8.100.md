# 0.8.100 — Guided onboarding tour (2026-07-14)

## Highlights
- New users get a short **spotlight tour** of the essentials on their first visit — replayable anytime.

## Features
- **First-visit onboarding tour.** A guided walkthrough highlights the toolbar, canvas, Properties
  panel, and the settings/help cluster, one step at a time. Step with Next/Back (→/←), or Skip (Esc).
  It auto-runs only once (tracked in `localStorage['yappy:tour:seen']`).
  - **Replay** from **Help (?) → “Take the tour”**, or from a script via **`window.Yappy.startTour()`**.
  - Theme-aware and accessible: every label/button clears WCAG AA contrast (≥4.5:1) in both light and
    dark themes (measured, not eyeballed). A step whose target isn't on screen falls back to a
    centered card.

## Internal / tests / docs
- New `components/onboarding-tour.tsx` + `.css`; wired into `app.tsx` (mount + first-visit auto-start),
  the Help dialog, and `api.ts` (`startTour`). Workspace help doc documents it.
- Verified with Playwright: auto-start on first visit, step order 1→6, close-on-finish, seen-flag
  persistence (no re-show on reload), replay, and WCAG contrast ratios in both themes.
- Backlog planning items added to `todo.md`: a HappyPaint-style landing "My drawings" gallery
  (IndexedDB-backed), and a "What's new" popup on the version number.
