# 0.8.60 — Dockable panels Phase D: Recolor, Brand Kit & Elements migrated (2026-07-10)

## Highlights
- The **Recolor Artwork**, **Brand Kit**, and **Elements** panels are now
  first-class **dockable panels** — dock them to an edge, float them, collapse
  them, reorder them in a stack, and the layout persists across reloads.

## Features
- **Phase D migration (Recolor + Brand Kit + Elements):** all three panels moved
  onto the shared dock chrome. Opening them the usual ways (menu, context menu's
  "Recolor Artwork…", the scripting API) now opens the *dockable* version — drag it
  to the left/right edge to dock, reorder it within a stack, or float it. Brand
  Kit's two "new kit" actions (**From doc** / **Blank**) moved into a small in-body
  toolbar; Recolor and Elements had no header actions beyond Close. The dock title
  bar carries dock-left / dock-right / float / collapse / close.
- Under the hood: the existing `toggleXxxPanel` actions drive the dock store via
  the `dock-layout.setPanelOpen()` bridge, so every entry point keeps working and
  the menu checkmarks track the real dock state (`isPanelOpen(id)`).

## Internal / tests / docs
- Two internal reads of the old `showXxxPanel` flags were rewired to
  `isPanelOpen(id)` so they still fire when the panel opens via the dock: Brand
  Kit's kit-list memo (re-reads `localStorage` on open) and Elements' heavy
  lucide-icon lazy-load (`createResource` gate). Without this the kit list would
  go stale / the icon grid would never load once the flag stopped flipping.
- `tsc -b` and `npm run build` both green. No CSS de-scoping was needed (none of
  the three had descendant selectors scoped under the removed wrapper class).
- `docs/dockable-panel-system-plan.md` updated: these three moved from **Remaining**
  to **Done (v0.8.60)**; remaining panels are property, layers, state, animation,
  behaviors, stick-figure, ds-ops, vector-tools (property/layers are the most
  coupled — scheduled last).

## Breaking changes / migration
- None. (The old `showRecolorPanel` / `showBrandKitPanel` / `showElementsPanel`
  settings flags are now unused; panel state lives in the persisted dock layout.)
