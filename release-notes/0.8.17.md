# 0.8.17 — Stick-figure full catalog: variants, props & scenes (2026-07-08)

## Highlights
- The Stick Figures library grows from 24 to **163 assets**: a full character
  **variant matrix** (Man / Woman / Boy / Girl), a **Props** category of standalone
  objects, and ready-made **multi-figure Scenes** — plus one-click **Add to Symbols**.

## Features
- **Character variants (Man / Woman / Boy / Girl)** — every figure pose now comes in
  all four. Pick a variant with the new chips in the panel: women get hair and a
  skirt, children a bigger head and a shorter body. Variants are generated from a
  single source pose, so the whole matrix stays consistent.
- **~16 new poses** across the six themes — pointing, thinking, sad, on a call,
  coffee break, offering a handshake, bright idea, applauding, taking notes, rolling
  a suitcase, under an umbrella, taking a selfie, holding a gift, raising a toast,
  waiter, chef, and cleaner.
- **Props category** — 12 standalone, editable objects you can drop and combine with
  figures: laptop, phone, microphone, bar chart, briefcase, package, coffee cup,
  lightbulb, speech bubble, arrow, gift, trophy.
- **Scenes category** — multi-figure bundles that drop as one grouped illustration:
  handshake, two people talking, team of three, family, and celebration. Every
  figure and limb inside stays individually editable.
- **Add to Symbols** — select a dropped figure and click <em>Add to Symbols</em> to
  register it as a reusable linked Symbol; place many instances and edit the master
  once to update them all.
- The panel gains **Man / Woman / Boy / Girl / All** variant chips and **Props** /
  **Scenes** category chips; drag-drop now centres each asset by its own aspect ratio.

## Fixes
- None (feature expansion).

## Internal / tests / docs
- Figures refactored from baked SVG strings into structured `Pose` objects
  (`library/stick-figures/poses.ts`); a shared `builder.ts` generates the variant
  matrix (`buildFigure`), with `props.ts` and `scenes.ts` supplying the new
  categories and `assets.ts` assembling all 163.
- `StickCategory` gained `props` / `scenes`; new `filterStickAssets({category,
  variant})` powers the panel filters (props/scenes bypass the variant filter).
- Help doc and keywords updated (variants, props, scenes, Add to Symbols); learnings
  recorded; repo map refreshed. Full catalog verified via gallery + in-app.

## Breaking changes / migration
- None. Existing figure ids are unchanged (the Man variant keeps the base id, e.g.
  `daily-waving`); other variants suffix it (`daily-waving-female`).
