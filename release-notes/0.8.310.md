# 0.8.310 — MCP server: security updates, Rocket tools removed (2026-11-26)

## Highlights
- The YappyDraw MCP server (`backend/mcp`) gets security updates and loses the Rocket Backend
  tools. The web app, the SDK and the VS Code extension do not change.

## Features
- None.

## Fixes
- **#486** Security updates for the MCP server. `@modelcontextprotocol/sdk` 1.26.0 → 1.32.2
  clears high advisories in `@hono/node-server`, `body-parser` and `express-rate-limit`.
  `zod` 3.25 → 4.6.7 clears GHSA-mrhx-c7xc-m3w5. `tsx` 4.21 → 4.23.15 brings `esbuild` 0.28.2.
  `npm audit` reports 0. Nothing had reported these, because `backend/mcp` is not on the mirror.
- **#487** `diagram_to_rocket_schema` and `rocket_schema_to_dsl` are removed. YappyDraw does not
  need them, and `diagram_to_rocket_schema` had been returning errors. The
  `yappy://rocket-conventions` resource is removed too. `analyze_diagram` stays. The in-app
  Export to Rocket feature and `Yappy.exportToRocket()` do not change.

## Internal / tests / docs
- zod 4: `z.record()` now has a key type. `bun.lock` was regenerated to match `package-lock.json`.
- `temp/mcp-smoke.mjs` and `temp/mcp-roundtrip.mjs` drive the server over stdio. The server has
  no unit tests.
- Docs: `backend/mcp/README.md`, `docs/uml-class.md`.

## Breaking changes / migration
- MCP clients that call `diagram_to_rocket_schema` or `rocket_schema_to_dsl`, or read
  `yappy://rocket-conventions`, now get "not found".
