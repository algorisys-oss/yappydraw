# 0.8.101 — Elements no longer vanish at the page edge (2026-07-14)

## Highlights
- On design/slide pages, dragging an element toward an edge no longer makes it **disappear** — it
  stays visible as long as any part is still on the page.

## Fixes
- **Elements/images/text vanished when dragged past the page edge** (design & slide docs). The renderer
  hid any element whose **centre** left the active page rectangle ("strict slide isolation"), so
  pushing an element's midpoint past the edge culled the whole thing even while its box and your cursor
  were still over the page. Now an element renders whenever its **bounding box overlaps** the page, and
  a **selected** element always renders — so straddling the edge (or dragging one off and back) keeps it
  visible; an unselected element only hides once it's *fully* off the page. Per-page ownership for
  save/export is unchanged (still centre-based). Reproduced and verified with Playwright by sampling
  canvas pixels across a drag on a 1080×1080 design doc.

## Breaking changes / migration
- None.
