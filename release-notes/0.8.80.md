# 0.8.80 — 3D Extrude keeps image pixels (tilt / bevel / expand) (2026-07-13)

## Highlights
- **Extruding a photo no longer flattens it to a solid colour.** When you tilt, bevel, or expand a
  3D-extruded image, the bitmap is now painted onto the (foreshortened) front face — the picture
  stays visible at every angle.

## Fixes
- **3D Extrude on an image lost the bitmap when tilted / beveled / expanded.** When the extrude
  *owns the front* (Tilt X/Y or Bevel), the effect draws the front face itself and the element's
  normal render is skipped — but `drawFront`/`drawBevelFront` unconditionally filled the outline
  with the shape's base colour, so an image's front face went solid. `expandExtrude` likewise baked
  the front as a flat-fill path. Now:
  - **Live render:** new `drawImageFront()` clips to the front outline (full face, or the
    bevel-inset ring) and draws the bitmap through the front-face world transform — element
    rotation composed with the world-axis foreshorten about the centre (the exact map applied to
    the outline), honouring `el.crop`. Non-image shapes keep the flat base fill.
  - **Expand to Faces:** the front face is emitted as a real **image element** (bitmap preserved) —
    untilted/bevel-only keeps the original image geometry exactly; tilted fits the bitmap to the
    foreshortened front bbox — instead of a solid-colour path. Side/back faces stay shaded paths.
  - Image export inherits the fix automatically (it shares the same `renderExtrudeBody` path).

## Internal / tests / docs
- `frontend/src/utils/extrude.ts`: `extrudeGeometry` now returns the foreshorten factors `fx`/`fy`;
  added `tracePolys()` + `drawImageFront()` helpers.
- Verified end-to-end via Playwright against the running app: tilted and beveled extrudes sample the
  image's saturated colours on the front face (not a flat fill); Expand yields 2 path faces + 1
  image front with the source removed.
- Updated the Effects help doc (3D Extrude → Images note), `docs/bugs/bug-fixes.md` (#156),
  `docs/learnings.md`, and `todo.md`.
