# 0.8.158 — The wrapped toolbar's icons line up (2026-07-29)

## Highlights
- The wrapped / vertical toolbar is a proper grid again: even columns, and every tool
  icon centred in its cell.

## Fixes
- **#228 Ragged columns in the wrapped toolbar.** The obvious suspect was the tool
  groups with their submenu chevrons, but measuring showed every button is a uniform
  28×28 either way. The real cause was the **drag grip** — a 40×12 box sitting inline in
  the flex-wrap flow, eating one cell of the first row so the first two icons landed at
  x61/x93 while every row below started at x17/x49/x81. Five distinct column edges for a
  3-column grid. The grip now takes a full-width row of its own and reads as a header
  strip; cells are pinned to a 28px box so a future group wrapper can't stretch one.
- **Tool icons sat against the right edge of their button.** Most visible on the active
  pen/brush. The submenu chevron was an inline sibling of the icon, so inside a fixed
  cell it stole horizontal space. It's positioned absolutely in the top-right corner now
  (the hotkey badge already owns bottom-right), so group and plain icons centre
  identically.

Measured after: one distinct cell width, three columns at 19/53/87 with uniform 34px
pitch, every icon centred to within a pixel, no clipping.

## Internal / tests
- `tests/toolbar-grid-align.spec.ts` — uniform cell width, evenly spaced columns, the
  grip on its own row, no clipping, and icon centring across both plain and grouped
