# 0.5.28 — Design Studio: Canva-style design documents (2026-07-04)

## Highlights
- New **Design Document** mode: fixed-size, multi-page designs (social posts,
  posters, cards, resumes) with size presets, a Pages panel, and page-exact export.
- **Design templates**, **Save as Template**, a **Brand Kit**, an **Elements
  library** with SVG import and a Lucide icon library, **one-click text
  effects**, and **AI assists** (Magic Write, AI image, background removal).
- Browser storage moved to **IndexedDB** — big documents, templates, and brand
  logos no longer hit the ~5 MB localStorage quota (works on iOS Safari too).

## Features
- **Design documents** — Menu → New Design… opens a size picker (Instagram
  post/story, YouTube thumbnail, Facebook cover/post, X post, LinkedIn,
  presentation 16:9/4:3, A4, US Letter, business card, poster, flyer,
  custom W×H). Pages reuse the slide substrate; the Pages panel adds/
  duplicates/reorders/deletes; Ctrl+M adds a page; new pages inherit the
  page size and never overlap after resizes. Page-size preset + W/H live in
  the property panel when nothing is selected.
  `Y.newDesign('instagram-post')`, `Y.setPageSize(w, h)`, `Y.getPageSizePresets()`
- **Page export** — Export → PNG gains "Current Page Only" (exact page bounds,
  background included); PDF stays one page per document page.
  `Y.exportPageToPng(index, scale)`
- **Design templates** — 12 built-ins under Templates → Designs (announcement,
  quote card, story, thumbnail, two-sided business card, poster, resume, flyer,
  certificate, invitation…). **Save Current as Template** snapshots any document
  into My Templates (with thumbnail, deletable).
  `Y.getTemplates('designs')`, `Y.applyTemplate(id)`, `Y.saveAsTemplate(name)`
- **Brand Kit** (Menu → Brand Kit) — five brand colors + heading/body font pair
  + logo per kit; extract palette from the current document; **Apply Brand**
  recolors the whole document by closest-luminance mapping and swaps heading/
  body fonts. `Y.createBrandKit({fromDocument:true})`, `Y.applyBrandKit(id)`
- **Elements library** (Menu → Elements) — quick shapes, photo-drop frames
  (dashed placeholders, cover-fit), and a searchable Lucide icon library that
  inserts icons as editable vector paths. `Y.toggleElementsPanel(true)`
- **SVG import** — dropping an .svg imports editable vector paths (full path
  grammar incl. arcs, groups, transforms, inherited styles) instead of a
  raster image. `Y.importSvg(svgText, {targetWidth})`
- **Text effects** — Text Effect dropdown on text elements: Shadow, Lift,
  Hollow, Splice, Outline, Echo, Neon, Background (and None to reset). New
  glyph-outline rendering carries into SVG export. `Y.applyTextEffect('neon')`
- **AI assists** (keys via AI Settings) — Magic Write on text right-click
  (rewrite/shorten/expand/fix/custom; any provider), Menu → AI Image…
  (OpenAI gpt-image-1, dall-e-3 fallback), Remove Background on image
  right-click (OpenAI, transparent PNG). `Y.magicWrite('shorten')`,
  `Y.generateImage(prompt)`, `Y.removeBackground()`

## Fixes
- New design documents opened at 100% zoom, pushing tall/wide pages off-view
  (blank white canvas) — design docs now open zoomed-to-fit.
- `loadDocument` never synced `store.dimensions` from the loaded document, so
  the first slide action silently resized a custom-sized first page back to
  1920×1080.
- Elements/Brand panels defaulted underneath the pages navigator, which
  swallowed their clicks; both now open clear of the rail.
- Elements panel shapes rendered as text-only labels and the panel close
  button collapsed to an empty box — both now render proper glyphs.
- Brand Kit panel didn't show kits created via the API in the same session
  (memo over non-reactive localStorage); kit/font selects showed the wrong
  entry (Solid select-before-options).

## Internal / tests / docs
- IndexedDB key-value store (`storage/idb-kv.ts`, dependency-free) with
  in-memory fallback; autosave/user-templates/brand-kits migrate from
  localStorage automatically; autosave keeps a <3 MB synchronous localStorage
  copy for crash safety and cross-tab warnings.
- `isPagedDocType()` replaces ~30 `docType === 'slides'` checks; `pageNoun()`
  drives Page/Slide wording.
- `strokeText` added to IRenderer/CanvasRenderer/SvgRenderer.
- 37 new Playwright specs across 7 files (design-mode, design-templates,
  brand-kit, svg-import-elements, text-effects, canva-ai — OpenAI mocked —
  and idb-storage).
- New in-app help page **Design → Design Studio**; hotkeys dialog updated;
  plan + learnings + bug log in `docs/`.

## Breaking changes / migration
- None. Existing documents, templates, and brand data migrate to IndexedDB
  automatically on first load; presentations and infinite canvas behave as
  before.
