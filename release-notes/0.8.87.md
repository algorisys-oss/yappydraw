# 0.8.87 — Unified element search: one box, everything (2026-07-13)

## Highlights
- The **Elements panel** now has a single **"Search elements" box** that fans one
  query across **icons, shapes, and photos at once** and shows them in one blended
  grid — the Canva-style "type a word, get everything" flow. This is **Phase 1** of
  the unified-search plan (`docs/unified-element-search-plan.md`).
- Search understands **aliases**, so you don't need the exact asset name: `love`
  finds the heart, `chat` the speech bubble, `box` the rectangle.

## Features
- **Unified element search** (`Menu → Elements`):
  - One search box replaces the old Icons / Fonts / Photos tabs. Typing shows a
    **blended results grid** filterable with **All / Icons / Shapes / Photos** chips.
  - **Icons** (full Lucide set, insert as editable vector paths) and **Shapes**
    (rectangle, circle, triangle, star, heart, hexagon, diamond, speech, arrow) match
    instantly (offline); **Photos** (Wikimedia Commons) stream in, debounced, with the
    **All / Landscape / Portrait / Square** orientation filters under the Photos chip.
  - Click a result to insert; **drag a photo** onto a frame/shape to fill, onto an
    image to replace, or onto empty space to place. Source link + attribution kept.
  - Alias map for natural-word matches (`love→heart`, `chat→speech`, `box→rectangle`, …).
- **Browse view** (empty search box) preserves everything from before: quick shapes,
  six-shape photo **frames**, featured icons, and curated heading/body **font pairings**.

## Fixes
- None (new feature).

## Internal / tests / docs
- New `frontend/src/library/elements/search.ts` — `AssetHit`/`AssetProvider` contract
  + `collectOfflineHits()` / `searchPhotoHits()` fan-out; providers wrap the existing
  `createElement` / `importSvgToCanvas` / `insertStockPhoto` insert paths, so
  sketch/architectural render parity is unchanged.
- `components/elements-panel.tsx` rewritten (search + chips + blended grid + browse
  view); `elements-panel.css` gains the mixed-cell results grid.
- Help updated (`design-studio-doc.tsx` + help-page keywords); `docs/learnings.md`
  entry added; plan doc marked Phase 1 shipped.
- Verified end-to-end with Playwright (blended results, kind filters, shape + icon
  insert, browse-view restore) and a clean `npm run build`.

## Known limitations / next (Phase 2–3)
- No bundled **illustration** library yet (OpenMoji) — the *Illustrations* chip and
  the full keyword-alias map land in Phase 2.
- No scriptable `Y.searchElements()` yet and no keyboard shortcut for the panel —
  planned for Phase 3.

## Breaking changes / migration
- None. The three-tab layout is replaced by the search + browse view; all previous
  actions (shapes, frames, icons, fonts, photo search/drag) remain available.
