# 0.8.266 — Expressive stick figures, and a real walk (2026-09-27)

Stick figures can now show many more emotions, set one facial feature at a time, blink,
talk, and change expression at chosen moments of an animation. The walk cycle was rebuilt so
it reads as walking rather than legs swinging.

## Highlights
- **26 expressions** (was 12): Laughing, Grinning, Crying, Shocked, Nervous, Embarrassed,
  In love, Smug, Cheeky, Thinking, Disgusted, Sleepy, Asleep and Dizzy join the originals.
- **Fine-tune face**: set eyes, brows, mouth and extras separately on top of an expression.
- **Faces over time** for animated figures: blinking, a talking mouth, and expression
  changes placed on the Scene Timeline.
- **A walk that looks like walking**, facing either way.

## Features
- Face parts: 15 eye shapes (adds closed, half-lidded, squeezed shut, looking left/right/up,
  hearts, crosses), 7 brows (adds flat, furrowed), 14 mouths (adds grin, laughing, smirk,
  tongue out, clenched teeth), and extras (blush, tears, sweat drop, Zzz). `'auto'` follows
  the expression; picking a new expression clears overrides not given with it.
- `setStickFace({ face, eyes, brows, mouth, accent })`, `listStickFaceParts()`, and the same
  fields on `insertStickFigure` / `insertAnimatedFigure`.
- Blink: on for new figures, each with its own rhythm; only open eyes blink.
  `setFigureBlink(on?, ids?)`.
- Talking mouth: Auto (during the Talk motion), Always, Off. `setFigureTalking(mode, ids?)`.
- Expression keys: tick **Set at playhead** in Face & hair with the Scene Timeline open, or
  `addFigureExpression(t, choice, id?)`, `setFigureExpressions`, `getFigureExpressions`,
  `removeFigureExpression`. Keys show as faces on the figure's timeline row (drag to retime,
  double-click to remove), switch instantly and hold until the next. Bake uses the key at the
  playhead.
- Walk: planted feet stay on the ground, arms swing opposite the legs and peak at contact,
  the swing foot lifts behind and lands low, legs straighten at contact.

## Fixes
- Figures facing left bent their knees backwards (#402).
- Walk and run feet bobbed with the hips; path-walking figures skated (#403).
- Dropping the same figure again ignored a clothing change (#401).
- `getAnimationDuration` ignored animated figures, so `npm run render` of a figure scene used
  the 5 s default (#405). The scene length also covers the last expression change plus 1 s.

## Internal / tests / docs
- `anim/face-motion.ts`: blink, talking mouth and expression keys as pure functions of time.
- Fill-only prims (`fillOnly`), so coloured marks survive an outline recolour.
- `applyFaceHair` cache keyed on the whole choice.
- `WALK_STRIDE` derived from the clip (`2·STRIDE / STANCE`); path foot depth from `GROUND_Y`.
- Tests: `face.test.ts` (10), `walk.test.ts` (7), `face-motion.test.ts` (9), 11 new
  `stick-face.spec.ts` cases. `stick-animation-speed.spec.ts` now renders exact-time frames and
  passes (it failed on every run before, #404).
- New UI strings are in the i18n catalogue (`stickFace.*`) with German, Spanish, French and
  Japanese translations.
- `stick-face.spec.ts` blush check renders with `renderFrame` instead of reading the screen.
- Help: Stick Figure Library (expressions, Fine-tune face, API, limitations) and Animated Stick
  Figures (walk, "Faces that change over time", API).

## Breaking changes
- None. Saved figures look and move as before, except that walks are now correct; figures saved
  without a blink setting don't blink.
