# 0.8.103 — Real MP4 export of animated pages + font picker fixes (2026-07-14)

## Highlights
- **Export → MP4 now actually exports your animated post.** It renders the page itself — exact
  page bounds, page resolution, animations playing — for a chosen duration and downloads a real
  H.264 `.mp4`. No more live screen-recording with grey workspace around your design.
- **Font picking fixed end-to-end**: the Font dropdown no longer runs off the screen, and arrow
  keys navigate fonts instead of nudging the selected element.
- New **"Stick-Figure Animation Demo"** sample template — five live animated figures, including a
  walker following a drawn path.

## Features
- **Page-scoped video export.** On page documents (designs/slides), Export → MP4/WebM renders the
  current page offline to a hidden canvas: exact page bounds at the page's own resolution (long
  side capped at 1920), animations driven by the same clocks as the live canvas, independent of
  your zoom/pan, with a **Duration (seconds)** field in the Export dialog. Infinite-canvas docs
  keep the live-capture behaviour. API: `Yappy.exportVideo(seconds?, 'mp4' | 'webm')`.
- **Custom font picker** (`components/font-picker.tsx`) for the property panel **and Touch Type**:
  viewport-clamped popup (flips upward near the bottom edge), scrollable, searchable, ↑↓ + Enter
  keyboard navigation, every row previewed in its own typeface, with **🔍 Google Fonts…** and
  **＋ Add font…** as proper buttons. Touch Type gains the Google Fonts picker too.
- **Stick-Figure Animation Demo template** — searchable as "animation" / "stick figure": a
  talk↔wave conversation pair, a walk→point→cheer action sequence, a dancer, and a walker
  following a sine-wave path, with captions pointing at the panel controls and Scene Timeline.

## Fixes
- **MP4 recordings now play everywhere.** MediaRecorder was asked for bare `video/mp4`, letting
  Chrome pick VP9 — a codec most mp4 players can't decode. The codec is now pinned to H.264
  (`avc1.42E01E`), and the bitrate raised to 8 Mbps so line art stays sharp in motion.
- **Arrow keys no longer move the selected element while a dropdown has focus.** Two layers: the
  global hotkey guard now exempts `<select>` elements, and — because the guard runs in the
  capture phase where widget `stopPropagation` can't reach — it also exempts focus anywhere
  inside the font picker, the Google Fonts panel, or any dialog.
- **Font dropdown spilling past the screen edge** with many user-added Google fonts (native
  select popups are OS-rendered and can't be clamped) — replaced with the custom picker above.

## Internal / tests / docs
- Playwright suite now pre-seeds the onboarding tour's seen-flag via `storageState` in
  `playwright.config.ts` — the v0.8.100 tour overlay was silently eating clicks in every
  click-driven spec.
- New permanent specs: `stick-rig-smoke.spec.ts` (first e2e coverage of the animation feature),
  `font-picker-check.spec.ts` (6 cases incl. capture-phase regressions),
  `stick-anim-demo-check.spec.ts`, `mp4-record-check.spec.ts`,
  `page-video-export-check.spec.ts` (asserts the download is page-sized, not screen-sized).
- Help docs refreshed: animated stick figures (ten clips, page-video export section), fonts
  section of Illustrator tools; bugs + learnings logged.

## Breaking changes / migration
- On page documents, Export → MP4/WebM now performs the offline page export instead of starting
  a live recording. Live canvas capture is still available from the Stick Figures panel's
  **Record video** button (and on infinite-canvas docs).
