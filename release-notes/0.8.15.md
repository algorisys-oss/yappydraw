# 0.8.15 — Flappy sample game (2026-07-08)

## Highlights
- New **Flappy** starter under **Menu → Game → New Game…** — a one-button flyer:
  tap or Space to flap through the scrolling pipe gaps.

## Features
- **Flappy** code template (`game/game-templates.ts`): gravity + a flap impulse,
  procedurally spawned pipe pairs with a random gap that scroll in, score on each
  pipe passed, and game-over on any collision (Space to retry). Opens on a portrait
  540×960 stage.

## Fixes
- None (feature release).

## Internal / tests / docs
- `tests/flappy.spec.ts`: the template starts, the bird flaps/falls, and pipes
  scroll in without errors. Deterministic harness verifies hold-before-start, flap
  lift, gravity fall, pipe spawn, ground-death, and clean retry/reset.
- Arcade help doc updated with the new starter.

## Breaking changes / migration
- None.
