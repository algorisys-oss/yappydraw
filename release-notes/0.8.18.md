# 0.8.18 — Stick-figure variant filter fix (2026-07-08)

## Highlights
- The **Man / Woman / Boy / Girl** variant chips now filter cleanly: picking a
  variant shows only that variant's figures.

## Fixes
- Genderless **props** and **scenes** no longer bleed into a gendered "All" view.
  Previously, selecting *Boy* (or *Woman* / *Girl*) still listed every laptop,
  phone and multi-figure scene alongside the figures, which read as "not
  filtering." Props and scenes now appear only when their own category chip is
  selected, or when the variant filter is set to *All*.

## Internal / tests / docs
- `filterStickAssets` skips no-variant assets in mixed (`category:'all'`) views
  while a specific variant is active. Learnings note added (incl. a Playwright
  gotcha: variant-count assertions need real re-render settle time).

## Breaking changes / migration
- None.
