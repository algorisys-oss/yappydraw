# 0.8.296 — Morph between slides (2026-11-01)

## Highlights
- **Morph**, item 6 of the DeckCraft-based slides backlog (`docs/slides-feature-gaps.md`):
  duplicate a slide, change things on the copy, set its transition to Morph, and they glide into
  place while presenting.

## Features
- **Morph transition** (⚡ Transition → Type → Morph). Objects on both slides move, resize, turn and
  change colour (fill, stroke, text, shadow) into place; the rest fade out or in; the backgrounds
  blend. Pairing: same name (`!!name` forces a pair), then same text on the same kind of object,
  then the same kind of shape without text — the nearest one when several qualify. Changed text
  cross-fades while it moves. On-click and start-hidden builds join after the Morph. A click
  mid-transition ends it.
- **PowerPoint**: written as `p159:morph` (PowerPoint 2019 / 365) with a fade for older readers;
  read back as Morph.
