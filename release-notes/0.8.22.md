# 0.8.22 — Stick-figure action sequences + smooth transitions (2026-07-08)

## Highlights
- Give an animated figure a **script**: chain motions over time (Walk → Wave → Talk…)
  that loop, with **smooth cross-faded transitions** between them.

## Features
- **Action sequences** — with an animated figure selected, the panel gains an
  **Action sequence** editor. Add timed steps (each a motion + duration in seconds);
  the figure plays them in order and loops. Rows have a clip dropdown, a seconds
  field and a remove button, plus **+ Add step** and **Clear**. Example:
  *Walk 3s → Wave 2s → Talk 2s*.
- **Smooth transitions** — steps are **cross-faded** automatically (a short pose
  blend at each boundary), so the figure eases from one motion into the next instead
  of snapping.
- **API** — `setFigureSequence([{ clip:'walk', dur:3 }, { clip:'wave', dur:2 }], id?)`
  (empty array clears the sequence).

## Fixes
- None.

## Internal / tests / docs
- `stickRig.sequence` (`{clip,dur}[]`) evaluated in the renderer by cumulative
  duration; `lerpRigPose` cross-fades between the outgoing and incoming poses at each
  step start (pose-level blend, clip-agnostic — works across foot-IK walk and
  angle-offset clips). Library `setFigureSequence`/`getFigureSequence`. Help doc
  updated with a sequences section; learnings recorded.

## Breaking changes / migration
- None. `sequence` is optional and additive.
