# 0.8.51 — Smooth Morph blend + Envelope Make-with-Top-Object (parity polish) (2026-07-10)

## Highlights
- Two Illustrator-parity upgrades: **blend now truly morphs shapes** (a circle becomes a star),
  and you can **warp artwork into any shape's silhouette**.

## Features
- **Smooth Morph blend** — right-click two shapes → **Blend ▸ Smooth Morph**. Instead of just
  recolouring/resizing the first shape, it interpolates the two **outlines** point-for-point, so a
  circle actually morphs into a star across the steps. Each step is an editable `path`; colours blend
  too. `Yappy.blendMorph(steps)`.
- **Envelope: Make with Top Object** — select **artwork + a shape on top**, right-click →
  **Envelope: Make with Top Object**. The top shape becomes the envelope (consumed) and the artwork
  is squeezed into its silhouette — text into a heart, a logo into a circle, etc. Live (bakeable via
  Apply / Bake Warp). `Yappy.envelopeWithTopObject()`.

  `envelopeWithTopObject`). Web help docs updated (`workspace-doc`, `illustrator-tools-doc`).
- These close the last two Medium items on the Illustrator text-effects parity plan (~17 of 18
