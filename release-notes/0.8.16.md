# 0.8.16 — Stick-figure library (drawify-style editable people) (2026-07-08)

## Highlights
- A new **Stick Figures** library: a searchable, categorized panel of 24
  hand-authored stick figures you drag onto the canvas. Each drops in as one
  **editable, recolourable vector group** — not a flat image.

## Features
- **Stick Figures panel** — open it from the toolbar (walking-person button) or
  Menu → **Stick Figures**. Search by name/tag (“wave”, “laptop”, “bike”, “box”…)
  and browse six categories: Daily & Emotions, Office & Work, Meetings & Talks,
  Street & Travel, Social & Family, Services.
- **Add two ways** — **click** a thumbnail to drop centered on the page, or
  **drag** it onto the canvas to place it exactly at the cursor. Either way it
  lands selected and grouped as one object, and in a single undo step.
- **Fully editable** — figures import as native Yappy `path` elements. The
  skeleton splits into **one path per limb** (torso, each arm, each leg), so after
  **Ungroup** you can select and restyle any single limb, the head, or a prop.
  Limbs are gentle **bezier curves** with grabbable handles — reshape, add
  curvature, or apply width profiles like any other path.
- **One-click recolour by part** — select a figure and the panel shows a
  **Recolour selected figure** section: **Outline** recolours the whole stroke,
  **Accent** recolours just the colourful props (laptop screen, briefcase, box,
  heart…) while neutral parts (podium, whiteboard) stay put. Powered by a new
  semantic `sfRole` tag on each part (body / head / accent / prop).
- **Clean defaults** — every figure drops at a crisp **4 px** outline weight
  regardless of size, with round line caps.
- **API** — `window.Yappy.insertStickFigure(id, opts?)`,
  `recolorStickFigure({ outline, accent }, ids?)`, `listStickFigures(category?)`,
  `listStickFigureCategories()`, `toggleStickFigurePanel(visible?)`.

## Fixes
- None (new feature).

## Internal / tests / docs
- New inline data module `library/stick-figures/` (types, 24 SVG assets,
  registry with search, insert + recolour helpers) mirroring the offline
  Templates registry pattern — no network fetches, PWA-friendly.
- SVG importer (`utils/svg-import.ts`) now preserves a `data-sf-role` attribute
  (inherited down the tree) onto imported elements; new `DrawingElement.sfRole`
  field registered in the `migration.ts` passthrough so it survives save/reload.
- `bones()` builder smooths each limb subpath into a bezier curve at build time
  (subtle bow for straight limbs, Catmull-Rom for jointed ones) while keeping
  authoring a single straight `d` string.
- New help doc **Stick-Figure Library** (`help-docs/features/stick-library-doc`)
  registered in the Help page. Render-style parity verified in both
  **architectural** and **sketch**. Learnings recorded; repo map refreshed.

## Breaking changes / migration
- None. The new `sfRole` field is optional and additive; existing documents are
  unaffected.
