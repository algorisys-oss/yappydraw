# Release Notes - v1.8.0

**Release Date:** February 8, 2026

## Overview

This release focuses on table UX improvements: 12 dedicated table animation presets, spreadsheet-style keyboard navigation for cells, a global settings dialog, cell selection highlighting, and a fix for the click/drag conflict when moving tables. It also resolves a property panel reactivity bug.

## What's New

### Table Animation Presets (12 new)

Tables now have dedicated animation presets that leverage their internal row/column/cell structure:

- **tableRowReveal** - Rows slide in one by one from the side
- **tableColReveal** - Columns appear sequentially
- **tableCellFill** - Cells fill in with color progressively
- **tableHeatmapFadeIn** - Cells fade in with heatmap coloring
- **tableRowHighlight** - Rows highlight sequentially with a sweep effect
- **tableColPulse** - Columns pulse with a scale effect
- **tableGridDraw** - Grid lines draw themselves progressively
- **tableHeaderSlam** - Header row slams in with emphasis
- **tableCountUp** - Numeric cells count up from zero
- **tableAccordion** - Rows expand accordion-style
- **tableCellsAssemble** - Cells fly in from scattered positions with rotation
- **tableLightningSplit** - Table splits with a zigzag lightning crack effect

### Table Keyboard Navigation

Spreadsheet-style keyboard navigation for table cells:

- **Arrow keys**: Navigate between cells when a cell is highlighted (not editing)
- **F2**: Start editing the highlighted cell
- **Delete/Backspace**: Clear highlighted cell content
- **Tab/Shift+Tab**: While editing, commit and move to next/previous cell (wraps at row boundary)
- **Enter**: While editing, commit and move down
- **Shift+Enter**: Insert newline within cell
- **Escape**: Cancel editing and return to cell selection

### Table Move Handle

- **Dedicated move icon**: Blue circle with 4-way arrow at top-left corner of selected tables
- **Click vs drag disambiguation**: Click a cell to select it, drag from any cell to move the table
- **Move cursor**: Shows move cursor when hovering the handle

### Visual Cell Selection

- **Cell highlight**: Click a cell to highlight it with a blue selection indicator
- **Multi-cell selection**: Shift+click or Ctrl+click to select cell ranges
- **Full column selection**: Click a header cell to select the entire column

### Global Settings Dialog

- **Text defaults**: Configure default font family and font size
- **Shape defaults**: Set default stroke color, background color, stroke width, and opacity
- **Drawing style**: Choose between Sketch and Architectural render styles
- **Reset to defaults**: One-click reset button

## Bug Fixes

- **Table click/drag conflict**: Fixed clicking a cell blocking table movement. Cell selection is now deferred to mouseUp with a 3px drag threshold
- **Property panel reactivity**: Fixed intermittent missing UI elements (icons, context menus) caused by repeated `activeTarget()` calls across independent `<Show>` conditions in SolidJS
- **Tab key regression**: Fixed Tab being intercepted for table cell navigation when it should create mindmap child nodes
- **Right-click column selection**: Fixed right-click on table header losing multi-column selection

## Upgrade Notes

This release is backward compatible. Existing tables will work as before. The new keyboard navigation activates automatically when a table is selected and a cell is highlighted. Table animations are available in the Animation Panel when a table is selected.
