# 0.8.43 — Canvas background themes (2026-07-09)

## Highlights
- A new **Canvas Theme** picker (Canvas Settings) with 10 one-click presets that set
  the background + grid texture together: Plain, Dot Grid, Line Grid, Graph Paper,
  Notebook, Paper, Parchment, **Blueprint**, **Dark**, and Chalkboard.

## Features
- Each theme bundles a background fill + a canvas texture; the grid/dot **ink now
  derives from the background's luminance**, so dark themes (Blueprint, Dark,
  Chalkboard) get light grid lines automatically — no more invisible grids on a dark
  canvas.
- Picker shows a live preview of each theme (background + texture) and highlights the
  active one. Persists per document via the existing background/texture fields.
- API: `Yappy.setCanvasTheme(id)` (ids in `config/canvas-themes.ts`).

## Fixes
- Canvas textures previously keyed their ink off the UI dark-mode flag, so a manually
  darkened canvas background showed dark-on-dark (near-invisible) grid lines. Now keyed
  off the canvas background luminance.

## Internal / tests / docs
- Verified: applying Blueprint gives a dark-blue canvas with light grid; Dark gives a
  dark canvas with light dots; the picker highlights the active theme. Recorded in
  `docs/learnings.md`.

## Breaking changes / migration
- None. Isometric grid + custom themes remain a follow-up.
