# 0.5.17 — UML Deployment Node & Artifact shapes (2026-06-30)

## Highlights
- **Deployment diagrams** are now first-class: a dedicated **Deployment Node** (3-D box) and **Artifact** (folded-corner document), closing the biggest UML gap from the completeness review.

## Features
- **Deployment Node** (`umlNode`) — a 3-D box (front + top + right faces) with the label on the front face, for devices / servers / execution environments.
- **Artifact** (`umlArtifact`) — a rectangle with a folded-corner document icon, for deployable files (`app.jar`, binaries, scripts).
- Both render in **sketch** and **architectural** styles, accept full fill / stroke / text styling, and are available:
  - in the **Architecture** toolbar group → *UML Structure* section,
  - via the command palette (*UML Deployment Node*, *UML Artifact*),
  - and via DSL aliases `[node]` / `[deployment-node]` and `[artifact]`.

## Internal / tests / docs
- New shapes wired end-to-end (renderer, geometry, hit-testing, transforms, draw/text-edit handlers, DSL defaults/aliases, property `applicableTo` lists, command registry).
- `docs/uml-completeness-review.md` updated — Deployment now ✅; remaining gaps: Object/instance, Port, History pseudostate, Activity action.
- Help doc gains a **Deployment Diagrams** section; learnings updated with the "new shape touches ~12 places" checklist.

## Breaking changes / migration
- None.
