# 0.8.187 — Shape Builder gets its box (2026-08-10)

## Highlights

- **`Shift`+drag in the Shape Builder rubber-bands a box** and takes every region it touches,
  instead of making you thread a stroke through each one. This is Illustrator's binding, and the
  half of it we were missing: `Alt` subtracts, `Shift` boxes.

## Features

- **Shift-marquee.** With the Shape Builder active, `Shift`+drag draws a dashed rubber-band box;
  on release every region it touches merges. `Shift`+`Alt`+drag does the same in delete mode, and
  the box takes the red colouring so the box, the cursor badge and the region highlight always
  agree about the mode.
- **The box catches regions larger than itself.** Rubber-banding a small detail that sits inside a
  much bigger background shape works — the case a naive "is a vertex of the region inside the box"
  test misses completely.
- **Box-vs-stroke is latched at press time.** Releasing `Shift` partway through a drag will not
  silently convert your rubber-band into a freehand stroke. `Alt` stays live right up to release,
  because it only chooses merge vs. delete.

## Fixes

None — this release is additive.

## Internal / tests

- Three new e2e tests: the marquee merge, `Shift`+`Alt` marquee delete (including the colour class
  on the box), and a marquee drawn wholly inside a larger region. That last one is the reason the
  hit test does two things rather than one; without it the cheap vertex-only test would have
  passed every demo built from small overlapping circles.
- Help doc and the hotkeys list updated (`Shape Builder … Shift+drag = box`).

## Breaking changes

None. `Shift` had no binding inside the Shape Builder before this.

## Note on deploying

`0.8.186` was tagged and pushed but its `dist/` was never uploaded to the web host, so this
build supersedes it — one upload covers both releases.
