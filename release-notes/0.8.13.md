# 0.8.13 — Pointer & velocity nodes → a drag-aim Blueprint Slingshot (2026-07-07)

## Highlights
- **Slingshot · Blueprint** — the drag-aim Angry-Birds sample, now built entirely
  in the Blueprint editor (tap the bird, drag to aim, release to fire, pop every pig).
- New Blueprint building blocks that make aim/drag games possible: a **Pointer**
  data node and **set velocity** / **move to point** actions.

## Features
- **Pointer data node** (`blueprint-types` / `blueprint-to-script`): read the
  pointer's `x`, `y`, or `is-down` (1/0) and wire it into math, comparisons, or
  action params.
- **`set velocity (vx, vy)`** and **`move to point (x, y)`** actions
  (`behavior-types` / `behaviors-to-script`) — both data-wireable, so you can drive
  velocity/position from a computed value (e.g. `(anchor − pointer) × power`). They
  work in behaviors and Blueprints alike.
- **Slingshot · Blueprint** starter (`game/blueprint-examples.ts`, New Game): a
  sprite-owned graph that follows the pointer while you drag and launches on
  release, with gravity, pigs to pop (with a win counter), and auto-reset to the
  sling for the next shot. Opens ready-made in the Blueprint editor.

## Fixes
- None (feature release).

## Internal / tests / docs
- `tests/blueprint-games.spec.ts` now covers the Slingshot: it compiles the pointer/
  velocity primitives into the game, launches under a **real-mouse drag** in the real
  runtime, and renders the new POINTER nodes in the editor without errors. The
  deterministic harness verifies launch vector, pig-pop + score, win-at-zero, and
  reset-to-sling.
- Arcade help doc + learnings updated.

## Breaking changes / migration
- None. Purely additive nodes/actions; existing games are unaffected.
