# 0.8.54 — 3D Bevel & Revolve, Effects menu, export fixes (2026-07-10)

## Highlights
- The 3D suite is complete — **Bevel** and **Revolve (lathe)** join Extrude and Tilt.
- A consolidated **Effects** menu makes the advanced effects browsable (not just searchable), and
  three previously API-only effects are now reachable in the UI.
- Two export bugs fixed (images missing; "worked once then nothing").

## Features
- **3D Bevel** — a lit chamfer on the extrude's front edge (Illustrator's "Extrude & Bevel").
  Property panel **Bevel** slider + context-menu preset.
- **3D Revolve (lathe)** — spin a shape's silhouette around its vertical axis into a solid:
  rectangle → cylinder, circle → sphere, triangle → cone, a goblet path → a vase. Right-click →
  **Effects ▸ 3D ▸ Revolve**; `Yappy.toggleRevolve()`.
- **Effects menu** — a new right-click **Effects ✨** submenu gathers Transform Effect (live copies),
  3D (Extrude / Bevel / Revolve / Tilt), Distort & Transform, **Feather**, **Outer Glow**, and
  **Scribble** into one place. Feather / Glow / Scribble were **API-only** before — now also in the
  **command palette** (⌘/Ctrl-K).

## Fixes
- **Images not appearing in export** — an image placed on top of another exported blank (only the
  background showed), because exporters render synchronously while images decode async. Exports now
  preload every image first.
- **Export "worked once then did nothing"** — the export dialog kept "Only selected" checked from a
  prior run, so re-opening with nothing selected silently exported nothing. It now resets to the
  current selection on open, and a toast replaces the silent no-op.

## Internal
- `applyFeather` / `applyGlow` / `applyScribble` extracted as store functions (API delegates), so
  menu + palette + API share one implementation. `preloadImages` / `ensureExportImages` in
  `image-cache` / `export`. New `utils/revolve.ts`; bevel in `utils/extrude.ts`.

## Breaking changes / migration
- None.
