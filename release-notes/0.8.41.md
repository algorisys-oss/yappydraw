# 0.8.41 — Mind-map presets: Sitemap & Random Words (2026-07-09)

## Features
- Two new mind-map starters in the menu (next to **New Mind Map**), each seeding a
  ready-to-edit, colour-coded map via the mind-map engine:
  - **Sitemap** — a top-down site hierarchy (Home → About / Products → Product A·B /
    Blog → Posts / Contact).
  - **Random Words** — a radial "brainstorm" central word with radiating single-word
    branches.
- Both are just `createMindMap` presets (`direction` + `branches`), so you can restyle
  them in place afterwards with the Properties-panel AUTO LAYOUT switcher.

## Internal / tests / docs
- Verified: Sitemap seeds 8 nodes (`vertical-down`), Random Words seeds 7 nodes
  (`radial`); both render with per-branch colour and organic connectors.
- Mind-map Phase 2 is now complete bar a Templates-gallery *card* (deferred — the
  template registry stores static `DrawingData`; the menu presets deliver the variants).

## Breaking changes / migration
- None.
