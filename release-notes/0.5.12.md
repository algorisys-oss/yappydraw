# 0.5.12 — Reusable pattern-swatch library (2026-06-29)

## Highlights
- **Patterns panel.** A document-level library of reusable pattern swatches.
  Build a palette of patterns once — captured artwork or tuned built-in motifs —
  and click to apply them to any shape. Open it from the menu → **Patterns** or
  with **Alt+P**.

## Features
- New `store.patterns` library of named `PatternFill`s, saved with the document
  and covered by undo/redo.
- **Patterns panel** (draggable): capture the current selection as a pattern tile
  (**＋**), apply a swatch to the selection, redefine a swatch from a selected
  shape's pattern, and rename/delete swatches. Custom swatches show their captured
  tile; built-in motifs render a live preview.
- **Save to Library** button in the PATTERN editor (Properties panel) — saves the
  current shape's pattern fill as a swatch.
- `window.Yappy` API: `addPatternSwatchFromSelection(name?)`,
  `savePatternSwatchFromElement(name?)`, `applyPatternSwatch(id)`,
  `updatePatternSwatch(id)`, `renamePatternSwatch(id, name)`,
  `deletePatternSwatch(id)`, `listPatternSwatches()`.

## Internal / tests / docs
- `patterns` wired through every doc-level collection touch point (state, history
  snapshot/restore, document save/load, `SlideDocument` type, id-generator scan) —
  mirroring the existing `graphicStyles`/`swatches` libraries.
- New `components/patterns-panel.tsx` (+ CSS); registered in `app.tsx`, the menu,
  and the help-dialog hotkey list (Alt+P).
- Help doc: **Patterns library** subsection; learnings + roadmap updated.
- **CLAUDE.md:** added a standing rule to always review the relevant web help doc
  for completeness when adding/changing features (and as part of "ship it").
- Verified end-to-end: capture → library, save built-in → library, apply to a new
  shape, panel renders both swatch types, zero console errors.

## Breaking changes / migration
- None. `patterns` defaults to an empty array for existing documents.

## Known limitations
- Applying a swatch copies the pattern onto the shape (no live link back to the
  swatch yet). Sketch-style SVG export of pattern fills remains raster-free only in
  architectural style (unchanged from 0.5.10).
