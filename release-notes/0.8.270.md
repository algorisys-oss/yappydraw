# 0.8.270 — Saved files keep the whole document (2026-10-07)

## Highlights
- **Save to disk no longer loses animations.** A `.yappy`/`.json` file saved from an
  animation reopened with an empty timeline; pattern swatches, symmetry, dimension annotations
  and composition tracks were dropped too. Cloud save and Save as Template lost other fields.
  Every save now writes the same, complete document.
- Opening a file from a newer Yappy is refused with an explanation, instead of opening it as
  a blank page that autosave then made permanent.

## Features
- None.

## Fixes
- **#406: six save paths had drifted.** Save to disk, cloud save (dialog and
  `Yappy.cloud.save`), Save as Template, autosave and the gallery each built the document by
  hand. Save to disk dropped `animTimeline`/`animScenes`, `patterns`, `symmetry`,
  `dimensionAnnotations` and `compositionTracks`; cloud save also dropped the game script,
  behaviours and variables. `buildSlideDocument` is now the only builder, and a test fails if a
  second one appears.
- **#407: a newer-version file opened as legacy.** `loadDocument` sent any version it didn't
  know (above 4) down the v1/v2 path and produced one default slide. It now throws
  `DocumentTooNewError` before touching the open document. If the stored autosave is from a
  newer build (an older cached build served by the service worker), autosave pauses so it can't
  overwrite it. Unknown top-level keys of readable documents are now kept on save.
- **#408: Pathfinder blamed the shapes when its engine crashed.** polygon-clipping overflows
  its stack on near-coincident edges, and the crash was reported as an empty result ("those
  shapes overlap exactly"). It now retries on a 1e-6 grid, which fixed every crashing input a fuzz
  run found. A remaining failure says the shapes *couldn't be combined* and changes nothing.
  Shape Builder no longer silently drops faces the same way.
- **#409: redundant repaints.** A burst of N edits in one task painted the whole scene N
  times in the same frame. Repaints are now coalesced to one per frame.
- Code fonts: the swapped weights are fixed, and text re-fits once fonts finish loading.

## Internal / tests / docs
- `tests/perf-budget.spec.ts`: first performance budgets (render fit/pan/400% in both styles, hit
  test, SVG export, save, open) on a seeded 2,000-element document. Skips on a loaded machine.
- New tests: `document-io.test.ts`, `save-whole-document.spec.ts`, `path-boolean-failure.test.ts`,
  `pathfinder-failure-toast.test.ts`, `redraw-coalescing.spec.ts`. Each fails against the
  previous code.
- Docs: `docs/vectorcraft-review.md` (review of storytold/vectorcraft and the pick list behind
  this release), `docs/command-registry-plan.md` (next refactor, for review), font system reference.

## Breaking changes / migration
- `Yappy.loadDocument(doc)` now **throws** `DocumentTooNewError` (and leaves the open document
  untouched) when `doc.version` is newer than this build reads. Before, it silently loaded the
  document as a blank legacy file. Saved files are unchanged and still `version: 4`.
