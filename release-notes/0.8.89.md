# 0.8.89 — Main menu: collapsible groups & tidier ordering (2026-07-13)

## Highlights
- The main hamburger menu is now organised into **collapsible groups** instead of one
  long flat list. Opening the menu shows a compact set of named sections you expand as
  needed — much less scrolling, Canva/pro-app style.
- Groups, in order: **New → File → AI → Game → Panels → Toolbars → Settings**. Document
  I/O (**File**: Load / Save / Export / Version History / Time-lapse) now sits **right
  after New**, at the top, where you'd expect it.

## Features / UX
- **New collapsible menu groups** (mirroring the existing Game group — chevron header +
  expand/collapse):
  - **New** — New Infinite Drawing, New Presentation, New Design…, New Mind Map, Sitemap,
    Random Words, Magic Resize, Templates, Import from Text. (Default expanded.)
  - **File** — Load Sketch, Export / Save, Export, Version History, Record/Play Time-lapse.
    Moved up to directly follow **New**. (Default expanded.)
  - **AI** — AI Drawing, AI Presentation, AI Design…, AI Image…. Consolidates the four AI
    operations (AI Image… had drifted below the Game section — now back with its siblings).
  - **Panels**, **Toolbars**, **Settings** — the three former plain text headers are now
    real collapsible groups. **Panels** (~17 entries) is the biggest decluttering win.
    (Default collapsed.)
- **AI Settings** intentionally stays in the **Settings** group (it's configuration), not
  the AI group (which holds creation operations).
- No shortcuts changed; all existing hotkeys (Alt+L/B/H/G/W/P/S/M/R/K, Ctrl+Alt+O/S,
  Ctrl+Shift+E/T/I, etc.) are unchanged and still shown on their items.

## Fixes
- None new in this release. (Two earlier fixes — connector-arrow swarm #159 and
  group→ungroup menu #160 — shipped in 0.8.88.)

## Internal / tests / docs
- All changes are in `components/menu.tsx`: six new `createSignal` toggles
  (`newMenuOpen`/`fileMenuOpen`/`aiMenuOpen`/`panelsMenuOpen`/`toolbarsMenuOpen`/
  `settingsMenuOpen`) and the corresponding `menu-group` headers + `<Show>` wrappers. No
  new CSS (reused the Game-group classes).
- **No menu items were lost** in the reorg — verified by diffing the *sorted* list of
  `<span class="label">` texts between HEAD and the working copy: only-additions (the new
  group headers), zero removals.
- Clean `npm run build`. `docs/learnings.md` updated (menu-grouping pattern +
  sorted-label verification technique).
