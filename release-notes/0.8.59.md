# 0.8.59 — Dockable panels Phase D: Graphic Styles, Patterns & Symbols migrated (2026-07-10)

## Highlights
- The **Graphic Styles**, **Patterns**, and **Symbols** panels are now first-class
  **dockable panels** — dock them to an edge, float them, collapse them, reorder
  them in a stack, and the layout persists across reloads.

## Features
- **Phase D migration (Graphic Styles + Patterns + Symbols):** all three panels
  moved onto the shared dock chrome. Opening them the usual ways (menu, `Alt+G` /
  `Alt+P` / `Alt+B`, the scripting API) now opens the *dockable* version — drag it
  to the left/right edge to dock, reorder it within a stack, or float it. Each
  panel's single header action moved into a small in-body toolbar:
  **Save style** (Graphic Styles), **Capture** (Patterns), **Create symbol**
  (Symbols). The dock title bar carries dock-left / dock-right / float / collapse /
  close.
- Under the hood: the existing `toggleXxxPanel` actions drive the dock store via
  the `dock-layout.setPanelOpen()` bridge, so every entry point keeps working and
  the menu checkmarks track the real dock state (`isPanelOpen(id)`).

## Internal / tests / docs
- `tsc -b` and `npm run build` both green; thumbnail render effects (rough.js
  canvases) unchanged and verified to set no signals (no reactive loops).
- Symbols panel's SVG-sizing CSS rules de-scoped from the removed `.symbols-panel`
  wrapper so the icons keep their fixed size body-only.
- `docs/dockable-panel-system-plan.md` updated: these three moved from **Remaining**
  to **Done (v0.8.59)**; remaining panels are property, layers, recolor, brand-kit,
  elements, state, animation, behaviors, stick-figure, ds-ops, vector-tools
  (property/layers are the most coupled — scheduled last).

## Breaking changes / migration
- None. (The old `showSymbolsPanel` / `showGraphicStylesPanel` / `showPatternsPanel`
  settings flags are now unused; panel state lives in the persisted dock layout.)
