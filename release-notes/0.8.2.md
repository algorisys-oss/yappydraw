# 0.8.2 — Arcade Hub, part 1: one Game menu + editor view switcher (2026-07-07)

## Highlights
- The game tools are no longer five loose menu entries. They live under a single
  collapsible **Game** group, and the three editors are now clearly three views of
  one thing, with a **Simple · Graph · Blueprint** switcher in every header.

## Features
- **Menu → Game** group: Build · Node Graph · Blueprint · Play Game · Advanced
  Script — collapsed into one section (click to expand).
- **Game view switcher:** a segmented **Simple / Graph / Blueprint** control in the
  Behaviors panel, Game Graph, and Blueprint headers. They edit the same
  behaviors + blueprints model, so switching is instant and lossless.
