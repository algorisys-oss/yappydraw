# 0.8.73 — Animation presets on paths & groups; layer-panel & dock fixes (2026-07-12)

## Highlights
- **Animation presets now work on vector paths, freehand strokes, and groups.** `drawIn`/`drawOut`
  reveal traces the outline of pen paths and freehand strokes (instead of popping in), and you can
  apply any preset (drawIn, shakeX, revolve, glitch, …) to a whole group — it's applied to each
  member.
- Fixed several **Layer panel** and **dock** papercuts: black toolbar icons, a copy-layer linkage
  bug, undersized tray icons, and a first-open screen flash.

## Features
- **Group / multi-selection presets** — the Animation panel's *Add Animation* menu and the *Stagger*
  effect list now cover the full preset set and apply the chosen preset to **every** selected
  element (a group is a multi-selection). The animation list shows the group's shared sequence, and
  edits/removes propagate across members; header Play/Stop preview the whole group.

## Fixes
- **`drawIn`/`drawOut` invisible on freehand strokes** — `FreehandRenderer` never checked
  `drawProgress`, so the reveal held the stroke at `opacity:0` and then popped it in. It now traces
  the freehand polyline progressively.
- **`drawIn` broken on SVG `path` shapes** — the reveal stroke used `beginPath()+definePath()+stroke()`,
  which can't trace a self-contained `Path2D`. Added an overridable `traceDrawStroke()` that strokes
  the path's `d` directly (honoring the reveal dash).
- **Couldn't apply presets to a group** — *Add Animation* keyed off the single-selection element (null
  for a group) and silently did nothing. It now applies to each member; so do the Rotate / Auto-Spin /
  Path / Morph / Keyframe add actions.
- **Layer toolbar New-Group / Add-layer icons rendered as black blocks** — `.icon-button` had no CSS
  rule and fell back to leftover Vite boilerplate (`button { background: #1a1a1a }`) that only cleared
  under a light-mode OS. Themed the buttons and made the bare-`button` default follow the app theme.
- **Duplicating a layer linked the copy to the original** (move one → both moved) — `duplicateLayer`
  didn't remap `groupIds`/`clipMaskId`, so the copy shared the original's group. Group ids are now
  remapped to fresh ones per copy.
- **Layer swipe-tray icons too small** — Lock / Duplicate / Delete glyphs bumped 15 → 20.
- **First Alt+L (open Layers) flashed the whole screen** — dock panel bodies are `lazy()`-loaded but
  the dock had no `Suspense`, so the first-open suspension bubbled to app.tsx's single shared
  `<Suspense fallback={null}>` and blanked all chrome. Each panel body now has its own Suspense.

## Internal / test changes
- `shape-renderer.ts`: extracted `traceDrawStroke()` from `renderDrawProgress`; overridden in
  `specialty-shape-renderer.ts` (via `geometryToDs()`) and used by `freehand-renderer.ts`.
- `animation-panel.tsx`: shared `addAnimToSelection()` helper; `handlePlayStagger` runs the real
  preset per member via `sequenceAnimator.playAnimation`; list edits are index-based across members.
- `dock-container.tsx`: per-panel `<Suspense>`; `.dock-panel-loading` placeholder.
- `index.css`: removed stale Vite `button` boilerplate defaults.

## Breaking changes / migration
- None.
