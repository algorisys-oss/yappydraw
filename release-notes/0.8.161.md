# 0.8.161 — Bézier handles you can actually grab (2026-07-30)

## Fixes
- **#230 Smooth nodes showed handles that couldn't be dragged.** Self-inflicted by
  0.8.159: the Node tool overlay's capture-phase `pointerdown` calls `stopPropagation()`
  on anything that isn't an anchor hit, so the handles — still drawn by the existing
  selection overlay, and already draggable under the Selection tool — never received the
  event. You could create a curve and then not adjust it.

## Features
- The Node tool owns handles now. Handles of the **selected** anchors are drawn with a
  leader line and grip (only the selected ones — every handle on a busy path is noise,
  and it matches Inkscape), and hit-tested *above* anchors since a handle often sits right
  next to its own.
- Dragging a handle on a **smooth** node mirrors the opposite one — opposite in direction,
  unchanged in length. That mirroring is what "smooth" means.
- **Alt**-drag a handle to break the mirror and give a smooth node a cusp.
- API: `Yappy.getNodeHandles()`.

## Tests
- Two additions to `tests/node-tool.spec.ts`: a smooth node exposes exactly two draggable
  handles and dragging one actually moves it; and after a drag the two handles are opposed
  (cos < −0.9), which is the property that makes the node smooth.

## Known
- The icon-alignment report from 0.8.160 turned out to be a stale dev-server view; the
  shipped build was correct. `toolbar-grid-align.spec.ts` still only covers the **wrapped**
  grid, never the horizontal bar — that coverage gap is real and still open.
