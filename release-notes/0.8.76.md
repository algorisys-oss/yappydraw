# 0.8.76 — Turntable Phase 4: animate the spin (2026-07-12)

## Highlights
- **Turntable spin is now keyframable.** Once a shape has a Turntable effect, its **Yaw** and
  **Pitch** show up as animation channels on the dope sheet — keyframe Yaw 0° → 360° for a
  rotating-turntable loop that scrubs, plays, and exports to video/HTML like any other property.

## Features
- **Keyframable `turntable.yaw` / `turntable.pitch`** — added to the animatable channels for any
  element carrying a turntable (alongside the existing Extrude / Transform-effect channels). The
  per-frame value merges onto the effect and re-renders the rotated path, so a keyframed spin is
  a real editable-vector turntable at every frame. Works in scrub, playback, and export with no
  extra setup.

## Internal / test changes
- `components/keyframe-panel.tsx`: `TURNTABLE_PROPS` (`turntable.yaw`, `turntable.pitch`); pushed
  in `animatablePropsFor` when `el.turntable` is present.
- No evaluator changes needed — `resolveNestedOverrides` already deep-merges dotted-path effect
  keys, so `turntable.yaw` interpolates while preserving `depthModel`/`depthScale`/`cx` (verified
  0→90→180→360).
- `help-docs/features/effects-doc.tsx`, `docs/turntable-plan.md` updated.

## Breaking changes / migration
- None.

## Notes
- This completes the deterministic Turntable roadmap (Phases 1, 2, 4). The only remaining phase
  is **Phase 3 — AI reconstruction** (premium/keyed reimagining of occluded geometry), which is
  optional and degrades to the deterministic spin offline.
