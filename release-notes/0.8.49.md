# 0.8.49 — Native desktop app (Tauri) + export crop/effects fix (2026-07-10)

## Highlights
- **Yappy is now a native desktop app** — a Tauri v2 wrapper (Windows / macOS / Linux) around the
  web frontend, running fully client-side and offline. Phase 1: it builds and runs natively.
- **Export no longer crops artwork** — rotated shapes, effects, and off-page-overlapping elements
  now export in full.

## Features
- **Desktop app** (`desktop/src-tauri/`, Tauri v2, `com.algorisys.yappy`). Runs the SolidJS
  frontend in the system webview — small footprint, offline, no backend.
  - `npm run desktop` (dev, hot-reload) · `npm run desktop:bundle` (release installers:
    `.deb`/`.rpm`/`.AppImage` on Linux, `.msi`/`.exe` on Windows, `.dmg`/`.app` on macOS).
  - See `desktop/README.md` (dev + release-build guide) and `docs/tauri-desktop-plan.md` (roadmap:
    native file open/save, menus, auto-update, stylus).

## Fixes
- **Export cropped artwork / dropped elements / omitted effects** (`utils/export.ts`):
  1. The crop box used the raw `x/y/w/h` union, ignoring **rotation, stroke width, shadow/glow/
     feather, 3D-extrude depth, and Transform-effect copies** — so those were clipped. Now uses a
     rotation- and effect-aware visual-bounds computation for all raster exports.
  2. Paged (design/poster) export included an element only if its **centre** sat inside the page,
     dropping shapes that overlapped the page but were centred off it. Now uses an overlap test.
  3. Export drew only the flat base shape — the live 3D-extrude body and Transform-effect copies
     (which live in the canvas render hook) were missing. They now render in exports too.
  - Applies to PNG / JPG / page / region / artboard / PDF / PPTX exports.

## Internal / tests / docs
- New `desktop/` project (Cargo.lock committed; `target/`/`gen/` gitignored). Root scripts
  `desktop:dev`/`desktop:build`/`desktop`/`desktop:bundle`; app version kept in step across
  `package.json`, `tauri.conf.json`, and `Cargo.toml`.
- Export fix adds `elementAABB`/`elementsBounds`/`overlapsRect`/`renderElWithEffects` in
  `utils/export.ts`. Verified in-app via Playwright (rotated + fan + extruded artwork export
  uncropped; desktop `cargo tauri build` produces installers and the binary launches).
