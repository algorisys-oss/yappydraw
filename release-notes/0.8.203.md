# 0.8.203 — Yappy speaks four languages, and the site finally has more than one URL (2026-08-20)

Two bodies of work that had to happen in one order. YappyDraw is now translatable and ships
Spanish, German and Japanese; and every public page — 31 documents, the examples, a long-form
guide — is a real URL with real HTML behind it, instead of a fragment after a `#` that no search
engine has ever been able to read.

The connection between the two is the middle step: converting 14,696 lines of help documentation
from Solid components to Markdown. Prose in a component cannot be handed to a translator and
cannot be rendered without a browser. Prose in Markdown can be both.

## Highlights

- **Four languages.** English, Español, Deutsch and 日本語, picked from Settings → Language. The
  switch is live — no reload — and it sticks.
- **The documentation is on the web.** `/help/uml/`, `/help/bpmn/`, `/learn/…` — 35 static pages,
  each about 26 KB, each readable without loading the 3 MB editor.
- **A BPMN document nobody could open** is now in the sidebar. It had been written, maintained,
  and never registered.
- **`articles/learn-to-draw/` ships** as `/learn/learn-to-draw-diagrams/` — 443 lines of finished
  long-form content that had been sitting unused in the repo.

## Features

### Languages

- Language picker in **Settings → Language**, persisted to `yappy.locale`, applied before the
  first paint. `<html lang>` and `dir` follow the choice.
- **Spanish, German and Japanese are complete** at 677/677 keys across every namespace extracted
  so far: the command palette and its categories, all 188 keyboard-shortcut descriptions, the
  welcome screen, the status bar and the toolbar chrome.
- Translation follows what a designer in that language already uses — Illustrator and Inkscape's
  Spanish vocabulary (*Buscatrazos*, *mesa de trabajo*, *cuentagotas*), German typography
  („low quotes", decimal comma, space before %), Japanese corner brackets 「」 and full-width
  parentheses.
- Standards and product names are never translated: UML, BPMN, DFD, SVG, Kubernetes, CDN. A test
  asserts it — "UML Class" translated is a shape nobody can find.
- Plurals are per-locale: German declines the noun (1 Element / 3 Elemente), Japanese has one
  form for every count.
- A **pseudo-locale** (`?pseudo`, or in dev) accents and pads every translated string, which is
  how you see what is *not* translated yet.

### Real URLs and static pages

| Before | Now |
| --- | --- |
| `/#/help` | `/help/` |
| `/#/help/uml` | `/help/uml/` — 31 pages |
| `/#/examples` | `/examples/` |
| (not deployed) | `/learn/learn-to-draw-diagrams/` |
| `/#/embed/…` | unchanged — deliberately |

- Old `#/…` links keep working. They are rewritten to the path before the first render, so a
  bookmark never renders the wrong page on the way to the right one.
- Each page ships its own `<title>`, description, canonical, Open Graph and Twitter tags, plus
  `TechArticle` / `Article` and `BreadcrumbList` structured data.
- `sitemap.xml` went from 2 URLs to 38, each with a `lastmod` taken from the file's own last
  commit rather than today's date.
- Fifteen documents that map to a real search carry a search-facing title — "How to make a
  flowchart online", "How to draw a BPMN diagram online" — rather than a sidebar label.

## Fixes

- **The BPMN help document was unreachable.** Written, maintained, and missing from the registry,
  so nothing linked to it and no route reached it.
- **Unstyled documentation.** Five tables, three code blocks and eleven notes used class names
  `help-page.css` has no rules for, and rendered plain next to their styled neighbours.
- **Two `<h1>`s per help page** (the chrome's title and the document's), and twelve on the learn
  article. One per page now.
- **The `www` hostname now redirects to the apex.** The site answered on both with identical
  content and no redirect, splitting every ranking signal in two while the pages' canonical named
  the apex.

## Internal / tests / docs

- `frontend/src/i18n/` — the runtime: reactive `t()`, per-key English fallback, `Intl` formatting
  and plurals, lazy per-locale chunks (~30 KB each, so a visitor downloads only their language).
- `npm run i18n:lint` is a **ratchet**, not a pass/fail lint: 1,629 hardcoded strings remain until
  Phase 3, and it fails only on an increase.
- `scripts/help-doc-to-md.mjs` + `scripts/help-doc-verify.mjs` — the conversion and its audit. The
  verifier renders each `.md` through the real renderer and diffs the word stream *and* the
  structural counts against the JSX; 29/29 clean. Kept in the repo: re-running them from this
  release's parent commit reproduces every conversion.
- `scripts/prerender.ts` (run by `tsx` after `vite build`) and `frontend/src/prerender/` — 35
  pages and the sitemap, from the same `renderHelpDoc` the app uses, so the indexable page and the
  in-app page cannot drift. A test asserts the pages contain no application bundle.
- `frontend/src/routes.ts` — one URL table for the router, the links, the prerenderer and the
  sitemap. It already tolerates a locale prefix, so per-locale URLs are a list, not a rewrite.
- Help-doc chunks are named `helpdoc-*`, which is what the precache filter matches. The rename
  from `*-doc.tsx` had silently added 586 KiB to every visitor's background download.
- `npm run verify:deploy` now checks the prerendered pages arrived, that their canonicals are
  self-referencing, that the sitemap is served, and that an unknown page answers 404 rather than a
  soft 404.
- 1,016 unit tests (up from 964).

## Breaking changes / migration

None for documents or drawings — nothing about the file format changes.

For anyone **hosting a copy**: the deploy is no longer a flat directory. `/help/` and `/learn/`
are directories of `index.html` files and must be uploaded, and `.htaccess` now carries the
routing rules (including the `www` → apex redirect; remove that block if your host only serves
`www`). Upload so the remote tree is replaced rather than merged, and include dotfiles.

Embeds are untouched: `#/embed/…` URLs in existing iframes, wikis and Confluence pages work
exactly as before.
