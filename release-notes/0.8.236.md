# v0.8.236 — Anshika's week-one review

**Date:** 2026-09-07

Ten fixes and three improvements from a designer's first sustained week in the app
(31 Aug – 4 Sep 2026), working the way a vector illustrator actually works: many layers,
many colour experiments, the Pen, and repeated exports.

## Highlights

- **Exports now match the canvas.** Any drawing built across more than one layer could export
  with its shapes stacked differently from what was on screen. This was the report that mattered
  most: the canvas was right and every exported file was wrong.
- **Deleting a layer group asks first**, and can keep the contents. It used to take the artwork
  with it silently.
- **The tool you pick stays picked** — draw three rectangles without going back to the toolbar.
- **The colour wheel's black and white corners work**, and exports can be named and filed.

## Fixes

- **Export z-order** (#348) — PNG, JPG, SVG, PDF, PPTX, paged export, copy-as-PNG, rasterize and
  slice all iterated the document in array order instead of layer order. All twelve call sites now
  share one `elementsInRenderOrder()` with the canvas renderer.
- **A locked layer froze panning** (#349) — the locked-layer guard sat above the tool dispatch, so
  the Hand tool and space-hold pan were both refused. Pan and Laser are dispatched before it now.
- **Deleting a group destroyed its contents with no prompt** (#350) — the confirmation counted only
  elements directly on the layer, which for a group is always none. Orphaned child layers then
  disappeared from the panel, the canvas and every export. The prompt now counts the whole subtree
  and offers to keep the contents.
- **The colour wheel's hue ring stole pure black and white** (#351) — the shade triangle was
  inscribed in the ring, so its corners sat inside the ring's grab band. The triangle is now inset,
  and a drag stays on whichever control it started on.
- **Stick figures: Mono looked identical to Colour** (#352) — the thumbnail path cleared accent and
  hair fills but not garments, so every skirted pose kept its colour in the panel.
- **Right-click with the eyedropper armed opened the context menu** over the target (#353).
- **Layer drag-reorder failed with a pen** (#354) — no `touch-action` on the drag handle, so the
  browser claimed the gesture as a scroll and cancelled the drag.
- **New layers jumped to the top of the stack**, out of the current group (#355). They now land
  directly above the active layer, in the same parent.
- **Duplicating a group layer produced an empty group** (#356) — the whole subtree is copied now.
- **Shape Builder painted every face with the backmost shape's appearance** (#357) — each face now
  takes the topmost shape covering it, matching Illustrator and this codebase's own Pathfinder.

## Features

- **Keep tool active after drawing** — on by default, matching Illustrator, Affinity, Figma and
  Inkscape. Settings → Input turns it off. The shape you just drew stays selected either way.
  Scripted via `Yappy.setKeepToolActive()` / `getKeepToolActive()`.
- **Pen: <kbd>Alt</kbd>-click an anchor you have already placed** to flip it between corner and
  smooth without leaving the Pen. This is the fix for "after a curve there is no way to make the
  next segment straight".
- **Pen: a close-path indicator** — a hollow blue ring on the first anchor when a click would close
  the shape.
- **Layers: <kbd>Shift</kbd>-click for a range, <kbd>Ctrl</kbd>/<kbd>⌘</kbd>-click to toggle.**
  Multi-select was previously reachable only by swiping a row sideways.
- **Exports prompt for a name and folder** on Chrome, Edge and the desktop build (File System
  Access API). Firefox and Safari keep the existing download behaviour.
- Selecting artwork scrolls its layer row into view in the panel.
- The colour picker's square/wheel switch is a segmented control, not two buttons that look like
  swatches.

## Internal

- `path-boolean-position.test.ts` — 9 tests pinning the boolean/pathfinder pipeline's position
  fidelity end to end (element → world polygon → boolean result → path element bbox) across
  rectangles, ellipses, editable paths and far-from-origin shapes. Added to settle the "the merged
  shape moves" part of the report: the geometry is position-preserving at every step, and the
  visible symptom was #357.

## Notes

No migration. `keepToolActive` defaults to on, which is a behaviour change for existing users:
tools no longer revert to Select after each shape. Settings → Input restores the old behaviour.
