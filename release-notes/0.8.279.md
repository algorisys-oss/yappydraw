# 0.8.279 — Print-ready PDF: vector, CMYK, spot colours, PDF/X-4 (2026-10-09)

## Highlights
- **PDF export is vector now.** Shapes, sketch strokes and gradients stay sharp at any zoom, and text stays real, selectable text in its own (embedded) font. The old one-picture-per-page PDF is still there as **Image**.
- **Print-ready PDFs.** Choose **CMYK (print)** and every colour, gradient and photo is separated to printing inks through a real press profile (FOGRA39 for Europe, GRACoL for the US). Pure black prints as black ink only.
- **Brand colours and spot inks.** Give a swatch exact CMYK values, or make it a named spot ink (e.g. PANTONE 186 C) that prints on its own plate.
- **PDF/X-4** for print shops, and an on-screen **print preview** that shows the canvas as it will print.

## Features
- Vector PDF via the SVG exporter + svg2pdf.js: one page per Design/Slides page, built-in fonts embedded (Regular, Bold, Italic — WOFF italics unwrapped to TrueType at export), custom `.ttf`/`.woff` fonts embedded, image filters baked in. `Yappy.exportPDF({ vector, onlySelected, background, scale, download })` resolves to the PDF Blob.
- Masks and effects in exports: clipping masks are real `<clipPath>` in SVG and stay vector in the PDF; opacity masks are a `<mask>` in SVG; drop shadow / glow / feather are SVG filters. In the vector PDF a shadow or glow is a small image under a still-vector shape.
- CMYK PDF (`Yappy.exportPDF({ colorMode: 'cmyk', profile: 'fogra39' | 'gracol' })`): ICC conversion with LittleCMS (lcms-wasm), relative colorimetric + black-point compensation; images converted to DeviceCMYK; gradients separated.
- Swatch print colour: Swatches panel → printer button — Screen vs “Prints as”, out-of-gamut note, C/M/Y/K sliders, spot-ink name; CMYK/SPOT badges. `Yappy.setSwatchCmyk(id, [c,m,y,k])`, `Yappy.setSwatchSpot(id, name)`.
- Spot colours export as PDF Separations — verified as their own plate with Ghostscript `tiffsep`.
- PDF/X-4 (`{ pdfx: true, title }`): output intent with the embedded press profile, XMP identification, Trim/Bleed boxes (the document bleed is added around each page), every font embedded.
- Print preview (soft proof): command palette → *Toggle Print Preview (CMYK)*, or `Yappy.setPrintPreview(true)`. A 3D colour lookup table through the profile, applied on the GPU over the live canvas; editing keeps working.

## Fixes
- **#431** Shadows, glows and feather were the wrong size in any export at a scale other than 1× (2×/3× PNG had half/third-size shadows) and changed size with zoom and screen density — canvas shadow lengths are device pixels; `RenderPipeline` now scales them by the render transform. On high-density screens shadows now draw at their true, larger size.
- **#432** SVG export ignored clipping and opacity masks; it now exports them (and shadow/glow/feather filters).

## Breaking changes / migration
- **PDF export defaults to Vector.** Effects that only exist as pixels are embedded as small images; choose **Image** in the dialog (or `{ vector: false }`) for the previous one-bitmap-per-page PDF.
- PDF/X-4 output has not yet been run through a commercial PDF/X preflight — preflight before sending to press.
