# 0.8.82 — Custom stroke dash patterns (2026-07-13)

## Highlights
- **Type any dash pattern, not just solid/dashed/dotted.** A new **Stroke Dash** control lets you set
  a custom on/off pixel sequence (e.g. `12, 5, 2, 5` for dash-dot), with a live preview and quick
  presets — rendered in both draw styles and exported faithfully to SVG.

## Features
- **Stroke Dash panel** (`property-panel.tsx` → `StrokeDashControls`): for any single element with a
  visible stroke, type a comma/space-separated dash pattern, pick a quick chip (Dash / Dot /
  Dash-dot / Long), or **Clear** back to the Stroke Style preset. A live SVG preview shows exactly
  what renders. Custom dashes override the `solid`/`dashed`/`dotted` preset.
- **Appearance strokes:** each stroke in the Appearance stack gains its own compact custom-dash
  field, so stacked strokes can carry different patterns.
- **API:** `Yappy.setStrokeDash(pattern?, ids?)` — set an on/off pixel array (empty/omitted clears
  it, reverting to the preset). Defaults to the current selection; one undo entry.
- **Model:** `DrawingElement.strokeDashArray?: number[]` and `PaintStroke.dashArray?: number[]`.

## Internal / tests / docs
- New shared `utils/stroke-dash.ts` (`resolveDash` / `customDash` / `parseDashInput` /
  `dashToString`) — a single resolver used by both the live canvas pipeline (`render-pipeline.ts`)
  and the **separate** SVG export pipeline (`export.ts`), which each keep their historical preset
  pixel values while gaining the custom-array override.
- Verified end-to-end via Playwright: custom dash applies via API, renders on canvas in both
  architectural and sketch styles, and exports to SVG (`stroke-dasharray`) in both; the panel input
  reflects/edits the pattern and Clear reverts.
- Updated the Workspace help doc (Custom stroke dashes section + API row), `docs/learnings.md`, and
  the vector-illustration roadmap (custom dash-pattern UI marked done).

## Breaking changes / migration
- None. Existing `strokeStyle` presets are unchanged; custom dashes are additive.
