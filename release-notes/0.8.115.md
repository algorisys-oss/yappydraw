# 0.8.115 — A mood per line

**Date:** 2026-07-19

## Highlights

- Set a character's mood on a single line, so it can change from panel to panel.

## Features

- **Inline emotion cues.** Put the emotion in the script and it applies to that line
  only:

  ```
  Ann (happy): the build is green
  Ben: nice
  Ann (angry): the build is green
  Ben: oh
  ```

  Ann is cheerful in the first panel and furious in the second, with identical
  dialogue — only the cue differs.

  - Uses the same bracket that already carried `(thinks)` and `(whispers)`, now read
    as comma-separated tokens, so cues **combine**: `Ann (angry, whispers):` is an
    angry whisper.
  - Emotions can be written by id or label, case-insensitively — `(angry)`,
    `(Laughing)`, `(SHOUTING)` all work.
  - **Precedence:** an inline cue beats Comic Studio's per-speaker emotion picker,
    which beats what the words themselves suggested.

  This fills the gap left by the existing `emotions` option, which is keyed by speaker
  and therefore applied to a whole strip at once.

## Internal / test changes

- The bracket is matched **all-or-nothing**: if any token isn't recognised, the
  brackets stay part of the speaker's name. Recognising `angry` in `(angry, CEO)` and
  quietly ignoring `CEO` would discard half of what was written while looking like it
  worked — and `Ann (CEO):` must keep naming a character.
- 6 new unit tests (id and label forms, case-insensitivity, combining with a balloon
  type, unrecognised brackets, all-or-nothing token matching, and one speaker carrying
  different emotions across panels) — 61 in the comic suite, 173 overall.
- Verified in the running app: two panels with identical dialogue render a thumbs-up
  figure and a stressed one, driven only by the cue.
- Recorded in `docs/learnings.md`: put the knob where the content is (an inline cue
  travels with its line; panel indices shift the moment the script is edited), and
  prefer "understand everything or nothing" when parsing optional user syntax.

## Breaking changes / migration

None. Scripts without a bracketed cue behave exactly as before.
