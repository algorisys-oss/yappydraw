# 0.8.246 — 1,582 illustrations (2026-09-13)

## Highlights
- **The illustration library grew from 85 to 1,582.** The Elements panel now carries the flat
  style of **Microsoft Fluent Emoji** — people and jobs, faces, animals, food, travel, objects,
  symbols and flags — and every one still inserts as an editable, recolourable vector.
- **Free to use in anything you make.** The set is MIT licensed, replacing OpenMoji's CC BY-SA,
  whose share-alike terms were awkward to apply to your own designs.

## Features
- **Search by name or keyword.** *developer* finds the technologist, *celebrate* the party
  popper. The best matches come first — exact name, then a name that starts with the word,
  then a name that contains it, then keywords — with alias-only matches ranked behind direct
  ones, up to 60 per search.
- **Loaded on demand.** Only the search index ships with the app (~120 KB, and only once search
  is used). Each picture is fetched the first time it is shown and then works offline.
- **API:** `Yappy.insertElement(hit)` returns a promise for illustration hits, because the SVG
  loads first. Await it before reading the new elements.

## Fixes
None.

## Internal / tests / docs
- `scripts/build-illustrations.mjs` rewritten to build from a sparse, blobless clone of
  `microsoft/fluentui-emoji`: writes `public/illustrations/fluent-<commit>/<id>.svg` plus
  `index-data.ts`. The directory is named after the upstream commit so a regeneration changes
  every URL — `.htaccess` marks `.svg` immutable and the service worker caches them CacheFirst.
- Illustrations are excluded from the service-worker precache and cached at runtime
  (200 responses only, max 400 entries, 90 days).
- 12 of 1,594 upstream SVGs use gradients, clip paths or masks the canvas importer cannot draw;
  they are skipped at build time rather than shipped broken.
- The loader rejects non-SVG bodies (a host answering a missing file with a 200 HTML page) and
  does not cache failures. A failed insert shows a toast and adds nothing.
- New `registry.test.ts` (14 tests: ranking, cap, dedupe, URL building, cache and failure
  paths); `element-search-illustrations.spec.ts` checks thumbnails load from the static files
  and adds a 404 case.
- Help → Element Search, the panel attribution line, `LICENSE.md` and `api.ts` updated.

## Breaking changes / migration
None. Documents that already contain OpenMoji illustrations are unaffected — an inserted
illustration is plain vector paths with no link back to the library.
