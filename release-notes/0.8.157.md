# 0.8.157 — 62% smaller cold load, and Shift finally constrains shapes (2026-07-29)

## Highlights
- **Cold-load JS cut from ~1,821 kB to 694 kB gzip (−62%).** YappyDraw was downloading
  most of an export bundle, a PDF/PowerPoint library and a whole icon package before it
  could draw a single line.
- **Shift now draws squares and perfect circles**, which the status bar had been
  promising for shape tools all along.

## Fixes
- **#226 Shift did nothing when drawing a shape.** `drawOnMove` only implemented an
  *angle* constraint, and only for `line`/`arrow`/`bezier`. Shape tools now constrain the
  drag to a square: it follows the larger drag axis and keeps each axis's sign, so it
  still draws in all four directions. The 15° angle snap keeps precedence for connectors.
- **#227 ~1.8 MB gzip of never-used code on every cold load.** Three separate causes:
  - `components/menu.tsx` statically imported `exportSceneAsHtml`, whose module graph
    ends at `assets/player-assets.ts` — the entire player bundle held as a 2.4 MB string.
    `api.ts` already loaded it dynamically; one remaining static import was enough to pin
    it to the entry. Now dynamic at both call sites.
  - `utils/export.ts` imported `jspdf` + `pptxgenjs` at module level for two functions,
    while seven modules import that file statically for plain PNG/SVG export. Moved
    inside `exportToPdf` / `exportToPptx`.
  - `manualChunks` named `lucide-solid`, forcing the **whole** icon package into
    `vendor-rendering` and defeating tree-shaking of the ~40 icons actually used.

  Making the imports dynamic was not sufficient on its own — a `manualChunks` entry keeps
  forcing its modules into a chunk reachable from the entry. `jspdf`, `pptxgenjs` and
  `lucide-solid` were removed from that config too.

## Numbers
| | Before | After |
|---|---|---|
| Cold-load JS (gzip) | ~1,821 kB | **694 kB** |
| `index` chunk | 4,748 kB / 1,379 kB gzip | 2,368 kB / 679 kB gzip |
| `vendor-rendering` | 674 kB | **28 kB** |
| `vendor-export` (eager) | 761 kB | — (now lazy) |

Every deferred feature still works — export to PDF, PPTX and standalone HTML all load
their dependencies on demand.

## Internal / tests
- `tests/bundle-lazy-load.spec.ts` — boot + draw, icons render, the export module graph
  survives losing its top-level vendor imports, the HTML-export chain still resolves, and
  a **gzip budget** over whatever `dist/index.html` actually references (fails at 900 kB).
  A/B'd: reverting one change takes cold load to 925 kB and the budget fails.
- `tests/shift-aspect-constrain.spec.ts` — square/circle/diamond constrain under Shift,
  free rectangle without it, all four drag directions, and lines still snap to 15°.

## Known
- The Playwright suite defaults to multiple workers against a single dev server; long
  combined runs flake under that contention. Run with `--workers=1` for a clean signal.
