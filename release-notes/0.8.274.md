# 0.8.274 — Letters as pen strokes (2026-10-08)

Three picks from reviewing [msurguy/draw-presenter](https://github.com/msurguy/draw-presenter).
Most of its feature list Yappy already had — build steps, direction-aware transitions, mermaid,
templates, laser and highlighter — and its stroke reveal is weaker than `rough-stroke-trace`,
which re-runs a shape's own `renderSketch()` so the reveal ends on exactly the strokes the
finished shape draws. These are the parts that were genuinely missing.

## Highlights
- **Single-line (stroke) text.** `Yappy.strokeText` writes with Dr A. V. Hershey's 1967
  letterforms — the data every pen plotter has used since. Unlike Create Outlines and `tex`,
  which produce *filled* glyph shapes, these are **centrelines**: the line a pen would travel.
  That makes handwriting that writes itself possible, and gives plotters and engravers something
  they can actually follow.
- **Spotlight** while presenting — dim everything except what matters.
- **Stepping back through a deck** lands on the previous slide fully built, instead of a
  half-empty one you had to click your way out of.

## Features
- **`Yappy.strokeText(x, y, text, opts)`** — one open, editable `path` per glyph, grouped so the
  word drags as one object, mirroring what `Yappy.tex` returns. `fontSize` is the cap height, as
  in `tex`. Five faces (`Yappy.strokeFonts()`): **Hershey Simplex** (the plotter default),
  **Duplex** (double-stroked, reads as bold), **Sans**, **Script** and **Gothic**. Options for
  `letterSpacing`, `lineHeight`, `align`, colour, weight and `renderStyle`. Characters outside
  ASCII 32–126 are skipped and listed in `missingChars` rather than silently drawn as something
  else. 78 KB of font data, fetched on first use.
- **`Yappy.drawIn(ids, duration, { stagger })`** and **`drawOut`** — the progressive stroke
  reveal, now reachable from a script. It existed but could only be triggered through
  `playEntranceAnimation`, which reads an element's own `entranceAnimation` property and so
  cannot be aimed at a preset. With `stagger` it is two lines to make a word write itself:
  ```
  const t = await Yappy.strokeText(120, 200, 'Hello', { font: 'hershey-script', fontSize: 72 });
  Yappy.drawIn(t.ids, 600, { stagger: 90 });
  ```
  In sketch style it traces the hand-drawn strokes themselves, so the reveal ends on the finished
  letterform instead of popping into it.
- **Spotlight** — select something and press 💡 in the presentation toolbar; the rest of the
  canvas fades to 12%. Press it again or <kbd>Esc</kbd> to bring it back. A spotlit container
  brings its children, so a mind-map branch or a grouped diagram lights as a whole. Dimmed
  elements stay clickable — this is emphasis, not a mode — and it is never saved into your file
  or recorded in undo. API: `Yappy.setSpotlight(ids)`, `toggleSpotlight()`, `spotlight`.

## Fixes
- **#428 Stepping back landed on a half-built slide.** `retreatPresentation` only decremented the
  slide index, and `setActiveSlide` then re-ran `slideBuildManager.init()`, which re-hides every
  on-click element. Forward navigation wants exactly that; backward wants the opposite, and
  nothing told them apart — so ← showed a half-empty slide that then took one ← per build step
  to leave. Going back now shows the slide as you last saw it.

## Internal / tests / docs
- Stroke fonts needed **no renderer changes**: `pathSubpaths` already carry a per-subpath
  `closed` flag, and `path` is registered to `SpecialtyShapeRenderer`, whose `traceDrawStroke`
  override strokes the SVG `d` directly — so open glyph paths render in both styles, hit-test,
  export, edit with the Node tool and animate, out of the box.
- `scripts/build-stroke-fonts.mjs` converts the `.jhf` source (`npm run build:stroke-fonts`).
  The vertical metrics were **measured, not recalled** — baseline y=+9, caps to −12, descenders
  to +16, so cap height 21, x-height 14, descender 7. The converter normalises every glyph to
  x=0 on a y=0 baseline, so the runtime is arithmetic-free.
- The spotlight shares the renderer's existing focus-dimming path (`dimExemptSet` unions mind-map
  focus with the spotlight) rather than adding a second one.
- 20 new unit tests run against the **shipped** font JSON, not a fixture, so a broken converter
  fails them. 18 new e2e tests; two of them check **pixels** — that the dimming reaches the paint
  and that the letters actually draw — because the bookkeeping can be perfect while the paint is
  wrong, which is how focus mode shipped half-built. Unit suite 1701 pass.
- `THIRD_PARTY_NOTICES.md` (new, repo root) carries the acknowledgements the Hershey licence
  requires; each generated font file also embeds them in a `notice` field so they cannot be
  separated from the data. Sources and verbatim licence text in `scripts/data/hershey/`.
