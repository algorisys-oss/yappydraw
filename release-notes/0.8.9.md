# 0.8.9 — Game Stop button single-click fix (2026-07-07)

## Highlights
- The **Stop** button while playing a game now stops on the first click (it used
  to sometimes need two).

## Fixes
- **Stop needed two clicks.** The play overlay captures pointer input for the
  runtime; a lingering pointer capture redirected the Stop button's `pointerup` to
  the overlay, so the `click` never fired on the button. Stop / Replay / Exit now
  act on `pointerdown`, and the overlay releases the capture on pointerup. (Bug #140.)

## Internal / tests / docs
- `game-overlay.tsx`: buttons fire on `pointerdown`; `onUp` releases pointer capture.
  e2e confirms single-click stop after interacting; arcade suite green (10).

## Breaking changes / migration
- None.
