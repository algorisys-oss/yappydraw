# 0.8.65 — After-Effects–class keyframe animation (Phases 0–3) (2026-07-11)

## Highlights
- **Keyframes timeline (dope sheet).** A new bottom panel (Menu → View → **Keyframes**,
  or **Alt+K**) gives any element an absolute-time, scrubbable animation timeline —
  keyframe position, size, rotation, opacity, fill and stroke on a playhead, exactly
  like After Effects. Preview plays live on the canvas and drives video export.
- **Easing / graph editor.** Click a keyframe to shape its timing: presets
  (Linear / Ease In / Out / In-Out / Hold) plus a draggable **bezier curve editor**
  with overshoot. Hold keyframes step instead of interpolating.
- **Transform parenting & null objects.** Parent one element to another (or to an
  invisible **null object**) so it inherits the parent's animated position, rotation
  and scale — animate one controller, move a whole rig.

## Features

### The spine (Phase 0)
- A pure, deterministic **`evaluateCompositionAt(t)`** evaluator: absolute-time
  `PropertyTrack`s (keyframes in seconds) are random-access seekable, interpolated with
  `lerp`/`lerpColor` and per-segment easing, and returned as render-time overrides. It
  merges into the existing animated-state map, so the scrubber preview, hit-testing and
  the video encoder all use the **same** result (WYSIWYG). No element is mutated —
  clearing the tracks restores the original. An adapter lifts the old normalized
  `KeyframeAnimation` (offset 0..1) onto absolute-time tracks.

### Dope sheet (Phase 1)
- Universal keyframe timeline for the selected element: property rows with a ◆
  **stopwatch** (record the current value at the playhead), draggable keyframe
  **diamonds** (retime, snapped to 0.05 s), double-click / **Del** to delete, click a
  lane or drag the ruler to scrub, an editable **duration** field, and play / loop.
- Keyframe edits are on the undo stack.

### Graph / easing editor (Phase 2)
- Per-keyframe easing on the **segment entering** it: 5 presets plus a bezier graph with
  two draggable handles (overshoot allowed). **Hold** keyframes render as amber squares
  and step the value with no interpolation.

### Transform parenting & null objects (Phase 3)
- `transformParentId` makes a child inherit its parent's animated **position, rotation
  and scale** (composed as affine matrices up the chain; a child with no keyframes of its
  own still follows an animated parent). Kept separate from mind-map parent/child.
- **Null objects** (`Yappy.createNull()`, or the ⊕ button in the panel) — invisible
  transform controllers that show as a crosshair while editing and never appear in
  presentations or exports.
- A **Parent** selector (pick-whip) in the panel header sets/clears the relationship
  (self and descendants excluded to prevent cycles).

## Scripting API (`window.Yappy`)
- `toggleKeyframePanel()`, `setCompositionTracks()` / `getCompositionTracks()` /

- `createNull(x?, y?)`, `setTransformParent(childId, parentId)`.

## Fixes
- **Keyframes playhead now repaints the canvas** — the composition clock was gated on the
  Scene Timeline only, so scrubbing the Keyframes panel didn't move shapes on-canvas
  (see `docs/bugs/bug-fixes.md` #146).
- **Stopwatch records the stored value**, not the held/evaluated one, so successive
  keyframes actually interpolate (#147).

## Known limitations
- The Property panel doesn't yet show/edit the *animated* value at the playhead (set the
  value, then keyframe it) — no auto-keyframe mode yet.
- Hit-testing uses stored positions (not composition overrides) during authoring;
  `compositionTracks` are not yet persisted with the document.
- Null objects are a flagged `rectangle` rather than a first-class element type.

## Breaking changes / migration
- None. New fields are optional; existing documents are unaffected.
