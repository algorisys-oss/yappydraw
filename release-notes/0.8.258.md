# 0.8.258 — Anshika's review, second pass (2026-09-16)

## Highlights
- **Pathfinder, Shape Builder and Offset Path keep brushed and pencil shapes where they are.**
  Uniting a big brush stroke with a small one used to shift each by half its own size, so the small
  piece landed up and to the left.
- **PNG and JPG exports match the canvas** for rotated shapes, clipping masks and anything posed by
  animation or parenting.
- **Deleting a layer group asks properly**: Cancel, Keep contents, or Delete everything.
- **The Pen keeps going after you close a shape**, and Alt-click on the point you just placed makes
  the next segment straight without flattening the curve behind it.

## Features
- `Yappy.getLayers()`; `Yappy.addLayer(name, parentId)`; `Yappy.duplicateLayer()` and
  `Yappy.createLayerGroup()` return the new id; `Yappy.deleteLayer(id, 'keep' | 'delete')`.
- Layers panel: pen-sized drag grip, auto-scroll while a drag rests near the edge, collapsed groups
  open when you select artwork inside them.
- Closing a Pen path fills it with the current fill colour.

## Fixes
- **#372** Pathfinder / Shape Builder / Offset Path / Distort / Knife / freehand clip masks moved
  point-based shapes by half their size (top-left `points` read as centred). Closed as not-a-bug in
  #357; the position test didn't cover freehand shapes. Simplify also re-fits its box now.
- **#373** Exports: rotated shapes were cropped (radians converted as degrees), mask shapes were
  drawn and never clipped anything, animated/parented poses and animation frames were ignored.
- **#374** New layers listed at the top of the panel and jumped there on the next drag (array vs
  `order`); repeated adds collided; adding while a group was active didn't nest.
- **#375** Duplicating a group gave every copied layer the same id (a self-parent cycle that froze
  the page on delete), merged separate groups in the copy, interleaved the copy's stacking with the
  original, and broke duplicated clipping masks.
- **#376** Group delete: Cancel still deleted; animation documents orphaned child layers; multi-delete
  asked once per child.
- **#377** "Move to Top Level" never accepted a drop; no auto-scroll; tiny grip.
- **#378** Pen close ignored *Keep tool active* and didn't leave the shape selected; Alt-click on the
  last anchor removed both handles.
- **#379** The colour wheel spun to red when reopened on black, white or grey.
- **#380** Scribble fill covered the bounding box instead of the shape and ignored rotation.

## Breaking changes / migration
- `Yappy.deleteLayer(id)` now returns a Promise and, for a non-empty layer, waits for the user's
  answer in an in-app dialog (it used to block on `confirm()`). Scripts that must not prompt pass
  `'keep'` or `'delete'`.
- SVG export still doesn't apply clipping masks, but it no longer draws the mask shape itself.
