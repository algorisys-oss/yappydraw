# 0.8.63 — Dockable panels Phase D: Layers migrated (2026-07-10)

## Highlights
- The **Layers** panel is now a first-class **dockable panel** — dock it to an edge,
  float it, collapse it, reorder it in a stack, and the layout persists across
  reloads. Only the **Property** panel remains to migrate.

## Features
- **Phase D migration (Layers):** the Layers panel moved onto the shared dock
  chrome. Opening it the usual ways (menu, `Alt+L`, the `\` hotkey that toggles
  Property + Layers together, the scripting API) now opens the *dockable* version —
  drag it to the left/right edge to dock, reorder it within a stack, or float it.
  The **Groups**, **New Group**, and **Add Layer** actions moved into a small in-body
  toolbar; the dock title bar carries dock/float/collapse/close.

## Internal / tests / docs
- **Dropped the panel's bespoke minimize subsystem.** Layers had its own
  collapse-to-header behaviour (`isLayerPanelMinimized`, a dblclick-header handler,
  minimize/expand buttons, a `.minimized` CSS class, and `<Show when={!minimized}>`
  guards around the whole body). The dock chrome already provides collapse, so all of
  that was removed and the dock's collapse now does the job. (`isLayerPanelMinimized`
  was only read inside this file, so the removal was self-contained.)
- **External flag reads rewired:** the `\` hotkey (toggles Property + Layers as a
  pair) and the Layers menu checkmark read `store.showLayerPanel`, which now stays
  frozen `false`; both were pointed at `isPanelOpen('layers')`.
- **Deliberately left inert:** the `setStore("showLayerPanel", false)` calls in
  `player-app` and `embed-viewer` were NOT converted to `setPanelOpen('layers',
  false)` — that would write the *persisted* dock layout the editor shares, and could
  hide the panel in the editor when a viewer is opened. Those viewers don't render the
  dock, so the writes are harmless no-ops on the now-unused flag.
- CSS was cleanly standalone (0 wrapper-scoped selectors), so this was a body-only
  fragment migration; the old `.layer-panel` positioning + `.minimized` rules are now
  dead.
- `tsc -b` and `npm run build` both green.
- `docs/dockable-panel-system-plan.md` updated: Layers moved to **Done (v0.8.63)**;
  only **Property** remains (it hosts the embedded animation sub-panel and is
  referenced app-wide — scheduled as the finale).

## Breaking changes / migration
- None. (The old `showLayerPanel` flag and `isLayerPanelMinimized` state are now
  unused; panel state lives in the persisted dock layout.)
