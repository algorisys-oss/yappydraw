# 0.5.20 — Letter spacing now drives auto-resize & wrapping (2026-06-30)

## Highlights
- Letter spacing (tracking) now affects a text's **box size and wrapping**, matching Illustrator — auto-sizing shapes grow to fit spaced-out text, and fixed-box word-wrap accounts for the extra width.

## Fixes
- **Letter spacing was ignored by text measurement.** The helpers that size auto-resizing shapes (`fitShapeToText` → `measureContainerText`) and compute wrapped height/width set the font but never the canvas `letterSpacing`, so they measured as if tracking were zero. They now measure with the element's letter spacing, so:
  - an auto-sizing shape's fitted box **grows** with tracking (Illustrator point-type behaviour),
  - word-wrap in a fixed-width box wraps at the right place (Illustrator area-type behaviour),
  - the selection box reflects the real width.

## Internal / tests / docs
- `measureWrappedTextHeight` gained a `letterSpacing` parameter (threaded through all 6 callers); shared measurement contexts reset `letterSpacing` to `0px` to avoid leaks; vertical type forces `0px` (tracking is horizontal).

## Breaking changes / migration
- None.
