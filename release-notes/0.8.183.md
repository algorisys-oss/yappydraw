# 0.8.183 — The object tree (2026-08-07)

The last of the five items of designer feedback. The layer panel managed *layers* and never
showed what was on them — so in a document of any size, the only way to reach a specific object
was to find it on the canvas and click it.

## Highlights

- **Every object on a layer, listed.** Open the Layers panel and click the box icon on a layer.
- Select (including one object inside a group), **hide**, **lock**, **rename**, and **drag to
  restack** — per object.
- Hidden objects are hidden *everywhere*: canvas, clicking, marquee, minimap, and every export.

## Features

### The object tree

Top-of-stack first, matching the artwork. Groups are one row until you expand them.

| Control | Does |
| --- | --- |
| Click a row | Selects that object — including a single object inside a group, without entering the group. Shift/Ctrl-click adds. |
| Eye | Hides it. Not drawn, not clickable, not marquee-able, not exported. |
| Padlock | Locks it against selection and editing. |
| Double-click the name | Renames it. |
| Drag a row | Restacks it — drop on a row's upper half to go in front, lower half to go behind. Dragging a group moves the group. |

Objects start with a **derived label** — their own text if they have any, else their type
("Rectangle", "Path", "Image") — so most never need naming. A name you set is a label for you; the
element's `id` is unchanged and remains what scripts address.

```js
Yappy.setElementsVisible([id], false);   // hide (accepts group ids too)
Yappy.toggleElementVisible(id);
Yappy.showAllElements();                 // the way back
Yappy.setElementName(id, 'Hero banner'); // '' clears it
Yappy.elementLabel(id);                  // what the tree shows
Yappy.moveElementsNextTo([id], targetId, 'above');
```

### Hiding means hidden

`visible` is honoured by every path that walks elements — canvas rendering, hit-testing (which
covers clicking, marquee and lasso), the minimap, and all seven export paths (PNG, JPG, SVG, PDF,
PPTX, artboard, page/region and rasterize) through one shared predicate. Hiding an object also
drops it from the selection: leaving it selected would float transform handles around nothing and
let the next drag move something invisible.

## Breaking changes / migration

**None, and no document version bump.** Two new *optional* fields on elements — `visible` and
`name` — where absent means "visible" and "no custom label". Documents saved before this release
load and behave identically; `loadDocument` passes elements through untouched and saving is a
structured clone. Both fields are registered in `normalizeElement`, the whitelist that would
otherwise drop them on template/import paths.
