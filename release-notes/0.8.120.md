# 0.8.120 — Trousers and shoes

**Date:** 2026-07-20

## Highlights

- Stick figures can wear **trousers and shoes**, and the clothing **follows the pose** —
  a seated figure's trousers bend at the knee, a cyclist's follow the pedalling leg.
- 8 trouser styles, 6 shoe styles, each with its own colour.

## Features

- **Trousers** — Straight, Baggy, Skinny, Shorts, Joggers, Skirt, Long skirt, None.

- **Shoes** — Shoes, Boots, Sneakers, Heels, **Front-facing**, None. Most are drawn in
  profile; Front-facing suits the library's head-on poses, where a side-view shoe reads
  as a foot turned sideways.

- **It follows the pose.** Clothing is generated from the figure's own leg geometry, not
  from a per-pose drawing, so every one of the 58 library poses is dressed correctly
  without anyone authoring a seated or cycling variant. The same holds for animated
  figures: trousers keep up with a walk cycle frame by frame, and come along on Bake.

- **Restyleable after the fact,** like faces and hair — select a figure and change its
  trousers from **Appearance** in the Properties panel (the section formerly called Face
  & hair), even after moving, scaling or ungrouping it.

- **Nothing you already made has changed.** Figures arrive dressed exactly as before: the
  Woman and Girl variants wear a skirt — now drawn by the shared garment system rather
  than a one-off helper — and everyone else is bare-legged. Trousers are opt-in.

- **API.**

  ```js
  Y.listStickTrousers();   // 8 styles
  Y.listStickShoes();      // 6 styles
  Y.setStickFace({ trousers: 'baggy', shoes: 'sneakers', trouserColor: '#374151' }, ids);
  Y.insertStickFigure('daily-walking', { trousers: 'straight', shoes: 'boots' });
  Y.insertAnimatedFigure('walk', { trousers: 'joggers', shoes: 'sneakers' });
  ```

## Internal / test changes

- New `library/stick-figures/garments.ts` — the limb-derived counterpart to `face.ts`. A
  garment is the limb's own polyline inflated into a closed outline by offsetting each
  point along its normal, with a per-style width profile. That single idea covers every
  trouser style as width-and-length parameters.

- Extracted `library/stick-figures/prims.ts` (the primitive union, its SVG emitter and
  polyline helpers) **before** writing garments, so trousers and shoes return the same
  type faces do — the rig renderer draws them with no new render code, and render-style
  parity is structural rather than something to remember.

- Closed outlines rather than a wide stroke, deliberately: a filled polygon fills *and*
  strokes correctly in both pipelines, whereas a wide rough.js stroke reads as noise.

- Garment widths scale from a pose-independent unit (rest-length hip→ankle), not the
  limb's own length — a foreshortened cycling leg is 55 units against a standing 84, so
  length-relative widths would make the same trousers 30% thinner on one pose.

- **Leg identification** was derived from the corpus rather than guessed. "Subpaths
  starting at the hip" scores 56/58; seated poses author a leg as thigh + shin in
  separate subpaths, so the rule follows any subpath continuing from the chain's end —
  58/58, frozen as a unit test over every pose so a future pose that breaks it fails
  loudly instead of silently losing its trousers.

- **Z-order:** faces sit on top of a figure and are appended, but garments sit *under*
  the bones and are spliced ahead of the first body part — appending would paint trousers
  over the legs they were derived from. Asserted by index ordering in the tests, not by
  eye.

- Leg bones now carry `data-sf-part="leg"` (a new `sfPart` element field), which is how a
  flattened figure can still be re-clothed.

- 10 new unit tests and 4 new Playwright tests — 236 unit tests, 17 stick-figure e2e.

## Breaking changes / migration

None. Trousers default to off (skirt for the Woman and Girl variants), which is exactly
how the library looked before this release.
