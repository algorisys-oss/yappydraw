# 0.5.3 — Tablet select + delete & richer touch gestures (2026-06-28)

## Highlights
- Keyboard-free **select and delete on tablets**: a floating ✕ button on any
  selection, a touch/pen **long-press context menu**, and a **3-finger scrub**
  to delete — porting Procreate-/happypaint-style ergonomics onto yappy's vector
  canvas.

## Features
- **Floating quick-delete button** — a ✕ disc sits just off the top-right of any
  selection (single *and* multi). One tap deletes the whole selection; no
  keyboard needed. Hidden in presentation/embed modes where it can't act.
- **Long-press → context menu** — touch-and-hold (500ms) on the selection/lasso
  tool opens the full Delete / Duplicate / Copy menu, since iPad/Android don't
  reliably fire a `contextmenu` event on a hold.
- **Three-finger horizontal scrub → delete selection** — Procreate's "scrub to
  erase", retargeted to the vector selection so it's undoable and a no-op when
  nothing is selected.
- **Stylus "second finger" constrain** — while resizing with the Apple Pencil,
  landing a finger acts like holding Shift (proportional resize).

## Fixes
- **Context menu was un-dismissable on touch** — it closed only on `mousedown`,
  which isn't synthesized from a tap; added a `pointerdown` outside-close
  listener so a tap dismisses it on keyboard-less tablets. (#132)
- **2-finger gesture cooldown could strand single-finger input** — a dropped/
  out-of-order `touchend` (common on iPadOS Safari) could leave `gestureCooldown`
  stuck `true`, permanently killing single-finger select/marquee. It now
  self-heals after a stale window without weakening the active-gesture guard.
  (#133)

## Internal / tests / docs
- New `frontend/src/utils/input/` module mirroring happypaint's input layer:
  `palm-rejection.ts` (`isPalmTouch`/`isPencilSizedTouch`, deduping three inline
  copies) and `touch-geometry.ts` (pure `allFingerTouches`/`pickFingerTouches`/
  `twoFingerMetrics`). The stateful gesture FSM stays inline in `canvas.tsx` by
  design — it carries hard-won iPadOS edge-case handling and can't be
  regression-tested without a real tablet, so a behavior-only extraction wasn't
  worth the risk.
- Shared delete-handle geometry (`getDeleteHandlePosition`) drives both the
  hit-test and the two overlay renderers from one source of truth.
- Help dialog gestures, `docs/learnings.md`, and `docs/bugs/bug-fixes.md`
  updated; repo map refreshed.

## Breaking changes / migration
- None.
