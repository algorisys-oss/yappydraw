# 0.8.66 — Dimension annotations (auto-updating measurement lines) (2026-07-11)

## Highlights
- **Dimension annotations.** Attach a persistent, CAD-style dimension line to any
  element — extension lines, arrowheads, and a **live px label** — that **auto-updates**
  as the element moves, resizes, or animates. Right-click a shape → **Dimensions ▸ Add
  Width / Add Height**. Great for technical drawings, specs, and layout callouts.
  (This is **Phase 5** of the precision & measurement plan — the Illustrator-style
  "Dimension tool" for Yappy.)

## Features
- **Persistent dimension annotations** attached to an element:
  - **Width** dimensions sit below the shape; **height** dimensions sit to the right.
  - The label shows the measured span in px and **recomputes every frame** from the
    target's current bounds — so it tracks resizes, drags, and keyframe animation live.
  - Rendered as a world-space overlay with constant-on-screen arrowheads and label
    (unaffected by zoom); a readable label chip in light/dark.
  - **Persisted with the document** and undoable (add/remove are history steps).
  - Deleting the target element cleans up its dimensions (no orphans).
- **Create / manage:** right-click → **Dimensions** submenu (Add Width, Add Height,
  Remove Dimensions), or scripting: `Yappy.addDimension(id?, 'width'|'height')`,
  `removeDimension(id)`, `removeDimensionsForTarget(id?)`, `listDimensions()`,
  `getDimensionValue(id)`.

## Fixes
- Store field name collision with the page-size `dimensions` — renamed the annotation
  collection to `dimensionAnnotations` (bug-fixes #149).
- `generateId` now scans the dimensions collection, so a second dimension no longer
  re-uses the first's id (#150).

## Known limitations
- Dimensions use the element's **axis-aligned** bounding box (rotation ignored), like the
  transform HUD. Angular/radial dimensions and click-two-points linear dimensions are not
  in this pass.
- On-canvas selection/drag-to-reposition a dimension isn't wired yet — manage via the
  context menu / API. Dimensions render on the canvas but aren't yet included in
  PNG/SVG export.

## Breaking changes / migration
- None. `dimensionAnnotations` is optional; existing documents are unaffected.
