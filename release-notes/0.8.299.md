# 0.8.299 — Tables to and from PowerPoint (2026-11-01)

## Highlights
- **Tables go to PowerPoint as real tables and come back as Yappy tables** — the "native PPTX
  tables" item of the DeckCraft-based slides backlog (`docs/slides-feature-gaps.md`).

## Features
- **PowerPoint export** (Editable shapes): a table becomes a real PowerPoint table — text, header
  and row colours, column widths, alignment (across and up/down), merged cells and lines — so it
  can be typed into and restyled in PowerPoint. Number formats go as the text they show; sort
  arrows are left out. A rotated or flipped table still goes as a picture.
- **PowerPoint import**: a table becomes a Yappy table when a Yappy table can draw it the same
  (one font and size, a bold header row, rows in one colour or alternating, one alignment per
  column, one vertical alignment, the same line on every edge); any other table comes in as its
  exact cell drawing, as before. A missing header flag (LibreOffice drops it) is inferred.
- **Vertical alignment for tables**: right-click a cell → Align Text Vertically → Top / Middle /
  Bottom; `setTableVerticalAlign(id, align)`; option `tableVerticalAlign`.
- **Show Sort Arrows** toggle (right-click a cell); option `tableSortArrows`. Tables opened from
  PowerPoint start without arrows.

## Fixes
- Help: sorting is by the arrows at the right of a header cell, not a click anywhere in it.

## Internal / tests / docs
- `TableItem`/`TableCell` in the deck model; `a:tbl` writer (`tableFrameXml`, `emuRuns`); reader
