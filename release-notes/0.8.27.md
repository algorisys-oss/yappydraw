# 0.8.27 — Timeline reorder + slide-synced animation (2026-07-08)

## Highlights
- Rearrange a figure's actions by **dragging blocks** on the Scene Timeline, and
  **sync the animation to your slides** so each slide plays it from the start.

## Features
- **Reorder actions** — drag an action block left/right on the Scene Timeline to
  change the order of a figure's motions (grab the body to move, the right edge to
  resize).
- **Slide-synced triggers** — on a slides/pages document, a new button in the
  timeline restarts the scene from the beginning whenever the active slide/page
  changes, so every slide plays its animation fresh (great for presentations).

## Fixes
- None.

## Internal / tests / docs
- Timeline block-reorder does a live splice-move on the figure's `sequence` (tracks
  the dragged index across moves; 5px threshold before the first shuffle). Slide-sync
  is a `createEffect(on(activeSlideIndex, …, {defer:true}))` guarded by a new
  `store.storySyncSlides`, resetting `storyTime`/`storyPlaying`; its toggle shows only
  for paged doc types. Help doc and learnings updated.

## Breaking changes / migration
- None.
