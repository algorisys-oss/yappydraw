# 0.8.69 — Nested-effect keyframing, in-place compound editing, adjustment layers (2026-07-11)

## Highlights
- **Animate 3D & warp.** Nested effect parameters are now keyframable via dotted-path
  tracks — **Extrude Depth / Angle / Tilt / Bevel** and **Warp Bend** — so a shape can grow
  a solid or bend over time.
- **Edit compound shapes in place.** Double-click a compound shape to explode it into its
  editable sources; move/edit them and press **Esc** to rebuild the compound. Cancel restores
  the original.
- **Adjustment layers.** Add a rectangular region (Menu → View → **Add Adjustment Layer**)
  that applies a filter — **blur / brightness / contrast / saturate / hue** — to everything
  drawn beneath it. Its filter params are keyframable, so you can sweep a blur or colour grade
  over time.

## Features

### Nested-effect keyframing (dotted-path tracks)
- Keyframe fields inside nested effect objects: `extrude.depth`, `extrude.angle`,
  `extrude.rotX/rotY`, `extrude.bevel`, `warp.bend`. Rows appear in the Keyframes panel once
  the effect is on the element. Scripting: `Yappy.addKeyframe(id, 'extrude.depth', 0, 0)` →
  `(id, 'extrude.depth', 2, 70)`.

### In-place compound editing
- **Double-click** a compound shape, or right-click → **Compound Shape ▸ Edit Contents**, to
  enter an isolation edit: the retained sources become real, selectable elements. Edit them,
  then **Esc** (or `Yappy.finishCompoundEdit()`) rebuilds the compound from the edits.
  `finishCompoundEdit(false)` cancels and restores the original.

### Adjustment layers
- `Yappy.createAdjustmentLayer(x, y, w, h, filters?)` or the View menu. Renders as a dashed
  region while authoring (hidden in presentation); filters the composite beneath within its
  bounds. Keyframe **Blur / Brightness / Contrast / Saturate / Hue Rotate**.

## Internal / tests / docs
- Evaluator: `resolveNestedOverrides` turns dotted override keys into complete nested objects
  (clone the element's nested value + set sub-fields) so the shallow render spread applies them;
  wired into `applyCompositionOverrides` + `api.evaluateComposition`. Panel gained a `getPath`
  dotted accessor and dynamic extrude/warp/filter rows.
- Compound edit: `enterCompoundEdit`/`exitCompoundEdit` mirror the symbol edit-in-place flow.
- Adjustment layer: `canvas-renderer` snapshots the composite into a scratch canvas and re-draws
  it through `buildFilterString(el)`, clipped to the region.
- Tests: `keyframe-nested-effects.spec.ts`, `compound-edit.spec.ts`, `adjustment-layer.spec.ts`
  (+ the full keyframe/compound/dimension suite — 9 e2e green). All three visually verified.
- See `docs/after-effects-plan.md` §14 and `docs/compound-shapes-plan.md` §3.

## Known limitations
- Adjustment layers apply on-canvas and in presentation but are **not yet drawn in PNG/SVG
  export**.
- Nested keyframing covers extrude/warp; `transformEffect.*` and stroke-gradient angle use the
  same dotted-path mechanism and just need panel rows (later).

## Breaking changes / migration
- None. All new fields are optional.
