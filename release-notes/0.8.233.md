# 0.8.233 — What a founding place will mean once collaboration exists (2026-09-04)

## Highlights
- `/founders/` now explains the collaboration server that is being built, before anyone pays
  for a place under wording it would later contradict. The section opens by saying the service
  **does not exist yet**.
- The promise that matters is stated in full: **every feature in the app stays free for
  everyone, always — collaboration included.** No Pro build, no licence check, no feature flag;
  anyone can point the client at a server of their own and collaborate without paying anyone.
- What costs money is the server *we* run. Founders get it **free for a year from launch**,
  then a founder discount for as long as they want it. Deliberately not "free forever": a
  single payment cannot honestly fund a cost that recurs every month.

## Features
- `FOUNDER_BENEFITS` (`frontend/src/data/founders.ts`) carries the hosted-collaboration line,
  with its cap and its "once it launches" qualifier in the benefit text itself.
- New *About the collaboration server* section on the founders page (`prerender/render.ts`).
- The Support section of the workspace help doc gains a matching `:::note`, and
  `support.foundersNote` is updated in all five locales (en, de, es, fr, ja).

## Fixes
- None.

## Internal / tests / docs
- `docs/collaboration-plan.md` — the decision record, written before any server code exists:
  what the money buys (the service, not the software), the twelve-month cap and why, and the
  licence boundary. That last one is the load-bearing part: **a server that reuses AGPL client
  code is a derivative work, and §13 then obliges us to offer its source to every user who
  connects to it over the network** — so the server is a separate program in its own repo that
  imports nothing under `frontend/src/`, not even types. Founder entitlement is therefore
  checked on the server, never in the client.
- `docs/learnings.md` — the licence choosing the architecture, and why the smaller promise is
  worth more than the one that has to be withdrawn.

## Breaking changes / migration
- None. `support.freeForever` ("nothing in YappyDraw is behind a payment, and nothing ever will
  be") is deliberately unchanged in all five locales: it is a statement about the app, every
  feature of which stays free, and hosting is not a feature.
