# 0.8.32 — Begin/end arrowheads on curvy bezier lines (2026-07-09)

## Highlights
- Standalone **curvy (bezier) lines** now expose the **Line Start / End Type**
  arrowhead controls, just like straight lines, arrows, and organic branches — so
  you can put a triangle, diamond, arrow, dot, etc. on either end of a curve.

## Features
- Added `bezier` to the `applicableTo` list of the `startArrowhead` /
  `endArrowhead` (and their size) properties. The connector renderer already drew
  arrowheads on bezier curves (deriving the tangent at each endpoint from the
  control points) — this exposes the controls in the properties panel so the
  capability is actually reachable. Verified: a bezier with a diamond start + a
  triangle end renders both heads.

## Internal / tests / docs
- Backlog planning added to `todo.md`: **Mind-map diagram styles/templates**
  (Miro-style: Mind Map, Sitemap, Random Words, Curved-Down, Straight-Down,
  Dual-Side-Curved-Horizontal) and an **advanced colour picker**
  (square/rect SV-box + triangle/HSV-ring, happypaint/Krita-style).
- Recorded in `docs/learnings.md`.

## Breaking changes / migration
- None. `path` (freeform vector) still has no arrowheads — its renderer would need
  real head-drawing work; tracked separately.
