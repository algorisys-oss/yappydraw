# 0.8.289 — Label lanes and waypoint snapping (2026-10-11)

## Highlights
- **Labels on runs, in lanes.** An elbow's label sits at the centre of a straight run (the run under the midpoint when the text fits, else the longest), never on a bend. Labels of neighbouring connectors are placed in id order and a later one slides along its run, or onto a lane beside the line, until it is clear of the earlier ones. SVG export places them identically. **Label Position** (start / middle / end) is now honoured; it was in the Properties panel but never read.
- **Waypoint snapping.** Dragging an elbow's segment snaps its moving coordinate to the parallel runs of other connectors, to shape edges and centre lines, and to the grid when Snap to Grid is on; a bend snaps on both axes. A guide line shows the match; Shift drags freely.

## Internal / tests / docs
- `utils/connector-labels.ts` (`setLabelScene`, `connectorLabelPlacement`, `estimateLabelSize`), used by the connector renderer with real text metrics and by the exporter with an estimate; scene registered per render pass and per export, like line jumps.
- `utils/waypoint-snap.ts` (`snapWaypoint`), used by the segment and bend drags; guides through the existing snapping-guide signal.
- Tests: `connector-labels.test.ts` (+7), `waypoint-snap.test.ts` (+6). Help: Connectors → "Labels", "Adjusting an elbow by hand". Learnings.

## Breaking changes / migration
- None. Labels on existing elbows may move from a bend to the nearest run on the next render.
