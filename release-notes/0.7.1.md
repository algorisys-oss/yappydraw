# 0.7.1 — Quick toolbar font colour fix (2026-07-06)

## Highlights
- The floating quick toolbar's **Text Color** control works again for text and
  rich-text elements.

## Features
- None.

## Fixes
- **Quick toolbar "Text Color" was a no-op for text / rich-text.** Picking a
  colour from the quick ("Shape") toolbar's text-colour swatch moved the swatch
  but left the font colour unchanged. The visible font colour resolves as
  `textColor || strokeColor`, and elements ship with a baked-in default
  `textColor`, so writing only `strokeColor` never took effect. The control now
  writes both `strokeColor` and `textColor` for text/rich-text elements (matching
  the main color picker). Shape stroke-colour behaviour is unchanged. (Bug #136.)

## Internal / tests / docs

  in `docs/learnings.md`.
