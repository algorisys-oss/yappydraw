# 0.8.102 — "What's new" popup (2026-07-14)

## Highlights
- Click the **version number** (bottom-right) to see a **What's new** popup — recent updates in plain
  language, newest first.

## Features
- **"What's new" changelog popup.** The version label in the status bar now opens a popup listing the
  most recent user-facing changes (from `data/whats-new.ts`). A small dot appears on the version when
  there are updates since you last looked, and clears once you open it. The popup also carries the old
  version-button action — a **Reload latest** button that clears the cache and reloads the newest build
  (handy on iPad/iOS Safari). Open it from a script with `window.Yappy.showWhatsNew()`.
  - Theme-aware and accessible (every label/badge clears WCAG AA contrast in light and dark — measured).

## Internal / tests / docs
- New `components/whats-new-dialog.tsx` (+ `.css`) and `data/whats-new.ts`; wired into `status-bar.tsx`
  and `api.ts` (`showWhatsNew`). Documented in the workspace help doc. The "ship it" checklist now
  includes updating `whats-new.ts` so the list stays current.
- Verified with Playwright: dot shows for returning users / hidden for fresh ones, open via click + API,
  close via Esc + overlay, newest-first ordering, and contrast in both themes.

## Breaking changes / migration
- The version number now opens the What's-new popup instead of hard-refreshing directly; the hard
  refresh moved to the **Reload latest** button inside the popup.
