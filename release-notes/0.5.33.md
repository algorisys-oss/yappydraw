# 0.5.33 — Template pack + polish round (2026-07-05)

The short-term follow-ups to 0.5.32: real template volume and the polish debt
from that sprint.

## Highlights
- **33 built-in design templates** (21 new) covering the formats people
  actually make: social posts, stories, thumbnails, slides, banners, posters,
  flyers, menus, cards, price lists, vouchers, invites.
- Magic Resize now **keeps edge-hugging elements pinned** to their edges.
- PWA install/update states are visible (toasts), version history shows
  **page previews**, and the Open dialog finally respects **dark mode**.

## Features
- **Design template pack** — 21 new templates across Instagram posts (product
  spotlight, tips carousel, testimonial, hiring, podcast episode, minimal
  sale), stories (launch countdown, serif quote), a tutorial YouTube
  thumbnail, 16:9 deck title & section slides, a webinar banner, typographic
  and workshop posters, a café menu, an open-house flyer, a thank-you card, a
  light business card, a salon price list, a gift voucher, and a kids birthday
  invite. All benefit from search + "✓ fits" sorting; shared builders moved to
  `templates/data/designs/helpers.ts` so future packs are cheap.
- **PWA lifecycle toasts** — on first install: "Yappy is ready to work
  offline — installable from your browser menu"; when a background update
  activates: "reload to finish applying it" (listens on `controllerchange`,
  which with skipWaiting/clientsClaim fires exactly at takeover).
- **Version-history previews** — snapshots capture a small page thumbnail at
  record time (cheap: snapshots are 3-min throttled) and the dialog shows it.

## Improvements
- **Magic Resize edge anchoring** — elements whose margin to a page edge is
  under 8% of the page dimension keep that margin (scaled) instead of drifting
  with the normalized center. Logos in corners and footer badges stay put;
  everything else behaves as before.

## Fixes
- **Open Drawing dialog in dark mode** — the stylesheet was hard-coded to
  light colors (white panel, dark text) making it glaring/unreadable in dark
  themes; now fully themed with CSS variables.

## Internal / tests / docs
- `tests/canva-next.spec.ts` grew to 9 specs: edge-anchoring math, template
  pack registration + load, and version thumbnail assertions added.
- Help doc (design-studio) updated for the template catalog and version
  previews.

## Breaking changes / migration
- None.
