# 0.5.23 — Spinner arrows on numeric property fields (2026-06-30)

## Highlights
- Numeric properties (Letter Spacing, Angle, Shear, …) now show **clickable ▴/▾ up-down arrows** to nudge the value, in addition to the existing Arrow-key stepping.

## Features
- Visible spinner buttons on every property-panel number field, revealed on hover/focus. Click to step by the field's increment; **Shift** = ×10, **Alt/Ctrl** = ×0.1 (same as the ↑/↓ keys). The field still accepts math expressions (`200-50%`) and live plain-number typing.

## Breaking changes / migration
- None.
