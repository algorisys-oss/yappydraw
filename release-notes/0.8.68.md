# 0.8.68 — Keyframable effects (glow, shadow, feather, blur) (2026-07-11)

## Highlights
- **Animate effects on the timeline.** The Keyframes panel now keyframes **live-effect
  parameters**, not just transform and colour: **Feather** (soft edges, any shape),
  **Stroke Width**, **Blur** (images/video), and — once the effect is on — **Glow**
  (radius + colour) and **Shadow** (blur, X/Y offset, colour). Key a glow or feather that
  reveals over time, pulse a stroke, animate a drop shadow. This is **Phase 4** of the
  After-Effects motion plan.

## Features
- **New animatable channels** in the Keyframes dope sheet, shown per element:
  - Always: **Feather**, **Stroke Width** (plus the existing X/Y, W/H, Rotation, Opacity,
    Fill, Stroke).
  - Images/video: **Blur**.
  - When **Glow** is enabled on the element: **Glow Radius**, **Glow Color**.
  - When **Shadow** is enabled: **Shadow Blur**, **Shadow X**, **Shadow Y**, **Shadow Color**.
- Effect params read/keyframe from **0 ("off")**, so you can animate an effect *in* from
  nothing (e.g. `featherRadius` 0 → 30). Colour effect params blend in hex; all support the
  same easing / graph editor as any keyframe.
- Everything rides the existing composition evaluator — the same scrub/play/export path.

## Internal / tests / docs
- No engine changes: flat effect fields already ride the generic override spread
  (`{ ...el, ...animState }`), the render pipeline reads them straight off the element, and
  keyframed elements bypass the element cache — so overrides render live. Work was purely
  the panel's animatable-property list becoming dynamic per element
  (`keyframe-panel.tsx` `animatablePropsFor`), plus defaulting numeric effect params to 0.
- Tests: `tests/keyframe-effects.spec.ts` (e2e: feather interpolates 0→15→30 and the canvas
  differs sharp-vs-soft; enabling glow surfaces its rows; glow radius keyframes interpolate
  and repaint). Build + full suite green.
- See `docs/after-effects-plan.md` §13.

## Known limitations
- **Nested-object effects aren't keyframable yet** — Extrude (`depth`/`angle`), Warp
  (`bend`), Transform-effect, and stroke-gradient angle live in nested objects; they need a
  dotted-path track model (planned). Adjustment layers are also still to come.
- `glowEnabled` / `shadowEnabled` are manual toggles (booleans aren't interpolated) — enable
  the effect, then keyframe its numeric params.

## Breaking changes / migration
- None.
