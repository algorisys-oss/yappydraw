# 0.8.255 — animation that survives export (2026-09-14)

## Highlights
- **Export HTML plays keyframes and tinyfly animations** and loops them. Before, the page showed a
  still of the first frame.
- **Scenes play and loop without a timeline panel**: in presentations, in exported HTML, and from
  `Yappy.playScene()`.
- **Page GIF and video exports start everything at t = 0**, and a GIF plays at canvas speed.
- **Null objects stay out of every export.**
- **`Yappy.batch(fn)` and `Yappy.createElements([...])`** make a script's shapes one undo step.

## Features
- **`Yappy.batch(fn)`.** Runs `fn(Yappy)` as one undo step and one reactive update, and returns
  `fn`'s result.
  - Batches nest.
  - If `fn` throws, history is re-enabled and undo removes the partial work.
  - It groups synchronous calls only, and warns if `fn` returns a Promise.
- **`Yappy.createElements(specs)`.** Creates `{ type, x, y, width, height, options? }` specs in one
  undo step and returns their ids.
- **`npm run build:player`.** Rebuilds the runtime that is inlined into exported HTML.

## Fixes
- **#363: null objects in exports.** The crosshair appeared in paged PNG/JPG, social exports, page
  thumbnails, slices, artboards, PDF, PPTX, page GIF/video and copy as image. `isExportable` now
  excludes null objects. Copy as image also stopped exporting hidden elements.
- **#364: Export HTML dropped keyframes and tinyfly clips.**
  - The export built its document from its own outdated field list; it now uses the Save document.
  - The player bundle had not been rebuilt since July because its build was broken. The build is
    fixed, and the player now bundles the tinyfly engine.
- **#365: looping needed a panel open.**
  - Scene duration and the play controller moved out of the Scene Timeline and Keyframes panels
    into `scene-clock.ts`, which the canvas starts.
  - With no panel open, the scene free-runs and wraps at its length.
- **#366: exports on the running clock.** Spin/orbit, animated figures and flow dashes now start
  at t = 0.
  - Figures no longer freeze during an export while the Scene Timeline is open and paused.
  - GIF frames are sampled at the centisecond delay the file stores, instead of `1000 / fps`, which
    played about 4% fast at 24 fps.
- **#367: no batch API.** See Features.
