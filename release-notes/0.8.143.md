# 0.8.143 — Animation Studio: an Animate-class frame timeline (2026-07-22)

## Highlights
- **A whole new document type: Animation.** Fixed stage + frame-based timeline in the spirit of Flash/Adobe Animate — keyframes, motion tweens with easing, onion skinning, movie-clip symbols with nested looping timelines, and one-click GIF/MP4 export of the loop.
- **Three ready-made samples** in Templates → Animations (Bouncing Ball, Rocket Launch, a 1080×1080 YappyDraw social-intro card) that double as social-media showcases.

## Features
- **New doc type** — Menu → New → New Animation… (stage presets, 12/24/30 fps, length). The cel model: each keyframe OWNS its content; whatever you draw lands on the current frame's keyframe of the active layer (one reconciler covers every creation path — tools, paste, API).
- **Timeline panel** (bottom chrome): layer rows (rename/hide/lock/delete) + a canvas-rendered frame grid — keyframe dots, span bars, tween arrows, labels, red playhead; click/scrub, drag keyframes, right-click for all frame ops. Transport header: play/stop, fps, length, loop, onion controls, frame + clip-instance properties. Sits above the status bar; top edge drags to resize (persisted).
- **Hotkeys**: `F5`/`F6`/`F7` insert frame/keyframe/blank cel, `Shift+F5`/`Shift+F6` remove/clear, `F8`/`Shift+F8` convert to movie clip/graphic, `Enter` play/pause, `,`/`.` step, `Home`/`End` jump. (In animation docs the F-keys belong to the timeline, not Present.)
- **Motion tweens**: F6 duplicates the previous cel with a shared `contentId`; matched elements interpolate x/y/size/angle/opacity/fill/stroke through a pure frame evaluator (bezier + named easings, per-span). Multi-object cels tween per-match; unmatched objects hold.
- **Onion skinning**: red (past) / green (future) ghosts with per-side counts, rendered through the real scene renderer — identical in sketch and architectural styles; paused-only, never exported.
- **Movie-clip symbols**: `F8` converts a selection into a symbol with its own frame timeline; instances loop / play once / hold a single frame, with a first-frame offset, all deterministic against the document playhead (scrub/export/undo always agree). Double-click an instance to edit the clip in place — the timeline panel swaps to the clip's own timeline and back.
- **Export**: GIF/MP4/WebM are frame-exact (quantized to the timeline fps); the export dialog defaults to exactly one timeline pass for animation docs.
- **Templates**: Templates → Animations with Bouncing Ball / Rocket Launch / YappyDraw Intro (first-frame preview cards).
- **API**: `Yappy.anim.*` — `newDocument`, `gotoFrame/stepFrame/play/pause/stop`, `insertFrame/insertKeyframe/insertBlankKeyframe/clearKeyframe/removeFrames/moveKeyframe`, `setTween/setFrameEasing/setFrameLabel`, `setFps/setFrameCount`, `setOnion`, `evaluate`, `visibleIds`, `loadExample`; plus `createSymbol(name, ids, 'movieclip')`.

## Fixes
- Legacy (v1/v2) document migration stripped `symbolId` from symbol instances (grey-box placeholders) — `normalizeElement`'s whitelist now passes `symbolId`/`loopMode`/`firstFrame`/`contentId` through.
- `tests/api.spec.ts` hardcoded `localhost:5173` instead of the Playwright baseURL — on machines where another app occupies 5173 all six tests timed out at boot.
- The floating Settings/Properties/Help cluster no longer overlaps bottom-docked timeline chrome — it lifts itself above the animation timeline via a published height variable.

## Internal / tests / docs
- New modules: `types/anim-types.ts`, `utils/animation/frame-timeline-evaluator.ts` + `frame-timeline-ops.ts` (pure, unit-tested), `utils/animation/anim-playback.ts`, `utils/onion-skin.ts`, `store/anim-ops.ts`, `templates/data/animations.ts`, timeline/mode-bar/new-dialog components.
- 82 unit tests (evaluator semantics, span ops, doc round-trip, template invariants) + 13 Playwright e2e (cel model, tweens, playback, grid UI/hotkeys, onion pixels, undo/persistence, movie-clip edit-in-place round trip, both render styles, Templates-dialog flow, panel layout/resize).
- `utils/migration.ts` no longer imports the store (pure, bun-testable). `SlideDocument` gains optional `animTimeline` (additive on v4 — older builds simply ignore it).
- Help: new searchable **Animation Studio** doc with a step-by-step bouncing-ball tutorial, onion-skinning explainer and editing guide; hotkeys added to the shortcuts dialog; `docs/api.md` §`Yappy.anim`.
- Learnings: Solid's `setStore` MERGES objects — a stashed store proxy is not a snapshot; one idempotent reconciler beats N creation-path hooks.

## Breaking changes / migration
- None. Existing document types are untouched; `animTimeline` is additive and ignored by older builds.
