# 0.8.142 — A "Beta" badge on the wordmark (2026-07-22)

## Highlights
- YappyDraw now says so: a small **Beta** pill sits next to the logo in the menu bar, so it is
  clear at a glance that the app is still moving fast.

## Features
- **Beta badge in the menu bar.** An 8px uppercase pill immediately after the `YappyDraw` wordmark,
  on an indigo → purple → pink gradient, with a slow sheen sweep every 4.5s. Hovering it (or the
  wordmark) explains what beta means here: expect rapid changes.
- **Footer attribution updated** — the status bar now reads *Developed with ❤️ by Algorisys
  Technologies* and links to [www.algorisys.com](https://www.algorisys.com) (previously "Algorisys
  Open Source Team", pointing at the GitHub org).

## Internal / tests / docs
- The badge uses fixed colours rather than theme tokens on purpose: white on that gradient clears
  the contrast bar against both the light and the dark panel, so one set of values is correct in
  every theme rather than needing a `--beta-*` token per theme.
- The sheen is decorative only — it is removed entirely (not just paused) under
  `prefers-reduced-motion: reduce`.

## Breaking changes / migration
- None.
