# 0.8.79 — Turntable Phase 3b: AI Reimagine (image → trace) (2026-07-12)

## Highlights
- **✨ AI Reimagine** — the higher-fidelity AI turntable tier. An OpenAI image model repaints your
  shape at the target angle (better at inventing the parts hidden in the flat view), then the
  result is auto-traced into colour vector paths and dropped in beside the original. This completes
  the Turntable roadmap end-to-end.

## Features
- **Two AI reconstruction modes** in the **TURNTABLE (3D SPIN)** panel (single shape):
  - **✨ AI Redraw** (v0.8.78) — a vision model (Claude / OpenAI / Gemini) redraws the shape as clean
    editable **vector** paths. Cleaner, cheaper, any provider.
  - **✨ AI Reimagine** (new) — an OpenAI image model repaints the shape at the new angle, then it's
    **auto-traced** to colour vector paths. More pictorially faithful (better at hidden detail) but
    messier vectors, OpenAI-only.
  Both insert the result as a **new element** beside the original (nothing overwritten, single undo)
  and degrade to a toast + deterministic **Bake** when no key is set. Scripting:
  `Yappy.reconstructTurntableAI({ yaw, pitch, mode: 'vector' | 'image' })`.

## Internal / test changes
- `ai/turntable-ai.ts`: `reconstructTurntableAIImage(id,{yaw,pitch})` — `exportRegion` → OpenAI
  `images/edits` (`gpt-image-1`, inline `postImageEdit`) → `traceRasterAsPaths`. Mirrors the Magic
  Edit image-call pattern.
- `store/app-store.ts`: new `traceRasterAsPaths(sourceId, rasterDataURL, {colors,simplify})` —
  loads the raster, colour-traces (`traceImageDataColor`, the shipped Trace primitive) and builds
  paths beside the source via `makePathFromWorldSubs`; single undo. Coordinate mapping mirrors
  `traceImage` (normalized 0..1 → world).
- `components/property-panel.tsx`: two AI buttons (✨ AI Redraw / ✨ AI Reimagine), both lazy-import
  the AI chunk. `api.ts`: `reconstructTurntableAI` gains `mode`.
- `help-docs/features/effects-doc.tsx`, `docs/turntable-plan.md`, `docs/learnings.md` updated.

## Breaking changes / migration
- None. Additive; no-ops with a toast when the relevant AI key is absent.

## Notes
- **Turntable is now feature-complete**: Phases 1 (core spin), 2 (group rig / reveal / auto-axis),
  3a (AI vector redraw), 3b (AI image reimagine → trace), and 4 (keyframable spin + Spin 360°) are
  all shipped. Live AI round-trips require your own provider key (browser-direct, BYO-key).
