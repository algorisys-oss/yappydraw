# 0.8.291 — Pan cursor, vanishing connectors, arrows pulled back (2026-10-29)

## Highlights
- **Three user-reported canvas bugs fixed.** The Pan tool's hand no longer sticks after switching tools; connectors routed round other shapes no longer vanish while panning; and drawing a new arrow no longer drags an existing arrow across the diagram.

## Fixes
- **Pan cursor stuck (#455).** After using Pan, Pen/Rectangle/Arrow kept showing the hand until the Select tool was picked. The canvas now resets the cursor on every tool change, and Pan shows its hand straight away.
- **Connectors disappeared while panning (#456).** Off-screen culling tested only a connector's start→end box, so an elbow routed round other shapes was skipped once that box left the screen, even with its path in view. Culling now uses the drawn extent (routed points and bezier control points) in both the WASM path and the JS fallback, and handles connectors drawn right-to-left. Layers with more than 2048 elements no longer hide everything past the 2048th.
- **New arrow moved an old one (#457).** Dropping a connector's end handle on empty canvas kept its old binding, so the arrow stayed secretly attached to the shape it had left; the next refresh of that shape (drawing another arrow into it) pulled it back. An end dropped in empty space now detaches. Drawings saved earlier keep the stale binding until that end is dragged once.
- **Turntable `axis: 'x'` (#458).** A horizontal turn from the API also turned the shape vertically. It is now a pure horizontal rotation (`pitch` ignored on that axis), and overlapping subpaths are depth-ordered after both rotations.

## Internal / tests / docs
- New `utils/cull-bounds.ts` (`cullBounds(el)`) used by `syncElementBounds`, the JS cull and the animation pre-cull; the AssemblyScript module is unchanged. `cull-bounds.test.ts` (6), `turntable.test.ts` (5).
- Browser checks: `temp/pan-cursor-cull-check.mjs`, `temp/arrow-steal-repro.mjs` (both A/B'd against the old code).
- Help: Connectors → "Moving or detaching an end" (new); Effects → Turntable `axis: 'x'`. `api.ts` turntable doc comment. Learnings.

## Breaking changes / migration
- Dragging a connector's end onto empty canvas now detaches it, where it used to stay bound to its old shape. That old behaviour was the bug.
