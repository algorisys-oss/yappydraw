# 0.8.268 — The Pen works like Illustrator's, and effects get a dialog with live preview (2026-09-29)

## Highlights
- The **Pen** now behaves the way someone coming from Illustrator expects: Shift snaps to 45°,
  Ctrl-drag fixes an earlier point, Space moves the point you're placing, and clicking the
  selected path adds or deletes points, with cursors that say which.
- **Distort & Transform** and **Scribble** open an **Effect** dialog with real settings and a live
  preview. Twirl finally works on rectangles, and Roughen is no longer overwhelming.

Phases 2 and 3 of Anshika's vector-workflow review.

## Features
- **Pen**
  - Shift constrains segments to **45°** (was 15°). Line and Arrow keep 15°.
  - **Ctrl/⌘ + drag** an anchor or handle of the path you're drawing to move it without ending
    the path. Ctrl + click on empty canvas still finishes the path open.
  - **Space while dragging** out an anchor moves it; its handles come along.
  - With the Pen idle over the **selected** path: click a segment to **add** an anchor, click an
    anchor to **delete** it. Picking the Pen keeps a single selected path selected.
  - Cursor badges: **+** add, **−** delete, **○** close, **/** continue.
- **Effect dialog** (right-click → Distort & Transform / Scribble fill…, Vector Tools, Effects
  panel, command palette, `Yappy.openEffectDialog(kind)`):
  - Pucker & Bloat (−100…100 %), Twirl (angle), Zig-Zag (size, ridges), Roughen (size, detail,
    New variation), Crystallize (size, detail), each with Smooth / Corner points; Scribble
    (spacing, angle, line width).
  - Live preview on the real shapes in both render styles; OK is one undo step, Cancel/Esc
    restores. The canvas and shortcuts are held while it is open.
- API: `Yappy.distort(kind, params, ids)` with `{ amount, angle, size, ridges, detail, seed, points }`;
  the old numeric strength still works.

## Fixes
- Twirl did nothing visible on rectangles (only the corners were twisted, and they sit where the
  twist fades to zero).
- Every distort effect was off-centre: the centroid counted the ring's closing point twice.
- Roughen and Zig-Zag turned into fuzz on large shapes (amplitude scaled with the shape, on a
  point every ~4 px).
- Scribble changed the original shapes in place; a cancelled preview would have lost their fill.
- Pen: clicking to close followed where the first anchor was placed, not where it is now.

## Breaking changes / migration
- Shift with the Pen snaps to 45° instead of 15°.
- Distort & Transform menu items open a dialog instead of applying instantly.
- `Yappy.distort` with a number gives slightly different shapes than before: the old strengths are
  mapped onto the new parameters, and the centring and density fixes change the result.
