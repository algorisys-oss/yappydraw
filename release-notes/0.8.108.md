# 0.8.108 — "My Drawings" local gallery (2026-07-17)

## Highlights
- **A local library of your saved drawings.** New **My Drawings** gallery keeps every drawing you save on your device (offline-first, in the browser's IndexedDB) so you can reopen, rename, duplicate or delete them anytime — no account required. Open it from the menu (**Save/Export → My Drawings…**), the command palette, or the **Jump back in** row on the welcome screen.
- **Ctrl/Cmd+S now saves to My Drawings.** A single keystroke snapshots the live canvas into the gallery — updating the drawing you have open, or creating a new entry. The full Export/Save dialog is still there on **Ctrl+Alt+S**.

## Features
- **Gallery grid** with per-card thumbnails, "time ago" / page / element counts, a **Game** tag for interactive docs, and inline rename. Cards: **Open** (click), **Rename**, **Duplicate**, **Delete**.
- **Save current / New drawing** from the gallery header. Starting a new drawing first snapshots any unsaved work into the gallery so nothing is lost.
- **Durable storage.** On first save the app asks the browser to mark its storage persistent (`navigator.storage.persist()`), which exempts your library from best-effort eviction and Safari/iOS's 7-day ITP wipe. Installed PWAs are typically granted this automatically. The gallery footer shows whether storage is durable and how much space is used.
- **Welcome-screen recents** — returning users see their latest saved drawings ("Jump back in") and can reopen with one click.
- **Scripting API** (`window.Yappy`): `saveToGallery(name?)`, `saveToGalleryAsNew(name?)`, `listDrawings()`, `openDrawing(id)`, plus rename/duplicate/delete.

## Fixes
- **Transform HUD badge** is now slightly translucent (with a subtle blur) so connector handles and content directly beneath the bottom-center measurement badge stay visible.

## Internal / tests / docs
- New modules: `frontend/src/storage/drawings-store.ts` (CRUD, thumbnails, active-entry tracking) and `frontend/src/storage/persistent-storage.ts` (feature-detected StorageManager helpers, never throw).
- New UI: `components/drawings-gallery-dialog.tsx` + `.css`, `components/drawings-gallery-signal.ts` (standalone open-state signal so the menu/welcome screen open the gallery without eagerly importing its storage code).
- Layout mirrors version-history: the drawings **index** (metadata only) is stored separately from each document body, so listing the gallery never loads full documents.
- New e2e spec: `tests/drawings-gallery.spec.ts`.
- Help dialog hotkeys and `api.ts` updated; learnings logged.

## Breaking changes / migration
- None. The gallery is additive and separate from auto-save (crash recovery), version-history, and the account-based cloud workspace. **Ctrl/Cmd+S** was previously unbound to a save action; it now saves to My Drawings.
