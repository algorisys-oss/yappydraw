# 0.8.308 — Security update: seroval 1.8.2 (2026-11-26)

## Highlights
- Security update. `seroval` goes to 1.8.2 to clear a moderate advisory (CWE-770) that Hostinger
  reported. The app was never exposed, and nothing you can see changes.

## Features
- None.

## Fixes
- **#484** `seroval` < 1.8.2 uses too much memory and CPU when it decodes `Error` and
  `AggregateError` values from untrusted input. It comes in only through `solid-js` 1.9.18, which
  pins `seroval ~1.6.11`, and no 1.9.x release allows 1.8. So `package.json` `overrides` now sets
  `seroval ^1.8.2` and `seroval-plugins ^1.8.0`. Solid uses seroval only for SSR, and the app
  renders only on the client: the built bundle has no seroval code.

## Internal / tests / docs
- `npm audit` no longer reports seroval. Build and `npm test` (2272 pass) are clean.
- Learnings: how to fix a pinned transitive dependency.

## Breaking changes / migration
- None.
