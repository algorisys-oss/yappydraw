# 0.5.14 — Appearance pattern fills export as true SVG `<pattern>` (2026-06-29)

## Highlights
- **Appearance-stack pattern fills now export as real, vector SVG patterns** in
  Architectural style — closing the last fidelity gap from 0.5.13.

## Fixes
- Pattern fills in the appearance stack previously exported to SVG as a flat
  foreground colour. Architectural appearance pattern fills now emit a real tiling
  `<pattern>` (rotation preserved), matching the on-canvas render and the base
  pattern fills. Sketch-style SVG still approximates with the foreground colour
  (rough.js can't reference an SVG pattern).

## Internal / tests / docs
- Extracted a shared `svgPatternDef(patternFill, defs, uid)` helper in
  `svg-paint.ts` (used by both base fills and the appearance SVG builder);
  `buildAppearanceSvgGroup` now threads `<defs>` through.
- Help doc, learnings, and roadmap updated.
- Verified: an architectural shape with a dots appearance fill exports SVG
  containing a `<pattern>` def referenced via `fill="url(#yd-pattern-…)"`, zero
  console errors.

## Breaking changes / migration
- None.
