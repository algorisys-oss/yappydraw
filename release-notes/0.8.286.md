# 0.8.286 — Arrowheads sized to the line (2026-10-11)

## Highlights
- **Arrowheads follow the stroke width.** 6px + 5× the stroke, clamped to 10–28px: a 1.5px architecture line gets a 14px head instead of 28px, the 2px default gets 16px, heavy lines keep 28px. Fan-ins of three connectors on one side no longer overlap their heads.
- An explicit **Start Size / End Size** (Properties panel, or `startArrowheadSize` / `endArrowheadSize` from a script) still wins; the panel shows the effective size until you set one.

## Fixes
- **#454** Fixed 28px arrowhead fallback in every draw site and an explicit 28 written by the tool defaults.

## Internal / tests / docs
- `utils/arrowhead-size.ts` (+ tests) used by the connector renderer (8 sites), SVG export and the organic-branch renderer; tool defaults leave the size unset.
- Help: Connectors → "Arrowhead size". Bug log #454, learnings.

## Breaking changes / migration
- Arrows drawn with the tool before this release carry an explicit 28px and are unchanged. Connectors made by scripts or the DSL had no stored size and render with the new default; set `endArrowheadSize: 28` to keep the old look.
