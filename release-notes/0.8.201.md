# 0.8.201 — Animation Studio: timing tools, and out of pegs (2026-08-16)

Five features picked out of a review of **Callipeg** (the iPad 2D animation app) against Yappy's
frame timeline. Callipeg is raster and Yappy's cels hold vectors, so none of the drawing half
transferred — but its *timing* vocabulary is model-agnostic, and that is where Yappy was thin. You
could express an animation; timing one was awkward.

## Highlights
- **Copy, cut, paste and duplicate blocks of cels** — across layers. There was previously no way to
  reuse a cel at all.
- **Timing tools**: set a cel's exposure, split a stretch onto twos, insert an in-between, and a
  document-level default cel length so drawing a sequence stays on twos by itself.
- **The timeline zooms** (and fits, and can count in seconds instead of frames). The cell width had
  been a hard-coded constant.
- **Flip cel to cel**, plus named ruler markers and a mark in/out range that playback *and* export
  honour.
- **Out of pegs** — slide, rotate or scale a cel's onion ghost without moving the drawing.

## Features

### Blocks of cels
- Drag across cells and rows in the grid to select a rectangle of frames. Dragging a keyframe dot
  still *moves* it, so **Shift+drag** always means "select" — that is how a block starts on a cel.
- **Copy Frames** (Ctrl+Alt+C), **Cut Frames** (Ctrl+Alt+X), **Paste Frames** (Ctrl+Alt+V),
  **Duplicate Frames** (Ctrl+Alt+D), **Delete Frames**. All also on the frame context menu.
- The frame clipboard is deliberately separate from the element clipboard: Ctrl+C/Ctrl+V still copy
  and paste *drawings*, which is what you want far more often while animating.
- Pasting **overwrites** the destination range rather than rippling it — F5 is the tool for making
  room. A pasted cel owns fresh copies of the drawings, so editing it cannot reach back into the cel
  it came from.

### Timing
- **Cel Duration** — 1/2/3/4/6/8/12 frames or a typed value; everything after the cel slides to fit.
- **Split Frames on 1s–6s** — re-expose a selected stretch. A cel with content is deep-copied into
  each new cel so they can then diverge; a blank cel splits into blank cels.
- **Insert In-between** — a blank cel halfway through the selected span.
- **`/cel`** in the timeline header — the default exposure for new F6/F7 cels. Set it to 2 and
  drawing forward stays on twos. It rides on the document, not on the user, so a file keeps the
  timing convention it was drawn on.

### Zoom and the ruler
- Zoom cluster (out · 1:1 · in · fit) in the header, plus **Ctrl+wheel** over the grid. Gridline
  density and keyframe-dot size follow the zoom, so a zoomed-out timeline stays readable.
- **`#`** switches the ruler between frame numbers and `seconds.frames`, for timing an animatic.

### Flipping, markers, play range
- **Alt+,** / **Alt+.** flip cel to cel — drawing to drawing, the way you flip paper — and the
  **«** / **»** buttons beside the frame counter do the same.
- Double-click the ruler for a named, coloured **marker**; **Alt+Shift+,** / **.** jump between
  them. A marker belongs to the ruler and stays on its frame when the cels under it are retimed
  (a frame *label* belongs to a cel and travels with it — both still exist).
- Right-click the ruler → **Mark In / Mark Out**. Excluded frames grey out, and playback, looping,
  Stop (which now rewinds to the in-point) and MP4/WebM/GIF export all cover only that range.

### Out of pegs
- Right-click a cel → **Edit Out of Pegs…**, then drag the canvas to slide that cel's onion ghost;
  Alt rotates, Shift scales, Esc finishes. Onion skinning switches itself on, since without ghosts
  there is nothing to move.
- **The drawing never moves.** The offset is read in exactly one place — the onion renderer — so
  playback, export, hit-testing and the HTML player are structurally unaware of it.
- A pegged cel shows a small orange `p`. Reset one cel or the whole document from the same menu.

## Fixes
- **Clearing the play range never cleared it.** `opSetMarkRange` returned an object with the keys
  *destructured away*; `setStore` merges, and a key that is absent from the patch is a key it never
  touches. Now sets them to `undefined` explicitly. See bug #302.
- **The timeline grid never redrew for an edit that moved nothing else** (pre-existing). Typing a
  new frame count updated the model but left the canvas at its old width, so the ruler stopped short
  and clicks past that point did nothing. The redraw effect's only timeline dependency was
  `store.animTimeline`, whose *reference* never changes because every write merges into the same
  proxy; edits normally redrew only because they also moved the playhead or selection.
  `animTimelineRev` already existed for this hazard but was a plain counter, so it could serve the
  hit-test caches (which compare it) and not effects (which must track it) — it is a signal now.
  See bug #303.

## Internal / tests / docs
- 74 new tests: 43 pure-op tests in `frame-timeline-ops.test.ts` (clipboard, exposure, split,
  in-betweens, markers, play range, cel/marker navigation, pegs) and four new store-level files —
  `anim-frame-clipboard.test.ts`, `anim-timing.test.ts`, `anim-markers.test.ts`, `anim-pegs.test.ts`.
  874 tests green.
- The peg test that matters snapshots every element, drags the ghost, and diffs: if a single
  coordinate moved, the feature would be an edit tool by accident.
- Store-test setups now null `animTimeline` before seeding it — optional keys omitted by a fresh
  object leaked from the previous test through the same merge, making the suite order-dependent.
- ~25 new `Yappy.anim.*` verbs (`selectFrames`, `copyFrames`, `splitFrames`, `setCelDuration`,
  `stepCel`, `setMarker`, `setMarkRange`, `playRange`, `setPeg`, …), documented in `docs/api.md`.
- Help: new sections in the Animate doc for cel blocks, markers/play range and out of pegs, plus
  eight new entries in the hotkeys dialog.
- `docs/animation-callipeg-picks.md` records the design decisions and what was deliberately *not*
  built (ping-pong cycles, linked cels, a per-sheet onion bar, draw-during-playback, transformation
  layers, rotoscope layers, audio waveforms, PNG-sequence export).
- Timeline header buttons are now tight enough to fit one row again — the zoom controls are a single
  segmented control rather than five pills.

## Breaking changes / migration
- `store.animFrameSelection` changed shape from `{ layerId, frames }` to `{ layerIds, frames }` (a
  rectangle). Internal state, not persisted, and no document or API consumer depended on it.
- `AnimTimeline` gained optional `markers`, `markIn`, `markOut`, `newCelFrames`; `AnimKeyframe`
  gained optional `peg`. All absent-by-default, so older documents load and behave exactly as before.
