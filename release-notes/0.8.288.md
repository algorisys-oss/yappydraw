# 0.8.288 — Line jumps at connector crossings (2026-10-11)

## Highlights
- **Line jumps.** Where a straight connector or an elbow run crosses another connector, the newer one draws a 6px arc over the other. Never within a few pixels of a bend or arrowhead; curves don't jump. Same arcs in SVG export. On by default; **Canvas properties → Line Jumps** turns it off per drawing, `Yappy.setConnectorJumps(false)` from a script.

## Fixes
- Sketch-style connectors cached their drawn shape by their own fields only, so a jump arc (and a changed corner radius) could lag behind; the cache key now includes both.

## Internal / tests / docs
- `utils/connector-jumps.ts`: scene registration (`setJumpScene`) by the canvas pass and the exporter, crossing detection with id priority, per-revision cache. `connectorGeometry` emits `commands` for elbow and straight connectors (rounded bends + jumps) and `d` from them; the connector renderer replays the same commands in both styles.
- `connectorJumps` global setting (default true), panel toggle, API.
- Tests: `connector-jumps.test.ts` (+8). Help: Connectors → "Line jumps"; Workspace canvas properties. Learnings.

## Breaking changes / migration
- None. `connectorGeometry(...).d` is now the plain chord for straight connectors instead of `null`.
