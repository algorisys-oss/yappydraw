# 0.8.14 — One-click game Export on the canvas (2026-07-08)

## Highlights
- A **⬇ Export** button on the game-mode bar downloads your game as a single
  self-contained, playable HTML file — no more digging through the Save dialog.

## Features
- **Export on the game bar** (`components/game-mode-bar.tsx`): next to ▶ Play, an
  Export button downloads the current game. Works for visual, Blueprint, and code
  games alike — `effectiveGameScript` compiles the behaviors *and* Blueprint graphs
  into the file, and the player runtime is bundled, so the result plays offline in
  any browser.
- Export logic is now a shared helper (`utils/export-game.ts` →
  `exportSceneAsHtml`), used by both the game bar and **Menu → Save… → Export HTML**
  so the two produce an identical build.

## Fixes
- None (feature release).

## Internal / tests / docs
- `tests/game-export.spec.ts`: verifies a Blueprint game exports with the compiled
  pointer/velocity script + bundled runtime, and that clicking the game-bar Export
  button downloads a playable `.html`.
- `menu.tsx`'s `handleExportHtml` refactored onto the shared helper (no behaviour
  change). Arcade help doc updated.

## Known
- The exported file is ~2 MB because the full player/vendor runtime is inlined —
  fine for sharing one game; a leaner split is possible later if wanted.

## Breaking changes / migration
- None.
