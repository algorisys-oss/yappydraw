# 0.5.19 — Hatch fills in architectural mode (2026-06-30)

## Highlights
- The sketchy line fills — **Hachure, Cross-Hatch, Zigzag, Dashed, Zigzag Line** — now render in **architectural** (clean) mode too, not just sketch. Full render-style parity for fills.

## Fixes
- **Hatch fills collapsed to a solid fill in architectural mode.** Added a clean line-based hatch renderer (`applyHatchFill`) that clips to the shape outline and strokes parallel / zig-zag / dashed hatch lines in the fill colour, density-aware via the **Fill Density** control. Cross-hatch adds a perpendicular pass. Sketch mode is unchanged (still RoughJS).

## Internal / tests / docs
- `buildRenderOptions` suppresses the architectural solid fill for hatch styles so the hatch shows through.
- bug-fixes + learnings updated (the architectural fill path / center-relative geometry note).

## Breaking changes / migration
- None — existing documents that used hatch fills now simply render those fills correctly in architectural mode.
