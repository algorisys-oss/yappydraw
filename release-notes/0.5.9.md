# 0.5.9 — Pen options bar placement hotfix (2026-06-29)

## Fixes
- **Pen 90°/45° options bar was unclickable.** In 0.5.8 the floating Pen options
  bar was positioned at `top:12px; left:50%` — the exact spot as the main toolbar
  (which has a much higher `z-index`), so the toolbar covered it and intercepted
  the tap. Moved the bar to `top:68px` (just below the default toolbar) and raised
  its `z-index`, so the Clock-Method constrain toggle is reachable. Caught by a
  runtime verification pass driving the real canvas.

## Internal / tests / docs
- No behavioural change beyond the bar position; all 0.5.8 Pen features
  (Shift / second-finger / toggle constrain, touch tap-to-toggle, long-press
  anchor menu) verified working end-to-end in-browser.

## Breaking changes / migration
- None.
