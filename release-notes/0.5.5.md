# 0.5.5 — Movable toolbar on tablets (2026-06-28)

## Highlights
- The drawing toolbar's **move / vertical / resize** controls now work on
  tablets, not just desktop.

## Features
- **Touch-friendly toolbar grips** — the drag and resize handles are now
  always-visible and larger on touch/coarse-pointer devices (they were
  `:hover`-only, so invisible on a tablet), with `touch-action: none` so
  dragging a grip doesn't scroll the page.
- **Floating toolbar enabled on tablets** — the phone breakpoint dropped from
  768px to 600px, so tablets (incl. iPad portrait at 768) keep the movable /
  orientable / resizable floating toolbar instead of force-docking to the
  bottom; phones still dock.

## Fixes
- Toolbar drag/resize used mouse events (`mousedown`/`mousemove`/`mouseup`),
  which are unreliable for touch — converted to pointer events so finger/stylus
  dragging works.

## Internal / tests / docs
- `PHONE_MAX_WIDTH` (toolbar.tsx) kept in sync with the `@media (max-width)`
  breakpoint in toolbar.css; new `@media (pointer: coarse)` affordance block.
- Learnings updated.

## Reminder (unchanged behaviour)
- Move: drag the dotted grip at the toolbar's leading edge.
- Vertical: click the rotate (⟳) icon to flip horizontal ↔ vertical.
- Resize: drag the trailing grip to wrap icons into a grid; double-click to
  reset. (This is grid-wrap, not icon-size scaling.)

## Breaking changes / migration
- None.
