# 0.8.122 — Sleeves sit under the jacket

**Date:** 2026-07-20

## Fixes

- **Crossed-arm sleeves merged into a bow across the chest.** A figure with folded arms
  wearing any sleeved top rendered as one large filled shape over the whole torso, with
  the jacket body hidden underneath.

  Folded arms are drawn as two diagonals running shoulder-to-opposite-side, so sleeving
  them and painting them *over* the jacket covered the chest entirely. Sleeves now draw
  **under** the torso body: the crossing happens behind the jacket and only the outer
  stubs show, which is how folded arms actually read.

  This is an ordering fix rather than a per-pose exception, so it holds for any future
  pose with unusual arms — and it also removes the seam line sleeves previously drew
  across the shoulder on ordinary poses, which makes every top look a little cleaner.

## Internal / test changes

- Z-order asserted in `garments.test.ts`, since the symptom is only visible when a fill
  happens to be opaque. 243 unit tests.
