# 0.5.25 — Touch Type: dragging a letter moves only that letter (2026-06-30)

## Fixes
- **Dragging one letter in Touch Type could move other letters** — if a multi-letter selection was left over from an earlier style edit, a plain click+drag moved the whole group. Now a plain click selects just that letter and drags only it, so moving is always predictable. Multi-select (Shift / Ctrl-⌘ / drag-a-box) still applies the scale / rotate / colour / font controls to many letters at once.

## Breaking changes / migration
- None.
