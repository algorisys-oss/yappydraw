# 0.8.99 — Spacing guides always clear (2026-07-14)

## Highlights
- The magenta equal-spacing badges/guides no longer get stuck on the canvas after a drag.

## Fixes
- **Spacing guides sometimes lingered (even on click-outside).** The pointer-up cleanup in
  `selectionOnUp` cleared the alignment (`snappingGuides`) and point-snap markers but not the
  equal-spacing guides. If a drag ended on a spacing match, the badges stayed — and because the same
  cleanup runs on every pointer-up, later clicks didn't remove them either. Now `spacingGuides` is
  cleared alongside the others. Verified with Playwright (drag → guides appear → release → click empty
  → all cleared).

## Breaking changes / migration
- None.
