# 0.8.97 — Constrained move + easier boolean-result selection (2026-07-14)

## Highlights
- **Shift+drag now constrains a move to an axis** (horizontal / vertical / 45°) — perfect for logos
  and precise alignment — and boolean/compound results are **click-selectable in their interior**.

## Features
- **Axis-constrained move.** Hold **Shift** while dragging a selected element (or group) to lock the
  move to horizontal, vertical, or a 45° diagonal, keeping the drag length. Great for nudging logo
  pieces into perfect alignment.

## Fixes
- **Unfilled boolean/compound results were hard to select.** After Unite / Intersect / etc., the
  resulting shape could only be grabbed on its outline (forcing a marquee) when it had no fill. Its
  interior is now click-selectable like every other shape.
- **Shift+drag couldn't move a selected element.** Shift-clicking a selected element used to deselect
  it instantly, so a Shift+drag moved nothing. The deselect is now deferred to pointer-up-if-not-dragged,
  so Shift+drag moves (constrained) and Shift+click still toggles selection.

## Internal / tests / docs
- `hitTestPathElement`: closed subpaths are interior-hittable regardless of fill (narrow-phase JS; WASM
  broad-phase unchanged). New `pState.pendingShiftDeselect` defers the modifier-toggle. New Playwright
  spec `select-and-constrain`. Logged as bug-fixes #164 / #165.

## Breaking changes / migration
- None.
