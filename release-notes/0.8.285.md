# 0.8.285 — Elbow routing holds up on a 52-box diagram (2026-10-11)

## Highlights
- **Routes stay clear of shapes beyond their own neighbourhood.** A detour could leave the ±100px box around a connector's ends into territory where no shape was an obstacle, and cut through three boxes. The obstacle region now grows to everything the route's grid can reach.
- **Connectors that detour are avoided too.** Avoidance looked at a connector's start→end box, which a detour lies outside by definition; it now looks at the drawn route.
- **No 1px or 5px side-steps.** A port 1px off a corner attaches to the edge it sits on; grid lines closer than 2px merge; a jog (a turn after a run shorter than 12px) is priced above an overlap, judged on the run behind the node so a lane step that continues straight into a port is not one.
- Measured on a 52-box, 64-connector platform diagram built through the real refresh path: 0 fallbacks, 0 routes through shapes, 0 along-edge departures, 2 overlaps (a 25px corridor shared by three connectors). v0.8.284 scored 3 / 2 / 1 / 2.

## Fixes
- **#450** Obstacle neighbourhood smaller than the grid → routes through shapes just outside it.
- **#451** Body avoidance rejected connectors by chord box → detours were invisible; bodies' own lines dropped from the grid (lanes only), budget 8000.
- **#452** Corner-adjacent ports classified by the wrong side → 1px stubs; `mergeGridCoords`.
- **#453** Zigzags; the first jog penalty made overlaps worse and was corrected to judge the run behind the turn. The own-edge clearance rule was measured and rejected.
