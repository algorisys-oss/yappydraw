# 0.8.46 — Palette + theme icons no longer overlap the Properties panel (2026-07-09)

## Fixes
- The fixed top-right **Colour Palette** and **Theme toggle** buttons overlapped the
  Properties panel's header when it was open (both live in the top-right corner, where the
  panel docks). They now shift left of the panel while it's open and slide back to the
  corner when it closes.

## Breaking changes / migration
- None.
