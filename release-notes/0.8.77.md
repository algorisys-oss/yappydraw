# 0.8.77 — Turntable: one-click Spin 360° (2026-07-12)

## Highlights
- **↻ Spin 360°** — a single button in the Turntable panel that auto-animates a full rotation.
  No manual keyframing: it authors a clean linear yaw sweep across the timeline that loops
  seamlessly on playback and exports to video/HTML.

## Features
- **One-click rotating turntable** — the **TURNTABLE (3D SPIN)** panel now has a **↻ Spin 360°**
  button. It ensures the shape has a turntable, then writes a `turntable.yaw` keyframe track from
  0° to 360° across the story duration (so a looping playback spins continuously). Works on a
  single shape or a group rig. Scripting: `Yappy.spinTurntable360({ seconds, turns })`.

## Internal / test changes
- `store/app-store.ts`: new `spinTurntable360(ids, { seconds, turns })` — reuses `setTurntable`
  for setup, then replaces each target's `turntable.yaw` track with a two-key linear 0→360°·turns
  sweep (default `seconds` = `storyDuration`). Single history step in the common case.
- `components/property-panel.tsx`: **↻ Spin 360°** button; `api.ts`: `spinTurntable360`.
- `help-docs/features/effects-doc.tsx`, `docs/turntable-plan.md` updated.

## Breaking changes / migration
- None.
