# 0.5.8 — Pen tool: Clock Method + keyboard-free anchor editing (2026-06-29)

## Highlights
- The vector **Pen** (`path` tool, **P**) gains Illustrator's **Clock Method**
  (Shift-constrain handles to 90°/45°) and makes all advanced anchor editing
  reachable on a **keyboard-less tablet**.

## Features
- **Clock Method (90°/45° constrain).** Hold **Shift** while dragging a Bézier
  handle to snap it to the nearest 45° — both while drawing and while editing.
  Keyboard-free alternatives: the new floating **90°/45°** toggle, or rest a
  **second finger** on the canvas while dragging with the stylus (the same
  Procreate-style constrain modifier used for proportional resize).
- **Tablet anchor editing** — the operations that were previously Alt/Ctrl-click
  only (and therefore unreachable without a keyboard) now have touch equivalents:
  - **Tap** an anchor → toggle smooth ↔ corner.
  - **Long-press** an anchor → menu: *Make Smooth/Corner*, *Delete Anchor*.
  - **Long-press** the path outline → *Insert Point Here*.
  - **90°/45°** toggle in the floating Pen bar for the constrain modifier.
- **Floating Pen options bar** — a compact 90°/45° toggle, visible while the Pen
  tool is active or a single path is selected (reachable mid-draw, before
  anything is selected).
- Desktop modifiers are unchanged: Alt-click anchor = convert, Ctrl/⌘-click =
  delete, Alt-click outline = insert, Shift-drag = constrain.

## Internal / tests / docs
- `constrainHandleVec()` (`utils/tool-handlers/pen-path-handler.ts`) snaps a
  handle vector to the nearest 45° preserving length; applied in `penOnMove`
  (creation) and `handlePathNodeDrag` (editing). Constrain flag is
  `e.shiftKey || pState.secondaryContact || store.penConstrain`.
- Second-finger constrain now also fires while *drawing* a path (added
  `isPenBuilding` to the gesture-handler gate).
- **Tap-to-toggle** uses a deferred-history arm (`pState.penTapAnchor`): set up
  the drag but skip `pushToHistory`; the node-drag ignores sub-slop (4px/scale)
  jitter and commits history only once a real drag starts; the lift fires
  `convertPathAnchor` if still armed. A tap is one clean undo (convert), a drag
  is one undo (move) — never both. Cleared in `cancelInflightForGesture` so a
  2-finger gesture can't strand a stale toggle. Arms only on the `path-anchor-*`
  handle, not `path-in`/`path-out`, so dragging the handles stays a pure drag.
- Long-press menu reuses the existing `ContextMenu` via a new `anchorMenuItems`
  signal + `buildAnchorMenu` (falls back to the generic menu when null);
  `canInsertPathAnchor` (non-mutating segment probe) gates the Insert item to
  presses actually on the path.
- New: `pen-options-bar.tsx` / `.css`; store flag `penConstrain` +
  `setPenConstrain`. Help docs (Illustrator Tools) and learnings updated.

## Breaking changes / migration
- None.
