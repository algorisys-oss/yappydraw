# Release Notes - v1.7.0

**Release Date:** February 6, 2026

## Overview

This release brings a major overhaul to the mindmap engine with organic branch connectors, semantic styling, focus mode, keyboard navigation, and drag-to-reparent. It also introduces kinetic typography animations, a glitch effect preset, canvas right-click export, and toolbar UX improvements.

## What's New

### Mindmap Engine Overhaul

#### Organic Branch Connectors

Mindmap connectors are now rendered as smooth, organic bezier curves instead of straight lines:

- **Organic branch rendering**: Connectors use bezier curves with elliptical cloud-style binding points
- **Curved text on branches**: Text labels render along the bezier curve path
- **Text editing**: Double-click organicBranch connectors to edit text at the bezier midpoint
- **Arrowhead support**: Optional arrowheads at start/end of organic branches

#### Semantic Branch Styling

Automatic visual hierarchy for mindmap branches:

- **Auto-coloring**: Each primary branch gets a unique color from a 9-color PALETTE; descendants inherit their branch color
- **Tapered connections**: Connector strokeWidth decreases with depth (4px at root, tapering to 1.5px)
- **Depth-based opacity fading**: Distant nodes fade progressively (100% at root down to 40% minimum)
- **Apply via Palette button**: Click "Auto Style Branch" to apply semantic styling to existing mindmaps

#### Focus Mode (Shift+F)

- **Dim non-branch elements**: Press Shift+F on a selected mindmap node to dim all elements outside its branch
- **Branch isolation**: Highlights the selected node, its ancestors, descendants, and connecting branches
- **Toggle off**: Press Shift+F again or Escape to restore full visibility

#### Arrow Key Navigation

- **Navigate mindmap with keyboard**: Use arrow keys to move between mindmap nodes
- **Left/Right**: Move between parent and child nodes
- **Up/Down**: Move between sibling nodes
- **Auto-select**: Navigation automatically selects and scrolls to the target node

#### Drag-to-Reparent

- **Drag nodes to new parents**: Drag a mindmap node onto another node to reparent it
- **SweetAlert2 confirmation**: Confirmation dialog before reparenting to prevent accidents
- **Auto-align**: Reparented nodes automatically position next to existing siblings
- **Subtree preservation**: The entire subtree moves with the reparented node
- **Unique sibling colors**: Reparented nodes get a unique branch color among their new siblings

### Kinetic Typography Animations

New text animation presets for dynamic presentations:

- **Typewriter**: Characters appear one by one with a blinking cursor
- **Word-by-word**: Words fly in sequentially with customizable effects
- **Text scramble**: Letters randomly shuffle before settling into final text
- **Wave**: Characters animate in a wave pattern
- **Multiline support**: All kinetic typography presets handle multiline text correctly
- **Replay support**: Animations can be replayed without page reload

### Glitch Effect Animation

- **Digital glitch preset**: RGB channel splitting, scan lines, and noise overlay
- **Configurable intensity**: Control glitch strength and frequency

### Canvas Right-Click Export

- **Export from context menu**: Right-click on the canvas to access export options
- **Multiple formats**: Export as PNG, JPG, or SVG directly from the context menu
- **Copy as PNG**: Copy the canvas content to clipboard as a PNG image

### Toolbar Improvements

- **Collapsed icon-selects**: Quick toolbar icon-selects now use single-button popovers for a cleaner UI
- **Mindmap collapse/expand toggles**: Rendered as top-layer pass for consistent visibility

### Other Improvements

- **Drawing Style for openBox**: Sketch and Architectural render styles now work on openBox 3D shapes
- **Examples/Showcase page**: New page with modern diagram templates for quick starts

## Bug Fixes

- **Infinite recursion in buildTree**: Fixed stack overflow when applying mindmap styling or tidying up layouts (connectors inheriting parentId from SolidJS proxy)
- **Child node overlap**: Fixed duplicate child creation when pressing Tab on a parent node repeatedly
- **Bezier text editing position**: Fixed text editing overlay to appear at the bezier midpoint for organicBranch
- **Kinetic typography restore**: Fixed animation state not restoring correctly after replay
- **Kinetic typography multiline**: Fixed word positioning for multiline text in kinetic typography
- **Text element bounding box**: Fixed bounding box not recalculating when fontSize changes
- **Text element width**: Fixed width not expanding when fontSize increases
- **getBranchInfo connector counting**: Fixed connector elements being counted as children, causing wrong PALETTE color assignment

## Upgrade Notes

This release is backward compatible. Existing mindmaps will work as before. To take advantage of semantic styling on existing mindmaps, select the root node and click the Palette button ("Auto Style Branch"). New child/sibling nodes automatically inherit depth-based strokeWidth and opacity.
