# 0.8.35 — Global colour palette: transparent reads as transparent (2026-07-09)

## Highlights
- In the global colour palette, the **Transparent** swatch now shows a checkerboard
  instead of a plain white square, so it's clearly distinct from **White**, and every
  swatch has a crisper outline so the light tiles stop blurring together.

## Fixes
- **Palette swatches were indistinguishable.** The palette painted `transparent` as
  solid white with no indicator (identical to the White swatch), and the near-white
  swatches (White / Off-White / Light-Gray / Soft-Red) had a barely-visible border.
  Now: `transparent` renders as a checkerboard (the standard "no colour" convention),
  and each swatch gets a two-ring outline — a darker border for a crisp edge on light
  tiles plus a subtle outer light halo so dark tiles separate from the dark panel.

## Internal / tests / docs
- Verified with an old-vs-new swatch render. `property-panel.tsx` already indicated
  transparent with a diagonal line, so only the global palette needed the fix. Recorded
  in `docs/bugs/bug-fixes.md`.

## Breaking changes / migration
- None. Purely visual.
