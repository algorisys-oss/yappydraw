# 0.8.4 — My Games launcher (2026-07-07)

## Highlights
- **My Games** — a launcher gallery of every game you've saved, so your games are a
  first-class collection, not documents lost among your drawings. This completes the
  **Arcade Hub** (menu grouping · view switcher · Code-as-a-view · New Game · library).

## Features
- **Menu → Game → My Games…** opens a card grid of your saved games. Each card shows
  a cover thumbnail; **hover to Play** (loads and runs the game on a clean stage, no
  editor chrome), **click to Open** it in the right editor, or **Delete** it. A
  **＋ New Game** tile opens the New Game chooser. Code-authored games show a "code" badge.

## Fixes
- **Manual Save dropped game data.** Saving a game via the Save dialog (workspace or
  disk) omitted its **Blueprint** and **authoring mode**, and wasn't mode-aware — so a
  saved-to-disk game could lose its Blueprint, and a code-authored game could be
  wrongly re-generated from its blocks. Both Save paths now persist `blueprints` +
  `gameAuthoringMode` and honour the authoring mode (matching autosave).

## Internal / tests / docs
- New `components/my-games-dialog.tsx` (+ signal module + css). Saves are tagged
  `isGame` (+ `mode`) in `doc-thumbnails` so the gallery filters without loading every
  document; cards reuse the saved-drawings store + thumbnails.
- e2e verified end-to-end (create → save → appears in My Games → Play). Game suites
  (arcade / game-graph / blueprint / behaviors) regression-green (50).
- Arcade help doc, `docs/learnings.md`, `docs/canva-features-plan.md` updated.

## Breaking changes / migration
- None. Games saved before this build surface in My Games once re-saved (that's when the
  `isGame` tag is written).
