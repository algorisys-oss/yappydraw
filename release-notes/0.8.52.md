# 0.8.52 — Two-audience help docs + tidier context menu (2026-07-10)

## Highlights
- Every in-app help doc now serves **both** end users (UI steps) **and** developers (a verified
  Scripting API section), and the selection **context menu** is grouped into clean submenus.

## Features / improvements
- **Help docs — two-audience pass (all 25 docs).** Each shape/feature doc now has step-by-step UI
  instructions *and* a **Scripting (API)** section with runnable `window.Yappy.*` examples. Every API
  method was verified against `api.ts` (no invented methods; real names corrected, e.g. `radialRepeat`,
  `convertTextToOutlines`, `createBpmnShape`, `mindmapFromOutline`). Previously-empty docs
  (Sketchnote, Infrastructure, Wireframing, UML) got real content; API-only docs (Embedding, YSL) got
  end-user how-tos. Docs honestly note the few API-only effects (Feather / Outer Glow / Scribble).
- **Context menu — reorganized.** The long flat selection menu is grouped into submenus:
  **Create** (Symbol / Pattern from Selection / Artboard from Selection / Graphic Style),
  **Select** (By Type / By Same Property / Similar), **Arrange** (z-order), **Export** (PNG / SVG).

## Fixes
- **Animation API drift** — 15 animation functions that the docs described but were never exposed
  (`animateAlongPath`, `animateMorph`, `typewriter`, `textScramble`, `stopAllElementAnimations`, …)
  are now actually on `window.Yappy`, so the animation help doc is accurate.

## Internal / tests / docs
- Verified via Playwright: help page renders every doc with Scripting sections, visible `Yappy.*`
  snippets, no broken escaping, zero console errors; the reorganized context menu renders with all four
  new submenus. `tsc -b` + `vite build` clean.

## Breaking changes / migration
- None.
