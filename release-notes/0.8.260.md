# 0.8.260 — Grids you can shape, and layout guides (2026-09-22)

From Anshika's review: the grid could only sit behind the artwork, its spacing couldn't be changed
in the UI, and there was no way to build a column layout.

## Highlights
- **Grid above the artwork.** *Draw above objects* puts the grid over your shapes instead of behind
  them. Selection handles stay on top.
- **A grid you can shape.** Spacing in px, mm, cm or in, a stronger major line every N lines,
  rotation, and a movable origin. Snapping follows the rotation and origin.
- **Axes.** Two lines through the grid origin that work with every grid style and show even while
  the grid is hidden.
- **Rows & Columns layout guides.** Columns, rows, gutters and margins as guides on the selection,
  the artboard or the page, with a live preview.
- **Guides snap and save.** Moving an object snaps to visible guides, and guides are saved with the
  document.

## Features
- New **Grid & Guides** section in Canvas properties: show/snap/smart snapping, style, spacing and
  unit, major lines, rotation, colour, opacity, draw above objects, axes and axis colour, origin,
  show/lock guides, Rows & Columns…, Clear guides, Perspective grid….
- Hotkeys: <kbd>Ctrl</kbd>+<kbd>'</kbd> grid (Shift+' still works), <kbd>Ctrl</kbd>+<kbd>;</kbd>
  show/hide guides, <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>;</kbd> lock guides.
- Command palette: *Show / Hide Guides*, *Rows & Columns Layout Guides…*, *Toggle Grid Above
  Objects*, *Toggle Grid Axes*, *Set Grid Origin to Selection*, *Reset Grid Origin & Rotation*.
- API: `setGridSpacing(value, unit)`, `setGridRotation(deg)`, `setGridOrigin(x?, y?)`,
  `snapPointToGrid(x, y)`, `addLayoutGuides(spec, opts?)`, `openLayoutGuidesDialog()`,
  `toggleGuidesVisible(visible?)`. `updateGridSettings` accepts `angle`, `originX`, `originY`,
  `majorEvery`, `unit`, `onTop`, `showAxes`, `axisColor`.
- Canvas Theme now explains that Line Grid / Graph Paper are paper textures, not the snappable grid.

## Fixes
- **#393** The grid could only draw behind the artwork; grid lines were blurred across two pixels.
- **#394** Grid spacing couldn't be changed from the UI.
- **#395** Moving an object on a Diagonal or Isometric grid rounded x and y separately, taking it
  off the slanted lines.
- **#396** Guides didn't snap and weren't saved with the document.

## Behaviour changes
- Lines and Dots grids thin out when zoomed far out (major lines first, then every second line),
  as the angled grids already did. Snapping is unchanged.
- Documents now carry a `guides` array. Older files load with no guides; older builds ignore it.

## Known limitations
- Only moving objects snaps to guides; drawing, resizing and pen points don't.
- Guides stay horizontal/vertical when the grid is rotated.
- Affinity-style multi-axis ("Advanced") grids and angled guides are not built.
