# 0.8.1 — Blueprint: flow control, data getters & full gate (2026-07-07)

A fast follow-up to the 0.8.0 Blueprint, adding the remaining flow-control and
data nodes, a tidier palette, and Game-Graph flow rewiring.

## Highlights
- The **Blueprint** node editor gains loops, timing, a proper stateful gate, and a
  full value/data layer — plus a cleaner palette organised into **Flow ▾** and
  **Data ▾** menus.

## Features
- **Palette dropdowns:** Event / Action stay as direct buttons; **Flow ▾**
  (Branch, Sequence, Delay, For Loop, Gate) and **Data ▾** (Get, Value, Compare,
  Math, Random, Sprite) hold the rest.
- **Sequence** (ordered outputs) and **Delay** (wait N seconds) flow nodes.
- **For Loop** — repeats its `↻` output N times (count inline or wired) then
  continues out `✓ done`; its `i` output exposes the current loop index.
- **Gate** — a full Unreal-style stateful gate: exec inputs *enter / open / close /
  toggle* and one *out*; execution entering `enter` passes only while open. Choose
  whether it starts open or closed.
- **Data nodes** carry values along cyan wires: **Get** (read a variable),
  **Value** (constant), **Compare** (`a ⟨op⟩ b → bool`), **Math**
  (`a ⟨+ − × ÷ %⟩ b`), **Random** (a number in a range), **Sprite** (a sprite's
  x / y / width / height). Wire a Compare into a Branch's condition, or a
  Math/Get/Random into a numeric action param — e.g. `set score = level × 10`.
- **Game Graph:** drag a rule's flow-out port onto a state / page pill to
  **re-target** its goToState / goToPage jump.

## Fixes
- Blueprint palette no longer clips the Play button when many node types are shown
  (the action row wraps; the palette is now grouped into dropdowns).

## Internal / tests / docs
- Compiler: exec edges carry a target port (`toPin`); the data/exec discriminator
  is `pin === 'val'`; `emitChain` enters a node as `{ to, port }` so a gate branches
  on its firing input (cycle guard keyed by node+port for the Enter→Close "do once"
  idiom). New preamble helpers `_after` (delay scheduler) and `_gate` (gate state).
- e2e: `tests/blueprint-graph.spec.ts` (21) + `tests/game-graph.spec.ts` (flow
  rewire); arcade + behaviors suites regression-green.
- Arcade help doc, `docs/learnings.md`, and `docs/canva-features-plan.md`
  (phases C.6–C.11) updated.

## Breaking changes / migration
- None. Blueprints keep the same `blueprints` document shape; the earlier
  once/toggle gate (unreleased) is superseded by the full gate.
