# 0.5.21 — Touch Type: multi-letter select & shape labels (2026-06-30)

## Highlights
- **Touch Type now works on a shape's label**, not just standalone text — style the letters of a rectangle/UML/etc. caption per-glyph.
- **Select multiple letters at once** and style them together.

## Features
- **Multi-glyph selection:** Shift-click a contiguous range, **Ctrl/Cmd-click** to toggle individual letters (discontiguous), **drag a marquee** across glyphs, or **Ctrl/Cmd+A** for all. Clicking outside the element exits Touch Type. Move (drag), scale (`[` `]` / A−/A+ / pinch), rotate (`,` `.` / ↺ ↻ / twist), recolour and re-font all apply to **every** selected glyph, as one undo step.
- **Touch Type on shape labels:** right-click a shape with a single-line label → *Touch Type*, or via the command palette. Per-glyph move/scale/rotate/colour/font render centred inside the shape.

## Internal / tests / docs
- `setCharTransforms(id, indices, patch)` — batched multi-glyph mutator; `patch` may be a `(index, current) => patch` function for per-glyph relative edits (move/scale/rotate).
- `touchTypeText(el)` resolves the editable text (`text` vs `containerText`); `setCharTransform(s)` key off it.
- Extracted the per-glyph draw into a shared `RenderPipeline.renderTouchTypeLine` used by both the text-element renderer (left-anchored) and shape labels (centre-anchored) — no regression to existing Touch Type text.
- Help docs updated.

## Breaking changes / migration
- None.
