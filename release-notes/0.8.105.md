# 0.8.105 — Interactive HTML player: keyboard navigation + auto-framing (2026-07-14)

## Highlights
- **Exported HTML presentations now navigate with the keyboard** — → / Space to advance
  (builds first, then slides), ← to go back, Home/End to jump — matching the in-app
  presentation experience.
- **Infinite-canvas HTML exports open framed to your content** instead of wherever pan (0,0)
  happened to land.

## Fixes
- **No keyboard navigation in exported presentations.** The main app's presentation hotkeys live
  in its global handler, which the standalone player never mounts. The player now binds its own
  keys to the same store actions the on-screen chevrons use (`advancePresentation` /
  `retreatPresentation` / `setActiveSlide`), skipped while a game runs or while typing.
- **Infinite-canvas exports could open blank/cropped.** Exported documents carry no viewport, and
  the player only positioned paged docs; content drawn away from the origin showed cut off or not
  at all. Non-paged docs now `zoomToFit()` on open.

## Internal / tests / docs
- New spec `tests/html-player-check.spec.ts`: exports both doc types for real, opens the
  downloaded files via `file://`, and asserts on canvas pixels (content visible/framed) and
  behaviour (animation advances; ArrowRight changes the slide).
- Player bundle rebuilt (`scripts/embed-player.js`) — the fixes live inside it.
- Help doc (Animated Stick Figures → export) documents the player's keys; bugs + learnings logged.

## Breaking changes / migration
- None. Re-export existing HTML files to pick up the new player behaviour.
