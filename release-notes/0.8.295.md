# 0.8.295 — Hide slide, sections, self-running shows; security updates (2026-11-01)

## Highlights
- **Hide slide, sections, auto-advance and loop** — item 5 of the DeckCraft-based slides backlog
  (`docs/slides-feature-gaps.md`). Together they make backup slides, organised long decks and
  self-running kiosk shows possible.
- **Security updates** for every open Dependabot alert that has a fix, including a critical one in
  the desktop app's updater, and 19 more `npm audit` found.

## Features
- **Hide slide** (slides panel → right-click): next, back and presenting from the start skip it; it
  stays in the file, the panel and exports, and links can still reach it. Dimmed, with its number
  struck through and an eye-off badge. API: `setSlideHidden`.
- **Sections** (right-click → *Add section here…*): a named heading over the slides it covers;
  double-click to rename; *Remove section* joins the section above. API: `setSlideSection`.
- **Auto-advance** (⚡ Transition → *Advance after (seconds)*): moves on by itself after the slide or
  its latest build step appears; a click restarts the count. **Loop until Esc** wraps from the last
  shown slide to the first. API: `setSlideAdvanceAfter`, `setSlideShowLoop`.
- The presenter view's *Next* panel follows hidden slides and the loop.
- **PowerPoint** export and import keep all four (`show="0"`, `advTm`, `p14:sectionLst`,
  `showPr loop`); checked against LibreOffice.

## Fixes
- **#465 — dependency advisories.**
  - Desktop: `zip` < 9.0.5 (critical "zip cloaking", high, medium) via `tauri-plugin-updater`
    2.10.1 → 2.14.1, which brings Tauri 2.11.5 → 2.12.5.
  - npm: `minimatch` → 11 (with `workbox-build`'s `glob` → 14 — see below), and in-range updates of
    `dompurify`, `solid-js`/`seroval`, `vite`, `shell-quote`, `browserslist`, `nanoid`,
    `body-parser`, `proxy-addr`, `fast-uri`, `qs`, `source-map-js`, `serialize-javascript`.
  - Not fixable yet: `deepmerge` (low; no patched release; build-time only).
- Caught before release: overriding `minimatch` alone made the service worker precache 5 files
  instead of 204 — offline support broken with a green build.

## Internal / tests / docs
- `utils/show-order.ts` (+ tests) is the one rule for which slide the show goes to.
- Tests: PPTX round trip of show settings; `tests/slide-show-flags.spec.ts` (skipping, auto-advance
  and loop, the panel menu, PowerPoint).
- Help: Design Studio (hide, sections, auto-advance and loop), Workspace (PowerPoint).

## Breaking changes / migration
- None. Slides gain optional `hidden`, `section`, `advanceAfter`; documents an optional
  `globalSettings.slideShowLoop`.
