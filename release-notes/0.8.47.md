# 0.8.47 — Live Transform effect + Warp presets (Illustrator text-effects parity, round 1) (2026-07-10)

## Highlights
- Two Illustrator-class, **non-destructive** effects land: a **live Transform effect** (accumulating
  copies → radial fans, rosettes, spirals, echoes) and **named Warp presets** (Arc/Arch/Flag/Wave/Rise/
  Bulge). Both render in **Sketch *and* Architectural** styles and can be baked to real geometry.

## Features
- **Live Transform effect** (`el.transformEffect`) — Illustrator's *Effect ▸ Distort & Transform ▸
  Transform*. Draws N accumulating copies, each with the per-step move/rotate/uniform-scale/reflect
  applied one more time, from a single editable object.
  - **Property panel** *TRANSFORM EFFECT* section: Copies / Rotate / Scale / Move X-Y / Pivot X-Y sliders
    (live drag), Reflect X/Y, and Add / Expand / Remove.
  - **Context menu** *Repeat & Mirror ▸ Transform Effect (live)* presets: Radial Fan, Rosette, Spiral, Echo.
  - **API:** `Yappy.setTransformEffect({ copies, moveX, moveY, scaleX, scaleY, rotate, reflectX, reflectY,
    originX, originY })`, `Yappy.expandTransformEffect()`, `Yappy.clearTransformEffect()`.
- **Warp presets — "Make with Warp"** (`el.warp.preset`) — deform a shape or text along a named envelope:
  **Arc, Arch, Flag, Wave, Rise, Bulge**, bent by `bend` (-1..1). Live/re-editable (re-apply to reshape);
  non-path shapes convert to a path first; bake with **Apply / Bake Warp**.
  - **Context menu:** *Path ▸ Warp Preset*. **API:** `Yappy.applyWarpPreset('arc', 0.6)`.

## Fixes
- **`createElement` accepted invalid type names** → invisible, non-functional elements. `'ellipse'` (the
  toolbar's own label; the real type is `'circle'`) now aliases to `circle` with a console warning, and
  `getShapeGeometry` treats stray `ellipse`/`oval` elements as circles defensively — so they render and
  participate in Pathfinder again.

- New `utils/transform-effect.ts` (clone-based per-copy math) + render hook in `canvas-renderer.ts`;
  `warpPresetGrid` in `utils/envelope-warp.ts`. Migration passthrough for `transformEffect`.
- Web help docs updated: `effects-doc` (Transform effect), `illustrator-tools-doc` (Warp presets).
- New planning docs: `docs/illustrator-text-effects-parity.md` (gap analysis + phased plan across 20
  Illustrator tutorials; logo video reviewed — no new primitives) and `docs/tauri-desktop-plan.md`

- Verified in-app via Playwright + screenshots (fans/spirals/warps in both styles; Expand bakes to real
  elements; live re-bend).

## Breaking changes / migration
- None. All new fields are optional and back-compatible.
