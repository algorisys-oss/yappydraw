# Release Notes - v1.8.3

**Release Date:** February 9, 2026

## Overview

Patch release fixing two copy-paste bugs: organic branch orientation distortion on paste, and pasted connectors incorrectly anchoring to original shapes.

## Bug Fixes

- **Organic branch orientation on paste**: Pasting organic branch shapes no longer distorts their curve direction. The `controlPoints` array stores absolute canvas coordinates, and these were not being offset by the paste displacement (`dx`/`dy`), causing the curve to warp when pasted far from the original position.
- **Pasted connector anchoring**: When pasting shapes that had connectors to elements outside the copied selection, moving the pasted shape no longer causes connectors to snap back to the original element. Bindings referencing elements not in the pasted set are now cleared to `null`, making the connector free-ended.

## Technical Changes

### Key Files Modified
- `src/utils/object-context-actions.ts` — Added `controlPoints` offset in `pasteYappyElements`; updated `remapElementBindings` to clear `startBinding`/`endBinding` when target element is not in the pasted set

## Upgrade Notes

This release is backward compatible. No data migration required.
