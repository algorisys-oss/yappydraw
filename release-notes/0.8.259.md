# 0.8.259 — Anshika's review, third pass: text, fonts, pages, mandala, swatches (2026-09-17)

## Highlights
- **Drag a text corner to scale the text.** A free drag stretches the letters (font size follows
  the height, the rest becomes Horizontal Scale); Shift-drag scales proportionally. Side handles
  still set the wrap width.
- **Variable fonts work from one file.** Add `Roboto-VariableFont_wght.ttf` and the Style dropdown
  offers Thin to Black, drawn from the font's real weight axis.
- **Design pages have a pasteboard.** Objects parked beside a page stay visible and clickable, and
  the part of a shape hanging past the page edge shows faded instead of vanishing. Exports are
  unchanged.
- **Dragging a mandala moves it.** It no longer sprays 32 arrows and leaves pieces behind, and
  deleting a mandala turns off the symmetry guides it left on.
- **Swatch groups** keep a design's colour combination together, and **layers have a Blend mode**.

## Features
- Hovering a font in the Font dropdown previews it on the selected text (arrow keys too); Esc or
  moving off restores it, a click applies it as one undo step.
- New Design → size → the template browser starts with a **Blank page** card at that size.
- Swatches panel: **Group** from the selection's colours, one section per group with a colour strip,
  rename, add-from-selection, delete, and move-to-group per swatch.
  `Yappy.renameSwatchGroup(from, to)`, `Yappy.deleteSwatchGroup(name, keepSwatches?)`.
- Layers panel **Blend** select; `Yappy.setLayerBlendMode(layerId, mode)`.
- Status bar **Kaleidoscope × / Radial ×** chip turns those symmetry modes off.
- `textScaleX` element attribute and a Horizontal Scale control in Properties → Text.

- **#383** No way to start a design from a blank page (new Blank page card).
- **#384** Objects beside a design page disappeared unless selected.
- **#385** Variable fonts only ever drew Regular (FontFace registered without a weight range) and
  listed as "Roboto Variable Font wdth,wght" with one style.
- **#386** Create Outlines would outline a variable font at the wrong weight; it now says which
  static file to add.
- **#387** Dragging a selected mandala started a connector from invisible per-member ports (left
  behind when #159 stopped drawing them), and armed symmetry copied it 32 times.
- **#388** Mandala symmetry guides stayed after the mandala was deleted, with no visible off switch.
- **#389** The part of a page's artwork past the page edge was invisible while working.
- **#390** Text corner drag resized only the box.
- **#391** Swatch groups existed in the store but the panel couldn't show or make them.
- **#392** No blend mode for a whole layer.

## Internal / tests / docs
- `utils/font-axes.ts` reads the `wght` axis from TTF/OTF/WOFF `fvar` tables (tests use the bundled
  Inter variable italic and a generated WOFF). `utils/layer-blend.ts` resolver keeps the render
  pipeline store-free. `utils/swatch-groups.ts`.
- New specs: `review-sep17-canvas.spec.ts` (mandala drag, symmetry disarm, text scaling, layer
  blend), pasteboard and Blank page in `design-templates.spec.ts`, font hover preview and outlined
  Text Color in `font-picker-check.spec.ts`, swatch groups in `swatches.spec.ts`.
- Fixed two stale specs: `font-picker-check` assumed Caveat was the second row; `swatches.spec.ts`
  used the pre-dock `.swatches-panel` selector.
- Help: Blank page, pasteboard + faded overhang, font hover preview, variable fonts, outlines limits,
  text corner scaling, mandala symmetry off-switch, swatch groups, layer Blend.

## Breaking changes / migration
- **Text corner drag now scales the text** instead of resizing the box. To change a box's width,
  use the left/right handles (unchanged).
- Objects fully beside a design page are now drawn on the pasteboard (they were hidden). They are
  still excluded from exports.
- Fonts added before this release are re-checked once for variable weight on the next load.
