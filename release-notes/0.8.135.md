# 0.8.135 — Focus theme earns its place; save a swatch from the OKLCH picker (2026-07-21)

## Highlights
- **Focus** is no longer a duplicate of **Dark** — it darkens the page surface you draw on.
- The OKLCH picker can **save the colour you mixed as a swatch**.

## Features
- **Focus darkens the drawing surface.** Dark theme darkens the app chrome and the workspace
  around a page, but leaves the page itself WYSIWYG white. Focus now darkens the page too, which
  is what its description always claimed and what nothing implemented. Measured: page area
  `rgb(255,255,255)` in Dark vs `rgb(0,0,0)` in Focus, with identical chrome.

  Strictly the live editing canvas. **Exports, thumbnails, video recording, time-lapse and
  presentation mode are untouched** — a PNG or MP4 that came out dark because of an editor
  preference would be a bug, and an audience should see the deck as authored. Implemented as an
  opt-in `focusDim` argument that only the editing canvas passes.

- **Focus is offered only on paged documents.** Its entire distinction is the page surface, and
  an infinite canvas has none — its drawing surface is already darkened by Dark. The theme cycle
  is now `Light → Dark → Focus → System` on presentations and design pages, and
  `Light → Dark → System` on an infinite canvas, with the tooltip matching. A document opened
  while Focus is active steps to Dark rather than getting stuck.

- **"+ Swatch" in the OKLCH picker.** Picking a colour applied it but never kept it — the only
  way to save one was to paint a shape, select it, and press Add in the Swatches panel. The
  picker now saves directly: `oklch(70.64% 0.1588 200.00)` lands in the document's swatches.

## Fixes
- Removed a stale comment in `app-store.ts` claiming `setTheme` adjusts `canvasBackgroundColor`
  for the focus theme. It never has — which is a large part of why Focus and Dark had silently
  become the same thing.

## Internal / tests / docs
- Verified by pixel measurement rather than inspection: before this change Dark and Focus differed
  by **152 of 921,600 pixels (0.017%)** on infinite canvas, slides *and* design documents — a
  16×14 region that was the theme-toggle button's own icon. An earlier measurement suggesting a
  real difference on paged documents was an artefact: a toast present in one screenshot and faded
  in the other, dominating the diff.
- The 2 failures in `layer-background.spec.ts` were confirmed pre-existing by stashing this work
  and re-running on the committed baseline, as with the 6 reported in 0.8.134.
- Fixed a flaky GIF-capture test: `page.goto` alone can exceed Playwright's 30s default while
  Vite performs its first compile of a session, so the test timed out before any assertion ran.
  `boot()` now raises the timeout and waits for real UI, the same guard `contrast.spec.ts` already
  had. Stable across three consecutive full runs.

## Breaking changes / migration
- Focus no longer appears in the theme cycle on infinite-canvas documents. `setTheme('focus')`
  still accepts it, so saved documents and scripts are unaffected.
