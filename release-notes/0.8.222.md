# 0.8.222 — the layer tray icons were being crushed, not drawn small (2026-08-25)

## Highlights
- The lock / duplicate / delete icons in the Layers swipe tray were a 6px sliver inside a 44px coloured block. They now fill their buttons properly.

## Fixes

**#329 — Layer swipe-tray icons rendered as a sliver.**

Reported as "the container is very big but the icons are very small". It was not a size problem — the icons were being *crushed*:

```
button (index.css)   padding: 0.6em 1.2em    ->  9.6px 19.2px
.tray-btn            width: 44px, border-box
                     content box = 44 - 19.2 - 19.2  =  5.6px
svg                  width="20", flex-shrink: 1
                     rendered                 =  5.6 x 20
```

A global padding meant for text buttons left 5.6px of content box, and an `<svg>` is a flex item that will shrink into it. The neighbouring row buttons escape it only because they happen to set their own padding.

Fixed with `padding: 0` on the tray buttons — they are full-bleed touch targets — plus `flex-shrink: 0` on the icon so it cannot be squeezed by its own button again. Icons now render at their full 20×20.

A page-wide sweep for the same defect (any button icon rendering under 75% of its declared size) found no others.
