# Release Notes - v1.8.4

**Release Date:** February 9, 2026

## Overview

This release adds localStorage auto-save for crash recovery and fixes three bugs: arrow connector endpoint tracking, arrow corruption during group moves, and missing text in SVG exports.

## New Features

### localStorage Auto-Save
- **Silent restore on startup** — Your last session is automatically loaded when you open Yappy, just like Excalidraw and tldraw. No recovery prompt.
- **Real-time debounced saves** — Changes are persisted to localStorage 1 second after the last edit.
- **Immediate save on slide navigation** — Switching slides triggers an instant save.
- **Save on tab close** — `beforeunload` ensures data is persisted even if the browser closes unexpectedly.
- **Dirty state indicator** — A red dot appears next to the document name in the status bar when there are unsaved changes.
- **Multi-tab awareness** — A toast notification warns when another tab is editing the same document.
- **Size limit handling** — Graceful error toast if the document exceeds localStorage quota.
- **API exposure** — `Yappy.forceAutoSave()` and `Yappy.clearAutoSave()` available on the public API.

## Bug Fixes

- **Arrow connector endpoint tracking** (Bug #19): Arrows created via connector handle dots now properly track their endpoint when the connected shape moves. The `position` property was missing from `endBinding` in `connectorHandleOnUp`.
- **Arrow corruption during group moves** (Bug #20): Moving a selection containing both shapes and their connected arrows no longer corrupts arrow geometry. Fixed by wrapping multi-element updates in `batch()` and using a two-pass approach (positions first, then bound line refresh).
- **SVG export missing text** (Bug #21): Standalone text elements and container text (text inside shapes) now render correctly in SVG exports with proper font family, weight, style, alignment, word wrapping, and vertical centering.

## Technical Changes

### New Files
- `src/storage/auto-save.ts` — Core auto-save module with `initAutoSave()`, `forceAutoSave()`, `clearAutoSave()`, `loadAutoSave()`

### Key Files Modified
- `src/store/app-store.ts` — Added `isDirty` state; `resetToNewDocument()` clears auto-save
- `src/app.tsx` — Loads auto-save on mount; saves on beforeunload
- `src/components/menu.tsx` — Clears auto-save after manual save
- `src/components/status-bar.tsx` — Dirty state indicator (red dot)
- `src/api.ts` — Exposed `forceAutoSave` and `clearAutoSave`
- `src/utils/tool-handlers/minor-handlers.ts` — Added position to connector handle endBinding
- `src/utils/tool-handlers/selection-handler.ts` — batch() wrapper, two-pass move, skip selected arrows
- `src/utils/export.ts` — SVG text rendering (standalone + container text)

## Upgrade Notes

This release is backward compatible. No data migration required. On first load after upgrade, the app will start with a blank canvas (no prior auto-save data exists). Subsequent sessions will auto-restore.
