# 0.8.26 — More motions + timeline block resize (2026-07-08)

## Highlights
- Four new stick-figure motions (**Run, Clap, Dance, Cheer**) and you can now
  **resize action blocks right on the Scene Timeline**.

## Features
- **New motion clips** — the animated-figure set grows from 6 to **10**: **Run**
  (leaning, arm-pumping run cycle with foot planting), **Clap**, **Dance** (hip sway +
  alternating arms) and **Cheer** (both arms up, pumping). Available everywhere clips
  are — the Animated tab, clip switcher, sequences and the timeline.
- **Timeline block resize** — drag the right edge of any action block on the Scene
  Timeline to change how long that motion runs (snaps to ½ second). The scene length
  re-fits automatically.

## Fixes
- None.

## Internal / tests / docs
- Four clips added to `anim/clips.ts` (Run reuses the foot-target + IK approach with a
  longer stride/faster cadence). Timeline blocks get a right-edge resize grip that
  captures px-per-second at drag start and writes the new step duration via
  `setFigureSequence`. Help doc, keywords and learnings updated.

## Breaking changes / migration
- None.
