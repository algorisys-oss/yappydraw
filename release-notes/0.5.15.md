# 0.5.15 — Industry-grade sequence diagrams, unified Architecture group, fonts & a UX sweep (2026-06-30)

## Highlights
- **Sequence diagrams are now industry-grade** — combined fragments (loop/alt/opt/par), activation bars, notes, actor lifelines, auto-numbering and proper sync/reply/async arrows, in both Mermaid and native YSL, in both render styles.
- **Unified "Architecture" tool group** — the Infrastructure, Cloud-Native and Technical dropdowns are merged into one sectioned fly-out.
- **Custom & per-character fonts** — upload your own fonts and use them anywhere; set a font per glyph in Touch Type.
- A batch of **UX fixes**: live numeric property edits, property-panel search, toolbar stays in view, fill controls grouped together, letter-spacing, and several connector/grouping bug fixes.

## Features
- **Sequence diagrams (DSL).** `layout: sequence` now renders a full ordered timeline:
  - Mermaid: `loop/alt/opt/par/critical/break` + `else/and`, `Note over/left of/right of`, `activate/deactivate` (and `+`/`-` on arrows), `autonumber`, and `->>`/`-->>`/`-)`/`-x` arrow semantics.
  - Native YSL: `note`, `loop/alt/else/opt/par/and`, `activate/deactivate`, `autonumber`, and `->>`/`-->>`/`-->` operators.
  - Actors get a dashed lifeline; activation bars stack by nesting depth.
- **Unified Architecture tool group** (`architecture-tool-group.tsx`): Infrastructure / Cloud-Native / Blocks & 3D / Data Flow / State sub-sections behind one toolbar button.
- **Custom fonts** (`utils/custom-fonts.ts`): upload `.ttf/.otf/.woff/.woff2` via the **＋ Add font…** entry in the property-panel Font picker or the Touch Type font dropdown; loaded with `FontFace`, persisted to localStorage, usable anywhere a built-in font is.
- **Per-character fonts in Touch Type** — `charTransforms[i].font`; a font dropdown joins the existing size/colour/rotate controls.
- **Property-panel search** — filter controls by label / key / group; matching groups auto-expand.
- **Letter spacing** — new `letterSpacing` text property (and a control), applied through the renderer so it affects measurement, wrapping and drawing.

## Fixes
- **Realtime property edits** — numeric fields commit live as you type a plain number (math expressions like `200-50%` still defer to Enter/blur).
- **Elbow connectors corrupted on group/shape move** — `refreshLinePoints` rebuilt elbow points as `{x,y}` objects (un-renderable); now flat `number[]`.
- **Connector un-clickable when its shapes are grouped** — the group bounding-box hit-test pre-empted the per-element test; demoted to a fallback so the connector in the gap stays clickable.
- **Connection handles dead on grouped shapes** — the green "+" handles were drawn but only hit-tested for single selection; now hit-tested for grouped members too.
- **"Reparent Node?" prompt fired for ordinary shapes** — now gated to mindmap/hierarchy nodes only.
- **Video "Insert Video" dialog clipped** by the toolbar's CSS transform — rendered through a `<Portal>`.
- **Toolbar could be dragged off-screen and lost** — now clamped fully into view after drag, on resize and on restore.
- **Two fill controls were far apart** — the Appearance stack now renders directly under the basic Fill.

## Internal / tests / docs
- New shared sequence-timeline model (`DSLDiagram.sequence`) computed once for both layout and rendering.
- `IRenderer.letterSpacing` added to Canvas + SVG renderers.
- repograph updated to latest; **all 11 npm vulnerabilities fixed**.
- e2e specs added for the sequence timeline and connector/grouping behaviour.
- Learnings + bug-fixes logged; help docs (UML/sequence, YSL tutorial) updated.

## Breaking changes / migration
- None for documents. The Infrastructure / Cloud-Native / Technical toolbar dropdowns are replaced by a single **Architecture** group (same shapes, reorganised).
