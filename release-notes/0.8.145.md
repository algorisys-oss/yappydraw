# 0.8.145 — Animation Studio finale: frame actions, HTML player, camera (2026-07-22)

## Highlights
- **Interactive playback**: frame actions (Stop / Go to Frame / Next Scene) in the spirit of Flash's `stop()`/`gotoAndPlay()`.
- **A living HTML export**: one self-contained page that plays the real animation — renderer, frame actions, audio and all — not a video.
- **Camera layer**: capture editor views as camera keyframes; playback and exports glide between shots (Ken Burns moves).
- This completes the P1–P8 Animation Studio roadmap.

## Features
- **Frame actions (P7)** — `AnimKeyframe.action`, set from the keyframe context menu (small "a" glyph above the dot): *Stop* parks the playhead on the frame; *Go to Frame…* / *Loop to Frame 1* jump the playhead (loop sections — `goto` rebases the playback clock and reschedules the audio row); *Next Scene* chains scenes into an act-by-act film. Fired only when playback crosses the keyframe (loop-wrap aware, skipped frames covered); scrubbing never triggers them. Works identically in the editor and the HTML player. API: `Yappy.anim.setFrameAction`.
- **HTML5 player for animations (P7)** — Menu → Export HTML ships the frame timeline(s) (`animTimeline`/`animScenes` now included in `exportSceneAsHtml`), and the standalone player auto-plays animation documents with looping plus a minimal restart/pause transport. Player bundle regenerated.
- **Camera layer (P8)** — `AnimTimeline.camera`: keyframed stage-local center + zoom, eased per key. The **📷** button captures the current editor view as a key at the playhead (📷✕ removes it); playback, video export and the HTML player apply the tweened camera as an outer stage transform, while paused editing keeps the free view. Pure `evaluateCameraAt`. API: `Yappy.anim.setCameraKey / setCameraKeyFromView / clearCameraKey / camera`.
