# 0.8.154 — Quick vector operations, and the NaN that broke every edited shape (2026-07-29)

## Highlights
- **Boolean operations are now one click away.** Select two or more shapes and a strip
  appears right above them with the full Pathfinder set — no more right-click → submenu.
- **`Ctrl+Alt+U/D/I/X`** for Unite / Subtract / Intersect / Exclude, and **`Shift+M`** for
  Shape Builder, which also gets a button in the main toolbar.
- **Fixed: shapes that had been through a path operation became unselectable and could
  not be combined again.** One parser bug explained both.

## Features

### Contextual boolean toolbar
Appears whenever two or more combinable shapes are selected, positioned above the
selection (below it when there isn't room, always clamped into the window). Hides itself
whenever another tool owns the canvas — Shape Builder, Live Paint, Knife, warps.

- **Top row:** Unite, Subtract, Intersect, Exclude, each with an Illustrator-style glyph.
- **Bottom row:** Divide, Trim, Merge, Crop, Outline — the region operations.
- **❖ Keep editable:** switches to a non-destructive *compound shape*, so the originals
  survive and the operation can be changed or released later. Illustrator hides this
  behind Alt-clicking a Pathfinder button; here it's a visible toggle that remembers your
  choice.

### Keyboard
| Operation | Shortcut |
| --- | --- |
| Unite | `Ctrl+Alt+U` |
| Subtract (minus front) | `Ctrl+Alt+D` |
| Intersect | `Ctrl+Alt+I` |
| Exclude | `Ctrl+Alt+X` |
| Shape Builder | `Shift+M` |

Inkscape's `Ctrl` `+`/`−`/`*`/`^` can't be used in a browser — those are page zoom, and
`Ctrl+K` is already the command palette. Plain `Ctrl+D` still duplicates; the boolean
handler only fires with Alt held, and there's a test pinning that.

### Shape Builder
Promoted out of a 25-item list into the main toolbar. Switching it on without at least
two shapes selected now says so, instead of leaving you in a mode that silently does
nothing.

## Fixes
- **Shapes from earlier path operations were unselectable and uncombinable.** `parsePath`
  had no exponent support, so a coordinate like `7.105427357601002e-15` — routine in
  boolean output, where values nearly cancel — parsed as a number, then `e` as a *command*,
  then `-15`, turning the rest of the path into `NaN`. Hit-testing then compared against
  `NaN` (no click ever landed) and the flattened polygon was invalid (Pathfinder reported
  "empty result"). Scientific notation is legal in SVG path data, so imported files hit
  this too. (#220)
- **The toolbar could render off-screen** at negative world coordinates or when zoomed
  out, which looked like it simply wasn't appearing. Now clamped on both axes. (#221)
- **A stray line in the selection emptied the whole operation** — lines flatten to zero
  polygons and the engine needs two inputs with area. The shapes now combine and the line
  is left alone. (#222)
- Empty results explain themselves: which objects were skipped, or why an intersection of
  non-overlapping shapes is legitimately empty.
- Toolbar hover was `#f9fafb` on a `#ffffff` panel — a 1% difference that read as the
  button turning white. Now a tinted wash, checked in light and dark.
