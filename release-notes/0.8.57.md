# 0.8.57 — Dockable panels: drag-to-dock (Phases B/C/E) + ghost-element fix (2026-07-10)

## Highlights
- **Drag-to-dock** the panel system: grab a panel by its title bar and drop it on
  the left/right edge to dock, tear it back out to float, and reorder a stack.
- **Fix:** a stray single click/tap with the line, arrow, or pen tools no longer
  leaves an invisible "ghost" element in the document.

## Features
- **Drag-to-dock (Phase B):** dragging a panel's title bar tears a docked panel out
  into a floating one that follows the cursor; live left/right **drop indicators**
  light up as you near an edge; release over an edge docks it there. The opaque
  dock zones sit above the canvas, so drawing never happens under a dock.
- **Multi-panel dock + reorder (Phase C):** two new dock-native panels —
  **Align & Distribute** and **Arrange** (z-order + flip) — join the pilot
  **Effects** panel. Drop a panel between siblings in a zone to **reorder** it;
  resize the zone, collapse a panel to its title bar, and the whole layout persists
  across reloads. Open any panel or **Reset Dock Layout** from ⌘K.
- **Responsive (Phase E):** on phones the dock falls back to a bottom sheet lifted
  clear of the bottom toolbar.

## Fixes
- **Invisible ghost line/arrow/pen elements (#144):** a click-without-drag left a
  0×0 element that rendered nothing yet counted toward the document and survived
  reload (reported as "fine-1 / arrw-1 hidden"). Zero-extent line/arrow/pen strokes
  are now discarded on release — bound connectors and real strokes are kept.

## Internal / tests / docs
- Verified drag-to-dock, tear-out, reorder, persistence, and the phone fallback via
  Playwright + screenshots. `docs/dockable-panel-system-plan.md` updated: Phases
  A/B/C/E shipped; **Phase D** (migrate the ~18 existing panels onto the shared
  chrome) remains as incremental follow-up.

## Breaking changes / migration
- None.
