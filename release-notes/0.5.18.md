# 0.5.18 — UML Object, Port, History & Activity Action shapes (2026-06-30)

## Highlights
- Four more UML shapes — **Object/Instance**, **Port**, **History pseudostate**, and **Activity Action** — closing every prioritized gap from the UML completeness review.

## Features
- **Object / Instance** (`umlObject`) — a box with an underlined `name:Class` label (object-diagram convention).
- **Port** (`umlPort`) — a small filled marker square for component/part boundaries.
- **History pseudostate** (`umlHistory`) — a circle with an **H** glyph for state machines.
- **Activity Action** (`umlAction`) — a rounded "stadium" rectangle for activity diagrams.
- All four render in **sketch** and **architectural** styles and are available in the **Architecture** group (UML Structure / UML Behavior), the command palette, and via DSL aliases `[object]`/`[instance]`, `[port]`, `[history]`, `[action]`/`[activity-action]`.

## Internal / tests / docs
- Wired end-to-end (renderer both styles + `definePath`, geometry, hit-testing, transforms + icons, draw/text-edit handlers, DSL defaults/aliases, property `applicableTo` lists, command registry).
- `docs/uml-completeness-review.md` updated — all prioritized gaps now ✅; only niche diagram types remain (Timing, Profile, Composite-structure parts, stereotype edge decorations).

## Breaking changes / migration
- None.
