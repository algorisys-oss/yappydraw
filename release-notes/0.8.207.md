# 0.8.207 — Teaching mode, and pasted objects you can actually grab (2026-08-21)

## Highlights
- **Teaching mode** strips the app back to the tools people draw with, for running a session
  in front of a room. One checkbox; the professional vector surface leaves the screen.
- **Paste finally hands you the Select tool.** Pasting or dropping anything while a brush or
  pen was in hand produced an object you could see and not touch.

## Features
- **Teaching mode** (`View → Teaching Mode`, or the graduation-cap button in the top bar).
  Pins the toolbar to the common drawing tools — Select, pen, line, arrow, rectangle, diamond,
  circle, text, image, eraser — and takes Vector Tools, Shape Builder, the Pathfinder strip,
  the vector Pen and the dimension badge off the top bar, the View menu and the right-click
  menu. The shape libraries (UML, BPMN, wireframe, cloud) are off too, so the toolbar stays
  one short row.
  - The tools are genuinely switched off, not merely hidden: the guard is at `setSelectedTool`
    / `toggleShapeBuilder` / `toggleVectorToolsPanel`, so the keyboard shortcuts (`P`,
    `Shift+M`), the command palette and the scripting API all hit it and say why.
  - Safe to flip mid-session — leaving the mode restores your Dimensions and Pathfinder
    settings exactly as they were. Persists across a reload; never read from a document, so
    opening someone else's file cannot turn it on or off.
  - API: `Yappy.setTeachingMode(on)`, `Yappy.getTeachingMode()`, `Yappy.toggleTeachingMode()`.

## Fixes
- **#307 — paste left the drawing tool armed, so the result was inert.** A pasted image or
  object arrived correctly selected and then refused to move, resize or rotate, and the next
  stroke drew straight over it. Being selected is only half of being editable: the handle box
  is drawn only under the Select tool, and a drag only moves/resizes under Select or Lasso.
  Every paste path now routes through one shared ending (`selectPastedElements`) — clipboard
  paste of images, Yappy JSON and plain text; both image drag-and-drop handlers and the
  DataTransfer fallback; the mindmap-outline paste; and the SVG file drop. Lasso is left alone,
  since it already selects. Same convention Select-All and pen-finish already followed.
- **Dropping several SVGs at once selected only the last one.** `importSvgToCanvas` selects its
  own shapes, so each file overwrote the previous file's selection. The ids are collected across
  the whole drop and selected together, matching the multi-image drop.

## Internal / tests / docs
- New `frontend/src/utils/teaching-menu-filter.ts` — the context-menu filter, extracted so it can
  be tested without loading Solid components.
- `TEACHING_MODE_TOOLS` is a **whitelist**, deliberately: `ToolType` spans every shape in the
  library and grows most releases, so a blacklist would spring a leak with each addition.
- 31 new tests — `store/teaching-mode.test.ts` (tool guard, settings round-trip, snapshot
  idempotency) and `utils/teaching-mode-menu.test.ts` (filter behaviour, plus a source-text
  assertion that every label the filter matches on still exists in the builder).
  `utils/paste-tool-switch.test.ts` pins the paste ending. Suite: 1067 tests across 72 files.
- Help: new **Teaching mode** and **Paste & drop** sections in `help-docs/features/workspace.md`.
- Learnings recorded in `docs/learnings.md`; fix logged in `docs/bugs/bug-fixes.md`.

## Breaking changes / migration
None. Teaching mode is off by default and existing documents are unaffected.
