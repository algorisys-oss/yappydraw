# 0.8.180 — Inside the group (2026-08-07)

Five items of designer feedback about layers and alignment. Three were real defects, one was a
feature that shipped where nobody could find it, and one was genuinely missing.

## Highlights

- **You can work inside a group.** Double-click a grouped object to step into it and select,
  move, restack and align its members individually. Esc steps back out.
- **Align and distribute stopped exploding groups.** Selecting two groups and hitting Align Left
  used to flatten every member onto the same x.
- **Bring Forward / Send Backward have shortcuts** — and they're the Illustrator/Figma ones.
- **Rasterize** — turn vector artwork into a bitmap, in place.
- **Align-to-key is visible**: the key object is outlined, and you can click to choose it.

## Features

### Group isolation ("enter the group")

Double-click a grouped object to step in. Clicks then select individual members, so one object
inside a group can be moved, restyled, restacked and aligned. A bar at the top of the canvas
shows the depth and the way out.

- Double-click again to go one level deeper into a nested group.
- **Esc** (or *Up one*) steps out one level and re-selects the group; clicking outside leaves
  entirely.
- Marquee select and `Ctrl+A` are confined to the isolated group's members.
- Text inside a group needs two double-clicks — the first enters the group, the second edits the
  text (as in Illustrator).

```js
Yappy.enterGroup(elementId);   // step into the group containing this element
Yappy.isolatedGroups;          // ['group-…'] — outermost → innermost
Yappy.exitGroup();             // up one level
Yappy.exitAllGroups();
```

### Rasterize (Object ▸ Rasterize)

Right-click → **Rasterize**, or the command palette. Converts the selection into a single image
element that takes its place — same layer, same slot in the stacking order. Rotation, opacity and
effects are baked into the pixels.

- **1× / 2× / 4×** pixels per canvas unit (2× is the default), plus **on White** and **a Copy**
  (keeps the vectors).
- Only the selected objects are drawn, so overlapping neighbours are never baked in.
- Rasterizing a whole group yields one ungrouped image; rasterizing part of a group leaves the
  image inside that group.
- Output is capped at 16384px on the longest edge rather than silently failing to allocate.

```js
const id = await Yappy.rasterize();                      // selection, 2x, transparent
await Yappy.rasterize([a, b], { scale: 4 });
await Yappy.rasterize(undefined, { keepSource: true });
```

### Align-to-key affordances

The mode existed but was undiscoverable. The key object now draws with a thicker outline and a
corner pip; with the mode on, **clicking an already-selected object makes it the key**
(Illustrator's gesture); and the toggle is mirrored into the dock's Align panel, next to the
align buttons.

## Fixes

- **Align/distribute treated every group member as a separate object** — two groups aligned left
  collapsed onto one x, destroying both. A group is now one unit: its bounding box is what lines
  up, and members keep their internal arrangement. Selecting *part* of a group (a marquee,
  shift-click) still aligns those members individually, since the objects were clearly the
  target. A lone group is a single unit, so aligning it alone is now a no-op rather than a
  scramble.
- **Bring Forward on a multi-selection took one undo per object**, let selected objects leapfrog
  each other (two adjacent objects swapped and netted out to nothing), and could step an object
  past an element on *another layer* — a data change with no visible effect, because paint order
  is layer order first. The selection now moves as a block: one undo, relative order preserved,
  steps confined to the object's own layer, and one press clears an entire group.
- **You could not select a single object inside a group at all** — clicking any member selected
  the whole group, which is the actual reason "aligning objects inside a group shifts everything
  together". Fixed by group isolation, above.

## Breaking changes / migration

**Z-order shortcuts now follow Illustrator and Figma.** Previously `Ctrl+]` / `Ctrl+[` jumped
straight to the front/back; there was no one-step shortcut.

| Action | Was | Now |
| --- | --- | --- |
| Bring Forward | — | `Ctrl+]` |
| Send Backward | — | `Ctrl+[` |
| Bring to Front | `Ctrl+]` | `Ctrl+Shift+]` |
| Send to Back | `Ctrl+[` | `Ctrl+Shift+[` |

`Alt+[` / `Alt+]` (reorder *layers*) are unchanged. Nothing in a saved document changes; this is
keyboard muscle memory only.

`Yappy.moveElementZIndex(id, dir)` keeps its signature and behaviour. The new
`Yappy.moveSelectionZIndex(ids, dir)` is the selection-level primitive.
