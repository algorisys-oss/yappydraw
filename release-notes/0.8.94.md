# 0.8.94 — Snap to path intersections (2026-07-13)

## Highlights
- Completes the **Precision & Measurement** plan: dragging an element now snaps onto the
  points where two other objects' outlines **cross**, not just onto their anchors.

## Features
- **Path-intersection snapping** (plan Phase 4c). With object snapping on, dragging an element
  makes its anchors snap onto the crossing points of other elements' outlines — so you can drop
  a corner exactly where two lines or edges meet. Uses the same magenta diamond marker as
  snap-to-point; hold **Shift** to suspend snapping.

## Fixes
- None.

## Internal / tests / docs
- New pure, unit-tested `utils/path-intersection.ts` (`elementSegments`, `segmentIntersection`,
  `getIntersectionPoints` with a bbox broad-phase + dup-merge; 9 unit tests). Crossings feed the
  existing `getPointSnap` as extra targets, computed once per drag and cached on the pointer state.
- New Playwright spec `path-intersection-snap`. Help doc updated.
- v1 limitation: non-path/non-ellipse concave shapes use their bounding-box edges as the outline
  approximation. **The Precision & Measurement plan (Phases 1–5) is now complete.**

## Breaking changes / migration
- None.
