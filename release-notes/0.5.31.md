# 0.5.31 — Design workflow gaps closed + Google Fonts live preview (2026-07-05)

Round 3 of the Canva-parity push: every quick-win gap from the two-course
evaluation (see `docs/canva-features-plan.md` → "Gap round 3"), plus a
user-reported font-picker UX fix and an offline-readiness audit.

## Highlights
- Templates are now discoverable the Canva way: search box, "✓ fits your page"
  sorting, and the browser opens automatically after picking a New Design size.
- The Google Fonts picker docks beside the canvas and stays open — click fonts
  back-to-back and watch the selection change live.
- Verified 100% offline for core work (new e2e spec blocks all external hosts).

## Features
- **Template search + size suggestions** — free-text search over names, tags,
  and descriptions across all categories; in a design document, templates with
  the same size or aspect ratio float to the top with a "✓ fits" badge.
  `Y.searchTemplates('poster')`.
- **New Design → templates chain** — choosing a size in New Design… opens the
  template browser on the Designs tab (close it for a blank page).
- **Aspect-ratio crop presets** — while cropping an image: Free, 1:1, 4:5,
  3:4, 16:9, 9:16. Presets snap to the largest centered rect and lock the
  ratio while dragging the crop handles.
- **Stock photo filters + drag-to-canvas** — All/Landscape/Portrait/Square
  chips on the Photos tab; drag a result onto a frame or shape to fill it,
  onto an image to replace it, or onto empty canvas to place it at the drop
  point. `Y.insertStockPhoto(photo, {x, y})`.
- **Six frame shapes** — rectangle, circle, triangle, star, heart, hexagon
  (was rect + circle).
- **JPG in the Export dialog** — with 1–3x scale and Current Page Only
  (JPEG always exports on white). `Y.exportPageToPng(i, 2, true, 'jpeg')`.
- **Set as Page Background / Detach Image from Background** — right-click a
  selected image or the empty canvas respectively; detach turns the page's
  background image back into a movable, croppable element.
  `Y.detachBackgroundImage()`.
- **Glitch text effect** — cyan/magenta chromatic-aberration preset alongside
  the existing eight. `Y.applyTextEffect('glitch')`.

## Fixes
- **Google Fonts picker closed on every pick (user-reported)** — selecting a
  font kicked you out of the list, so comparing fonts meant reopening and
  re-scrolling every time. The picker now applies on click and stays open
  (row shows "✓ applied"), and it docks to the right edge with no dimmed
  backdrop so the canvas — the thing being previewed — stays visible and
  interactive. Close with Done, Esc, or ✕.

## Internal / tests / docs
- New e2e suites: `tests/design-gap-round3.spec.ts` (glitch, template search,
  detach background, JPG page export) and `tests/offline-check.spec.ts`
  (aborts every non-localhost request: app boots, full design workflow runs,
  IndexedDB autosave survives reload — kept as a regression guard).
- `tests/design-extras.spec.ts` updated for the new frame grid (6 cells).
- Help docs refreshed (design-studio, illustrator-tools font picker section);
  `api.ts` gained `searchTemplates`, `detachBackgroundImage`, JPG page export,
  and point-targeted `insertStockPhoto`.
- Offline audit notes: AI, Google Fonts, stock photos, Google Drive, and video
  embeds are online by design and degrade gracefully; the hosted site still
  needs a service worker to cold-load offline (not included in this release).

## Breaking changes / migration
- None. (`exportPageToPng` gained an optional trailing `format` parameter;
  existing calls are unaffected.)
