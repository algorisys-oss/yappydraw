# 0.5.22 — Puppet Warp gated to warp-capable elements (2026-06-30)

## Highlights
- **Puppet Warp** now only engages on elements it can actually deform — shapes, paths and images — and tells you when it can't.

## Fixes
- **Puppet Warp silently did nothing on text & connectors.** It accepted any element, but the warp mesh only bends a vector outline or image pixels. Now it's gated to shapes/paths/images; for text or connectors the capture overlay doesn't appear (the canvas stays interactive) and a hint explains why.

## Breaking changes / migration
- None.
