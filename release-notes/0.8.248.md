# 0.8.248 — Styled QR codes with logos (2026-09-13)

## Highlights
- **QR codes can match your design.** Choose square, rounded or dot modules, square, rounded or
  circular corner eyes, and give the corners their own colour.
- **Put your logo in the middle.** Upload an image or paste a URL, set its size, and the code
  clears a space for it. Yappy warns when the logo is too big for the error-correction level.

## Features
- New QR properties: **Module Style** (Square / Rounded / Dots), **Corner Shape** (Square /
  Rounded / Circle), **Corner Color** (defaults to Stroke), **Logo**, **Logo Size** (10–35%).
- Rounded modules round a corner only where no neighbour touches it, so runs join into smooth
  shapes.
- Alignment patterns are drawn as solid rings in styled codes. Broken into dots, they stopped
  scanners from locking onto the grid, and no dot-style code decoded.
- The logo's cleared area never reaches a corner eye; on small codes the logo is capped.
- New warnings: logo too large for the error-correction level; corner colour with too little
  contrast or lighter than the background.
- **API:** `Yappy.setQrCodeLogo(id, url | null, size?)` (undoable, size clamped to 0.1–0.35);
  `createQrCode` options accept `qrModuleStyle`, `qrFinderStyle`, `qrFinderColor`, `qrLogo`,
  `qrLogoSize`.
- SVG export keeps every style as vectors, with the logo as the only `<image>`.

## Fixes
- **Image fills, custom pattern fills and video posters could export blank.** The export image
  preload read a field nothing sets (`fillImageUrl`), so a fill the canvas had not drawn yet
  (off-screen, on another page, or set by a script) exported as an empty shape.

## Internal / tests / docs
- Logo warning budgets (coverage of the data area: L 6%, M 9%, Q 14%, H 19%) calibrated by
  decoding 144 exported codes with jsQR across 2 data lengths, 4 levels, 6 logo sizes and 3
  module styles: 0 undecodable codes without a warning.
- `qr-code.test.ts` grows to 32 tests, including alignment-pattern centres checked against
  `uqr` output across versions 2–40 and "every arc follows a moveTo".
- `tests/qr-code.spec.ts` adds 5 tests (style parity across both drawing styles, vector SVG with
  logo, logo in a fresh export, `setQrCodeLogo`, property panel); new
  `tests/export-image-fill.spec.ts` for the export fix.
- Replaced a literal NUL byte in `qr-code.ts` with its escape; git had been treating the file as
  binary.
- Help → QR Codes: styles, logos, a logo-size guide per level, and known limitations.

## Breaking changes / migration
None. Existing QR codes keep their square look.
