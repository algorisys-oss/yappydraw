# 0.8.37 — Mind-map layouts (Miro-style) from the DSL (2026-07-09)

## Highlights
- New **mind-map layouts** you can drive straight from the DSL: a central-node,
  dual-side map plus top-down curved/straight variants — with **per-branch colour**,
  pill nodes, an emphasised centre, and curved branch links, all from a single
  `layout: mindmap-*` line.
- Bonus: **bezier & elbow connectors now export as real curves** in SVG (they used to
  flatten to straight lines) — fixes the whole app, not just mind-maps.

## Features
- **Three mind-map layout strategies:**
  - `mindmap-radial` — dual-side: the root's branches split left/right of a central node.
  - `mindmap-down-curved` — top-down tree with curved branch connectors.
  - `mindmap-down-straight` — top-down tree with straight connectors.
- **Automatic Miro-style theming** (no hand-styling needed): each top-level branch gets a
  distinct colour that its whole subtree — nodes *and* connecting links — inherits; the
  central node is emphasised; nodes render as rounded pills. Applied purely from the
  `layout: mindmap-*` value, so it stays the single source of truth.

  ```
  ---
  layout: mindmap-radial
  ---
  root [rect] "Product Plan"
    a [rect] "Research"
      a1 [rect] "Interviews"
    b [rect] "Design"
    c [rect] "Build"
    d [rect] "Launch"
  ```

## Fixes
- **Curved connectors exported straight.** `exportToSvg` drew every connector as a
  straight chord regardless of `curveType`; it now emits the real bezier/elbow path
  (`connectorCurvePath`), matching the on-canvas curve.

## Internal / tests / docs
