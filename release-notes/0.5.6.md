# 0.5.6 — Tap-version hard refresh (2026-06-28)

## Highlights
- Tap the **version** in the status bar to hard-refresh to the latest build —
  the "hard reload" iPad/iOS Safari doesn't otherwise offer.

## Features
- **Version-tap hard refresh** — the `v{version}` label in the status bar is now
  a button. Tapping it unregisters any service worker, clears all Cache Storage
  entries, and reloads with a cache-busting query param so iOS Safari refetches
  the app shell instead of serving a stale cached build. Workspace is untouched
  (it autosaves to IndexedDB); existing URL params are preserved.

## Internal / tests / docs
- New `frontend/src/utils/hard-refresh.ts`. Mirrors HappyPaint's version-tap
  intent, adapted: yappy ships no service worker, so this is a genuine
  cache-busting reload rather than a SW update check.
- Learnings updated.

## Notes
- A `?_hr=<timestamp>` param is appended on refresh (this is what busts the iOS
  document cache) and lingers in the address bar — harmless.

## Breaking changes / migration
- None.
