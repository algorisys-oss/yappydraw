# 0.5.1 — deleteSlide fix (2026-06-27)

## Highlights
- Fixed a real, user-facing bug where deleting a slide could silently do nothing.

## Fixes
- **`deleteSlide(index)` now actually deletes.** Deleting a non-active slide whose
  index sat below the active slide left the slide count unchanged. Cause:
  `setActiveSlide` (called inside `deleteSlide`'s `batch()` with the stale
  `activeSlideIndex`) saved the "leaving" slide via `setStore("slides", staleIndex, …)`
  with an out-of-range index, which re-extended the array and undid the delete.
  Now the save is bounds-checked. Verified by `tests/slides.spec.ts` (13/13);
  slide switching / duplicate / reorder unaffected.

## Internal / tests / docs
- Also fixed stale tests: `hotkeys` (laser = Shift+P), `bpmn` (pool default 600×300),
  `flare` (rays render as `path`). `docs/bugs/bug-fixes.md` updated.

## Breaking changes / migration
- None.
