# 0.8.29 — Type an exact value on quick-toolbar sliders (2026-07-09)

## Highlights
- The floating quick-properties toolbar's mini-sliders (Font Size, Opacity, …) are now **tap/click-to-type**: nudge with the slider, or tap the number to enter a precise value.

## Features
- **Editable mini-slider values.** In the quick toolbar, the value beside each mini-slider is now an inline number field — click/tap it to type an exact number. Enter applies, Esc cancels, the value clamps to the slider's range, and the whole edit is a single undo step. Applies to every mini-slider (Font Size, Opacity, and any others) since they share one component.

## Fixes
- None.

## Internal / tests / docs
- `MiniSliderControl` (`components/quick-toolbar.tsx`) swaps its read-only value `<span>` for a click-to-edit `<input type="number">`; history is snapshotted once on edit start (mirrors the track's `onMouseDown`).
- CSS: hover affordance on the value + compact number input with spin buttons hidden (`quick-toolbar.css`).
- Help: Smart-toolbar section of the Workspace help doc now documents tap-to-type.
- The full Properties panel already paired its `slider` type with a number input; this brings the quick toolbar to parity.
