# 0.5.27 — Letter Spacing for shape & connector labels (2026-07-03)

## Highlights
- The **Letter Spacing** property now works everywhere text does: shape labels
  and line/arrow (connector) labels, not just standalone text elements — with
  matching tracking in the in-place editor.

## Features
- **Letter Spacing on shapes**: the property (Text group, −5…40 px, 0.5 steps)
  is exposed for every text-capable shape — the same list as Font Size
  (rectangles, flowchart/UML/BPMN shapes, UI stencils, connectors, paths, …).
  `Yappy.createElement(type, x, y, w, h, { letterSpacing: 8 })` already passed
  the value through; now it renders.
- **Connector labels** (line/arrow) honour `letterSpacing`, and the label's
  readability background pill sizes around the widened text.
- Works identically in **both sketch and architectural** drawing styles, and
  SVG export emits a true `letter-spacing` attribute (already supported).

## Fixes
- Shape labels *measured* text with letter spacing (wrapping) but never drew
  with it — `RenderPipeline.renderText` now sets `renderer.letterSpacing`, so
  wrapping, highlight pills and painted glyphs agree.
- The in-place edit textarea never applied `letter-spacing` CSS, so editing
  looked tighter than the committed result — affected standalone text elements
  too. Now scaled by zoom for WYSIWYG.

## Internal / tests / docs
- Verified end-to-end with a Playwright run: painted label width grew exactly
  10 gaps × 8 px in both draw styles; edit-overlay computed style matches.
- Help doc (Illustrator tools → Letter spacing) updated to cover shape and
  connector labels; bug-fixes.md and learnings.md entries added.

## Breaking changes / migration
- None. Rich-text labels (per-span layout) still ignore element-level tracking —
  same pre-existing limitation as standalone rich text.
