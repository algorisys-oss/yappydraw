# 0.8.171 — The Node tool lands where you click, and the timeline works on an iPad (2026-08-03)

## Highlights
- **Path anchors were drawn — and hit-tested — 46px left and 52px above the path they belong to.**
  The Node tool's overlay spoke canvas-local coordinates onto a window-fixed layer, so you had to
  click 46px to the right of an anchor to grab it. Same bug the rulers and symmetry axes had in
  0.8.163; same cure.
- **F6 now hands you the copy, ready to drag.** Insert Keyframe duplicates the previous cel and
  leaves it selected with the Select tool armed — which is what the tutorial always said to do.
- **The animation timeline is usable on a tablet.** Touch and hold a frame for the menu that a
  right-click gives a mouse. Without it, an iPad had no route to Insert Keyframe at all.
- **A marquee no longer selects the onion-skin ghosts** of frames the playhead isn't on.

## Features
- **Node tool / Direct Selection has a shortcut and a command.** Press **N**, or find
  *Node Tool / Direct Selection* in the Command Palette. Illustrator calls it Direct Selection
  (the white arrow) and Inkscape calls it the Node tool; both names are in the command label so
  either search term finds it. `N` is Inkscape's key rather than Illustrator's `A`, because `A`
  is already the Arrow tool here. Pressing it with nothing selected says so rather than appearing
  to do nothing.
- **F6 (Insert Keyframe) switches to the Select tool and selects the duplicated cel**, from the
  key and from the timeline's right-click menu alike. F7 (blank keyframe) deliberately keeps your
  drawing tool, since a blank cel means you're about to draw. Adobe Animate doesn't switch tools
  on F6 either — but *its* default tool is Selection; Yappy's is the Ink Brush, so the same rule
  left you holding a brush with nothing selected.
- **Touch and hold a frame in the timeline** (500ms) to open the frame menu on a keyboard-less
  tablet: Insert Keyframe, Insert Blank Keyframe, motion/shape tweens, frame labels, frame
  actions, Clear Keyframe, Remove Frame. A hold that turns into a drag scrubs instead.
- **Documentation opens in a new tab.** The Help dialog gained a *Docs in new tab* button, and
  every page in the docs sidebar is a real link — Ctrl/⌘-click, middle-click, bookmark or copy it.

## Fixes
- **Node anchors drawn and hit-tested at the wrong place.** `.node-tool-layer` is
  `position: fixed`, i.e. window space, but positions came from `viewport-transforms`, which
  speaks canvas-local px. Every anchor sat at the dock offset from its path, and because
  `nodeAt()` compares `clientX/Y` against those same displaced points, the anchors could not be
  grabbed where they appeared. A rotated view was wrong too: the viewport cast left the rotation
  centre at 0, so it rotated about the canvas's top-left corner instead of its centre.
- **The Select tool's transform chrome was painted on top of the anchors.** Eight resize handles,
  the rotate grip, the quick-delete ⊗ and the quick-connect buttons all sit on the bounding box —
  exactly where a converted rectangle's corner anchors are. None of it was clickable (the node
  overlay swallows the pointer), so it was inert decoration burying live targets. The canvas also
  drew its own copy of every anchor on top of the overlay's. Node mode now draws the outline and
  nothing else, as Illustrator and Inkscape do.
- **A marquee or lasso selected things you couldn't see or touch.** Both area-selects swept every
  element with no filter, while click hit-testing correctly gated on interactability. In Animation
  mode that meant dragging a box grabbed *other frames' cels* — visible as ghosts with onion
  skinning on — and the selection bounds stretched across a pose the playhead wasn't on. Locked
  elements and elements on hidden layers leaked in the same way.
- **The animation timeline ran underneath a docked toolbar.** The panel was pinned to the window,
  so with the toolbar on the left (the default) the layer column and the start of the frame ruler
  sat behind the tool icons. It now offsets by the toolbar's own edge, on all four dock positions.
- **Timeline icons were too faint to find.** The `+` that adds a layer, and the eye/lock/delete
  icons on each row, were drawn in the secondary text colour — which clears AA as a colour pair
  but reads as barely-there at a 12px one-pixel stroke. The two *add* buttons now carry a standing
  affordance. The **♪ Audio** label was a genuine failure at **3.3:1** on the dark panel and gets a
  lighter amber; the delete-hover red was 3.76:1 on white and gets a deeper one.
- **The Node tool's hint lied.** It said "Alt-click a segment to add a node" even when the
  selection was a rectangle with no anchors at all. It now says what's actually true — that this
  isn't an editable path yet, and points at the Convert to Path button beside it.
- **Help searched for "ruler" found nothing.** Help search only matches a doc's name, description
  and keywords, and no doc carried the word.

## Internal / tests / docs
- `utils/overlay-transform` now owns the Node tool's world↔window mapping, alongside the rulers,
  symmetry axes and artboard frames it was written for.
- New `--toolbar-bottom` CSS variable, so bottom-anchored chrome can clear a bottom-docked
  toolbar the way the other three edges already could. The timeline's hardcoded `bottom: 28px`
  and its mobile `36px` twin are now one `calc()` over `--statusbar-h`.
- New specs, each verified to fail against the bug it guards:
  `selection-marquee.test.ts` (5), `node-tool-chrome.test.ts` (5), `anim-keyframe-select.test.ts`
  (7), plus a fifth case in `overlay-alignment.spec.ts` measuring node anchors in **two** dock
  layouts — reverting the fix reports "off by -46px" on a left dock and "-52px" on a right one, so
  a hardcoded offset cannot pass both.
- Note for future store-level tests: Bun shares one module registry across test files, so a test
  that leaves `docType: 'animation'` set breaks unrelated specs in `app-store.test.ts`. Restore
  the store in `afterAll`.
- Help docs: a full **Rulers & guides** section in Workspace (how to show them, pulling and
  deleting guides, Convert to Guides, and the two honest limitations — nothing snaps to guides,
  and guides are session-only), the **Node tool** documented with its gesture table in Vector
  Paths, and the F6/tablet behaviour in Animate. Search keywords added for both docs.

## Breaking changes / migration
- None. `Yappy.insertKeyframe()` is deliberately unchanged — it stays a pure timeline edit and
  never touches the user's tool or selection; the tool switch lives in the UI path only.
