# 0.8.28 — Stick-figure neck no longer draws inside the head (2026-07-09)

## Highlights
- Fixed a long-standing cosmetic glitch on **animated stick figures**: the neck line
  used to run all the way to the head's centre, leaving a visible stub inside the
  circle that read as a radius. It now stops cleanly at the head outline.

## Features
- None.

## Fixes
- **Animated stick figure — neck crossed into the head.** Every `stickRig` figure
  (on the canvas, in the clip-picker thumbnails, and when baked to SVG) drew the
  neck bone from the shoulder to the head-circle **centre**, so its last ~22px sat
  inside the head as a radius line. The neck now terminates at the head **outline**
  (the point along the shoulder→centre direction, `centre + unit(shoulder − centre)·headR`).
  Static library poses were already correct and are unchanged.

## Internal / tests / docs
- Added a shared `headAttach(pose)` helper in `library/stick-figures/anim/rig.ts`,
  used by BOTH render paths — `rigPoseToSvg` (thumbnails + bake) and
  `StickRigRenderer.computePose` (live canvas, `CHAINS[1]`). Audited all 58 static
  poses: 0 draw the neck inside the head. Learnings + `docs/bugs/bug-fixes.md` updated.

## Breaking changes / migration
- None.
