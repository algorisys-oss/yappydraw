# 0.8.254 — the npm package is @algorisys/yappydraw (2026-09-14)

## Highlights
- **The SDK's npm package is `@algorisys/yappydraw`**, in the same `algorisys` scope as
  [`@algorisys/tinyfly`](https://www.npmjs.com/package/@algorisys/tinyfly).

## Features
- **Help → Embedding** now mentions that tinyfly is on npm too.

## Fixes
- **The 0.8.253 docs named a package that does not exist.**
  - Symptom: Help → Embedding, the README and What's New said `npm install yappydraw`.
  - Cause: the SDK was renamed to `@algorisys/yappydraw` before its first npm publish, after
    0.8.253 had already shipped with the unscoped name.
  - Now: every install command, import, npm link and jsDelivr npm URL uses the scoped name.
  - Nothing was ever published as `yappydraw`.

## Internal / tests / docs
- `scripts/publish-npm.sh` publishes as `@algorisys/yappydraw`. The 0.8.253 package was published
  under that name.
- `docs/learnings.md`: the tinyfly vendoring learning notes that tinyfly has been on npm since
  0.64.0.

## Breaking changes / migration
- None. The unscoped name was never published.
