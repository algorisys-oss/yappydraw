# 0.8.74 — Turntable: rotate 2D vector art in pseudo-3D (2026-07-12)

## Highlights
- **New Turntable effect** — spin a flat vector shape around as if it were a 3D object
  (Adobe *Project Turntable* idea), and at every angle it stays a **clean, editable path**.
  Non-destructive, re-editable, and renders in both **Sketch** and **Architectural** styles.
  This is Phase 1 (deterministic, no AI): a real, demoable feature for simple/symmetric art.

## Features
- **Turntable (3D Spin)** — a new live effect in the property panel (**TURNTABLE (3D SPIN)**,
  right after 3D Extrude). *+ Add Turntable* (a non-path shape is auto-converted to a path),
  then drag:
  - **Yaw** — spin about the vertical axis (−180…180°).
  - **Pitch** — tilt forward/back.
  - **Depth** — bulge strength for the rounded look.
  - **Persp** — 0 = orthographic (tidy anchors) … up = perspective distortion.
  - **Volume** model — *Flat* (pure foreshorten, always correct) or *Symmetry* (a
    cylinder-like bulge inferred from the vertical mirror axis, so a turned figure/logo reads
    as solid).
  - **Bake** — freeze the current angle into a real editable path (single undo). **Remove**
    restores the flat shape.
- **Scripting API** — `Yappy.turntable({ yaw, pitch, depthModel, depthScale, perspective })`,
  `Yappy.bakeTurntable()`, `Yappy.clearTurntable()`.

## Fixes
- **`pathSubpaths` was silently dropped on document normalize** — `migration.ts` is a
  hand-written field passthrough with no catch-all, and multi-subpath paths (holes / disjoint
  islands) were lost on a migrate round-trip. Now preserved.

## Internal / test changes
- `types.ts`: new `Turntable` interface + optional `turntable?` field on `DrawingElement`.
- `utils/turntable.ts` (new): `applyTurntable(el) → PathSubpath[]` — per-anchor depth
  (`flat`/`symmetry`), yaw→pitch rotation, orthographic/perspective projection, bézier-handle
  aware, subpath z-order sort. Isolated from `geometry.ts`, so no WASM changes needed.
- `utils/shape-geometry.ts`: `case 'path'` uses `applyTurntable(el) ?? getPathSubpaths(el)`,
  so live render, both draw styles, and SVG export inherit the rotation for free.
- `store/app-store.ts`: `setTurntable` / `clearTurntable` / `bakeTurntable` (mirror the live
  Extrude pattern; auto-convert to path on add; Bake replaces in place with a single undo).
- `components/property-panel.tsx`: `TurntableEditor` (mirrors `ExtrudeEditor`).
- `api.ts`, `utils/migration.ts`, `help-docs/features/effects-doc.tsx`, `docs/learnings.md`,
  `docs/turntable-plan.md` updated.

## Breaking changes / migration
- None. The `turntable` field is optional and fully back-compatible; the `pathSubpaths`
  migration fix only *preserves* data that was previously being dropped.
