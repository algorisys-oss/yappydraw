# 0.8.298 — Data charts, to and from PowerPoint (2026-11-01)

## Highlights
- **Data charts with a data grid, round-tripped as real PowerPoint charts** — item 8 of the
  DeckCraft-based slides backlog (`docs/slides-feature-gaps.md`).

## Features
- **Data chart** (`chart` element): Column, Bar, Line, Area, Pie, Doughnut; Stacked, Data labels,
  Legend (Bottom/Right/Top/None), Gridlines, value-axis range. Draws clean in Architectural and
  hachured in Sketch, and goes into every export.
- **Chart data window**: categories × series grid; type `1,250` or `12%`; a blank cell is a gap;
  a block pasted from Excel, Google Sheets or Numbers fills right and down and grows the grid.
  The whole session is one undo step. Opens on insert and on double-click.
- Insert from the **Data/Metrics** tools (**Data chart**) or the command palette (**Insert data
  chart**).
- **PowerPoint export** writes a real chart (`c:chartSpace`) with an embedded workbook, so Edit
  Data works in PowerPoint.
- **PowerPoint import** turns column/bar/line/area/pie/doughnut charts (3-D ones drawn flat) into
  data charts, with their data, colours (the chart's own theme override), title, legend, labels,
  gridlines and axis range. Scatter, radar, stock, bubble and the 2016 chart types keep the
  labelled frame.
- API: `insertChart(spec?, box?)`, `getChart(id)`, `updateChart(id, spec)`, `openChartData(id)`.
