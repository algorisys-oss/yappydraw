# 0.8.262 — CDN SDK loads again (2026-09-25)

0.8.261 was tagged in this repo but never published: the open-source publish refused it because
the CDN SDK threw while loading. 0.8.262 is the first published release carrying 0.8.261's
features (Doodles, the working sketch render cache). See `0.8.261.md` for those.

## Fixes
- **#399** The CDN SDK threw `ReferenceError: Cannot access 'v3' before initialization` on load,
  so `yappy.js` exported nothing. The Doodle dialog read its default palette from `api.ts` while
  its own module was loading, and `api.ts` is in an import cycle with the menus that load the
  dialog, so in the SDK bundle the dialog ran first.

## Internal / tests / docs
- `DEFAULT_DOODLE_PALETTE` moved to `utils/doodles`, which imports nothing from the app.
- Caught by `scripts/verify-sdk.mjs` (runs on every OSS publish); reproduced locally with
  `npm run build:sdk && node scripts/verify-sdk.mjs dist-sdk` before and after the fix.

## Breaking changes / migration
- None.
