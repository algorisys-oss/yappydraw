# 0.8.281 — Artboards: resize to selection, aspect lock, and buttons that keep their colour (2026-10-10)

## Highlights
- **Resize Artboard to Selection (Ctrl+Shift+R).** The artboard snaps exactly onto the selection, as Inkscape's "resize page to selection" does. A 1280 circle gives a 1280 × 1280 artboard.
- **Aspect-ratio lock in the New Artboard dialog.** Type one side and the other follows.
- **Fixed:** coloured buttons (such as Create in the New Artboard dialog) turned near-white when hovered or clicked.

## Features
- `fitArtboardToSelection(id?, pad = 0)`: Ctrl+Shift+R, command palette, right-click → Create. It resizes the artboard under the selection, or the active one, to the selection's visual bounds, with stroke and rotation included so nothing is clipped on export. With nothing selected it fits the artboard's own artwork; with no artboard it creates one. One undo step. Ctrl+Shift+R is only taken while there is a selection or an artboard; otherwise it stays the browser's hard reload.
- New Artboard dialog: a lock button beside ⇄. The ratio is captured when the lock goes on, so typed sizes don't drift. Swap inverts it, and picking a preset while locked uses that preset's ratio.

## Fixes
- **#435** Global `button:hover` / `button:active` (specificity 0,1,1) outranked single-class button styles, so every accent button went near-white on hover and press (29 classes affected). The defaults are now wrapped in `:where()`.
- **#436** Artboard from Selection added 20px on every side (a 1280 circle got a 1320 frame) and ignored stroke and rotation. It is now tight and uses visual bounds. The palette's Fit to Artwork is tight too.

## Internal / tests / docs
- `elementsBounds` moved from `utils/export.ts` to the new `utils/element-bounds.ts`, so the store can use it without an import cycle. `export.ts` re-exports it.
- `utils/aspect-lock.ts` (`followLockedSide`), with unit tests.
- `tests/artboard-fit-selection.spec.ts` (6 tests). The button-state test forces `:hover`/`:active` over CDP, because a synthetic `mouse.down()` doesn't set `:active` in headless Chromium. The `next-batch.spec.ts` fit test uses stroke 0.
- Artboards help doc: new "Resize an artboard to the selection" section, aspect lock, API table. Hotkey list: Ctrl+Shift+R.

## Breaking changes / migration
- Artboard from Selection (`addArtboard('selection')`) no longer adds a 20px margin. `Yappy.fitArtboardToArtwork` keeps its `pad = 20` default; only the palette action became tight.
- Fit to Artwork now measures visual bounds (stroke included), so a stroked shape gives a frame larger by half the stroke width on each side.
