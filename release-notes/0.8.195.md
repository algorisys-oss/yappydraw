# 0.8.195 — a mandala generator (2026-08-15)

## Highlights
- **Mandala generator.** A whole design from parameters, with a live outline preview on the
  canvas: pick a preset, set the size, and Apply. Five presets ship — Simple 8, Lotus 12,
  Lace 24, Star 16, Rosette 6 — and *Edit bands* opens the design up band by band.
- **It undoes in one step.** However many shapes a mandala contains, one undo removes it. That
  required fixing something worse than it sounds — see below.
- **Generated and hand-drawn work agree.** Every motif is mirror-symmetric about its own spoke,
  the same property Kaleidoscope symmetry (0.8.193) gives hand-drawn strokes, and *Arm symmetry
  after* points Kaleidoscope at the new mandala's centre and spoke count so you can carry on by
  hand immediately.

## Features
- **Mandala…** in Vector Tools → Insert, right-click → Insert, and the Command Palette
  ("Mandala Generator"). Presets, *Size*, *Line weight*, *Arm symmetry after*, and a shape
  count so a design that will produce 300 elements says so before you commit.
- **Bands.** A mandala is concentric bands, each repeating one motif. Per band: motif, copies,
  inner/outer radius, rotation against its neighbours, and how fat the motif sits in its wedge.
  Add and remove bands freely.
- **Nine motifs**: Petal, Lotus, Teardrop, Diamond, Dot, Arc, Scallop, Spike, and a plain Ring
  divider.
- Output is **ordinary grouped paths** in your current drawing style, whole design selected,
  no fill and a 2px black stroke by default — colouring-page defaults, editable with every
  normal tool including the Node tool.
- **Kaleidoscope symmetry now has a Command Palette entry** ("Symmetry: Kaleidoscope"), which
  was missed when the mode shipped in 0.8.193.

## Fixes
- **Bulk element creation destroyed undo history.** `addElement` snapshots before every single
  element, so a 122-path mandala pushed 122 entries. Undoing it needed 123 presses — and since
  the stack is 50 deep, the entries that could have removed it were pushed off the front,
  making the mandala **impossible to undo and taking every earlier state with it**. New
  `withoutHistory(fn)` in the store suspends snapshots for a bulk edit (a nesting-safe counter
  with a `finally`, not a flag); `createMandala` pushes exactly one snapshot and wraps the rest.
  Verified: the 122-path preset now grows history by exactly 1 entry and undoes in one press,
  with prior artwork intact and redo restoring it.
- **The generator centred its output on the window, not the canvas.** With the toolbar and
  Properties panel taking their space that is ~127px off, putting the design's edge under the
  panel. The dialog now converts through `windowToWorld(canvasOrigin + canvasSize/2)`.

## API
- `createMandala(cx, cy, { preset?, rings?, radius?, armSymmetry? }, options?)` — returns the
  group id, or null for a spec that produces nothing.
- `mandalaPresets`, `mandalaMotifs` — the built-in designs and the motif vocabulary.
- `withoutHistory(fn)` in the store, for any future bulk generator with the same need.

## Docs
- Logo & Design Toolkit help page: a "Mandala generator" section covering presets, bands, the
  motif list, undo behaviour, arming symmetry, API snippets, and the preview's one honest
  limitation. The existing hand-drawing walkthrough now says explicitly that it is the by-hand
  route.
- Help search keywords for "mandala generator", the preset names, and the motif names.
- `docs/learnings.md`: why a bulk generator needs one undo and how the suspend counter works;
  why motifs are built in a canonical frame and rotated; and why `window.innerWidth / 2` is
  not the middle of the canvas.

## Tests
- `frontend/src/utils/mandala.test.ts` — 11 cases, written first and seen to fail. The load-
  bearing ones: **every motif in the vocabulary is bilaterally symmetric about its spoke**, and
  every point of a band stays inside its radial `[rInner, rOuter]` range so bands never bleed
  into each other. Plus preset sanity (no NaN, no radially overlapping bands).
- `tests/mandala-generator.spec.ts` — 7 cases: the preview writes **no elements and no undo
  entries**, preset switching, Cancel and Escape leaving nothing, Apply committing exactly the
  previewed count as one selected group in the current style, one-step undo/redo of the
  122-path preset, centring on the canvas (asserting the canvas and window centres actually
  differ, so the test can fail), and armSymmetry landing on the mandala's centre.
- Full suite: 563 unit tests, plus the history-panel and boolean-ops suites re-run because
  `withoutHistory` touches shared undo code. All pass.

## Known limitations
- The preview is an outline overlay, so in **sketch** render style the committed mandala gains
  rough.js wobble the preview doesn't show. Layout, counts and radii are exact. Stated in the
  dialog and the help page.
- A generated mandala is **baked**, not a re-editable parametric object: reopening the dialog
  starts a new design rather than editing the one on the canvas. Iterating in the preview
  before Apply covers most of the need; a live mandala object (like compound shapes) is the
  natural next step.
- Not fixed, reported: `center()` in `vector-tools-panel.tsx` has the same window-vs-canvas
  frame bug, so Spiral, Arc, Rectangular Grid, Polar Grid and Lens Flare all insert slightly
  off-centre. Left alone to keep this change scoped.
