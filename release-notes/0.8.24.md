# 0.8.24 — Scene Timeline for stick-figure animation (2026-07-08)

## Highlights
- A **Scene Timeline** to direct a whole animated scene: **play, pause and scrub**
  every stick figure together on one shared clock.

## Features
- **Scene Timeline** — click **Scene timeline** in the Stick Figures panel to open a
  timeline across the bottom of the screen. Each animated figure is a **track**, with
  its action sequence drawn as coloured blocks along a time ruler.
  - **Play / Pause / Restart** and a **Loop** toggle drive all figures from one clock.
  - **Scrub** — drag the red playhead (or click the ruler) to jump to any moment; every
    figure (including walk-along-a-path) poses at that instant.
  - Click a track's label to select that figure on the canvas.
  - Scene length is set automatically by the longest figure.
- **API** — `toggleSceneTimeline(true)`, `playScene(playing?)`, `seekScene(seconds)`.

## Internal / tests / docs
- New `scene-timeline.tsx` + store playhead state (`storyTime/storyPlaying/storyLoop/
  storyDuration`). The stickRig renderer reads `storyTime` when the timeline is open
  (scrubbable) and free-runs otherwise; a controller effect advances the playhead from
  the animation clock. Help doc gains a "Direct the whole scene" section; learnings
  recorded.
