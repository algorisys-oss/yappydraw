# 0.8.48 — Live 3D Extrude + Blend-along-spine + Warp-preset editor (Illustrator parity, round 2) (2026-07-10)

## Highlights
- **Live 3D Extrude** brings real depth (and 3D tilt) to any shape — the classic "3D text" look,
  non-destructive and re-editable, with **Expand to Faces** for editable/exportable geometry.
- **Blend along a spine** distributes interpolated copies of two shapes along a path.
- **Warp presets** gain a proper property-panel editor with a live bend slider.

## Features
- **3D Extrude** (`el.extrude`) — Illustrator's *Effect ▸ 3D ▸ Extrude & Bevel*. Draws a shaded back
  face + side walls behind the shape at render time; both render styles; re-editable.
  - Property panel **3D EXTRUDE**: Depth / Angle / **Tilt X / Tilt Y** (3D perspective) / Shade sliders,
    plus **Expand** & **Remove**. Context menu **Repeat & Mirror ▸ 3D Extrude** (Extrude / Deep / Tilted).
  - **Expand to Faces** (`expandExtrude`) bakes the 3D into grouped editable path faces (front / side /
    back) — which also makes it SVG-exportable.
  - **API:** `Yappy.setExtrude({ depth, angle, rotX, rotY, shade })`, `Yappy.expandExtrude()`, `Yappy.clearExtrude()`.
  - *Note:* extrude works on a shape's outline; a text element's outline is its bounding box, so for 3D
    **letters** run **Convert to Outlines** first.
- **Blend along a spine** (`blendAlongPath`) — select two shapes + a path/line → distribute N interpolated
  copies along the path (arc-length), auto-oriented to the tangent, blending size/colour/opacity/stroke.
  Context menu **Blend Along Spine**; **API** `Yappy.blendAlongPath(steps, orient)`.
- **Warp-preset property-panel editor** — a **WARP PRESET** section (style dropdown + live **Bend** slider
  + Bake/Remove) for elements warped with Arc/Arch/Flag/Wave/Rise/Bulge (was context-menu-only, fixed bend).

## Fixes
- **Numeric property inputs snapped to their minimum when cleared** (font size jumped to 8, others to 0)
  because `onInput` committed `Number('') = 0` on every keystroke. The field now stays editable while you
  clear/retype and resyncs on blur.

## Internal / tests / docs
- New `utils/extrude.ts` (world-outline body render + `extrudeGeometry`/`expandExtrude`); render hook in
  `canvas-renderer.ts`. `blendAlongPath` reuses the `path-follow` arc-length sampler.
- Migration passthrough for `extrude`. Web help docs updated (`effects-doc`, `workspace-doc`).
- Parity plan (`docs/illustrator-text-effects-parity.md`) updated — Phases 1–4 now have shipped cores
  (~15–16 of 18 tutorials achievable). Verified in-app via Playwright + screenshots.

## Breaking changes / migration
- None. All new fields are optional and back-compatible.
