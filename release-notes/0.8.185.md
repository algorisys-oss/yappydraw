# 0.8.185 — Designer review: flip, the pen, type and corners (2026-08-09)

## Highlights

- **Flip finally takes the anchors with it.** Flipping a pen path mirrored the shape but left
  its anchor points on the un-mirrored ghost, so the handles you could see and grab were no
  longer on the curve. Mirror Copy had the same defect, and curved connectors' control points
  didn't move at all.
- **Shift draws straight lines with the Pen.** Between clicks it now constrains the segment to
  15° — exact horizontals, verticals and diagonals. It had only ever constrained the Bézier
  handles.
- **Moving an anchor on a rotated shape no longer drags the rest of the shape with it.**
- **Type gets the two controls it was missing**: line spacing, and per-word font size inside a
  single text box.
- **Rectangles get four independent corners.**

## Features

- **Line spacing (leading).** A **Line Spacing** field in the Text group, next to Letter
  Spacing — a multiple of the font size like CSS `line-height` (1.2 default, 1 solid, 2 double)
  so it stays proportional when you resize. Applies to text elements, shape labels and rich
  text, and follows through wrapping, auto-height, in-place editing and SVG/PNG/PDF export.
  `Yappy.createElement(type, x, y, w, h, { lineHeight: 1.6 })`.
- **Different font sizes in one text box.** Select some words in a rich-text element and pick a
  size from the new **A<sub>A</sub>** button — one word of a headline at 72 while the rest stay
  32, in a single object. *Default* returns the selection to the element's own size.
- **Independent corner radii.** Four per-corner sliders (**Corner ↖ ↗ ↘ ↙**) under Roundness.
  A corner you don't touch follows Roundness, so setting one doesn't square the rest; an
  explicit `0` makes it sharp. Percent of the shorter side, like Roundness, so corners keep
  their proportions on resize. It's the real outline: fills, gradients and image clipping
  follow it, both draw styles render it, SVG writes one arc per rounded corner, and Convert to
  Path / Knife / Warp keep it. `{ radiusTL: 40, radiusBR: 40 }`.
- **Rename groups.** Double-click a group row in the object tree and give it a real name
  instead of *Group (4)*. Nested groups are named independently. The name travels with the
  artwork through save, undo, duplication and copy-paste.
  `Yappy.setGroupName(gid, 'Front panel')` / `Yappy.getGroupName(gid)`.
- **Eyedropper shortcut: `Shift`+`I`.** Illustrator's plain `I` inserts an image here, so it
  joins the Shift+letter block with Shape Builder, Width and Blob Brush. Press again to cancel.
- **Pen: `Shift` between clicks constrains the segment to 15°** — the same increment the Line
  and Arrow tools use, and it overrides Snap to Grid for that click. The rubber-band preview
  shows where the point will land, and clicking the first anchor still closes the path. The
  tablet **90°/45°** toggle and second-finger contact drive it too.

## Fixes

- **Flip left the anchors behind.** `flipSelected` mirrored point-based elements but sent every
  vector path through the `flipX` render flag — a canvas transform the anchor overlay and
  anchor hit-test know nothing about. The mirror is now baked into the stored geometry, world-
  space control points reflect about the axis, and the flag is kept only for shapes with no
  geometry to bake. Paths mirrored by the old code **heal themselves** on the next flip.
- **Moving an anchor on a rotated path moved the whole shape.** Re-normalizing a path's bbox
  moves the element's centre, and a rotated element is drawn about that centre, so every
  untouched anchor drifted — 15.6px at 30°, 23.2px at 45°, and exactly zero at 0°, which is why
  it hid for so long.
- **Cutting a rounded rectangle squared it off.** The shape→path conversion never read the
  corner radius, which affected Knife, Scissors, Warp, Pathfinder and Convert to Path alike.
- **Undo after dragging the warp Bend slider did nothing.** The history snapshot was taken at
  the *end* of the drag, so it captured the value you'd just dragged to.
- **Ungroup → regroup resurrected a name you'd just discarded.** Group ids are recycled, so a
  leftover name re-attached itself to a brand-new group.
- **Legacy documents lost letter spacing and every rich-text run.** `letterSpacing`, `richText`
  and `richContainerText` were missing from the element whitelist used when opening
  pre-slide-format drawings. Current documents were never affected.

## Internal / tests / docs

- New single-owner helpers where several code paths had been duplicating a rule:
  `geometry-mirror` (flip), `rotated-bbox` (bbox re-normalization under rotation),
  `text-line-height` (leading, previously written out at eleven sites) and `corner-radius`.
- 599 unit tests (up from 524), including a pen-constraint suite A/B-verified against the
  unfixed code. Every fix was additionally checked against the running app by sampling the
  rendered canvas rather than the model.
- Help docs updated for flip/anchors, the pen's two Shift behaviours, the warp Bend slider
  (which already existed and was simply undiscoverable — the toast now points at it), group
  renaming, per-word size, line spacing, per-corner radii and the eyedropper shortcut.
- `docs/bugs/bug-fixes.md` #281–292; five new entries in `docs/learnings.md`.

## Known / awaiting a repro

Two reported items could not be reproduced and are logged in `todo.md` rather than guessed at,
because the plausible fix for each would change existing artwork:

- **"Fill behaves like a stroke on certain shapes"** — 31 shape types swept, all fill correctly.
  Needs the name of one affected shape.
- **"Vertical alignment behaves opposite to its labels"** — measured correct (12% / 49% / 86%).
  There is a real inconsistency behind it (the vertical-text path defaults to `top`, everything
  else to `middle`), but changing that default would move existing vertical text.

## Breaking changes / migration

None. All new fields are optional and absent means the previous behaviour: `lineHeight` defaults
to the 1.2 that was hardcoded before, and an unset corner radius follows `borderRadius`.
