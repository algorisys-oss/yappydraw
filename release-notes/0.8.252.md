# 0.8.252 — tinyfly animations in Yappy documents (2026-09-14)

## Highlights
- **Play tinyfly animations on your shapes.** Export a timeline from the
  [tinyfly](https://github.com/algorisys-oss/tinyfly) editor (**More → Export JSON**), then choose
  **Menu → File → Import tinyfly animation…** in Yappy.
- **It behaves like Yappy's own keyframes.** The animation plays on the Scene Timeline, saves
  with the document, undoes, and appears in MP4, WebM and GIF exports.
- **tinyfly features keep working.** Springs, staggers and motion paths are intact, because
  Yappy runs tinyfly's own engine on the animation.

## Features
- **Target matching.** Each tinyfly target is matched to a shape by id, then by name, then to the
  selected shapes in order. A message reports what matched, what did not, and which properties
  were ignored. If nothing matches, nothing is added.
- **Values keep tinyfly's meaning.**
  - `x`/`y` and motion paths move the shape from where it sits.
  - `rotate` adds degrees.
  - `scale`/`scaleX`/`scaleY` scale about the centre.
  - `opacity` is 0–1.
  - `fill`, `stroke`, `strokeWidth`, `width`, `height`, `blur` and `text` are applied too.
- **Works with parenting.** A shape parented to a tinyfly-animated shape follows it. Both render
  styles work.
- **Scene Timeline row.** Each animation gets a row; click its name to select the shapes it drives.
- **API:**
  - `Yappy.tinyfly.add(json, { bind?, start?, name?, requireMatch? })` returns
    `{ id, bound, unbound, unsupported, duration }`.
  - Also `list()`, `update(id, patch)`, `remove(id)`, `toJSON(id)`, `ready()`.
  - `bake(id, fps?)` replaces the animation with editable keyframes.
- **Translations.** The menu item and messages are in English, German, Spanish, French and
  Japanese.

## Fixes
- **Video and GIF exports could start mid-animation.**
  - Cause: export frames evaluated keyframes on the app's animation clock, which keeps the time
    accumulated by any earlier animation in the session.
  - Symptom: after anything had animated, the export began part-way through the scene. Most
    scenes run a few seconds, so the export showed only the final pose.
  - Now: keyframes and tinyfly animations start at t = 0.
- **The Scene Timeline had nothing to scrub for a keyframe-only scene.**
  - Symptom: without stick figures, it showed the "Add animated figures" message and no ruler or
    playhead.
  - Impact: **Menu → Panels → Scene Timeline**, added in 0.8.251, could not play the scenes it was
    added for.
- **Documentation:** the SDK doc comment said `tinyfly.live.to`; the call is `tinyfly.to`.

## Internal / tests / docs
- **Vendored engine.** `frontend/src/vendor/tinyfly/` holds the tinyfly engine v0.61.0 (MIT, with
  its licence and version), built from the public tag by `scripts/vendor-tinyfly.sh <tag>`.
  - It loads as a lazy 37 KB chunk only when a document has tinyfly animations. The boot
    bundle grew by 9 KB of Yappy code.
  - The chunk is precached, so such documents play offline.
- **Evaluator.** `utils/animation/tinyfly-clips.ts` (local time with loop/alternate/repeatDelay/speed,
  value conversion, binding resolution, baking).
- **Wiring.** `applyCompositionOverrides` and `resolveParentedPoses` take the clip overrides as an
  optional `extra` map, merged before parenting.
- **Document field.** New `tinyflyClips`, persisted in save, autosave, `loadDocument` and undo.
- **Tests.**
  - `tinyfly-clips.test.ts`: 20 bun tests.
  - `tests/tinyfly-clips.spec.ts`: 7 tests covering evaluation, canvas in sketch and
    architectural, parenting, springs, save/load, undo, bake, menu import and rejection.
  - `tests/export-animation-start.spec.ts`.
  - A keyframe-only case added to `tests/scene-timeline-menu.spec.ts`.
- **Checked by hand.** Exported the "Bouncing Ball" sample from the tinyfly editor and imported
  the file into Yappy: the drop, squash and bounce matched tinyfly's timing.

## Breaking changes / migration
None.

**Known limits:**
- The HTML player export does not include tinyfly animations. It already omitted keyframes.
- A tinyfly Animation Document (with its own elements) is refused; export the timeline JSON
  instead.
- Moving an animation's start time is API-only for now.
