# 0.8.124 — My Templates get previews too

**Date:** 2026-07-20

## Fixes

- **Templates you saved yourself showed a blank placeholder icon.** "Save Current as
  Template" only captured a thumbnail for page-based documents (designs and
  presentations), so anything saved from an ordinary drawing had no preview — and that's
  the most common way to save one.

  Saved templates now always get a preview, and templates you saved *before* this
  release get one too, without needing to re-save them.

## Internal / test changes

- `templatePreviewSvg` gained an optional pixel size, and a `templatePreviewDataUrl`
  wrapper for the places a thumbnail is stored as a string and rendered via `<img src>`
  (a percentage-sized SVG has no intrinsic dimensions and won't scale there).

## Breaking changes / migration

None.
