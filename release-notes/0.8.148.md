# 0.8.148 — The Beta badge was failing WCAG AA, and the audit couldn't see it (2026-07-28)

## Highlights
- The **Beta badge** on the wordmark had white text on a gradient measuring **3.53:1** at its lightest stop — well under the 4.5:1 that 8px text requires. Fixed.
- The contrast audit that should have caught it was **blind to gradients**, and had been quietly reporting a nonsense failure instead. It now scores text against every gradient stop, worst-case.

## Fixes
- **Beta badge contrast (real accessibility bug).** The gradient used the 500-level stops `#6366f1 / #a855f7 / #ec4899`, which give white text **4.47 / 3.96 / 3.53:1** — every one below AA for text this size, and the source comment claiming "4.6:1 against the lighter end" was measuring the wrong end. Moved one shade deeper to `#4f46e5 / #9333ea / #db2777`: **6.29 / 5.38 / 4.60:1**, all clearing 4.5, with the indigo→purple→pink identity unchanged.
- **The contrast audit ignored gradient backdrops.** An element painted with `background: linear-gradient(...)` has a *transparent* computed `backgroundColor`, so the backdrop walk sailed straight past it to the nearest solid ancestor — reporting the badge as white-on-white, 1:1, in every surface it visited. The probe now extracts the gradient's colour stops and scores the text against the **worst** one, since text has to stay readable everywhere the gradient lands. Strictly stronger than before: the whole-app sweep passes with the tighter rule, so nothing else was hiding behind it.
- **`contrast.spec.ts`, `ui-panels.spec.ts` and `hotkeys.spec.ts` targeted a hardcoded `localhost:5173`** instead of the configured `baseURL`, so they audited whatever else happened to be on that port.

## Internal / tests / docs
- Repaired the remaining specs left over from the dockable-panel refactor, each against verified live behaviour rather than assumption:
  - **Layers panel** is dock-hosted → `isPanelOpen('layers')`, not the dead `state.showLayerPanel`. (The Property panel's flag *is* still live, so it stays as-is — the two had to be checked separately.)
  - **Minimap** state is `state.minimapVisible`, not `showMinimap`.
  - **Canvas background** is `state.canvasBackgroundColor`, not `canvasBackground`.
  - **Theme cycle** is light → dark → system (three steps); the spec still assumed a four-step cycle including `focus`.
  - **Zen mode** deliberately does *not* clear panel flags — it gates rendering on `store.zenMode` so leaving zen restores your layout exactly. The test asserted on flags that were never meant to flip; it now asserts on what's actually rendered.
  - **`Alt+\` / `Alt+Enter`** set up state by assigning into `window.Yappy.state`, which is a Solid store proxy — the writes silently did nothing. They now drive the real APIs.
- New API: `Yappy.setShowCanvasProperties(visible)` (existed in the store, was never exposed).

## Breaking changes / migration
- None. The badge gradient is a visual refinement; the API addition is additive.
