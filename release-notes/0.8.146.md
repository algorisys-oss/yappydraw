# 0.8.146 — Texture overlays, Simplify on anything, cross-document asset library (2026-07-28)

## Highlights
- **Procedural grain**: two new texture motifs (`noise`, `grunge`) plus a one-click full-composition **Texture Overlay** — the "lay a grungy texture over the art at low opacity" move, without hunting for a texture.
- **Simplify works on what you actually drew**: `Ctrl+L`, and it converts a pencil stroke or a shape to a path first — as a single undo step.
- **An asset library that outlives the document**: save a tree once, drop it into every future project.
- Along the way: **SVG arcs are finally parsed**, which quietly restores Convert to Path / Simplify / Offset for nine shapes that never had them.

## Features
- **Noise & Grunge pattern fills** — two procedural motifs alongside stripes/grid/dots/checker/crosshatch. `noise` is per-cell film grain; `grunge` is 3-octave value noise (fBm) thresholded into soft blotches. Both are seeded from a stored `PatternFill.seed`, so a texture renders identically on every redraw, reload and export — no shimmer during animation, and the SVG export matches the canvas. Available on any shape, in both Sketch and Architectural styles, exporting as a real `<pattern>`. API: `Yappy.applyPatternFill('noise' | 'grunge')`, `Yappy.setPatternFill({ seed, strokeWidth })`.
- **Texture Overlay (one click)** — **Vector Tools → Insert → Noise Texture / Grunge Texture** drops a rectangle covering the active artboard (else the page, else the artwork's bounding box), pre-set to `multiply` blend at 14% opacity and no stroke. API: `Yappy.addTextureOverlay(kind?, { opacity, color, scale })`.
- **Pattern editor, texture-aware** — for the two texture motifs the meaningless *Spacing* slider is hidden, *Thick* is relabelled **Grain**, and a **Randomize** button re-rolls the seed.
- **Simplify / Smooth auto-convert** — both now accept anything convertible (pencil/fineliner strokes, stars, hexagons…) and convert it to an editable path as part of the same operation, so one `Ctrl+Z` undoes the whole thing. New hotkey **`Ctrl+L`** for Simplify (guarded so `Ctrl+Shift+L` lock/unlock still wins); both remain in the right-click **Path** submenu, now offered for convertible shapes too.
- **Asset library (cross-document)** — a new section at the bottom of the Symbols panel, backed by IndexedDB (`storage/asset-library.ts`, index/body split like the drawings gallery, so listing never loads bodies). Save the selection, then insert it in *any* document. Assets are detached snapshots, not instances: they arrive as ordinary elements with fresh ids and no link back, which is what you want for scenery you intend to vary — use a symbol when every copy should update together. API: `Yappy.saveToAssetLibrary(name?, ids?)`, `listAssets()`, `insertAsset(id)`, `renameAsset(id, name)`, `deleteAsset(id)`.
- **Transform HUD is see-through** — the size/position badge under a selection anchors right on top of the quick-connect handle, so it now uses a near-transparent fill with a subtle accent border and accent-coloured text (instead of a solid accent chip with white text). Content behind it stays visible; outer size unchanged.
- **New API accessors** — `Yappy.getElements()` (all elements in z-order), `Yappy.isPanelOpen(id)` (real dock-backed panel visibility), `Yappy.toggleVectorToolsPanel(visible?)`.

## Fixes
- **SVG arc (`A`) commands were silently dropped by `PathUtils.parsePath`** — there was no `A` case, and the arc's seven arguments weren't consumed either. Nine shapes (cloud, database, lightbulb, magnet, magnifyingGlass, pin, puzzlePiece, storageBlob, umlRequiredInterface) parsed to an *empty* command list, which reads as "this shape has no outline" — so Convert to Path was never offered for them and Simplify / Smooth / Offset Path / text-on-path did nothing. Arcs are now flattened into ≤90° cubic segments (SVG spec F.6.5/F.6.6), emitted as ordinary `C` commands so every downstream consumer works unchanged.
- **Dead panel-visibility flags reported `false` forever** — `showSymbolsPanel`, `showRecolorPanel` and `showBehaviorsPanel` were orphaned by the dockable-panel refactor; nothing had written them since. They're annotated as dead at their initializers, and `Yappy.isPanelOpen(id)` is the accessor that actually answers.

## Internal / tests / docs
- New e2e `tests/upa-texture-simplify-library.spec.ts` (12 tests): texture overlay defaults and z-order, noise/grunge surviving SVG export as real `<pattern>` defs, Simplify auto-convert **as a single undo step**, arc-shape conversion across eight arc-based shapes, and the asset library surviving `Y.clear()` *and* a full page reload.
- Fixed four specs that had been failing on `dev` before this work, all test drift rather than product bugs: `symbols-panel` (queried the dead flag; looked for a `.symbols-panel` wrapper the dock no longer renders — it's `.symbols-panel-body`), `vector-tools-panel` ×2 (opened the palette via the dead `showVectorToolsPanel` localStorage key, so no `.vt-row` ever existed), and `symbol-edit` (drove selection with raw canvas clicks, but the app opens on the **inkbrush**, so those clicks were drawing).
- Library cards use their own `.sp-lib-card` / `.sp-lib-thumb` classes so `.sp-card` / `.sp-thumb` keep counting symbols only.
- Help docs updated: Pattern Fills gains a "Texture overlays" section, Symbols gains "Asset library", Vector Paths documents `Ctrl+L` and the auto-convert behaviour, Illustrator Tools lists the texture inserts. Hotkey list in the Help dialog updated. `docs/learnings.md` and `docs/bugs/bug-fixes.md` (#207–#209) updated.

## Breaking changes / migration
- None. `PatternFill.seed` is an additive optional field ignored by older builds, and `patternFill` already passed through the migration whitelist as a whole object.
