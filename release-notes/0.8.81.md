# 0.8.81 — Numeric Transform panel (X / Y / W / H / rotation) (2026-07-13)

## Highlights
- **Type exact position, size, and rotation for any object.** A new **Transform** section in the
  Properties panel gives editable **X/Y**, **W/H**, and **∠** (rotation°) fields for the selected
  element — Illustrator's Transform panel, long the roadmap's top "quick win".

## Features
- **Transform panel** (`property-panel.tsx` → `TransformControls`): single-select an object to get
  numeric **X/Y** (position), **W/H** (size), and **∠** (rotation, degrees) fields. Commit on
  **Enter / blur**; each edit is one undo step and the fields track the object live as you drag or
  rotate it on canvas. Resizing rescales the object's geometry (pen points, path anchors, text size)
  exactly like a handle drag — it reuses the existing `setElementTransform` action.
- **API:** `Yappy.setElementTransform(id, { x, y, width, height, angle })` now also accepts
  **`angle`** (radians) alongside position/size:
  ```js
  Yappy.setElementTransform(id, { x: 120, y: 80 });            // move
  Yappy.setElementTransform(id, { width: 240, height: 160 });  // resize
  Yappy.setElementTransform(id, { angle: Math.PI / 4 });       // rotate 45°
  ```

## Internal / tests / docs
