# 0.8.267 — Artboard tool, side-by-side variations, and text on any path (2026-09-29)

## Highlights
- An **Artboard tool** (Shift+O): drag a frame on the canvas, or click for a New Artboard dialog with presets, a custom size and a count, so several versions of a design sit side by side.
- **Text on any path**, including curves drawn with the Pen tool, from a real **Type on Path** tool (Alt+T), with **Flip** for the bottom of a badge.

Both came from a user designing a logo: building every version on one infinite canvas with no
frames, and no way to set type on a curve.

## Features
- **Artboard tool** — toolbar (#, next to Crop) and Shift+O. Drag draws an artboard of exactly that
  size (Shift = square). Click empty canvas for the dialog, placed where you clicked.
- **New Artboard dialog** — logo presets (square, horizontal, app icon, favicon) plus every social,
  video, presentation and print size; custom width × height with a swap button; **Count** and **Gap**
  lay frames out in a row. Also on right-click → Artboards → New Artboard…, and the command palette.
- **Variations** — click inside an artboard with the tool, or its menu's *Duplicate as
  Variations…*: N independent copies of the frame and its artwork, side by side.
- **Type on Path tool** — Alt+T or the Text tool's flyout. Click a Pen path, line, connector,
  freehand stroke or shape outline and type into an on-canvas field (Enter applies). The text
  starts centred: on top of a loop, mid-way along an open path.
- **Pen-tool paths carry curved text** (first subpath of a compound path).
- **Text Align** (start / center on position) and **Flip to Other Side**. On a loop, Flip runs the
  text the other way round so the bottom of a badge reads left to right; on an open path it moves
  the text below the line, still readable.
- Curved text follows each shape's real outline: rounded rectangle corners, capsule ends,
  parallelogram skew.
- API: `Yappy.createArtboards({ width, height, count, gap, name, x, y })`,
  `duplicateArtboard(id, gap, count)`, `openArtboardDialog()`, `toggleArtboardTool()`,
  `attachTextToPath(id, text, { align, offset, flip, side, spacing })` (now returns a boolean),
  element props `textPathAlign` and `textPathFlip`.

## Fixes
- **17 tool overlays clicked 46px left and 52px above the pointer** (Type on Path, Shape Builder,
  Knife, Measure, Width, Live Paint, Curvature, Reshape, Puppet Warp, Blob Brush, Path Eraser,
  Slice, Symbol Sprayer, Symbolism, Touch Type, Perspective Grid, the game overlay), and further
  off with the canvas rotated. They mapped window px as if canvas-local; now `windowToWorld`.
- **Duplicated artboards stayed grouped with the original**; copied curves kept their bend at the
  old position; a second duplicate landed on the first copy.
- **Curved text vanished when its path's stroke was set to none.**
- **SVG export flattened curved text** into one straight centred label.
- Text on capsules, parallelograms and rounded rectangles followed the bounding box.
- Bottom-of-circle text read backwards ("CBA") with no way to fix it.

## Internal / tests / docs
- New: `tests/artboard-tool-type-on-path.spec.ts` (tool drag/click, dialog, variations, Type on
  Path click, both render styles, SVG export), `frontend/src/store/artboard-variations.test.ts`,
  `frontend/src/utils/text-on-path.test.ts`.
- `shape-builder.spec.ts` and `reshape.spec.ts` pointed at canvas-local coordinates and only passed
  while the overlays had the same mix-up; they now align world to window px first.
- `text-on-path.ts` no longer imports `render-element` (it would pull the shape registry into the store).
- Help: Artboards (tool, dialog, variations, shortcuts) and Text on Path rewritten; hotkeys
  Shift+O / Alt+T; translations in all five locales.

## Breaking changes / migration
- Shift+O now opens the Artboard tool; it used to fall through to the ellipse tool (O / 4 still do).
- `attachTextToPath` returns `false` for an element with no path to follow instead of silently
  setting text on it.
