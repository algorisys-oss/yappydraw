# 0.8.190 — Stroke alignment, corners and end caps; guides you can select as a group (2026-08-13)

## Highlights
- Strokes can now sit **inside**, **centred on**, or **outside** a shape's outline, so a thick
  border no longer eats into the shape it frames.
- **Corner** and **end cap** styles now work on Pen tool paths, lines and freehand strokes, not
  just on closed shapes.
- Guides can be **selected several at a time** and moved, nudged or deleted as one group.

## Features

### Stroke alignment (Inside / Center / Outside)
New `strokeAlign` property, in the Properties panel under Stroke. Center is the old behaviour and
stays the default, so nothing you have already drawn changes.

- **Inside** keeps the whole stroke within the outline — the shape never grows past the box you
  drew it in.
- **Outside** keeps the whole stroke outside it — a thick border never covers the fill or artwork
  inside.

Works on closed shapes and closed Pen paths, in both the sketch and architectural draw styles.
Open paths, lines and freehand strokes stay centred, and the control is hidden for them rather
than shown doing nothing.

### Stroke corners on paths
`strokeLineJoin` (Sharp / Round / Bevel) already existed but was only offered on about 28 closed
shapes. It is now available on Pen paths, lines and freehand strokes too.

### Stroke end caps
New `strokeLineCap` for open paths: **Butt (Flat)**, **Round** and **Square**. Round and Square
push the line half a stroke width past its last point; Butt stops exactly on it, which is what you
want when a route has to end on a precise spot.

### Selecting several guides at once
- Click a guide to select it; **Shift** (or Ctrl/Cmd) **+click** adds or removes one.
- **Ctrl+Shift+A** selects every guide. **Esc**, or a click on the canvas, clears the selection.
- Drag any selected guide and the whole selection moves. Each guide slides along its own axis, so
  a mix of horizontal and vertical guides keeps its shape.
- **Arrow keys** nudge by 1px, **Shift+Arrow** by 10px.
- **Delete** removes every selected guide at once.
- New **Lock / Unlock Guides** command freezes guides so a finished layout can't be nudged by
  accident.

Selected guides draw thicker and in a different colour.

### API
Element options gain `strokeAlign`, `strokeLineCap` and `strokeLineJoin`. New guide methods:
`listGuides`, `selectGuides`, `selectGuide`, `selectAllGuides`, `getSelectedGuides`,
`clearGuideSelection`, `moveSelectedGuides`, `removeSelectedGuides`, `toggleGuidesLocked`.

## Fixes
- **Every guide shared the id `guid-1`.** `generateId()` never looked at `store.guides` when
  working out the next free id. Because moving and deleting a guide both match on id, dragging one
  guide actually moved all of them and deleting one deleted the lot. It stayed hidden while guides
  were only ever handled one at a time.
- **Outside-aligned shapes lost their text.** The pass that draws the fill hid the stroke by
  setting its colour to transparent, and text falls back to the stroke colour when it has none of
  its own — so the label was drawn in transparent.
- **Export cropped outside-aligned strokes.** Export padded the image by half the stroke width,
  which is only right for a centred stroke. It now pads by nothing, half, or the full width to
  match the alignment.

## Internal / tests / docs
- New `utils/stroke-align.ts`. Alignment is done by drawing the stroke at double width and clipping
  away the half on the wrong side, wrapped around the shape renderer's own draw call — so it covers
  every shape and both draw styles without touching the ~120 places that apply a stroke. Reuses the
  existing `buildClipPath2D` from clipping masks.
- SVG export reproduces alignment with a `<clipPath>`, since SVG has no `stroke-alignment`
  attribute. Corners and caps map straight to `stroke-linejoin` / `stroke-linecap`.
- `PropertyConfig` gains `visibleWhen`, a predicate for controls that depend on an element's state
  rather than its type — `applicableTo` is a type list and `path` covers both open and closed pens.
- Help docs updated: Rulers & guides (workspace), a new "Stroke Alignment, Corners & End Caps"
  section (vector paths), and the hotkeys dialog.

## Breaking changes / migration
None. All three stroke properties default to the previous behaviour, so existing drawings render
exactly as before.
