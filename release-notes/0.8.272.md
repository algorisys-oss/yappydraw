# 0.8.272 — Mind mapping, actually working (2026-10-08)

## Highlights
- **Mind maps arrange themselves again.** Auto-reflow had been switched off by default for
  roughly 230 releases, on a diagnosis that named the wrong suspect: the comment blamed the
  `balanced` layout for "laying out vertically", but the tall single column being seen is what
  `horizontal-right` does — and that was the default direction, so `balanced` had never once
  run. Measured on a root with 4 branches × 3 children: `horizontal-right` 610×920,
  `balanced` 1050×440, both collision-free. Balanced is now the default and the reflow is back on.
- **Three layout bugs had been sitting behind that disabled flag**, because with it off every
  reflow path was dead code. Radial overlapped 46 node pairs on a 66-node tree; vertical spread
  the same tree across ~9800px; a node that outgrew its label never triggered a re-layout.
- **Deleting a node now takes its subtree with it** — the help doc had promised that all along
  while the children were in fact left stranded on the canvas with a branch drawn to nowhere.
- **Reorder a branch**, export a map as Markdown / text / OPML, set the layout spacing, and
  focus mode is finished rather than half-built.

## Features
- **Reorder nodes within a branch.** `Alt+Shift+Arrow` swaps a node with the sibling actually
  lying that way — up/down in a horizontal map, left/right in a vertical one — or use **Move
  Earlier** / **Move Later** in the right-click **Hierarchy** menu and the property panel. The
  node's subtree comes with it, and the new order survives a re-layout: it *is* the order, not
  just a position. API: `Yappy.moveMindmapNode(id, 'earlier' | 'later')`,
  `Yappy.swapMindmapSiblings(a, b)`, `Yappy.mindmapSiblingInDirection(id, dir)`.
- **Take a map out as text.** Right-click → **Hierarchy → Export Outline** for Markdown (`.md`),
  indented text (`.txt`) or OPML (`.opml`). Markdown and text paste straight back in, so the
  round trip is lossless for structure; OPML is what FreeMind, Xmind and Workflowy import.
  Export starts from the node you pick, so one branch can leave on its own. API:
  `Yappy.mindmapToOutline(rootId, format)`, `Yappy.saveMindmapOutline(rootId, format)`.
- **Layout spacing is configurable** — **Settings → Mindmap** now has **Branch Spacing** (gap
  between whole subtrees; the vertical gap scales with it) and **Leaf Spacing** (gap between two
  neighbouring leaves, deliberately tighter). API: `Yappy.setMindmapSpacing({ spacing, leafSpacing })`,
  `Yappy.getMindmapDefaults()`.
- **Nodes grow to fit their label.** Commit a label too long for its box and the node gains
  height for the extra wrapped lines — widening only if a single word won't fit — then the tree
  reflows around the new size. API: `Yappy.fitMindmapNodeToText(id)`.
- **Focus mode finished** (it existed as `Shift+F`, but only as dimming): everything outside the
  branch is now unclickable as well as dim, the view fits itself to the branch on entry, and a
  bar names what you're focused on with a **Show all** button. Reachable from the Hierarchy menu
  and the property panel too. API: `Yappy.setFocusBranch(id)`, `Yappy.toggleFocusBranch()`,
  `Yappy.focusedBranch`.
- `Yappy.deleteElements(ids)` (plural, one history step) and `Yappy.setMindmapAutoLayout(on)`.
  `Yappy.addChildNode` / `addSiblingNode` now forward their options, so `{ animate: false }`
  makes a script's reflow synchronous.

## Fixes
- **#411 Auto-reflow was off by default** on a misdiagnosis of the default *direction*. Default
  direction is now `balanced` and auto layout is on. Explicit choices in settings still win.
- **#412 Radial overlapped nodes past depth 2** — it split each parent's wedge evenly regardless
  of subtree size, measured rings from the parent's centre rather than the root's, and shrank the
  radius 0.8× per level while the node count per ring grew. Replaced with two invariants: a
  node's wedge is its share of the tree's *leaves*, and rings are concentric about the root and
  step out by more than a node's extent. Overlap is now impossible by construction.
- **#413 Vertical layout spread a 66-node tree across ~9800px** — every sibling pair was charged
  the full 100px inter-*subtree* gap. Leaf siblings get their own tighter gap; same tree is 7700px.
- **#414 Deleting a node orphaned its subtree** and left the parent→child branch drawn to the
  empty space. Delete now expands through the descendants and sweeps up the branches, in the same
  single undo step.
- **#415 A long label spilled over the branches and neighbouring nodes** — a child inherited its
  parent's box verbatim and nothing re-measured; container text is centred and not clipped.
- **#416 The reflow animation re-routed every connector in the document**, eleven times per
  reflow. Now scoped to the nodes being laid out, with the incoming-branch lookup indexed once.
- **#417 A branch's order could not be changed**, and dragging a node past a sibling appeared to
  work then snapped back — the layout reads children in element order, and nothing could change it.
- **#418 A shortcut using Alt could not live in app.tsx's shared-shortcuts block**, which is
  guarded by `!e.altKey`; both new Alt bindings were inert until a test caught it.
- **#419 Focus mode's dimmed elements stayed fully clickable** — you could drag geometry rendered
  at 12% opacity, because the focus set was known only to the renderer.
- **#420 Entering focus mode didn't move the view**, so a branch off-screen stayed off-screen.
- **#421 Nothing said you were in focus mode**, or how to leave; it wasn't in the help doc at all.
- **#422 A focus id pointing at a deleted node dimmed the whole canvas** with no visible cause.
- **#423 No way to get a map out as text** (the import side had existed all along).
- **#424 Mindmap spacing was recorded as configurable but was hardcoded** — the engine accepted a
  spacing option from day one and its only caller passed none.
- **#425 Five copies of the connector-type list, two missing `polyline`** — a polyline with a
  `parentId` counted as a child node when laying out and as a connector when navigating.
- **Arrow-key navigation followed the layout**, rather than a hardcoded left-is-parent that only
  described `horizontal-right`. It is now resolved from where nodes actually are, so it is right
  in balanced (both halves), vertical and radial. `Alt+Arrow` nudges a node 1px, since bare
  arrows move the selection.

- `frontend/src/utils/mindmap-layout.test.ts` — 42 assertions: no two nodes overlap across 6
  directions × 4 tree shapes, compactness, left/right mirroring, collapse-as-leaf, `parentId`
  cycles, semantic styling, and `parseOutline` edge cases. The engine had no unit tests at all.
- `mindmap-navigation.test.ts` (12), `mindmap-outline.test.ts` (17, including both round trips),
  `mindmap-focus.test.ts` (8); e2e `mindmap-p0` (8), `mindmap-reorder` (7), `mindmap-p3` (8).
  Every new spec was A/B'd against the unfixed source.
- One `MINDMAP_CONNECTOR_TYPES` + `mindmapChildren` now backs layout, navigation, the store,
  handle detection and the export, so none of them can disagree about what a branch contains or
  what order it reads in.
- `zoomToFit` takes an optional id list instead of always fitting the whole document.
- Help doc rewritten where it was wrong: five claims didn't match the code (auto-layout state,
  the balanced default, Delete semantics, a "Mind Map tool" that doesn't exist, the layout
  table), plus new sections for focus mode, outline export and spacing.
- todo.md Phases 54/55 corrected — several items were ticked while unimplemented or unreachable.

## Breaking changes / migration
- **Mind maps now re-arrange themselves on edit.** If you had never changed the setting you were
  getting no auto layout at all; adding, deleting, collapsing or reparenting a node will now
  reflow the tree. Turn it off again in **Settings → Mindmap → Auto Layout**; an explicit choice
  you had already made is respected.
- **The default layout direction changed** from `horizontal-right` to `balanced` for trees with no
  layout of their own. Existing trees that were given a direction keep it.
- **Deleting a mind-map node now deletes its subtree.** One undo step restores the lot.
