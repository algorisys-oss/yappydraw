# 0.8.8 — Stop restores your camera (2026-07-07)

## Highlights
- Pressing **Stop** (or Esc) after playing a game now returns the canvas to the
  exact zoom/pan you had before Play — not the auto-fit-to-stage view.

## Fixes
- **Stop didn't restore the camera.** Play frames the stage (zoom-to-fit), but Stop
  only restored elements / selection / slide / mode — leaving the canvas at the
  fitted zoom. The play snapshot now also captures `viewState`, and Stop restores it.
  (Verified: the Stop button stops the game, hides the overlay, and returns docType /
  mode / camera to the pre-play state.)

## Internal / tests / docs
- `game-runtime.ts` snapshot gains `viewState`; `stopGame` calls `setViewState`.
  e2e confirms the Stop button works on a game doc and restores the camera exactly;
  arcade suites regression-green (10).

## Breaking changes / migration
- None.
