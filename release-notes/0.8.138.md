# 0.8.138 — Floating panels were white in dark mode (2026-07-21)

## Highlights
- **Swatches, History, Symbols, Stick Figures, Brand Kit, Elements, Recolor and every other
  floating panel rendered WHITE in dark and focus mode**, with pale grey text on them.
- Root cause: **24 CSS custom properties referenced across ~60 files but defined nowhere.**
- The contrast sweep now visits **27 surfaces instead of 9**.

## Fixes
- Bug #199: **floating dock panels ignored the dark theme entirely.** `.dock-floating` used
  `background: var(--bg-primary, #fff)` — and `--bg-primary` is defined nowhere, so the
  declaration always took its `#fff` fallback. The panels inside are transparent, so the whole
  stack sat on white while the text used the dark theme's light colours. Unreadable, and clearly
  wrong at a glance once a panel was opened in dark mode.

  Auditing every `var(--x)` against the set actually defined found **24 such tokens**, including
  `--accent-color` (29 files), `--bg-hover` (17), `--shadow-lg` (11) and `--bg-primary` (6).
  Each is now defined per theme. **Light values are exactly the previous fallbacks**, so light
  mode is unchanged by construction; the dark and focus blocks give them real values.

  One visible side effect, and it is the intended design finally working: `.toolbar-btn.active`
  specifies `background-color: var(--primary-light)`. With the token undefined the declaration was
  invalid and the active tool button had no tint; it now gets one.

- Bug #200: **contrast failures in panels the previous sweep never opened.** Fixed: stick-figure
  mode/variant/animation chips (white on the indigo accent — 4.47 light, 2.98 dark), the History
  row count, the States panel's Capture button (3.68) and its empty state, the hotkey badge on a
  tinted active toolbar button (3.96), and the layer drag handle (4.2).

## Internal / tests / docs
- The sweep's surface list grew from 9 to **27**: every dock panel (layers, properties, history,
  swatches, graphic styles, patterns, symbols, elements, brand kit, stick figures, recolor,
  states, scene timeline, keyframes, vector tools, minimap, rulers, slide navigator) plus the
  command palette, settings, export, save, help, menu, colour palette and What's new. Each entry
  closes itself afterwards so one surface can't mask the next.
- **Coverage is now asserted**, not assumed: the test fails if it visited fewer surfaces than
  expected, so a renamed control degrades into a visible failure rather than a quiet clean pass.
- The audit now **skips disabled controls** — WCAG 1.4.3 exempts inactive components, and a dimmed
  disabled button is how "inactive" is conveyed. Flagging them would push the UI toward making
  disabled look enabled.

## Breaking changes / migration
- None. Light mode is unchanged by construction; dark and focus gain the panel backgrounds they
  should always have had.
