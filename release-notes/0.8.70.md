# 0.8.70 — Animations persist, adjustment layers export, more keyframable channels (2026-07-11)

## Highlights
- **Keyframe animations now save with your document.** Composition tracks (and dimension
  annotations) are written to the saved/`.yappy` document and restored on load — your
  timeline survives a reload or a Save/Open round-trip.
- **Adjustment layers now show in exports.** Their filter (blur/brightness/…) is applied to
  PNG/JPG exports of what's beneath them (the authoring gizmo is omitted).
- **More keyframable channels.** Fill **Gradient Angle**, **Stroke Gradient Angle**, and the
  live **Transform Effect** params (Copies, Move X/Y, Scale X/Y, Rotate) are now animatable —
  spin a gradient or unfurl a spiral over time.

## Features
- **Document persistence** for `compositionTracks` and `dimensionAnnotations` — wired into
  both the auto-save format and the on-disk `.yappy`/export format (previously dimensions
  only survived auto-save). New `Yappy.getDocument()` returns the serializable document.
- **Adjustment layers in raster export** — `export.ts` snapshots the composite drawn so far
  and re-draws it through the layer's CSS filter, clipped to the region (same technique as
  the live canvas). (SVG export still to come.)
- **New keyframe rows** (shown when the element has the feature):
  - `gradientDirection` (fill gradient angle),
  - `strokeGradient.angle` (dotted-path),
  - `transformEffect.copies / moveX / moveY / scaleX / scaleY / rotate` (dotted-path).

## Internal / tests / docs
- Persistence: added the collections to `document-io.ts buildSlideDocument` + `auto-save.ts`
  + the load path + `SlideDocument` type. Export: `renderElWithEffects` handles
  `isAdjustmentLayer`; removed the raster-export exclusion.
- Tests: `persistence-and-gradient.spec.ts` (doc round-trip restores the animation + dimension
  and the evaluator still interpolates; fill + nested gradient angles keyframe),
  `adjustment-export.spec.ts` (export output changes with the adjustment layer). Full suite —
  **27 unit + 12 e2e** green; transform-effect + gradient animation visually verified.
- See `docs/after-effects-plan.md` (v0.8.70 note).

## Known limitations
- Adjustment layers apply in **raster** export (PNG/JPG) but not yet in **SVG** export.
- `transformEffect` reflect flags and origins aren't exposed as keyframe rows (booleans/pivots).

## Breaking changes / migration
- None. Documents saved by older versions load unchanged; new fields are optional.
