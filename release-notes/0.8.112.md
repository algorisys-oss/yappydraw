# 0.8.112 — Comic Studio: strips, and a panel to drive it

**Date:** 2026-07-19

## Highlights

- **Comic Studio panel** — write a script and draw a comic without opening the
  console. It shows who it found, the pose each character will strike, and how many
  panels your script becomes.
- **Multi-panel strips** — longer conversations split into panels laid out
  left-to-right, wrapping into rows.
- **Emotion controls** — override what the words suggested and set the mood
  yourself, per character.

## Features

- **Comic Studio panel** (Window/Panels → Comic Studio, or the command palette).
  A script box, a live read-out of the detected speakers and panel count, per-speaker
  **figure** (Man/Woman/Boy/Girl) and **emotion** pickers, and options for figure
  height, text size, panels per row, border and monochrome. The primary button
  switches between "Generate panel" and "Generate strip (n)" depending on how the
  script splits, with "One panel" to override.

  The preview is computed by the same pure functions the generator uses, so what the
  panel reports cannot drift from what gets drawn.

- **`api.createComicStrip(script, opts?)`.** Splits a longer script into panels and
  arranges them on a grid. Panel breaks follow Comic Chat's rules — chiefly *one
  balloon per character per panel*, so a speaker taking another turn starts the next
  panel and an alternating back-and-forth naturally becomes a row of two-person
  panels. Adds `columns` and `panelGap` on top of the panel options. The strip is one
  group (each panel a group inside it) and commits as a single undo step.

  Note: the paper also breaks panels on a 15% random chance for pacing variety. That
  is deliberately omitted — regenerating the same script should produce the same
  strip.

- **Emotion overrides.** A small palette — Neutral, Happy, Laughing, Sad, Angry,
  Shouting, Thinking, Unsure, Waving, Pointing, Idea, Presenting, Love, Asking —
  each mapped to a pose we have art for. Set one per speaker in the panel or via the
  API (`emotions: { Bob: 'angry' }`); "Auto" hands the choice back to the words.

  This is Comic Chat's emotion-wheel idea (§4.1): a system cannot reliably infer how
  someone feels, so the person writing gets the final say. The palette is kept short
  on purpose — an emotion with no art behind it is worse than no option at all.

## Internal / test changes

- `library/comic/panel-layout.ts`: `splitIntoPanels()` — pure and deterministic.
- `library/comic/index.ts`: extracted `buildPanelElements()` so the panel and strip
  generators share element construction and a strip is one batch.
- `library/comic/pose-rules.ts`: `EMOTIONS` palette + `poseForEmotion()`.
- `components/dock/comic-panel.tsx`: dock-native panel, registered in the panel
  registry with a menu entry, a command-palette entry and `toggleComicPanel()`.
- 10 new unit tests (panel splitting, emotion palette integrity and override) — 44 in
  the comic suite, 152 overall.
- Verified in the running app: a 6-line script produced 3 evenly spaced panels with
  the ALL-CAPS line visibly posing its speaker with a megaphone; and two panels with
  identical dialogue rendered different poses once emotions were set, confirming the
  override reaches the drawing.

## Breaking changes / migration

None. Additive API and a new panel; no document format change.
