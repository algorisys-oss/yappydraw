# 0.5.10 — Vector pattern fills (2026-06-29)

## Highlights
- **Pattern fills.** Fill any shape with a seamless repeating motif — stripes,
  grid, dots, checker, or crosshatch — with control over colour, background,
  scale, spacing, line thickness, and rotation angle. Closes the last open
  sub-item of the appearance-stack track in the vector-illustration roadmap.

## Features
- New `fillStyle: 'pattern'` with a per-element `patternFill` describing the
  motif. Choose **Fill → Pattern** in the Properties panel to reveal the
  **PATTERN** editor (motif picker, foreground/background colour with a
  transparent toggle, and Scale / Spacing / Thickness / Angle sliders).
- Renders identically in both **Sketch** and **Architectural** styles (the fill
  is rasterized into a shape-clipped buffer, mirroring image/mesh fills), and
  exports as a true-vector SVG `<pattern>` (with `patternTransform` rotation).
- `window.Yappy` API: `applyPatternFill(type?, ids?)`,
  `setPatternFill({ type, color, background, scale, spacing, strokeWidth, angle }, ids?)`,
  and `clearPatternFill(ids?)` — all default to the current selection.

## Fixes
- Hardened `normalizeElement` (legacy import) to pass `patternFill` through; the
  migration allowlist would otherwise silently drop new element fields.

## Internal / tests / docs
- New `utils/pattern-fill.ts` (seamless tile generator + element-sized buffer),
  `RenderPipeline.applyPatternFill`, and a `<pattern>` branch in `svg-paint.ts`.
- Help doc: new **Pattern Fills** section in Masks/Appearance/Trace.
- Learnings + vector-illustration roadmap updated.
- Verified end-to-end in-browser: all 5 motifs render clipped-to-shape in both
  draw styles, angle/scale apply, SVG export emits `<pattern>`, zero console errors.

## Breaking changes / migration
- None. Existing documents are unaffected; `patternFill` is additive.
