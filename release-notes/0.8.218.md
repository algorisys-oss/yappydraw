# 0.8.218 — Eight fixes from one pillar drawing (2026-08-23)

## Highlights
- **Convert to Path keeps the curves.** Every arc-based shape used to convert into a polygon —
  the outline was sampled at 96 points and simplified. A `database` now converts to six exact
  Bézier anchors instead of thirty flat chords, and it brings its cap with it.
- **Rounded corners survive every polygon operation.** The flattener behind Pathfinder, the
  Shape Builder, the Knife, Distort, Live Paint and the 3D extrude read a rectangle's box and
  ignored its corner radii, so all of them squared a rounded rectangle off.
- **3D blocks can be converted to a path at all.** `isometricCube`, `solidBlock`,
  `perspectiveBlock` and `openBox` published faces and no outline, so every tool that needs a
  path silently refused them.
- **The Pen can finish a path open with a pointer**, and **Ctrl+Z mid-path steps back one
  anchor** instead of discarding the whole path.
- **A cylinder can taper** into a column or a pot, live and re-editable.
- **Hidden layers stay out of exports** — including out of the crop box they were stretching.

All of it came from one user's report after building a stone pillar out of shapes, blocks and a
converted `database`; none of the eight fixes was about pillars.

## Features

- **Cylinder ▸ Taper** (Properties → Dimensions, −0.95…0.95). Narrows one end into a truncated
  cone: negative narrows the near cap (the top of an upright cylinder) for a column, positive
  narrows the far cap for a pot or a tumbler, `0` is the plain tube. The wide end keeps the box
  fit, so the solid still fills the width you drew, and axis angle and cap perspective stay
  editable. Both draw styles.
  ```js
  Yappy.createCylinder(100, 100, 130, 340, { capRatio: 18, taper: -0.3 }); // column
  Yappy.createCylinder(300, 100, 150, 220, { capRatio: 22, taper:  0.4 }); // pot
  ```
- **Pen: Ctrl/Cmd + click anywhere finishes the path open** — and, unlike Enter / Esc /
  double-click, keeps the Pen selected, so a run of separate open curves is one continuous
  gesture. A single-anchor path is still discarded rather than left as a stub.
- **Point-level undo.** Ctrl/Cmd + Z while the Pen or the Polyline is building removes the most
  recent anchor (the same as Backspace). Undo the first anchor and the path is dropped and the
  tool freed. Once the path is finished, Ctrl+Z is the ordinary document undo again.
- **Convert to Path emits a shape's stroke-only decoration** as sibling paths: a `database`'s
  cap ellipse, a `predefinedProcess`'s bars, an `internalStorage`'s rules. Selected together
  with the body, so a converted database is a usable starting point for a hand-built cylinder.
- **Convert to Path works on 3D solids**, producing the silhouette (the union of the faces).
  That also unlocks the Node tool, Warp, Turntable, the Knife, the Scissors and the Pathfinder
  on 3D blocks, all of which had refused them.

## Fixes

- **#314 — Convert to Path turned every curve into a polygon.** `shapeToPath` sampled
  `path`/`multi` geometry at 96 uniform steps and ran Ramer–Douglas–Peucker over the result. It
  now converts command by command; `parsePath` already lowers arcs to cubics, so nothing needed
  approximating. Multi-contour outlines stay compound instead of being welded into one ring.
- **#315 — …and dropped the cap.** `getShapeGeometry` returns only the fill silhouette, which
  is correct, so the cap the renderer draws separately had never been visible to converters.
  Published via `shapeDecorationSubpaths` and emitted as siblings, not extra subpaths —
  subpaths fill even-odd, so a cap ring folded into the body would punch a hole in the lid.
- **#316 — The database's fill outline was a different shape from the database.** Its geometry
  closed the top *under* the cap while the renderer fills the whole cap, so gradient, pattern,
  image and hachure fills were clipped away across the lid and hit-testing missed the top of
  the shape. One sweep flag.
- **#317 — Undo mid-path threw the whole path away.** The in-progress path is one history
  entry, so the document undo rewound past all of it. Now routed through a small registry the
  global shortcut consults, rather than a second window listener — both would be capture-phase
  listeners on `window`, where `stopPropagation` does nothing between listeners on one target
  and the winner is decided by component mount order.
- **#318 — Open paths looked impossible.** They were supported, but only through keyboard or
  timing gestures, so with a stylus in hand none of them was reachable — the reported
  workaround was drawing the curve with a liner brush, which then behaves like a stroke and not
  a path and showed up as such in the Shape Builder.
- **#319 — Hidden layers were in every export, including the crop box.** `isExportable` checked
  only the element's own `visible` flag; the canvas skips whole hidden layers. So hidden-layer
  content was drawn into every PNG/JPG/SVG/PDF/PPTX/Rasterize/Slice **and** widened the
  bounding box those exports size themselves from — one stray object on a switched-off layer
  was enough to blow the image up and leave the drawing in a corner. `elementsBounds` now also
  drops non-finite boxes rather than letting one NaN coordinate poison the whole crop.
- **#320 — Rounded corners were dropped by every polygon operation.** `geometryToRings` read a
  rect's `x/y/w/h` and never looked at `geo.r`, so everything built on polygon flattening
  operated on a shape that was not the one on screen. It now builds the same quadratic-corner
  path the renderer draws and flattens that, per-corner radii included, with the radius clamped
  to half the shorter side. This is also what makes rounded rectangle + Extrude + **Bevel**
  produce a genuinely blunt-edged block.
- **#321 — 3D blocks could not be converted to a path at all.** The `multi` branch looked for a
  published `outline`, then guessed at "the first `path` face"; block primitives are built
  entirely from `points` faces and have neither, so it returned `null` and every gated tool hid
  its option. The silhouette is the union of the faces — computed from raw rings, because
  `elementToMultiPolygon`'s containment pass reads one overlapping face as a hole in another.

## Internal / tests / docs

- New `frontend/src/utils/point-undo.ts` — a one-function registry so the global Ctrl+Z asks
  whether a building tool wants the key instead of racing it.
- `geometryToRings` exported from `path-boolean.ts` for callers that want raw rings without
  hole inference.
- `shapeToPath` returns an optional `subpaths` for genuinely compound outlines; single-ring
  callers (Knife, Scissors, Pathfinder, Warp, Turntable) are unchanged.
- New specs: `shape-to-path-curves`, `rounded-rect-flatten`, `pen-open-path`,
  `export-hidden-layer`; taper cases added to `cylinder-geometry`.
- `pen-undo-recovery.spec.ts` rewritten: it asserted that Ctrl+Z mid-path deletes the whole
  path, which is the behaviour #317 fixes. Its original orphan-recovery coverage is kept, with
  the orphan produced by deleting the element instead.
- `i18n/hotkey-extraction.test.ts` pinned the dictionary to its extraction-time size of 188, so
  every new shortcut failed an oracle about whether the *extraction* was faithful. It now
  asserts the frozen fixture's 188 keys all survive and lets the dictionary grow.
- Docs: `docs/bugs/bug-fixes.md` #314–#321, six new sections in `docs/learnings.md`, and four
  help docs (`vector-paths`, `geometric-shapes`, `effects`, `workspace`) plus two new hotkey
  entries across all four locales.

## Breaking changes / migration

None for documents or the API. Two behaviour changes worth knowing:

- **Hidden layers no longer export.** If you relied on a hidden layer appearing in exports, turn
  its eye back on. This also applies to an element whose layer no longer exists — the canvas
  does not draw those either.
- **Ctrl/Cmd+Z means "remove the last anchor" while the Pen or Polyline is building.** It is the
  document undo again as soon as the path is finished. Redo is untouched.
