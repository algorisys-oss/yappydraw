# 0.8.278 — Documenting the Command Palette (2026-10-09)

Documentation only. No "What's new" entry: the feature itself was announced in 0.8.276, and
this is the help page it shipped without.

## Internal / tests / docs
- **`workspace.md` gains a Command Palette section.** The command registry shipped in 0.8.276
  with no user-facing documentation at all — only a release note and the design plan, neither
  of which is in the app. Both halves were undocumented: that the palette now greys an
  unavailable command and says what it needs (which every user sees), and `Yappy.commands`
  (the kind of scripting surface nobody finds without docs).
- `workspace.md` had referenced the Command Palette a dozen times without ever explaining it,
  so that is where the section goes: what it is, why an unavailable command is shown with its
  reason rather than hidden, that one command is one named undo step, and how to drive it from
  a script — plus `historyEntries`, `undoLabel` and `redoLabel`.

## Breaking changes / migration
- None.
