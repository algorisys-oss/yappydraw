# 0.8.307 — Editable images, and the VS Code extension's first two phases (2026-11-26)

## Highlights
- **Editable images.** A `.yappy.svg` or `.yappy.png` is an ordinary image that also carries the
  whole drawing. It shows as a picture on GitHub, in Markdown and in a browser, and
  **Export / Save… → Load → Load from file** opens it as an editable drawing again.
- **VS Code extension (coming soon).** The extension that opens `.yappy` files in VS Code,
  Cursor and VSCodium is built and tested, but not yet in the VS Code Marketplace or Open VSX.
  Help has a page for it that says so.

## Features
- New API: `Yappy.exportEditableImage('svg' | 'png', { download?, name? })` saves the current
  drawing as an editable image and resolves to the Blob; `Yappy.openEditableImage(blob)` opens
  one and resolves `false`, changing nothing, when the image has no drawing in it.
- The SVG is the vector export; the PNG is the PNG export at 2× on the drawing's background.
- Load refuses an ordinary SVG or PNG (no drawing inside) with a message, instead of opening an
  empty page.
- VS Code extension, P1 and P2 (`vscode/`, not yet published): custom editor for `.yappy` with
  dirty marker, Ctrl+S, Save As, Revert and hot-exit backup; New Drawing; theme follows VS Code;
  exports go through VS Code's Save dialog; editable `.yappy.svg` / `.yappy.png` editing.
