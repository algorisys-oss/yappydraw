# 0.8.85 — Stick figures: sensible default size + baked figures are actually reshapeable (2026-07-13)

## Highlights
- Library stick figures drop at a more reasonable size, and a baked figure no
  longer shows path-anchor squares you can't grab.

## Features
- None (fixes + tuning).

## Fixes
- **Dropped figures were too large.** `STICK_DEFAULT_WIDTH` 130 → **110** (viewBox
  140×260 ⇒ ~110×204), closer to the ~120px icon-insert footprint. Applies to both
  static drops and animated figures.
- **Baked/grouped figure showed un-draggable anchor squares.** The editable-path
  anchor squares were drawn for every selected `path`, but node hit-testing is gated
  on `selection.length === 1`. A baked figure is a group of many path parts, so
  selecting it (always the whole group) drew squares on every part that none could
  grab. Drawing is now gated on a single selection too — squares appear **iff**
  they're editable. To reshape a baked figure: ungroup and select one part, or use
  the **Reshape** tool.

## Internal / tests / docs
- `docs/bugs/bug-fixes.md` entry #157; `stick-animation-doc.tsx` gains a
  reshape/node-edit note on the Bake step; learnings updated.

## Breaking changes / migration
- None. Existing documents are unaffected; only the default size of newly-dropped
  figures changed.
