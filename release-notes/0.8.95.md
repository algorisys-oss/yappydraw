# 0.8.95 — Measurement polish: units, angular/radial dimensions, rotation-aware (2026-07-13)

## Highlights
- The Precision & Measurement polish pass: choose your **units**, add **radius / diameter / angle**
  dimensions, and get **rotation-aware** readouts everywhere.

## Features
- **Measurement units (px / mm / in).** Settings → *Measurement Units* switches every readout — the
  transform badge, Measure tool, gap measuring, and dimension annotations — between pixels,
  millimetres, and inches (96 px = 1 in). Scripting: `Yappy.setMeasurementUnit('px'|'mm'|'in')`.
- **Angular & radial dimensions.** Beyond width/height, add **Radius** / **Diameter** on
  circles/ellipses and an **Angle** dimension that draws the element's rotation as an arc. Right-click
  → Dimensions, or `Yappy.addDimension(id, 'radius'|'diameter'|'angle')`.
- **Rotation-aware bounds.** Dimension annotations now follow a rotated element's edges (measured
  along the rotated edge, offset along its normal), and the transform badge sits under a rotated
  element's true visual corners.
- **True outlines for intersection snapping.** Snap-to-intersection now uses each shape's real outline
  (triangle / star / diamond / rotated shapes) instead of its bounding box, so crossings land on the
  actual edges.

## Fixes
- None (polish/behaviour).

## Internal / tests / docs
- New pure `utils/units.ts` (10 unit tests). `dimension-geometry.ts` reworked to a discriminated
  `linear | radial | angular` geometry (rotation-aware; 10 unit tests). `path-intersection.ts` gains an
  injectable `outlineOf` supplier (fed by `shapeToPath`). New Playwright spec `measure-polish`.
- Note: the Measure line keeps ≥1-decimal precision; the units formatter has no thousands separator.
  **The Precision & Measurement plan is now complete.** Remaining: dimension export inclusion (PNG/SVG).

## Breaking changes / migration
- None. Documents default to `px`; the unit preference is per-user (localStorage).
