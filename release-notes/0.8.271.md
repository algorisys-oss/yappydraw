# 0.8.271 — image-size security update (2026-10-07)

## Highlights
- Fixes two High-severity dependency advisories in `image-size` (CVE-2025-71329, CVE-2025-71330)
  that Hostinger's dependency scan reported. No change in behaviour.

## Features
- None.

## Fixes
- **#410: `image-size@1.2.1`, which `pptxgenjs` pulls in.** It had denial-of-service infinite
  loops in the JXL/HEIF and ICNS parsers, fixed in 2.0.3. `pptxgenjs@4.0.1` is the latest release
  and still asks for `^1.2.1`, so `package.json` `overrides` now pins `image-size` to `^2.0.3`
  (resolves to 2.0.4). Actual exposure was nil: pptxgenjs never imports `image-size`, and it was
  never part of the built app. The scan reads the lockfile, so it was flagged anyway.

## Internal / tests / docs
- Learnings entry: check whether a flagged dependency is reachable, and fix it regardless.

## Breaking changes / migration
- None.
