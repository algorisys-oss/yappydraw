# 0.8.123 — Template previews you can actually read

**Date:** 2026-07-20

## Highlights

The template browser now shows you what each template contains, and fills stay inside
shapes you've rounded the corners on.

## Features

- **Every template card shows a real preview.** "Choose a Template" previously showed a
  generic icon for diagrams, a flat colour swatch for designs, and a strip of fake grey
  text-lines for presentations — none of which told you anything about the template.

  Cards now draw the template's actual content: diagram cards show the diagram (nodes,
  connectors, colours), design cards show the first page at its true aspect ratio, and a
  presentation card's strip previews each of its first four slides with a `+N` for the
  rest. Search results in the Elements panel use the same previews.

  These are simplified marks rather than a full render — text appears as bars and sketch
  styling isn't applied — because drawing a template properly would mean loading it into
  the document first. It's enough to tell layouts apart at thumbnail size. Text Diagram
  templates are YSL/Mermaid source, so they keep their language badge instead of a
  preview, and My Templates cards keep the real thumbnail captured when you saved them.

## Fixes

- **Fills escaped rounded corners on squares and diamonds.** Raising corner roundness on
  a rectangle/square or diamond rounded the outline but left gradient, pattern, image,
  mesh, dots and hachure fills painting the sharp corners, so the fill visibly spilled
  past the stroke.

  Stroke and fill were computed from two different geometry sources and only the stroke
  knew about roundness: the fill clip hard-coded a fixed radius for rectangles and had no
  rounded diamond at all. Both now share the renderers' own corner-radius math, in
  sketch and architectural styles alike.

- **Design template cards collapsed to slivers.** On the Designs tab every card rendered
  about 11 pixels tall with its name, size badge and description clipped away. The card's
  `overflow: hidden` zeroed its minimum size, so once the tab had more rows than fit on
  screen the grid shrank the rows instead of scrolling. Fixed at the grid so no card type
  can hit it again.

## Internal / test changes

- `templatePreviewSvg` moved out of `library/elements/search.ts` into
  `templates/template-preview.ts` and extended to cover all three template data shapes
  (design `pages`, presentation `slides`, diagram `data.elements`); `search.ts` now
  imports it rather than owning a copy.
- `getShapeGeometry` gained shared `cornerRadius()` math mirroring the shape renderers,
  and rounded diamonds bail out of the WASM shape fast path (which dispatches on element
  type alone and can't express a per-element radius).

## Breaking changes / migration

None.
