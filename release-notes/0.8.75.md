# 0.8.75 — Turntable Phase 2: group spin, back-face reveal, auto-axis (2026-07-12)

## Highlights
- **Turntable now spins whole groups and reveals the far side.** Building on the v0.8.74
  Turntable effect, a multi-selection spins as one shared 3D rig, symmetric shapes can show
  their occluded back face on a turn, and the mirror axis is detected automatically. The
  effect panel now appears only for shapes that can actually be turned.

## Features
- **Group turntable** — select **two or more** shapes and the panel switches to
  **TURNTABLE — GROUP**. The whole selection spins about a shared axis (the selection centre),
  so members **orbit together** (position *and* shape) instead of each spinning in place.
  `Yappy.turntable({ yaw: 40 }, [id1, id2, id3])`.
- **Back-face reveal** — under the *Symmetry* volume model, a **Reveal back face** toggle draws
  the mirrored far side alongside the front (z-sorted), so a strong turn shows the occluded
  back — reading as a closed 3D volume. `Yappy.turntable({ depthModel: 'symmetry', reveal: true })`.
- **Auto mirror-axis detection** — the Symmetry model now finds the shape's real vertical mirror
  line automatically (centroid seed + reflection-error search), so the rounded look is correct
  without setting an axis by hand.
- **Bake tightens bounds** — baking a rotated (or group-orbited) shape now re-fits its bounding
  box to the new geometry, so the selection box tracks the shape.

## Fixes
- **Turntable panel showed for shapes that can't be turned** — the **TURNTABLE (3D SPIN)** section
  now renders only for turntable-capable shapes (a path, or anything convertible to one) and is
  hidden for text, connectors, tables, etc.

## Internal / test changes
- `utils/turntable.ts`: `detectMirrorAxisX()`; `reveal` back-face layer + z-sort; `cx/cy`
  rotation-centre so group members share one rig in their own local frames.
- `store/app-store.ts`: `setTurntable` computes the shared group centre and pins it per member
  (default depth model `flat` for groups); `bakeTurntable` re-tightens bbox + shifts anchors to
  origin; new `canTurntable(el)` capability check.
- `components/property-panel.tsx`: `TurntableEditor` is now selection-driven and self-gating
  (single shape *or* group), with the Depth slider + Reveal toggle shown under Symmetry only.
- `types.ts` (`reveal`/`cx`/`cy`/`group` fields), `api.ts`, help `effects-doc.tsx`,
  `docs/learnings.md`, `docs/turntable-plan.md` updated.

## Breaking changes / migration
- None. All new `Turntable` fields are optional and back-compatible.
