# 0.8.221 — closing the classes, not the instances (2026-08-25)

## Highlights
- Fills now cover what a shape **draws**, not what it declares — so the few shapes that reach outside their own box on purpose (a puzzle piece's interlocking tabs, a 3D solid's depth) no longer lose that part of a pattern, mesh or image fill.
- Layer reordering moved off HTML5 drag-and-drop entirely. The no-entry cursor from 0.8.219 is gone at the root rather than exempted, and the drag now works over the whole panel.
- The three 3D effects — **Extrude, Inflate and Turntable** — are translated into German, Spanish and Japanese.

## Fixes

**#327 — Pattern and image fills stopped at the box on shapes that draw outside it.**

0.8.220 fitted nine shapes to their bounding boxes and exempted two kinds that are outside theirs *on purpose*: a puzzle piece whose tabs stopped at the box would not interlock with the piece beside it, and a 3D solid's extruded depth is drawn beside the front face the box describes. That exemption was honest about the geometry and silent about the consequence — it removed those shapes from the *test*, not from the bug. A pattern or image fill on a `puzzlePiece` left its tabs empty.

The buffer-backed fills rasterise a buffer the size of the element and clip it to the outline, so where the outline reaches past the element the buffer has already run out. `fillBufferRect` now sizes that buffer from what the geometry actually occupies: exactly the element's box for any shape that fits, grown only where a shape draws outside it. Applied to pattern, mesh, image, Inflate and the appearance-fills list, and to SVG export so the exported tile matches what the canvas draws.

**#328 — Layer reorder no longer uses HTML5 drag-and-drop.**

Not a new report; this removes the class behind #323. Drag-and-drop hands every listener on the propagation path a handle to the same `DataTransfer`, which is how a global image-drop handler that knows nothing about layers was able to invalidate the panel's drag from a distance. 0.8.219 fixed it with an exemption; this removes the thing that needed exempting.

Reordering is now a pointer drag, with its own listeners and no shared state. The drop behaviour is unchanged. Two things improve as a side effect: the target is resolved from the pointer's position rather than from whichever element the browser decided the drag was over, so **the drag works across the whole panel** including its padding and past the ends of the list; and releasing somewhere that isn't a row simply cancels, instead of showing a no-entry cursor.

## Features

**The 3D effects speak your language.** Extrude, Inflate and Turntable are translated into Deutsch, Español and 日本語 — sixty strings covering every slider, button and tooltip in all three sections.

Translated as one block deliberately: they sit adjacent in the properties panel, and one section in the reader's language between two in English reads as a bug rather than as progress. Terminology follows the localised builds of the tools these effects mirror, so a user who knows the effect from Illustrator recognises its name here — Bevel is *Abflachung* in German, *Bisel* in Spanish, *ベベル* in Japanese; Expand is *アピアランスを分割*, which is what Illustrator JP calls that command.

The i18n ratchet drops 1508 → 1476, repaying the twelve strings Inflate added in 0.8.219 and clearing twenty more that were already there.

## Internal / tests / docs

- `utils/geometry-extent.ts` answers "what box does this geometry occupy", solved analytically — curve extrema from the derivative's roots, arc extrema from the parametric angles where the tangent goes axis-aligned, including the x-axis-rotation and the spec's F.6.6 radius correction. Sampling would be simpler and always *under*-estimates, which in this use is the one error that clips artwork. Its tests measure the same shapes by flattening instead, so the two disagree loudly rather than quietly.
- Two mistakes recorded in `docs/learnings.md` because they generalise. Slack that guards against noise must live in the *decision* (`if overflow > SLACK`) and never in the *value* (`extent - SLACK`) — the first version did the latter and left the puzzle piece's buffer short of its own tabs, reproducing the bug inside its own fix. And a fill cannot be judged from a screenshot when the pattern's background is transparent: this was called fixed, then broken, twice, from pictures of a checkerboard tab that looked half empty until the canvas was actually sampled.
- Help: the Layers section no longer promises the no-entry cursor it used to produce.
