# 0.8.129 — Record straight from the presentation toolbar (2026-07-21)

## Highlights
- A **Record** button in the presentation toolbar captures the whole run as an MP4 — slides,
  animations, laser pointer and ink included.
- `Ctrl+Shift+E` no longer silently arms the Export dialog while you're presenting.

## Features
- **Record from the presentation toolbar.** Present (`F5`), then press the video-camera button
  in the bottom toolbar; it turns into a red Stop square, and pressing it again finishes and
  downloads the MP4. Available on **both** presentation toolbars — the paged one (slide arrows +
  counter) and the infinite-canvas one. It captures the canvas surface, so toolbars, panels and
  the REC badge never appear in the file.
- Recording is the only way to capture a whole deck: the offline page export renders a single
  page, so it can't follow you across slides — and on an infinite canvas, which has no page
  bounds, it can't run at all.
- The presentation toolbar **no longer auto-hides while recording**, so Stop stays reachable.
  Safe to leave on screen, since it isn't in the capture.

## Fixes
- Bug #187: `Ctrl+Shift+E` did nothing during a presentation and then opened the Export dialog
  when you pressed Esc. The dialog is hosted by `<Menu>`, which is unmounted while presenting,
  so the shortcut set a flag nothing was rendering. It now declines with an explanation, and
  entering presentation mode clears the flag so a dialog left open beforehand can't reappear.
- Bug #188: the record button initially reached only the paged presentation toolbar, not the
  infinite-canvas one. Both now have it.

## Internal / tests / docs
- Help docs: the Animation doc's "Recording & Export" section was **materially wrong** — it
  listed only WebM and GIF (no MP4), never said where the export lived, and documented
  Resolution / Frame Rate / Background controls that do not exist. Rewritten to cover all three
  formats, where to find them, the offline-page-render vs live-capture split, the new Record
  button, real limits (video ≤120s/1920px, GIF ≤30s/960px/256 colours), and correct API names —
  the previous draft of this rewrite referenced a `Yappy.startRecording()` that never existed;
  the method is `recordAnimation(seconds, format)`.
- Verified in a real browser via Playwright on both document types (record toggle round-trip,
  toolbar staying put while recording, shortcut toast, no stale dialog after Esc). Scratch
  specs, not committed.

## Breaking changes / migration
- None.
