# 0.8.61 — Dockable panels Phase D: Display States, Behaviors & Stick Figures migrated (2026-07-10)

## Highlights
- The **Display States**, **Behaviors**, and **Stick Figures** panels are now
  first-class **dockable panels** — dock them to an edge, float them, collapse
  them, reorder them in a stack, and the layout persists across reloads.

## Features
- **Phase D migration (Display States + Behaviors + Stick Figures):** all three
  panels moved onto the shared dock chrome. Opening them the usual ways (menu,
  `Alt+S` for Display States, the toolbar's stick-figure button, the game-mode
  bar's Simple tab, the scripting API) now opens the *dockable* version — drag it
  to the left/right edge to dock, reorder it within a stack, or float it. Panel
  actions that lived in the old floating headers moved into small in-body
  toolbars: Play-All / Reset (Display States) and the game view-switcher + Play
  (Behaviors). Stick Figures had a title-only header, so it just disappears.

## Internal / tests / docs
- **Display States** had its own bespoke drag implementation (not the shared
  `draggablePanel` util) — removed the pointer tracking, position signal, and
  window listeners. Its CSS is heavily scoped under `.state-panel` with generic
  child class names (`.panel-actions`, `.input-group`), so rather than de-scope
  ~15 collision-prone rules, the body root keeps the `.state-panel` class and its
  floating-only positioning (`position:fixed`, fixed width/max-height) was
  neutralized.
- **Behaviors** kept the shared `GameViewSwitcher` in an in-body `.bp-toolbar`;
  the two `.behaviors-panel .gvs-btn` compaction rules were re-scoped to
  `.bp-toolbar .gvs-btn` (a bare `.gvs-btn` would have restyled every switcher).
- **External flag reads rewired** (not just the panels themselves): the toolbar's
  stick-figure button (`active` highlight) and the on-canvas **game-mode bar**
  (its visibility + which view tab is current) both read the old `showXxxPanel`
  flags, which now stay frozen `false`. Both were pointed at `isPanelOpen(id)` so
  the button still lights up and the Simple/Graph/Code switcher tracks the open
  Behaviors panel.
- `tsc -b` and `npm run build` both green.
- `docs/dockable-panel-system-plan.md` updated: these three moved from
  **Remaining** to **Done (v0.8.61)**; remaining panels are property, layers,
  animation, ds-ops, vector-tools (property/layers are the most coupled —
  scheduled last).

## Breaking changes / migration
- None. (The old `showStatePanel` / `showBehaviorsPanel` / `showStickFigurePanel`
  settings flags are now unused; panel state lives in the persisted dock layout.)
