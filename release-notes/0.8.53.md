# 0.8.53 — Export border + font-size fixes; OSS lockfile (2026-07-10)

## Fixes
- **Export no longer adds a transparent border.** Image/vector exports (PNG / JPG / copy-to-PNG /
  SVG) padded the crop box by a fixed 20px, which showed as a transparent margin when the
  background was off. Reduced to a tight 2px (the crop already accounts for stroke/effects);
  PDF/PPTX keep a print margin. A 162px shape now exports at 166px (was 202px).
- **Font size no longer snaps to 8 in the quick toolbar.** The compact quick-toolbar size control
  clamped on every keystroke, so typing "1" (for "16") jumped to the minimum (8) and blocked
  further typing. It now live-previews only complete, in-range values; a partial/below-min entry
  stays in the field and is clamped on blur/Enter. (The property-panel field was already fixed.)

## Internal
- **OSS publish now ships an accurate client-only `package-lock.json`.** The mirror previously had
  no lockfile, so Dependabot analysed loose manifest ranges and flagged a moderate transitive dep
  the main repo's resolved (patched) tree doesn't have. `publish-oss.sh` regenerates a lockfile for
  the stripped package.json; verified locally to audit clean (0 vulnerabilities).

## Breaking changes / migration
- None.
