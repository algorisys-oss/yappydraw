# 0.8.150 — Scene script + math plotting: manim-style animations from the API (2026-07-28)

## Highlights
- **`Yappy.scene`** — write an animation as a linear script (`play` / `wait`) instead of
  computing absolute keyframe times by hand. Each call starts where the last one ended,
  exactly like manim's `self.play()`.
- **`Yappy.plot`** — coordinate systems, function graphs and parametric curves.
  `sin(x)` goes from ~25 lines of manual arithmetic to a single call.
- Two bugs that made API-authored scenes look broken: they were capped at 4 seconds,
  and pressing Play never moved the playhead.

## Features

### Scene script (`Yappy.scene`)
A playhead over the existing composition engine — it writes ordinary keyframes, so the
Scene Timeline, Keyframes panel, scrubbing and video export all work on the result.

| Call | Purpose |
| --- | --- |
| `scene.play(id, to, opts)` | Animate one element; advance the playhead by `duration` (default 1s) |
| `scene.playAll(specs, opts)` | Several elements over the same span (manim `AnimationGroup`) |
| `scene.playLagged(ids, to, opts)` | One animation across many elements, offset by `lag` (manim `LaggedStart`) |
| `scene.wait(s)` | Hold — a track keeps its last value, so the gap reads as a hold |
| `scene.at()` / `scene.seek(s)` / `scene.reset()` | Playhead position / move it / clear everything |

```js
const dot = Yappy.createCircle(100, 300, 24, 24, { backgroundColor: '#ef4444' });
Yappy.scene.reset();
Yappy.scene.play(dot, { x: 600 }, { duration: 2 });      // 0s → 2s
Yappy.scene.wait(1);                                      // hold to 3s
Yappy.scene.play(dot, { opacity: 0 }, { duration: 0.5 }); // 3s → 3.5s
Yappy.toggleSceneTimeline(true);
Yappy.playScene(true);
```

Easing names are now **validated**: the default is `easeInOutCubic`, and an unrecognised
name (`'easeInOut'` is a common guess and is not real) logs one console warning listing
the valid names instead of silently falling back to linear.

### Math plotting (`Yappy.plot`)
`plot.axes()` returns an `AxesSpec` — plain data, no closures, so it survives
`JSON.stringify`, the embed bridge and a saved document.

```js
const ax = Yappy.plot.axes({ xMin: -4, xMax: 4, yMin: -2, yMax: 2 });
Yappy.plot.graph(ax, Math.sin, { strokeColor: '#2563eb' });
Yappy.plot.graph(ax, 'Math.exp(-x*x)');                    // string form (embed-safe)
Yappy.plot.parametric(ax, 'Math.cos(t)', 'Math.sin(t)');
Yappy.plot.point(ax, Math.PI / 2, 1);                      // coords → pixels (manim c2p)
Yappy.plot.coords(ax, 450, 250);                           // pixels → coords
```

Poles and domain errors (`1/x` at 0, `tan`'s asymptotes, `sqrt` of a negative) **split**
the curve into separate subpaths rather than drawing a spike from +∞ to −∞. A range with
nothing finite in it creates no element and returns `null`.

### Example
`examples/manim-gradient-descent.js` — a complete gradient-descent scene (axes, parabola,
12 descent steps, captions) you can paste into the DevTools console.

## Fixes
- **Scene Timeline was capped at 4s for API-authored scenes.** Duration was derived from
  animated stick-figure clips only, so a document with no figures — i.e. every scripted
  scene — was pinned to the 4s floor and anything longer silently never played. Composition
  keyframes now feed the same calculation. (#215)
- **Pressing Play never advanced the playhead** on a scene made purely of composition
  keyframes. The timeline advances from the global animation clock, but that clock only ran
  for presentation mode, flow animations, a playing stick-rig or a video export — none of
  which a scripted scene has. Scrubbing worked, which is why it looked like a render bug.
  (#216)
- **The onboarding tour could come back after being dismissed.** The "seen" flag was written
  only when the tour formally ended, so reloading or closing the tab mid-tour left it unset.
  It is now written when the tour auto-opens — a one-shot offer — with an in-memory fallback
  for private mode. Replaying from Help (?) is unaffected. (#217)

## Known limitations
- **No LaTeX.** Equations must be written in Unicode (`L = x²`); no fraction bars, integrals
  with limits, or matrices. This remains the largest gap for maths/ML explainers.
- No `ValueTracker`/updater equivalent (reactive derived geometry), vector fields, or 3D axes.
- Plotted curves are dense polylines, not fitted beziers; axes are drawn once, not live.

## Breaking changes / migration
None. Both namespaces are additive, and everything they produce is ordinary elements and
composition tracks.
