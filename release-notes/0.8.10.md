# 0.8.10 — Slingshot: an Angry-Birds sample game (2026-07-07)

## Highlights
- A full **Slingshot** game (Angry-Birds-style) ships as a one-click starter:
  **New Game → Slingshot**. Drag the bird back in the slingshot, release to fire,
  and smash the wooden blocks to pop the green pigs across two levels.

## Features
- **Slingshot sample** — a shapes-only, code-authored game showing the `game.*` API
  doing real gameplay: custom projectile physics (gravity, ground bounce with
  restitution + friction, circle-vs-box collisions), drag-to-aim with a live
  trajectory preview, destructible blocks, poppable pigs, score/HUD, and level flow
  (Space = next / retry, Esc = stop). Also available in the Code view's "Start from"
  list. Ported in spirit from a C#/raylib reference.
- New Game → Slingshot opens it as a code-authored game on a 1280×720 stage.
