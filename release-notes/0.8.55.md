# 0.8.55 — Image placeholder + replace; tunable Glow & Feather (2026-07-10)

## Features
- **Image tool — placeholder + replace flow.** Cancelling the Image-tool file picker now drops an
  empty **placeholder** frame (dashed box + image glyph + "Click to add image") so you can lay out
  first and add the picture later. Fill or swap any image **in place** (keeping its size/position)
  via the **property-panel "↻ Replace Image"** button, a **quick-toolbar** image button, or
  right-click **Add / Replace Image…**.
- **Tunable Glow & Feather.** The property panel now has a **GLOW & FEATHER** section with live
  sliders — **Feather** radius, and an **Outer Glow** toggle with **colour** + **radius**. (They
  were preset-only before.)

## Internal / docs
- Shared `utils/image-io.ts` (`openImagePicker` + `compressImageDataUrl`) and
  `utils/image-actions.ts` (`addImagePlaceholder` / `replaceImageOn`); empty image elements render a
  placeholder via `image-renderer.renderPlaceholder`.
- New planning + follow-up docs: `docs/dockable-panel-system-plan.md` (the deferred docker system,
  scoped) and `todo.md` notes for the Image-tool flow (done) and a known 3D-extrude-on-image limit
  (tilt/bevel/expand currently fills the front with a flat colour, not the bitmap).

## Breaking changes / migration
- None.
