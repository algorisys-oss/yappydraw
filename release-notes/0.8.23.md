# 0.8.23 — Record your stick-figure animation to video (2026-07-08)

## Highlights
- Animations can now **leave the canvas**: record a moving stick-figure scene to a
  **video** file you can share.

## Features
- **Record video** — with an animated figure selected, click **Record video** in the
  Stick Figures panel. It captures the live canvas — every figure, action sequence and
  walk-along-a-path exactly as it plays — and **Stop & save recording** downloads a
  `.webm`. A red indicator shows while recording.
- **API** — `Yappy.recordAnimation(seconds?, format?)` (auto-stops after `seconds`, or
  call `Yappy.stopRecording()`).

## Fixes
- None.

## Internal / tests / docs
- Reuses the existing canvas recorder (`recording-manager.ts` + `VideoRecorder` over
  `canvas.captureStream`); the `requestRecording` signal now also carries a **stop** so
  it can be driven programmatically and from the panel. Because it records the live
  canvas, procedurally-animated `stickRig` figures are captured with no export-specific
  code. Help doc gains an “Export your animation as a video” section; learnings updated.
- Note: static image/PDF/HTML export still captures a single frame (the exported HTML
  player has no rig runtime yet) — use video for motion.

## Breaking changes / migration
- None.
