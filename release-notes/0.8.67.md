# 0.8.67 — Non-destructive compound shapes (2026-07-11)

## Highlights
- **Compound Shapes.** Combine two or more shapes with a boolean (Unite / Minus Front /
  Intersect / Exclude) that **keeps the source shapes editable** — unlike Pathfinder,
  which flattens and discards them. Right-click ≥2 shapes → **Make Compound Shape ▸ …**.
  You can **change the operation** at any time (the result re-evaluates live),
  **Release** it back into the original shapes, or **Expand** to flatten. This is
  Illustrator's "Compound Shapes" for Yappy.

## Features
- **Non-destructive booleans** over ≥2 selected shapes:
  - **Make Compound Shape ▸ Unite / Minus Front / Intersect / Exclude** — one object that
    retains its sources.
  - Select a compound → **Compound Shape ▸ Op: Unite/Minus/Intersect/Exclude** to change
    the operation after the fact (re-evaluates the retained sources).
  - **Release** — get the original editable shapes back.
  - **Expand (flatten)** — commit to a plain vector path (drops the sources).
- The result renders, hit-tests, exports, and combines exactly like any vector path
  (fill + stroke, both draw styles, even-odd holes).
- **Scripting:** `Yappy.makeCompound(ids, op)`, `setCompoundOp(id, op)`,
  `releaseCompound(id)`, `expandCompound(id)`.

## Internal / tests / docs
- Reuses the existing boolean engine (`runBooleanOp` / `polyToPathSubpaths` /
  `buildPathFromPoly`) — a compound is a `path` element carrying `compoundOperands` +
  `compoundOp`, so no new element type / renderer / hit-test was needed. See
  `docs/compound-shapes-plan.md`.
- Touched: `types.ts` (`compoundOperands`, `compoundOp`), `store/app-store.ts`
  (`makeCompoundShape` / `setCompoundShapeOp` / `releaseCompoundShape` /
  `expandCompoundShape` + combine helper), `utils/context-menu-builder.ts` (menus), `api.ts`.
- Tests: `tests/compound-shapes.spec.ts` (e2e: retains sources; union vs intersect bbox;
  the compound draws pixels — union frame differs from an empty canvas; op-change
  re-renders; release → sources back; expand → plain path). Build + full suite green.

## Fixes
- A single-ring compound (e.g. Unite) rendered blank — it needed `pathAnchors` to fill,
  not a lone `pathSubpaths` entry (bug-fixes #151).

## Known limitations
- **In-place source editing isn't wired yet** — to edit a source shape, Release the
  compound, edit, then Make Compound again. (An isolation edit-mode is the planned next step.)
- Operand sync follows translation of the compound; rotating/scaling then changing the op
  re-evaluates from the un-rotated sources. Editing the result path's nodes directly
  desyncs it from the sources (as in Illustrator).
- Four Shape Modes only (Unite/Minus/Intersect/Exclude); exposed via right-click + API,
  no docked Pathfinder panel yet.

## Breaking changes / migration
- None. New fields are optional; existing documents are unaffected.
