# 0.8.215 — the menu speaks four languages, and D4 comes due (2026-08-21)

## Highlights
- Every **menu item** — all 68 labels from *New* through *Toggle Theme* — is translated into
  Español, Deutsch and 日本語. Ratchet **1565 → 1496**.
- Fixes a German inconsistency introduced one release ago, and stops short of the tooltips
  because finishing them means answering **decision D4**.

## Features
- 68 new `menu.*` keys across all four locales: the File / AI / Game / Panels / Toolbars trees,
  every panel name, and the view toggles. `AI` localises properly — `KI` in German, `IA` in
  Spanish — rather than being left as an English initialism.
- `menu.toggleTheme` is interpolated: `t('menu.toggleTheme', { theme: store.theme })`, so the
  current theme name renders inside the label in whatever language the label is in.

## Fixes
- **German had two conventions for modifier keys, and the new one was mine.** German localises
  `Ctrl` → `Strg` (six shipped instances across `statusBar` and the help dialog) while keeping
  `Shift` and `Alt` as-is. The `settings.autoRecordTitle` string added in v0.8.214 used
  `Ctrl+Shift+T`, making `de.ts` the only locale carrying both. Now `Strg+Shift+T`, matching the
  established precedent. Spanish and Japanese use `Ctrl` consistently and were never affected.

## Deliberately not done — decision D4
Only the 68 **labels** were extracted. The 19 menu **tooltips** were left alone because several
embed key names, and two of them have no precedent in any locale:

- `Delete (Del)` — is that `Löschen (Entf)` or `Löschen (Del)` in German?
- `Toggle Properties (Alt+Enter)` — `Alt+Eingabe` or `Alt+Enter`?

`Ctrl` and `Shift` are settled and can be followed mechanically. `Del` and `Enter` are not, and
picking one would silently answer D4 across a surface that keeps growing — the `hotkeys`
namespace alone is 189 strings. Both the plan (§6/D4) and the comment in `de.ts` say the same
thing: not a question to answer without a translator. Answering it unblocks the menu tooltips
and the whole `hotkeys` namespace at once.

## Internal / tests / docs
- Ratchet baseline tightened to 1496; `menu.tsx` 120 → 51. Phase 3 running total: **1628 → 1496**
  across two files fully extracted.
- Suite: 1085 tests across 74 files, including the 83 i18n tests asserting locale parity; tsc clean.

## Known limitation
As with v0.8.214, these translations are **machine-grade and unreviewed by a native speaker**
(§5 step 2, still not done for any locale). Menu labels are short, which limits how wrong they
can be, but German compounds — `Anzeigezustände`, `Einstellungsebene hinzufügen` — are exactly
the kind of thing that overflows a menu row.
