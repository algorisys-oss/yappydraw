# 0.8.173 — Documentation catches up with 0.8.171/0.8.172 (2026-08-03)

Docs-only, plus one new spec. No behaviour changes.

## Docs
- **Onion skinning now says ghosts can't be selected.** The section already covered "paused only"
  and "never exported" but not the selection rule — which was the whole point of the 0.8.171 fix.
  A user who remembered the old behaviour had nothing confirming the new one is deliberate.
- **The hotkey dialog's Node tool entries were stale.** They listed `N`, `Ctrl+A`, `Del` and
  `Alt+Click` but not the gestures added in 0.8.172: click a shape to switch, Shift-click to add,
  click empty space twice to let go, drag to pick shapes when nothing is loaded, and how to leave.
- **The node-editing API was undocumented.** All eight methods have doc comments in `api.ts` and
  none appeared in the web docs, so the Node tool read as UI-only when it is fully scriptable.
  Vector Paths gains a **Node editing** section: the `NodeRef` (`{ id, sub, i }`) shape, a worked
  snippet, and eight API-table rows — `toggleNodeTool`, `setNodeSelection`, `allNodesOfSelection`,
  `getPathNodes`, `getNodeHandles`, `moveSelectedNodes`, `setSelectedNodesKind`,
  `deleteSelectedNodes`.
- Search keywords extended so the scripting names and "switch shape while editing" find the page.

## Internal / tests
- New `tests/node-api-doc-accuracy.spec.ts` runs the published snippet **verbatim** against the
  live API and checks the documented shapes and effects: every method exists, `NodeRef` really is
  `{ id, sub, i }`, `setSelectedNodesKind('smooth')` applies to all anchors,
  `moveSelectedNodes(0, -20)` moves exactly −20, `getNodeHandles()` returns `{x, y, ax, ay}`, and
  `deleteSelectedNodes()` removes exactly the selected anchor. A renamed or removed method now
  fails here rather than in a user's console.

## Breaking changes / migration
- None.
