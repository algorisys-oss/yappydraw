🎨 Image Pixel Effects Demo

Click any button below to see different pixel-by-pixel reveal effects!

Current effect: None

Integration Instructions

To use this demo with Yappy:

  1. Build and include the Yappy bundle in this HTML file
  2. Initialize Yappy with the canvas: Yappy.init({ canvas: document.getElementById('yappy-canvas') })
  3. Create an image element: const img = Yappy.addImage({ dataURL: '...', x: 200, y: 150, width: 400, height: 300 })
  4. The buttons will then trigger real pixel effects!

Example Code:

// Create image
const img = Yappy.addImage({
    x: 200,
    y: 150,
    width: 400,
    height: 300,
    dataURL: 'data:image/png;base64,...'
});

// Apply glitch effect
Yappy.pixelEffectPresets.glitch(img.id, () => {
    console.log('Glitch complete!');
});

// Or custom configuration
Yappy.animatePixelEffect(img.id, {
    effectType: 'wave-center',
    duration: 3000,
    easing: 'easeOutCubic',
    params: { waveCount: 3 }
});
