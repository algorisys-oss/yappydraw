# Release Notes - v1.8.1

**Release Date:** February 9, 2026

## Overview

Patch release with two bug fixes: text tool now correctly switches back to selection on first click-away, and bold/italic toggles are disabled for fonts that don't support those variants.

## Bug Fixes

- **Text tool click-away**: Fixed text tool not switching to selection tool on first click outside. The browser fires `pointerdown` on the canvas before `blur` on the textarea, so `commitText()` cleared `editingId` before the blur handler could switch the tool. Now the canvas pointer-down path also switches to selection.
- **Font bold/italic support**: Disabled Bold and Italic toggles (in both the property panel and quick toolbar) for fonts that lack those variants:
  - **Handlee** (Hand-drawn): no bold, no italic
  - **Permanent Marker** (Marker): no bold, no italic
  - **Caveat**: no italic (bold is supported)

## Upgrade Notes

This release is backward compatible. Elements that previously had bold/italic applied with unsupported fonts will retain their values but the toggles will appear disabled.
