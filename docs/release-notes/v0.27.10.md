# Release Notes - v0.27.10

**Release Date:** May 6, 2026

## Fixed

### Apple Pencil hover triggered drawing

Apple Pencil 2 / Pro fire `pointermove` events with `pointerType: 'pen'` and `pressure: 0` when hovering near the screen. v0.27.8's pointermove recovery branch synthesized a `drawOnDown` from any pen pointermove without an active stroke (when I dropped the `pressure > 0` check in a follow-up iteration), which translated hover into stroke starts.

Removed the pointermove recovery. v0.27.9's TouchEvent path is the load-bearing fix for missed-pointerdown; the pointermove synthesizer was a redundant safety net that became hover-active once the pressure check was loosened.

## Key Files Modified

- `frontend/src/components/canvas.tsx` — removed pointermove `drawOnDown` recovery
- `package.json` — version bump to 0.27.10
