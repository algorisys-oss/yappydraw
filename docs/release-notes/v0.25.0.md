# Release Notes - v0.25.0

**Release Date:** February 28, 2026

## Overview

This release focuses on AI presentation enhancements: 2-stage agentic generation (Quick/Deep modes), rich slide visuals with gradients and shapes, auto-assigned slide transitions and element animations, token usage tracking, and UX improvements including a styled unsaved changes dialog.

## New Features

### AI Presentation Generator
- **Full AI slide generator** — Enter a topic prompt to generate a complete slide deck with styled elements, transitions, and entrance animations.
- **2-stage agentic generation (Deep mode)** — Content Agent researches and writes substantive content, then Visual Agent maps it to optimal slide types and palettes. Quick mode remains available for fast single-shot generation.
- **Rich slide visuals** — Gradients, drop shadows, shaped icons, and 4 new layout types: `card-grid`, `metrics`, `timeline`, `comparison`, plus `two-column`, `quote`, `section-break`, and `closing`.
- **Up to 50 slides** — Slide count selector expanded from 20 to 50 with dynamic token budgets.
- **Auto-assigned slide transitions** — Each slide gets an appropriate transition (fade, slide-left, zoom-in) based on its type and position.
- **Element entrance animations** — Slide elements are classified by role (title, subtitle, content-card, metric-value, timeline-dot, etc.) and assigned staggered entrance animations (slideInDown, fadeIn, zoomIn, slideInLeft).
- **Token usage display** — After AI generation (both slides and diagrams), shows total token count with prompt/completion breakdown.

### Template Library & Markdown Import
- **Presentation template library** — Built-in templates selectable from the menu.
- **Markdown slide import** — Paste markdown with headings and `---` separators to create slide decks via the DSL import dialog.

### UX Improvements
- **Styled unsaved changes dialog** — Replaced native `confirm()` with a themed modal dialog (Cancel, Discard, Save & Continue) when creating new documents or loading templates with unsaved changes.
- **Save & Continue** opens the standard export/save dialog rather than silently saving to workspace.

## Bug Fixes

### 70. Slide element strokes invisible despite strokeColor being set
- **Root cause:** All element factory helpers (`rectEl`, `gradientRectEl`, `cardEl`, `shapeEl`) hardcoded `strokeWidth: 0`, so even when `strokeColor` was explicitly passed (e.g., on card-grid icons), no stroke rendered.
- **Fix:** Helpers now set `strokeWidth: 1` when a non-transparent `strokeColor` is provided.
- **File:** `frontend/src/utils/slide-element-factory.ts`

### 69. Unsaved changes dialog Save & Continue button turns white on hover
- **Root cause:** Global `button:hover { background-color: var(--btn-hover) }` in `index.css` overrides the save button's blue background.
- **Fix:** Explicitly set `background: var(--primary-color)` on `.unsaved-btn-save:hover` and `:active` states.
- **File:** `frontend/src/components/unsaved-changes-dialog.css`

### Text data loss when animations force-stopped
- Fixed text element content being lost when presentation animations are interrupted mid-play.
