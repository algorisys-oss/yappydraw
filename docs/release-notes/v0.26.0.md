# Release Notes - v0.26.0

**Release Date:** March 22, 2026

## Overview

This release introduces comprehensive **Bulk Editing & Selection** capabilities — multi-select property editing with mixed value indicators, Select by Type, and Select by Same Property. These features make it easy to manage visual consistency across large diagrams.

## New Features

### Multi-Select Property Editing (Phase 1)

When multiple shapes are selected, the property panel now shows only properties **common to all selected types** and intelligently handles differing values.

- **Common property filtering:** Changed from union to intersection — only properties applicable to ALL selected element types are shown
- **Mixed value detection:** Compares values across all selected elements; when they differ, a "Mixed" indicator appears
- **Mixed indicators per control type:**
  - Color: "Mixed" badge above the picker
  - Slider: "(Mixed)" label, empty number input with dash placeholder
  - Select: Disabled "(Mixed)" option at top of dropdown
  - Toggle: Indeterminate checkbox with "(Mixed)" label
  - Input/Textarea: Empty with "(Mixed)" placeholder
  - Number: Empty with dash placeholder
- **Bulk apply:** Changing any property sets the new value on ALL selected elements
- **Selection summary:** Header shows "Selection (N)" with type breakdown (e.g., "3 rectangle, 2 arrow")
- **Delete for multi-select:** Delete button available in panel header for multi-selection
- **dependsOn for multi:** Dependent properties evaluate correctly across selected elements

### Select by Type (Phase 2)

A new **"Select by Type"** submenu in the right-click context menu for quickly selecting all elements of a certain category.

- **Category shortcuts:** All Lines & Arrows, All Text & Notes, All Images, All Videos, All Shapes
- **Per-type entries:** Each unique type on the canvas listed with count (e.g., "rectangle (5)")
- **"All Same Type":** When elements are already selected, expands selection to all elements of matching type(s)
- **Available everywhere:** Both canvas (no selection) and element context menus

### Select by Same Property (Phase 3)

Right-click a single element to access **"Select by Same Property"** — finds all elements sharing a specific property value.

- **10 matchable properties:** Fill Color, Stroke Color, Text Color, Stroke Width, Font Size, Font Family, Opacity, Fill Style, Stroke Style, Drawing Style
- **Count indicators:** Each entry shows how many elements match (e.g., "Same Fill Color: #e03131 (7)")
- **Smart filtering:** Only shows properties that have >1 matching element

## Typical Workflow

1. **Right-click** → "Select by Type" → "All Lines & Arrows" (or "Select by Same Property" → "Same Fill Color")
2. **Property panel** shows common properties — "Mixed" indicators highlight differences
3. **Change a property** (e.g., stroke color) → applies to all selected elements at once
