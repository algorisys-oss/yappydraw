# Release Notes - v0.25.2

**Release Date:** March 1, 2026

## Overview

Patch release with default shape roundness, slide navigation UX fixes, and viewport stability improvements after exiting presentation mode.

## New Features

### Default Shape Roundness
- **borderRadius default set to 9** — Newly created shapes (rectangles, diamonds, capsules, cards, buttons, badges, tooltips, and other applicable shapes) now have a subtle rounded corner by default instead of sharp edges. Adjustable via the Roundness slider in the property panel.

## Bug Fixes

### 71. Slide content invisible after exiting presentation mode
- **Observation:** After exiting slideshow presentation and returning to design mode, clicking on slides in the navigator showed a blank canvas — the slide content existed but was out of the viewport.
- **Root cause:** When exiting presentation mode, `appMode` switches to `'design'` before `exitFullscreen()` fires. The `fullscreenchange` resize handler only called `zoomToFitSlide()` when `appMode === 'presentation'`, so the viewport was never re-fitted to the smaller design-mode window. Additionally, clicking the already-active slide in the navigator early-returned without correcting the viewport.
- **Fix:** (1) Changed `handleResize` to zoom-to-fit for all slide documents (`store.docType === 'slides'`) regardless of app mode. (2) When clicking the already-active slide, call `zoomToFitSlide()` before returning to re-center the viewport.
- **Files:** `frontend/src/components/canvas.tsx`, `frontend/src/store/app-store.ts`

### Redundant slide number toast on navigation
- Removed `showToast()` call that displayed the current slide number on every slide navigation. The slide navigator already shows the active slide, making the toast unnecessary.
- **File:** `frontend/src/store/app-store.ts`

## Key Files Modified
- `frontend/src/store/app-store.ts` — Default borderRadius, slide viewport fix, removed toast
- `frontend/src/config/properties.ts` — Updated borderRadius defaultValue from 0 to 9
- `frontend/src/components/canvas.tsx` — Resize handler zoom-to-fit for all slide modes
- `package.json` — Version bump to 0.25.2

## Upgrade Notes

This release is backward compatible. No data migration required. Existing shapes retain their current borderRadius; only newly created shapes use the new default of 9.
