# Release Notes - v0.25.3

**Release Date:** March 2, 2026

## Overview

Performance and UX patch — eliminates idle CPU waste from the animation engine, fixes flow animation reverse direction, and reorders toolbar hotkeys to match the visual layout with new hotkey badge indicators.

## New Features

### Toolbar Hotkey Badges
- Small numeric indicators now appear on toolbar buttons showing the keyboard shortcut at a glance.
- Numeric shortcuts (1-0) have been reordered to match the toolbar's left-to-right visual order:
  - **1** Selection, **2** Rectangle, **3** Diamond, **4** Ellipse, **5** Arrow, **6** Line, **7** Pen, **8** Text, **9** Image, **0** Eraser
- Help dialog, command registry, and all tool group dropdown labels updated to match.

### Auto-grow Text Elements
- Text elements now automatically expand their height as content grows during typing.

## Performance

### Idle CPU Usage Reduction
- **Animation engine**: rAF loop now stops when only paused/idle animations remain (previously kept running if any animation existed in the map). SolidJS time signals (`effectiveTime`, `globalTime`) are only updated when there are running animations or the force ticker is on.
- **Ink overlay cleanup**: Converted always-on 500ms `setInterval` to a demand-based interval that starts when ink elements are created and auto-stops when none remain.
- **Cursor position**: Store writes coalesced via `requestAnimationFrame` — at most one update per frame instead of 60+/sec during mouse movement.
- **Recording manager**: Thumbnail capture effect now tracks `elements.length` instead of the entire elements proxy, so it only fires on add/remove rather than every deep property change.

## Bug Fixes

### 72. High CPU usage on idle canvas
- **Observation:** Chrome/Edge tabs showed elevated CPU with no active animations or interaction.
- **Root cause:** Animation engine loop condition `this.animations.size > 0` kept the rAF loop alive for paused animations, unconditionally updating SolidJS signals that triggered 60fps canvas redraws.
- **Fix:** Changed loop condition to `hasRunningAnimations || this.forceTicker` and gated signal updates behind the same check.
- **Files:** `animation-engine.ts`, `app-store.ts`, `canvas.tsx`, `minor-handlers.ts`, `recording-manager.ts`

### 73. Flow animation reverse shows solid dark line
- **Observation:** Toggling "Reverse" on a flow animation produced a solid dark line instead of dashes moving backwards.
- **Root cause:** JavaScript `%` returns negative values for negative operands, causing the modulo check to pass for every position.
- **Fix:** Used positive modulo `((x % n) + n) % n` in connector-renderer (3 sites) and path-renderer (1 site).
- **Files:** `connector-renderer.ts`, `path-renderer.ts`

### Line/connector text editing improvements
- Improved text editing and auto-highlight behavior on lines and connectors.

### Toolbar organization
- Moved Lasso and Crop tools to the end of the toolbar for better grouping.
