# Release Notes - v1.6.0

**Release Date:** February 5, 2026

## Overview

This release focuses on enhanced 3D shape capabilities, particularly the Open Box shape with click-to-open animations, and introduces presets for quick styling: 45 gradient presets and 13 openBox style presets. Major improvements to gradient rendering ensure proper per-face shading on all 3D shapes.

## What's New

### Open Box Enhancements

The Open Box shape now supports interactive click-to-open animations in presentation mode:

- **Click-to-open animation**: Click on an openBox in presentation mode to animate the lid opening/closing
- **Element reveal**: Link any element to reveal with customizable animation when the box opens
- **Reveal animations**: Choose from fadeIn, slideUp, scaleUp, or pop effects
- **Restore after reveal**: Automatically close the box and hide the reveal element after animation
- **Configurable duration**: Set custom animation duration for the open/close animation

### Lid Style Options

Multiple lid configurations for different visual effects:

| Lid Style | Description |
|-----------|-------------|
| **Single** | One lid hinged on selected edge (back/front/left/right) |
| **Split** | Two half-lids opening from center outward |
| **Double** | Two lids on opposite sides opening simultaneously |
| **Quad** | Four corner flaps opening outward |
| **Flaps** | Two flaps that meet edge-to-edge at center when closed |

### Additional Open Box Features

- **Text editing**: Double-click to edit text directly on the openBox shape
- **Lid hinge option**: Show/hide the hinge connector line on the lid
- **Separate lid colors**: Independent fill and stroke colors for the lid
- **Backface stroke color**: Custom stroke color for back-facing edges

| Category | Presets |
|----------|---------|
| **Presentation** | 🎭 Theatre Reveal, ❓ Mystery Box, 🎩 Magic Box |
| **Product** | 📦 Shopping Box, 📱 Unboxing, 💎 Premium Package |

### 3D Shape Gradient Improvements

- **Per-face gradient shading**: Gradients now render correctly on each face of 3D shapes with proper lighting simulation
- **Automatic shade calculation**: Each face automatically darkens/lightens the gradient based on its orientation
- **Sketch mode support**: Gradients render properly in both architectural and sketch (RoughJS) modes

### Tool Locking

- **Double-click to lock**: Double-click any tool to keep it active after drawing (no auto-switch back to selection)

## Bug Fixes

- **Gradient fills for 3D shapes**: Fixed gradient not filling correctly on solidBlock, cylinder, isometricCube, perspectiveBlock, and openBox
- **Sketch mode hachure artifacts**: Fixed gradient fills showing unwanted hachure patterns in sketch mode
- **Reveal element visibility**: Fixed reveal elements not hiding when entering presentation mode or switching slides
- **Presentation mode reset**: Fixed openBox elements remaining open after exiting presentation mode (ESC)
- **Perspective block rotation**: Fixed rotation handle position for perspectiveBlock shape
- **3D shape depth scaling**: Depth now scales proportionally with shape size

## Upgrade Notes

This release is backward compatible. Existing 3D shapes will automatically benefit from improved gradient rendering. OpenBox shapes will need `enableClickToOpen` enabled in the property panel to use the new click-to-open feature.
