# Release Notes - v0.25.8

**Release Date:** March 17, 2026

## Overview

This release extends the AI Drawing Deep Mode to work with image/sketch uploads via a 2-stage vision pipeline, adds automatic text-fitted node sizing across all AI-generated diagrams, and introduces Brainstorm Mode — a compact toolbar for quick ideation.

## New Features

### Image Deep Mode (2-stage vision pipeline)

Complex diagrams like risk mind maps, architecture charts, and multi-level hierarchies are difficult for a single vision call to reproduce accurately — it must simultaneously OCR text, identify shapes/colors, understand hierarchy, map connections, and produce valid DSL.

Image Deep Mode splits this into two focused stages:

- **Stage 1 — Vision Analyst:** Receives the image and a vision-specific research prompt. Methodically scans the image to extract every node, text label, color, hierarchy level, and connection. Outputs structured research JSON (same schema as text Deep Mode). Temperature 0.5 for thorough exploration.
- **Stage 2 — Diagram Composer:** Receives the research JSON and converts it into a visually rich YappyDraw diagram with proper layout, color-coding by group, sizing by importance, and edge styling by connection type. Reuses the existing text Deep Mode composer — no duplication.

**Usage:** Upload an image in the AI Drawing dialog, check "Deep Mode", and generate. Progress updates show "Analyzing image deeply..." then "Composing detailed diagram...".

### Auto-sizing nodes to fit text

Previously, AI-generated nodes used fixed default dimensions (e.g., 150x80 for rectangles) regardless of label length, causing text to overflow or look cramped in dense diagrams.

Now, a pre-layout pass measures each node's label text using an offscreen canvas and stamps text-fitted dimensions before the layout engine runs. This ensures:
- Shapes expand to contain their full label text
- The layout engine spaces nodes correctly based on actual sizes
- Works across all modes: quick, deep, sketch, image deep
- Falls back to a character-count heuristic if canvas is unavailable

### Brainstorm Mode (Compact Toolbar)

The full toolbar has 16 tool groups with dropdowns — powerful but overwhelming for quick brainstorming. Brainstorm Mode reduces it to 10 flat buttons: Selection, Pen, Line, Arrow, Rectangle, Diamond, Ellipse, Text, Image, Eraser.

- **Toggle:** Click the collapse/expand icon (first button after the drag handle)
- **Default:** Brainstorm mode is on by default for new users
- **Persistence:** Preference saved in `localStorage` — survives page reloads
- **Hotkeys:** All keyboard shortcuts work in both modes

## Upgrade Notes

This release is backward compatible. No data migration required. The auto-sizing only applies to newly generated diagrams — existing canvas elements are unaffected.
