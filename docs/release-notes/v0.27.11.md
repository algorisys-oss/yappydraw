# Release Notes - v0.27.11

**Release Date:** May 6, 2026

## Fixed

### Palm + pen multi-touch dropped strokes on iPad

v0.27.9's `handleTouchStart` bailed early when `e.touches.length !== 1` — which was true whenever the user's palm rested on the canvas alongside the Apple Pencil. The TouchEvent path then deferred to PointerEvents, which is the broken path on iPad.

Now picks the `touchType: 'stylus'` Touch from `changedTouches` (Apple Pencil reports `'stylus'`, finger reports `'direct'`), tracks it by `identifier` for the rest of the stroke, and ignores moves/ends for any other touch (palm shifting, palm lift). The reference demo's pattern, made multi-touch-safe.

### Stroke draw cadence on TouchEvent path

Match the pointer-path RAF schedule: call `requestAnimationFrame(draw)` on every `touchmove` so the visible stroke keeps pace with the pen tip. Multiple RAFs in the same frame coalesce.

## Key Files Modified

- `frontend/src/components/canvas.tsx` — `pickStylusTouch` / `findTouchById` helpers; `activeTouchIdentifier` tracked across the stroke; per-event RAF draw
- `package.json` — version bump to 0.27.11
