# Release Notes - v0.24.0

**Release Date:** February 26, 2026

## Overview

This release completes the full 8-phase WASM adoption plan (Phases 0-7) via AssemblyScript, accelerating geometry math, hit testing, A* routing, object snapping, shape path generation, sketch rendering, and batch viewport culling. All phases are independently shippable with automatic JS fallback — WASM loads async and enables progressively.

## New Features

### WASM Acceleration (Phases 0-7)

- **Phase 0 — Foundation:** WASM build pipeline via AssemblyScript, async loader with verification, per-feature runtime flags, shared memory pool, Vite plugin with HMR support.
- **Phase 1 — Geometry Core:** 11 math functions ported (ray casting, bezier evaluation, point-in-ellipse, distance-to-segment, rotation, polyline tests). Foundation for all subsequent phases.
- **Phase 2 — Hit Testing:** Batch broad-phase AABB testing in a single WASM call. Shape-specific narrow phase for diamond, ellipse, bbox shapes. Complex shapes (bezier, polyline) fall back to JS. **3-5x speedup with 200+ elements.**
- **Phase 3 — A* Path Routing:** Obstacle-avoiding orthogonal connector routing with min-heap, turn penalties, and generation-based lazy reset. **5-10x speedup for complex connector routing.**
- **Phase 4 — Object Snapping:** Two-pass snapping algorithm (find best deltas, collect guides) over O(n^2) element comparisons. **2-4x speedup during drag with 200+ elements.**
- **Phase 5 — Shape Path Generation:** 23 polygon-based shape types computed in WASM (triangle, diamond, hexagon, star, burst, arrows, UML signals, brackets, etc.). Unsupported shapes fall back to JS.
- **Phase 6 — Sketch Engine:** RoughJS generator replacement with WASM-based hand-drawn path generation. Ports Park-Miller PRNG, jittered double-line, hachure/cross-hatch/zigzag fills, and ellipse generation. Outputs RoughJS-compatible Drawable objects. **2-3x faster sketch rendering.**
- **Phase 7 — Batch Rendering:** Batch viewport culling in a single WASM call, CanvasRenderer instance reuse per frame, and batch shape path pre-computation. Viewport check reordered before expensive hierarchy filters for additional speedup.

### Runtime Feature Control

- URL param: `?wasm=off | ?wasm=on | ?wasm=geometry,hitTesting`
- localStorage: `yappy-wasm=off` (master kill switch)
- localStorage: `yappy-wasm-disable=sketchEngine,batchRenderer` (per-feature disable)

## Upgrade Notes

This release is backward compatible. WASM loads asynchronously and all features default to JS fallback until WASM is ready. No data migration required. To disable WASM entirely, use `?wasm=off` or `localStorage.setItem('yappy-wasm', 'off')`.
