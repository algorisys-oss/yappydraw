# Release Notes - v0.27.3

**Release Date:** May 6, 2026

## Overview

Hotfix for iPad: writing quickly with Apple Pencil could pop iOS's native "Copy / Look Up / Translate" text-selection menu, breaking the user's flow.

## Fix

`-webkit-touch-callout: none` and `-webkit-user-select: none` were already set inline on the `<canvas>` element in v0.27.1, but iPadOS Safari can still trigger its selection callout when fast Pencil contact briefly lands on the wrapping div or surrounding UI chrome — those elements were inheriting the page defaults, not the canvas inline rules.

Moved the suppression up to `html, body` so it inherits across the whole app:

```css
html, body {
  -webkit-touch-callout: none;
  -webkit-user-select: none;
  -webkit-tap-highlight-color: transparent;
  user-select: none;
  overscroll-behavior: none;
}

/* Editable surfaces still need text selection. */
input, textarea, [contenteditable="true"], [contenteditable=""] {
  -webkit-user-select: text;
  user-select: text;
  -webkit-touch-callout: default;
}
```

Notes:
- `touch-action` is **not** set on `html, body` — that would block scrolling inside property/layer/slide-navigator panels on touch. Only the canvas surface sets `touch-action: none` inline.
- `overscroll-behavior: none` blocks the iPad rubber-band/bounce that can also be misread as a gesture during a stroke.
- `-webkit-tap-highlight-color: transparent` removes iOS's grey tap flash on toolbar buttons.

## Key Files Modified

- `frontend/src/index.css` — global `html, body` callout/selection suppression with editable-element overrides
- `package.json` — version bump to 0.27.3
