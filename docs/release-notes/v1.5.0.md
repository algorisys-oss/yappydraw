# Release Notes - v1.5.0

**Release Date:** February 4, 2026

## Overview

This release introduces Excalidraw-like text element behavior, providing a more intuitive and flexible text editing experience. Text elements now support drag-to-create, automatic word wrapping, and improved resize behavior.

## What's New

### Excalidraw-like Text Elements

Text elements have been completely revamped to behave like Excalidraw:

- **Drag to create**: Click and drag to set the initial width and height of a text box
- **Click to create**: Single click creates a default 200px wide text box
- **Word wrapping**: Text automatically wraps within the fixed width
- **Auto-expanding height**: Height grows based on wrapped content
- **Constant font size**: Font size stays fixed during resize operations

### Improved Text Resize Behavior

| Handle | Behavior |
|--------|----------|
| Side handles (left/right) | Width changes, text re-wraps, height auto-adjusts |
| Top/Bottom handles | Height changes freely, text centers vertically |
| Corner handles | Free resize of both dimensions |

### Visual Improvements

- **Background color support**: Text elements can now have a background fill color
- **Creation preview**: Dashed border shows the text box bounds while dragging to create
- **Centered text input**: The text editing overlay is now centered both vertically and horizontally

## Bug Fixes

- **Resize handle orientation**: Fixed issue where resize handlers were not correctly oriented when a shape was rotated

## Technical Changes

### Files Modified
- `src/components/canvas.tsx` - Text tool event routing
- `src/components/text-editing-overlay.tsx` - Centered text input
- `src/shapes/renderers/text-renderer.ts` - Word wrapping and background color
- `src/utils/text-utils.ts` - New `measureWrappedTextHeight` utility
- `src/utils/tool-handlers/minor-handlers.ts` - Drag-to-create handlers
- `src/utils/tool-handlers/selection-handler.ts` - Text-specific resize behavior
- `src/utils/tool-handlers/text-editing-handler.ts` - Preserve width on commit

## Upgrade Notes

This release is backward compatible. Existing text elements will automatically use the new rendering behavior.
