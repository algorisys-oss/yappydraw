# Release Notes - v1.8.2

**Release Date:** February 9, 2026

## Overview

Patch release fixing copy-paste positioning (pasted shapes now maintain relative positions) and migrating all element/layer/slide/state ID generation to human-readable sequential IDs (`rect-1`, `text-2`, etc.).

## Bug Fixes

- **Copy-paste relative positioning**: Pasting multiple shapes (Ctrl+C, Ctrl+V) no longer stacks them at a single point. Three issues were fixed:
  1. Copy serialization now unwraps SolidJS store proxies (`JSON.parse(JSON.stringify(...))`) before writing to clipboard
  2. Paste handler uses already-parsed clipboard data directly instead of unreliable async clipboard re-read
  3. Bounding box calculation guards against undefined width/height with `|| 0` fallback
- **Duplicate/paste ID generation**: Duplicate (Ctrl+D) and paste now generate human-readable sequential IDs (e.g. `rect-3`) instead of GUIDs. A new `batchIds` parameter prevents duplicate IDs when creating multiple elements in a single operation.

## Changes

- **Human-readable ID migration**: All element, layer, slide, and state ID generation migrated from `crypto.randomUUID()` to `generateId()` with sequential naming pattern (`{type}-{n}`). The only exception is `slide-types.ts` which retains `crypto.randomUUID()` to avoid a circular dependency at initialization time.
- **`generateId()` enhancements**:
  - Accepts optional `batchIds: Set<string>` parameter for multi-element operations
  - Scans all store collections (elements, layers, slides, states) for prefix uniqueness

## Upgrade Notes

This release is backward compatible. Existing elements with GUID-style IDs will continue to work. New elements will receive human-readable sequential IDs.
