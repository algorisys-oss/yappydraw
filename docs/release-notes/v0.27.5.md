# Release Notes - v0.27.5

**Release Date:** May 6, 2026

## Overview

iPad parity for the per-tool defaults workflow. On desktop you can right-click any tool button to open its defaults; on iPad you previously had no shortcut at all. v0.27.5 adds two native iPad gestures — **long-press** and **double-tap** — that open the same panel.

## What Changed

Every toolbar button (simple tools and tool groups) now responds to three gestures, all opening the property panel for that tool:

| Gesture            | Where it works                | Notes                                  |
| ------------------ | ----------------------------- | -------------------------------------- |
| Right-click        | Desktop (mouse)               | Already worked.                        |
| **Long-press**     | iPad / any touch device       | New. ~500 ms hold opens the panel.     |
| **Double-tap**     | iPad / any touch device       | New. Two quick taps opens the panel.   |

The property panel auto-shows that tool's defaults — there's no element selected, so the panel is in "Defaults" mode. Anything you set there is saved to `store.toolStyles[tool]` and restored next time you pick that tool.

## Why Both Gestures?

Long-press feels native on iPad (it's the system gesture for "secondary action"), but it's slow — you wait ~500 ms. Double-tap is faster but less obvious. Wiring both adds zero ambiguity (they go to the same handler) and gives users their preference.

## Why Not Filter Touch on Toolbar?

v0.27.1 added `if (e.button !== 2) return` to every toolbar `handleRightClick` to suppress iOS's contextmenu on long-press, fixing a bug where palm rest on the **canvas** popped the panel. That filter was overcautious for **toolbar buttons** — palm doesn't rest on toolbar buttons, so iPadOS's long-press contextmenu there is intentional, not noise. Removing the filter on toolbar `handleRightClick` (only) restores iPad's native gesture without bringing back the canvas palm issue.

The canvas `onContextMenu` handler still filters — palm rest on the drawing surface remains silent.
