# Release Notes - v0.25.7

**Release Date:** March 6, 2026

## Overview

Adds Deep Mode to AI Drawing — a 2-stage agentic pipeline that produces significantly richer and more detailed technical diagrams compared to the default single-shot generation.

## New Features

### AI Drawing Deep Mode

The AI Drawing dialog now has a **Deep Mode** checkbox (with a BrainCircuit icon) that enables a 2-stage generation pipeline:

**Stage 1 — Research Agent:**
- Deeply analyzes the topic's architecture, components, sub-systems, data flows, and internal mechanisms
- Produces a structured JSON breakdown with 20-30+ components grouped into logical layers
- Includes annotations for key insights and non-obvious behaviors
- Covers runtime internals (memory regions, thread models, I/O handling, queues, scheduling algorithms) and architecture topics (services, protocols, caching, scaling)

**Stage 2 — Diagram Composer:**
- Converts the research output into a visually rich YappyDraw diagram
- Color-codes groups/layers for visual distinction
- Sizes nodes by importance (primary → large, tertiary → small)
- Maps connection types to appropriate edge styles (solid, dashed, dotted)
- Expands sub-components as smaller connected nodes
- Adds entrance animations to primary components

**Result:** Diagrams with 20-50 nodes vs the typical 5-15 from quick mode, with deeper technical accuracy.

**Ideal for:**
- Node.js event loop internals
- Elixir BEAM VM architecture
- Kubernetes cluster architecture
- Database engine internals
- Any complex technical system

### Progress Feedback
During deep generation, the dialog shows real-time stage progress:
- "Researching topic deeply..." (Stage 1)
- "Composing detailed diagram..." (Stage 2)
